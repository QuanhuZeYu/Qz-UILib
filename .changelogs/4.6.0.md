# Qz-UILib 4.6.0

## 本次更新

- 新增递归结构化列表 schema 与默认 Scene 编辑器，支持稳定 identity、嵌套校验、未知成员无损往返及字段默认恢复。
- 新增通用被动 HUD API、TextHud/CompactHud 预制、四角稳定堆叠、安全区与显式占位扩展。
- 新增可扩展搜索选择器与领域值展示接口，支持 ALL/SELECTED 两态、多选、未枚举 key 保留、键盘导航和视口内滚动；显式 LIST_MEMBERS 模式提供摘要 + Manage、默认折叠 raw 高级入口、稳定 raw 列表项编辑/追加与两步确认删除，重复 candidate 不自动合并。
- 收紧配置草稿所有权、磁盘变更检测、重载恢复、保存校验及批次回灌的事务边界。
- 完善 Scene 图片绘制管线、中文 IME 文本桥、字体排序拖拽与主线程批次派发。
- 修复结构化列表长标识遮挡、窄宽布局裁剪、错误路径映射及非空默认值恢复。

## 兼容性说明

- 对比基线 4.5.2；现有简单配置字段及既有 ConfigUI 入口保持兼容。
- SearchPicker、ValueEditorProvider 与 ConfigUI editor registry 仍为 beta API，不属于 LTS 稳定承诺。
- LIST_MEMBERS 确认只替换目标项或追加，Picker 删除需两步确认，raw 仍可高级修正/删除；malformed/duplicate 仅通用提示、不泄露 raw、不合并，旧 SINGLE_VALUE/Codec 路径保持兼容。
- 配置 canonical、YAML 与网络语义不由 UILib 自动改写。
- HUD 首版不提供输入或拖拽；断线或世界卸载后调用方需在新世界生命周期重新注册。
