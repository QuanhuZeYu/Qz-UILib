# Qz-UILib 4.5.3-beta-2

## 更新

- 完成正式结构化列表能力，表达 `List<Object{id:String, members:List<String>}>`，并保持 config core 与 scene 互相隔离。
- 新增 `ValueKind` / `ValueSpec` / `Values` 递归 schema DSL 与 `STRUCTURED_LIST`，以及 `SectionSpec.Builder.structuredList`。
- 默认 renderer 支持 keyed 增删、上移 / 下移、标量与 `List<String>` member 编辑、reset 与嵌套错误映射；`withIdentityMember` 可声明可靠行身份。
- unknown member PRESERVE：读取、Draft 深拷贝和 YAML 写回均保留；Authority、Draft、YAML 严格类型校验；`DraftValidator` 支持列表下标与 member 嵌套 path。
- 修复：旧五种 `FieldType` 与旧 `FieldSpec` 构造器继续兼容，修正旧 CHOICE 的递归描述映射；keyed `forEach` 列表容器与增删 / 排序操作栏分离，避免 reconcile 丢按钮；reset / reload 不再按位置复用行 key——唯一 identity 按身份复用，重复 / 空 identity 与无 identity 的不等值行均分配新内部 key；`List<String>` 后代错误按当前行路径动态聚合显示（此前只订阅 member 根）。

## 兼容性与升级动作

- 不迁移既有调用方；`club.heiqi.config.schema` / `runtime` 保持零 scene 依赖。
- 升级动作：无需手工动作；旧五 FieldType 路径继续可用。
- 本标签为连续 beta 预发布，非稳定 4.5.3；稳定公共能力目标为 4.6.0。
