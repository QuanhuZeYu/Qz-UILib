# Qz-UILib 5.0.0-beta1

UILib 5.0 拆分为三个独立仓库：`QuanhuZeYu/Qz-UILib` 继续维护 Minecraft 多版本 Mod，核心与平台适配分别迁至 `Qz-UILib-Core` 与 `Qz-UILib-Platform`。
本版为 `5.0.0-beta1` 预发布；自有代码采用 MIT 许可证，第三方组件保留原许可。

## 主要变化

- **提供四宿主适配（beta 按实例验证）**：覆盖 Minecraft `1.7.10` Forge（运行需 UniMixins）、`1.12.2` Forge、`1.16.5` Forge 与 `26.3` NeoForge（Java 25；`neoforge263` 对应 MC `26.3`）。
- **薄宿主与提取式渲染**：接入同版本 Core 与 Platform，负责页面生命周期、资源重载、原生输入转换与 GPU 提交，保持原版字体替代与 GL 状态恢复。
- **正式 Mod、媒体可选包与人工广场包分离**：正式 Mod 仅含生产组件；音视频播放按需搭配独立媒体包（当前随包媒体原生库重点面向 Windows）；含参考案例与 `/qzcore` 的 `manual` 广场包独立提供。

## 下载与升级说明

- **玩家与整合包安装**：请按游戏版本下载对应的安装 ZIP，其中已配齐该宿主所需的 UILib 运行库；需要音视频播放或测试广场时，再加入媒体可选包或 `manual` 广场包。
- **开发者迁移与构建**：5.0 公开 Maven group 为 `asia.quanhuzeyu.uilib`（Java 包名不变，旧 group 仅用于 `4.x`）；本地构建可将同版本 Core 与 Platform 的 Maven ZIP 解压至同一目录，通过 `-PuilibRepository=<本地目录>` 接入。
- **宿主验证**：各 Minecraft 实例的窗口启动、GPU 画面、输入法、音频及模组配合需在实际客户端中按实例验证。
