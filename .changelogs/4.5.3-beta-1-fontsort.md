# fontSort 回归修复

## 修复

- 在 screen open、ConfigSaveListener/coordinator initial apply 之前冻结 discovered font snapshot，renderer 与 restore policy 共享同一份 immutable 顺序。
- 增加纯 Java merge/filter/index/filtered-drag 模型：自动删除失效项、canonical 化重复项、按 snapshot 追加新字体，隐藏项在筛选拖拽中保留。
- FontSort renderer 改为稳定高度筛选栏、清空按钮、拖拽把手、全局 1-based 索引输入和只读字体名行；玩家不能添加、删除或改名。

## 事务边界

- 打开、合并、筛选和 MOVE 仅更新 presentation；UP、合法索引移动和显式恢复默认才通过现有 DraftSignalAdapter 整体提交完整 merged 列表。
- CANCEL、no-op、非法索引不提交；reload 按原 screen snapshot 重merge，stale 冲突不因编辑清除。
