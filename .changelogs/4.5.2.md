## 本次更新

**4.5.2** 是 4.5.1 之后的修订补丁，为配置保存事务增加可选的提交前校验钩子，并接入配置页 UI 错误展示。按仓库版本策略登记为 **向后兼容 patch 例外**（修复/扩展保存事务缺口，不升 minor）。

### 新增

- `DraftView` / `SnapshotDraftView`：提交前只读草稿视图（仅 schema 字段，深度冻结）
- `ValueCopy` + 三阶段乐观 save 事务（revision + Authority base 守卫）
- YAML/JSON 锁外序列化 + 同目录 temp replace；优先 ATOMIC_MOVE，不支持时非严格原子 fallback
- `DraftValidator.validate(DraftView)`；`noop()`；全局错误 path `_config`
- `ConfigManager.bootstrap(File, ConfigSchema, DraftValidator)`：注入 final validator
- `ValidationResult.merge` / `summary`：合并错误与 UI 摘要
- `DraftSignalAdapter.setSubmitValidation`：提交错误并入字段红字 / 计数
- 回归：`DraftValidatorSaveTest`、ConfigScreen / DraftSignalAdapter 提交错误 UI 测试

### 行为

- 二参 `bootstrap(file, schema)` 保留公开签名，委托 `DraftValidator.noop()`；既有调用方无需迁移
- `save`：短锁 capture → 锁外 validate/prepare → 复锁 verify/write/引用交换；stale/并发冲突 INVALID 且不覆盖实际修改
- `DraftView` 是 validator 唯一稳定输入；契约禁止写来源状态或重入保存。null / 异常 / 视图构造失败 fail-closed
- NUMBER 合法字符串全链规范化为 Double；非法与非有限数拒绝保存
- INVALID/成功后 UI 全字段回读 Signal；List Signal 只读；`_config` 计入 errorCount
- BATCH_SAVE 锁外恰发布一次；通知同步重入返回 INVALID，RuntimeException/AssertionError 不阻断后续监听器

### 兼容性说明

- 公共 API **仅新增**，无破坏性变更；既有调用方零迁移
- 源码版本号仍由 Git tag / GTNH Gradle 推导
