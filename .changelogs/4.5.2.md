## 本次更新

**4.5.2** 是 4.5.1 之后的修订补丁，为配置保存事务增加可选的提交前校验钩子，并接入配置页 UI 错误展示。按仓库版本策略登记为 **向后兼容 patch 例外**（修复/扩展保存事务缺口，不升 minor）。

### 新增

- `DraftView` / `SnapshotDraftView`：提交前只读草稿视图
- `DraftValidator.validate(DraftView)`；`noop()`；全局错误 path `_config`
- `ConfigManager.bootstrap(File, ConfigSchema, DraftValidator)`：注入 final validator
- `ValidationResult.merge` / `summary`：合并错误与 UI 摘要
- `DraftSignalAdapter.setSubmitValidation`：提交错误并入字段红字 / 计数
- 回归：`DraftValidatorSaveTest`、ConfigScreen / DraftSignalAdapter 提交错误 UI 测试

### 行为

- 二参 `bootstrap(file, schema)` **100% 向后兼容**，委托 `DraftValidator.noop()`
- `save`：内置 `validateAll` → 只读快照 → custom → 合并；INVALID 时 Authority / 磁盘 / draft current / 事件均不变化
- validator 无法写回原 draft；null / 异常 / 视图构造失败 fail-closed
- INVALID 反馈展示真实错误摘要；编辑字段清空提交错误；`_config` 计入 errorCount

### 兼容性说明

- 公共 API **仅新增**，无破坏性变更；既有调用方零迁移
- 源码版本号仍由 Git tag / GTNH Gradle 推导
- 对比：[`4.5.1...4.5.2`](https://github.com/QuanhuZeYu/Qz-UILib/compare/4.5.1...4.5.2)
