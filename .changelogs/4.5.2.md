## 本次更新

**4.5.2** 是 4.5.1 之后的修订补丁，为配置保存事务增加可选的提交前校验钩子 `DraftValidator`，供接入方在写盘前做跨字段 / 业务规则校验。

### 新增

- `club.heiqi.config.runtime.DraftValidator`：`ValidationResult validate(DraftBuffer draft)`；`noop()` 明确无操作语义；全局错误 path `_config`
- `ConfigManager.bootstrap(File, ConfigSchema, DraftValidator)`：注入 final validator
- `ValidationResult.merge`：合并内置与自定义字段错误（同 path 内置优先）
- 回归测试 `DraftValidatorSaveTest`：reject / throw / null fail-closed、通过路径、合并、二参兼容、IO 回滚

### 行为

- 二参 `bootstrap(file, schema)` **100% 向后兼容**，委托 `DraftValidator.noop()`
- `save` 顺序：内置 `validateAll` → custom validator → 合并；任一 INVALID 时 Authority / 磁盘 / draft current / `BATCH_SAVE` 均不变化
- validator 返回 null 或抛 `RuntimeException` 时 fail-closed 为 INVALID，不向外传播到提交后阶段
- 既有 IO_FAILED 回滚语义不变；`ConfigScreen` 无需改动，仍经 `manager.save` 显示失败

### 兼容性说明

- 公共 API **仅新增**，无破坏性变更；既有调用方零迁移
- 源码版本号仍由 Git tag / GTNH Gradle 推导
