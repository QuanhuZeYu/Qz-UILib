# Qz-UILib 4.5.2

## 更新

- 配置保存事务增加可选的提交前校验钩子，并接入配置页 UI 错误展示；按仓库版本策略登记为**向后兼容 patch 例外**（修复 / 扩展保存事务缺口，不升 minor）。
- 新增 `DraftView` / `SnapshotDraftView`：提交前只读草稿视图（仅 schema 字段，深度冻结）。
- 新增 `ValueCopy` 与三阶段乐观 save 事务（revision + Authority base 守卫）。
- 持久化改为 YAML / JSON 锁外序列化 + 同目录 temp replace，优先 `ATOMIC_MOVE`，不支持时非严格原子 fallback。
- 新增 `DraftValidator.validate(DraftView)` 与 `noop()`，全局错误 path `_config`；`ConfigManager.bootstrap(File, ConfigSchema, DraftValidator)` 可注入 final validator。
- 新增 `ValidationResult.merge` / `summary`（合并错误与 UI 摘要）与 `DraftSignalAdapter.setSubmitValidation`（提交错误并入字段红字 / 计数）。
- 保存语义：短锁 capture → 锁外 validate / prepare → 复锁 verify / write / 引用交换；stale 或并发冲突返回 INVALID，且不覆盖实际修改。
- `DraftView` 是 validator 唯一稳定输入；契约禁止写来源状态或重入保存；null、异常、视图构造失败一律 fail-closed。
- NUMBER 合法字符串全链规范化为 Double，非法与非有限数拒绝保存；SIMPLE_LIST 保存候选严格限定为 `List<String>`（允许 null 元素），非法标量与非字符串元素列表拒绝保存。
- INVALID 或成功后 UI 全字段回读 Signal，List Signal 只读，`_config` 计入 errorCount；BATCH_SAVE 锁外恰发布一次，同一 manager 通知期内任意线程 save 均返回 INVALID，`openDraft` 只读可完成；`RuntimeException` / `AssertionError` 不阻断后续监听器。

## 兼容性与升级动作

- 公共 API **仅新增**，无破坏性变更；既有调用方零迁移：二参 `bootstrap(file, schema)` 保留公开签名，委托 `DraftValidator.noop()`。
- 升级动作：无需手工动作。需要提交前校验的调用方注入自己的 `DraftValidator` 即可。
- 发布渠道为 JitPack + GTNH Maven；源码版本号仍由 Git tag / GTNH Gradle 推导。

## 验证边界

- 已验证（本地 build）：完整构建通过。
- 已验证（回归覆盖）：新增 validator 保存事务与配置页 / `DraftSignalAdapter` 提交错误 UI 的回归用例。
- 未验证：真机运行态未记录。
