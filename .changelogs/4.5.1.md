## 本次更新

**4.5.1** 是 4.5.0 之后的修订补丁，修复与小地图等宿主 HUD 叠用时，uilib 裁切栈覆盖/关闭外部 scissor 导致字符与几何绘制越界的问题（issue #63）。

### 修复

- 宿主 scissor / stencil 基线：在 `UiRenderContext` 构造时捕获主 framebuffer 上的当前裁切状态；首层 UI clip 与宿主 scissor 求交。
- clip 栈空时幂等恢复宿主基线，避免 `popClip` 后再经 transform/opacity 收尾二次 `clear` 关掉宿主 scissor。
- 静态 FBO / deferred 路径仍可强制 `clearClipState`，与实例「恢复宿主基线」语义分离。
- `pushClip` / `popClip` 变更前 flush deferred text batch，防止未来启用延迟文本批时跨裁切边界提交。
- 新增 `ClipStackHostBaselineTest` 覆盖求交、幂等恢复、stencil 常用状态恢复、静态 clear 与实例 restore 分叉。

### 兼容性说明

- 公共 API 无破坏性变更；行为上更尊重进入 uilib 前宿主已设置的 scissor。
- 源码版本号仍由 Git tag / GTNH Gradle 推导。
- 对比：[`4.5.0...4.5.1`](https://github.com/QuanhuZeYu/Qz-UILib/compare/4.5.0...4.5.1)。
