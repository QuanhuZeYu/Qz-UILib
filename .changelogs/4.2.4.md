# Qz-UILib 4.2.4

**本版要点**

- 新增可配置 UI 背景模糊系统：全局 `BackdropBlurConfig`、页面级 `BackdropBlurPolicy`、`BackdropBlurPreset` 与文档运行时控制器，业务页面可在创建 `UiDocumentScreens` 时选择禁用、性能优先或质量优先策略。
- 新增内部 `DocumentVirtualizedOptionList`，自动完成输入与下拉选择的大量候选渲染改用共享虚拟列表。
- 新增 `UiKeyCodes` 与内部输入后端抽象，收拢业务层键码常量并支持 LWJGL3ify / LWJGL 运行时降级，同时加固降级路径避免基础输入丢失。
- 字体 atlas 改为 AWT baseline + actual pixel bounds + 可变 slot 契约，`font-size` 接入 UI 像素语义，文本测量、换行、裁剪和绘制使用统一字号快照。
- 修复自动完成控件在大量候选项下卡顿、未安装 `lwjgl3ify` 时配置界面文本框无法输入数字或普通字符，以及字体 baseline 对齐与可变 glyph slot 装箱问题。

## 兼容性与升级动作

- 本版本保持 4.2.3 公共 API 向后兼容。
- `lwjgl3ify` 从发布硬依赖调整为可选增强运行时；无该 Mod API 时仍保留基础键盘、鼠标、滚轮和基础可打印字符输入能力，完整 IME、组合输入和补充平面字符仍建议使用增强输入环境。
- `font-size` 现在按 UI 像素参与测量和绘制，依赖旧固定字号视觉细节的页面可能出现更准确但略有差异的文本几何。
- 页面级背景模糊策略只影响当前页面，不写回全局配置，也不会污染其它页面。
- 发布渠道仍为 JitPack + GTNH Maven；源码版本号由 Git tag / GTNH Gradle 推导。
- 升级动作：无需手工动作；需要背景模糊的页面显式选择策略即可。
