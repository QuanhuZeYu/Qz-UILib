## 本次更新

4.2.4 是 4.2.3 之后的小版本更新，重点增强字体渲染、长候选列表性能、LWJGL3ify 可选化输入后端和背景模糊配置能力。

### 新增

- 新增可配置 UI 背景模糊系统，支持全局 `BackdropBlurConfig`、页面级 `BackdropBlurPolicy`、常用 `BackdropBlurPreset` 与文档运行时控制器。
- 新增页面级背景模糊快捷入口，业务页面可在创建 `UiDocumentScreens` 时选择禁用、性能优先或质量优先策略。
- 新增内部 `DocumentVirtualizedOptionList`，复用 select 与 autocomplete 的固定行高虚拟候选列表渲染逻辑。
- 新增 `UiKeyCodes` 与内部输入后端抽象，收拢业务层键码常量并支持 LWJGL3ify / LWJGL 运行时降级。

### 优化

- 字体 atlas 改为 AWT baseline + actual pixel bounds + 可变 slot 契约，减少字号变化下的绘制偏移和固定方格浪费。
- `font-size` 接入 UI 像素语义，文本测量、换行、裁剪和绘制使用统一字号快照。
- 自动完成输入与下拉选择的大量候选渲染改用共享虚拟列表，降低超长选项列表创建、布局、绘制和命中测试成本。
- `lwjgl3ify` 不再作为 Maven 发布硬依赖；运行时优先反射接入增强输入 API，缺失或注册失败时回退基础键鼠轮询。

### 修复

- 修复自动完成控件在大量候选项下容易卡顿的问题。
- 加固 LWJGL3ify 输入后端降级路径，避免增强输入 API 不可用或监听注册失败时直接丢失基础输入。
- 修复未安装 `lwjgl3ify` 时配置界面文本框无法输入数字或普通字符的问题。
- 修正字体 baseline 对齐、可变 glyph slot 装箱和绘制入口一致性。
- 明确 `BackdropBlurPolicy.enabled` 为页面级强制总开关，避免禁用预设重复覆盖底层 shader / fallback 字段。

### 文档与测试

- 补充背景模糊配置、页面级背景模糊策略、LWJGL3ify 解耦和字体字号路线相关开发文档与决策记录。
- 新增 glyph ink bounds、可变 slot 装箱、字体 batch quad、虚拟候选列表、输入后端和背景模糊策略相关回归测试。

## 兼容性说明

- 本版本保持 4.2.3 公共 API 向后兼容。
- `lwjgl3ify` 从发布硬依赖调整为可选增强运行时；无该 Mod API 时仍保留基础键盘、鼠标、滚轮和基础可打印字符输入能力，完整 IME、组合输入和补充平面字符仍建议使用增强输入环境。
- `font-size` 现在按 UI 像素参与测量和绘制，依赖旧固定字号视觉细节的页面可能出现更准确但略有差异的文本几何。
- 页面级背景模糊策略只影响当前页面，不写回全局配置，也不会污染其它页面。
- 当前发布渠道仍为 JitPack + GTNH Maven；源码版本号由 Git tag / GTNH Gradle 推导。
