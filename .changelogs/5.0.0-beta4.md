# Qz-UILib Minecraft 5.0.0-beta4

新增被动 HUD 与位置编辑宿主、物品列表模板及可声明的背包组件。统一各版本输入转换与页面退休顺序，修正物品图标光照、固定管线状态和 GUI Scale 对原生像素 HUD 的影响。优化原版文字缓存与提交，接入持久化滚轮距离和可选激进合批设置。

Core、Platform 与 Minecraft 请整组升级至 `5.0.0-beta4`。Maven group 为 `asia.quanhuzeyu.uilib`，Java 8 使用对应 `java8` 制品；离线接入使用同版本 Maven ZIP。Minecraft 玩家安装对应游戏版本的正式宿主包。
