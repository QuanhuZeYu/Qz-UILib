## 本次更新

**4.5.3-beta-1** 是面向连续 beta 迭代的预发布修订，在 4.5.2 之上收紧配置草稿所有权、修 I3 展示初始化，并纳入**参与式写前检测**、UI 主线程契约、从磁盘显式 reload（完整校验 + RELOAD 事件）、通知期事务封锁、**配置回灌全局协调器**与 **disk 严格 NodeType**，以及**批次交换派发 / Registration 强线性化 / section raw overlay 保留**。

> **不是稳定 4.5.3**：本标签用于连续 beta 验证；稳定公共能力目标归入 **4.6.0**。正式 tag / GitHub Release 尚未执行。

### 新增

- `ConfigFileSnapshot`：canonical 路径 + 一次读取不可变原始字节；状态 `MISSING` / `REGULAR` / `NON_REGULAR`；精确字节等价（不依赖 mtime/hash）；写域仅 canonical path 语法别名（**不**保证硬链接/inode）
- `ConflictType.CONFIG_FILE_CHANGED_SINCE_LOAD`（`requiresReload=true`）+ `ConfigConflictException`（兼容 `flushRaw throws ConfigException`）
- `ConfigManager` / `Persistence` 持 expected 磁盘快照；save/flushRaw **capture 冻结 expected 基线**，commit 复核 manager expected 仍等基线且 disk compare 用该基线——reload 推进 expected 后旧 prepared 结构化冲突，禁止拿新 expected 写旧 prepared
- `ConfigManager.reloadDraftFromDisk()`：**三阶段** capture → 锁外完整校验 → 写域 commit；成功发布 `ChangeType.RELOAD`；结构化 `ConfigReloadException.Reason`
- `ConfigManager.owns(DraftBuffer)`；`DraftSignalAdapter` owner 线程封闭（含 `seedFieldBaseline`）
- `SchemaReplaceCompatibility`；`Persistence` 包级 fault injector
- 通知期封锁：BATCH_SAVE **与** RELOAD 期间 save/flushRaw/reload + Legacy mutation fail-closed
- `ModernConfigApplyCoordinator` + `ConfigSaveListener`：**强线性化** Registration（generation+manager+active）；register 使旧失活并 auto initial apply；pending 携 registration identity；apply lease + register wait（防死锁）；no-spin；tick `retryPendingOnce`；新 registration 返回后旧 apply 不得写
- `MainThreadDispatcher`：**真正批次交换**（每 side lock + current queue；drain 原子 swap 旧 batch，锁外消费；swap 后 enqueue 仅进新队列 / next-drain）；FIFO + 单任务异常隔离；**禁止** CLQ.size 快照
- `ConfigException.Category`（VALIDATION/IO/CONFLICT/UNSPECIFIED）；reload/UI 禁止英文 substring 匹配
- section **raw overlay**：schema section 内未知字段/子树 load 保留；`prepareWrite` 以 raw 为底再覆盖 schema typed（路径冲突 schema 优先）；无静默丢失
- `ConfigEventBus.subscribe` 使用 `addIfAbsent`

### 行为

- disk / legacy raw 严格类型：STRING/CHOICE 仅 STRING；BOOLEAN 仅 BOOLEAN；NUMBER 仅 NUMBER（quoted `"80"` 拒绝）；SIMPLE_LIST 仅 LIST 且每项非 null STRING；schema 字段 `setRawJson` 错型抛异常且零变化
- UI NUMBER 字符串解析**仅**限 DraftBuffer 提交边界，与 disk 路径分离
- 写前检测 **不是** OS 级跨进程 CAS：仅保证**同 classloader 参与式 writer**
- Atomic write（temp+move）**不**承诺 fsync / 掉电持久化
- `Persistence.writeAll` deprecated：低级无 expected 比较、**非**参与式写前检测旁路；生产 ConfigManager 不调用
- move 失败后 draft base/current 旧、proposed 保留、dirty true；清 hook 后可重试
- 测试 hook **不得吞** `AssertionError`（直接 rethrow）

### 兼容性说明

- 公共构造/工厂兼容；`flushRaw` 仍 throws ConfigException（冲突为子类）
- 对比基线：4.5.2（beta 链，非正式 4.5.3 tag）
