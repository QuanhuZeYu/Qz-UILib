## 本次更新

**4.5.3-beta-1** 是面向连续 beta 迭代的预发布修订，在 4.5.2 之上收紧配置草稿所有权、修 I3 展示初始化，并纳入**参与式写前检测**、UI 主线程契约、从磁盘显式 reload（完整校验 + RELOAD 事件）与通知期事务封锁。

> **不是稳定 4.5.3**：本标签用于连续 beta 验证；稳定公共能力目标归入 **4.6.0**。正式 tag / GitHub Release 尚未执行。

### 新增

- `ConfigFileSnapshot`：canonical 路径 + 一次读取不可变原始字节；状态 `MISSING` / `REGULAR` / `NON_REGULAR`；精确字节等价（不依赖 mtime/hash）；写域仅 canonical path 语法别名（**不**保证硬链接/inode）
- `ConflictType.CONFIG_FILE_CHANGED_SINCE_LOAD`（`requiresReload=true`）+ `ConfigConflictException`（兼容 `flushRaw throws ConfigException`）
- `ConfigManager` / `Persistence` 持 expected 磁盘快照；save/flushRaw 写前同 classloader **参与式 writer** 串行 + 写前精确字节检测
- `ConfigManager.reloadDraftFromDisk()`：从磁盘构造候选，**先**完整 schema 内置校验 + custom `DraftValidator`（冻结 DraftView），通过后才原子更新 Authority+expected；成功锁外发布一次 `ChangeType.RELOAD`（**不得**伪装 `BATCH_SAVE`）；非法/validator/IO 时旧态零推进
- `ConfigManager.owns(DraftBuffer)`：公开身份查询、不泄露 token；`ConfigScreen` 构造 fail-fast 要求 manager 拥有 adapter draft
- `DraftSignalAdapter` UI 主线程封闭（构造捕获 ownerThread；全部 mutator 违规 `IllegalStateException` 且状态零变化）
- `SchemaReplaceCompatibility`：同 owner 下 schema 路径/类型纯判定（constraints/default/widget 随 owner 冻结，无 manager 内 schema reload）
- `AtomicFileWrites` 测试缝：fault injector 可在 temp 写成功后、move 前失败，覆盖真实 IO_FAILED 零推进
- 通知期封锁：BATCH_SAVE **与** RELOAD 通知期间 save/flushRaw/reload + Legacy/Authority raw mutation 全部 fail-closed（`SAVE_DURING_NOTIFICATION` / `ConfigConflictException`）

### 行为

- 未绑定 owner 的外部 Draft 不得写任意 manager（`DRAFT_OWNER_MISMATCH`）
- **I3**：SimpleList/FontSort render 期 prefill 局部只读；首次真实控件交互经 `onFieldEdit`
- ConfigScreen reload 按钮调用 `reloadDraftFromDisk` + `replaceDraft`；校验/IO 失败保留冲突与用户编辑，友好显示原因（不静默 NUMBER→0.0）
- `ConfigSaveListener` 对 `BATCH_SAVE` 与 `RELOAD` 都从 Authority 回灌运行态，但 reason 区分保存/重载；他 mod 消费者**必须**处理 RELOAD（Qz-Miner 适配留后续）
- 写前检测 **不是** OS 级跨进程 CAS：仅保证同 classloader 参与式 writer；外部 writer 的 compare→replace 窗口不承诺
- 相同字节重建 / A→B→A（same-byte ABA）视为等价；删除 / missing→exists / 目录 / 不同内容重建 → `CONFIG_FILE_CHANGED_SINCE_LOAD`
- 硬链接共享写域**不保证**

### 兼容性说明

- 公共构造/工厂二进制与源码兼容；`setDraftAndCurrent` / `seedFieldBaseline` deprecated 仍可用
- `flushRaw` 签名仍为 `throws ConfigException`；冲突/通知期抛子类 `ConfigConflictException`
- `ChangeType.RELOAD` 既有枚举值；事件语义从「DefaultMutableConfig 旧路径」扩展到 `ConfigManager.reloadDraftFromDisk` 成功路径
- 源码版本号仍由 Git tag / GTNH Gradle 推导
- 对比基线：4.5.2（beta 链，非正式 4.5.3 tag）
