## 本次更新

**4.5.3-beta-1** 是面向连续 beta 迭代的预发布修订，在 4.5.2 之上收紧配置草稿所有权、修 I3 展示初始化，并纳入**同 JVM 磁盘 CAS**、UI 主线程契约与从磁盘显式 reload。

> **不是稳定 4.5.3**：本标签用于连续 beta 验证；稳定公共能力目标归入 **4.6.0**。正式 tag / GitHub Release 尚未执行。

### 新增

- `ConfigFileSnapshot`：canonical 路径 + 一次读取不可变原始字节；状态 `MISSING` / `REGULAR` / `NON_REGULAR`；精确字节等价（不依赖 mtime/hash）
- `ConflictType.CONFIG_FILE_CHANGED_SINCE_LOAD`（`requiresReload=true`）+ `ConfigConflictException`（兼容 `flushRaw throws ConfigException`）
- `ConfigManager` / `Persistence` 持 expected 磁盘快照；save/flushRaw 写前同 classloader 静态 monitor 串行 compare + atomic replace
- `ConfigManager.reloadDraftFromDisk()`：事务锁内重解析 Authority+expected，返回同 owner 新 Draft；**不**发布 `BATCH_SAVE`
- `DraftSignalAdapter` UI 主线程封闭（构造捕获 ownerThread；mutator 违规 `IllegalStateException` 且状态零变化）
- `SchemaReplaceCompatibility`：同 owner 下 schema 路径/类型纯判定（constraints/default/widget 随 owner 冻结，无 manager 内 schema reload）

### 行为

- 未绑定 owner 的外部 Draft 不得写任意 manager（`DRAFT_OWNER_MISMATCH`）
- **I3**：SimpleList/FontSort render 期 prefill 局部只读；首次真实控件交互经 `onFieldEdit`
- ConfigScreen reload 按钮调用 `reloadDraftFromDisk` + `replaceDraft`；IO/非法文件失败保留冲突与用户编辑
- 磁盘 CAS **不是** OS 级跨进程 CAS：跨进程 compare→replace 窗口仍可能竞态；beta 不虚假承诺
- 相同字节重建视为等价；删除 / missing→exists / 目录 / 不同内容重建 → `CONFIG_FILE_CHANGED_SINCE_LOAD`

### 兼容性说明

- 公共构造/工厂二进制与源码兼容；`setDraftAndCurrent` / `seedFieldBaseline` deprecated 仍可用
- `flushRaw` 签名仍为 `throws ConfigException`；冲突时抛子类 `ConfigConflictException`
- 源码版本号仍由 Git tag / GTNH Gradle 推导
- 对比基线：4.5.2（beta 链，非正式 4.5.3 tag）
