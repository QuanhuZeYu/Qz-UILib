# Qz-UILib 4.2.5

**本版要点**

- 新增独立 Config 模块（`club.heiqi.config`），提供 JSON / YAML 复杂配置能力，独立于 uilib，未来可拆分为独立模组。
- 新增只读 `ConfigNode` 与可变 `MutableConfig` 接口：支持嵌套树形结构（MAP、LIST、STRING、NUMBER、BOOLEAN）、路径访问、类型安全转换、默认值、链式调用与 `set()` / `remove()` / `clear()` 修改 API。
- 新增配置持久化与变更通知：`save()` / `saveTo()` / `reload()`、脏标记 `isDirty()`，以及 `ConfigChangeListener` 与 `ConfigChangeEvent` 实时监听。
- 新增 JSON 加载 / 写入器（`JsonConfigLoader` / `JsonConfigWriter`，基于 Gson）与支持注释、嵌套、列表、引号字符串等基本语法的 YAML 加载 / 写入器，并补充 Config 模块使用指南与架构文档。

## 兼容性与升级动作

- 本版本保持 4.2.4 公共 API 向后兼容。
- Config 模块位于独立包 `club.heiqi.config`，不与现有 uilib 代码产生冲突。
- 已知限制：YAML 支持为简化实现，不支持锚点、别名、多行字符串等高级特性，完整 YAML 支持建议后续集成 SnakeYAML。
- 发布渠道仍为 JitPack + GTNH Maven；源码版本号由 Git tag / GTNH Gradle 推导。
- 升级动作：无需手工动作。
