## 本次更新

4.2.5 是 4.2.4 之后的小版本更新，新增独立 Config 模块，提供比 Forge Configuration 更灵活的复杂配置能力。

### 新增

- 新增独立 Config 模块 (`club.heiqi.config`)，提供 JSON/YAML 复杂配置能力，独立于 uilib，未来可拆分为独立模组。
- 新增只读配置接口 `ConfigNode`，支持嵌套树形结构（MAP、LIST、STRING、NUMBER、BOOLEAN），路径访问 `config.get("database.credentials.username")`，类型安全转换和默认值。
- 新增可变配置接口 `MutableConfig`，支持 `set()`、`remove()`、`clear()` 修改 API，链式调用 `config.set("a", 1).set("b", 2).save()`。
- 新增配置持久化能力，支持 `save()`、`saveTo()`、`reload()`，脏标记 `isDirty()` 自动追踪配置变更状态。
- 新增 `ConfigChangeListener` 和 `ConfigChangeEvent`，支持配置变更实时监听和通知。
- 新增 JSON 格式加载器 `JsonConfigLoader` 和写入器 `JsonConfigWriter`，基于 Gson。
- 新增 YAML 格式加载器 `YamlConfigLoader` 和写入器 `YamlConfigWriter`，支持基本 YAML 语法（注释、嵌套、列表、引号字符串等）。

### 文档与测试

- 新增《Config 模块使用指南》完整使用文档。
- 新增 Config 模块架构文档。
- 新增 28 个测试用例（JSON 加载、YAML 加载、可变配置）全部通过。

## 兼容性说明

- 本版本保持 4.2.4 公共 API 向后兼容。
- Config 模块位于独立包 `club.heiqi.config`，不与现有 uilib 代码产生冲突。
- YAML 支持为简化实现，不支持锚点、别名、多行字符串等高级特性，完整 YAML 支持建议后续集成 SnakeYAML。
- 当前发布渠道仍为 JitPack + GTNH Maven；源码版本号由 Git tag / GTNH Gradle 推导。
