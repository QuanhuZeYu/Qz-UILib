# Qz-UILib 4.7.0 候选版本说明

## 本次更新

- 字体异步核心 Phase A-F 落位：字体重载改为 signal 驱动（`FontReloadSignal`，替换 debouncer 轮询）；运行时代际统一为不可变 generation，候选字体在后台构建、经资源指纹与快照校验后整体换代；glyph 请求引入 `GlyphRequestToken` 状态机，重复或过期请求只回放一次结果；demand 按帧有界调度并支持 reload 屏障；上传以事务化 upload plan 执行，失败回滚不污染共享纹理页。
- 物品渲染改为上层替换当帧直绘：纯 2D 图标由 Qz 等价自绘，3D block/多 pass item model 委托原版 `renderItemAndEffectIntoGUI`（含 Forge hook）；删除 FBO 栅格化、缓存 composite guard、GL 状态围栏、错误跟踪与帧中止组件（`HostImageRenderSession`、`HostImageGlStateGuard`、`HostImageGlErrorTracker`、`HostImageCacheCompositeGuard`、`HostImageResourceEpoch`、`UiRenderFrameAbortException`、`SceneFrameAbortBoundary` 等）及对应测试。
- 字体管线尾状态幂等与批渲染守卫收口：字体共享准备显式恢复 per-unit TEXTURE_2D（attrib pop 只覆盖 push 时刻 active unit），批渲染 blend 与 vanilla 一致（`glBlendFuncSeparate(SRC_ALPHA, ONE_MINUS_SRC_ALPHA, ONE, ZERO)`），避免尾状态泄漏污染后续渲染。
- 修复 HUD GL 状态围栏崩溃（issue #70）：`HudGlStateGuard` 的 float/int/boolean 查询缓冲容量由 4 提升到 16，满足 LWJGL2 `glGet*` buffer 重载对 remaining 的恒定 ≥16 校验；`FontRenderStateGuard` 同类查询缓冲一并修正。
- 修复宿主裁切基线与文字批渲染边界（issue #63）。
- FML 远端版本范围固定为 `[4.7.0,4.8.0)`，为双方都携带该合同的同 minor 端点提供握手准入。
- 规格文档目录与文件名中文化；新增多维度架构图集（架构总览、字体引擎、异步时序、上传与换代所有权等）、字体引擎代码地图与原版物品渲染流程参照图。
- 配置页 Material 主题 Motion 扩展：导航平滑滚动与指示条动效、字段卡片级联进入动画；修复字体排序与 draggable 列表拖拽时序及输入框动画与滚轮响应。

## 兼容性说明

- 本次候选不破坏公共 API；主 `NetEnvelope` 仍为 v2，Realtime `NetRealtimeFrame` 仍为 v1，不提供运行时协议协商、能力探测或降级路径。
- 物品 icon 无缓存、无占位、无预算/cooldown、无帧中止；纯 2D 图标路径不再绘制附魔 glint（与原版 2D 分支一致），3D block、多 pass item model 委托原版行为一致。
- FML 范围按 Maven 版本排序解释：会接受排序低于正式版的 `4.7.0-alpha`、`4.7.0-beta`、`4.7.0-rc1` 与 `4.7.0-SNAPSHOT`，拒绝正式 `4.8.0`。
- FML 会双向执行本端 checker。已发布旧 `4.6.3` 携带 `[4.6.2,4.7.0)`，会拒绝正式 `4.7.0`；新端点不能单方面绕过，混合双端需要协调升级。
- 远端缺少 `qz_uilib` 的方向性不变：客户端有而服务端缺少时接受，服务端有而客户端缺少时拒绝。

## 候选状态

- 本机完整 build（编译、checkstyle、全量 JUnit、classpath isolation、assemble）通过；运行态与光影（issue #49）复测仍待用户执行，不代表已经测试或正式发布。
