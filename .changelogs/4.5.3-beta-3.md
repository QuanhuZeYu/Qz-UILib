## 本次更新

**4.5.3-beta-3** 收口结构化列表输入焦点与通用中文 IME 宿主桥接。

### 修复

- StructuredList member、List<String>、增删、排序等内部编辑统一先更新本地 keyed rows，再调用
  `DraftSignalAdapter.onFieldEdit`；identity 逐字符输入不再触发行/input 节点重建。
- 增加有限 identity lineage。当前唯一 identity 优先，仍存活 row key 的历史唯一 identity 次之；
  空、重复、历史多 key 或已占用映射均分配新内部 key，禁止猜测 refocus。
- `McScreenBridge` 作为唯一 host owner 幂等注册 `SceneLwjgl3ifyTextBridge`，成功才启用 external
  text mode，注册失败安全降级，关闭时 finally 注销并复位。devtools 手工注册已迁移删除。

### 验证与诊断边界

- 指定日志片段 `fml-client-latest.log:15313-15321` 是 beta-2 修复前基线，仅有 ROW/COLUMN
  grow WARN；它既不是代码根因证明，也不能证明 beta-3 行为。
- 代码确定诊断为：生产 Config 未注册 text bridge 导致中文 IME 没有完整 String 入口；renderer 本地
  SSOT 缺失导致 adapter 回调前外部 bind 重建 keyed rows，产生一键失焦。
- ROW/COLUMN grow WARN 未改布局，等待修复后实机确认是否能定位到固定兄弟缺 preferred 尺寸。

### 兼容性说明
