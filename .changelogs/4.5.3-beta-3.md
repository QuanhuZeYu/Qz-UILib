# Qz-UILib 4.5.3-beta-3

## 更新

- 收口结构化列表输入焦点与通用中文 IME 宿主桥接。
- StructuredList member、`List<String>`、增删、排序等内部编辑统一先更新本地 keyed rows，再调用 `DraftSignalAdapter.onFieldEdit`；identity 逐字符输入不再触发行 / input 节点重建。
- 增加有限 identity lineage：当前唯一 identity 优先，仍存活 row key 的历史唯一 identity 次之；空、重复、历史多 key 或已占用映射均分配新内部 key，禁止猜测 refocus。
- `McScreenBridge` 作为唯一 host owner 幂等注册 `SceneLwjgl3ifyTextBridge`，成功才启用 external text mode，注册失败安全降级，关闭时 `finally` 注销并复位；devtools 手工注册已迁移删除。
- `SceneLwjgl3ifyTextBridge` 在副作用前校验监听注册 / 移除与文本输入启停完整配对；半完成注册按 end、remove 独立回滚并保留失败步骤供重试；lwjgl3ify 探测改为锚定 classloader 的无初始化加载。

## 兼容性与升级动作

- 保持现有 `McScreenBridge` 子类构造和 `UiSurface` API；非 lwjgl3ify 环境继续使用 char 降级路径。
- 升级动作：无需手工动作。

## 验证边界

- 已验证（诊断结论）：生产 Config 未注册 text bridge 导致中文 IME 没有完整 String 入口；renderer 本地 SSOT 缺失导致 adapter 回调前外部 bind 重建 keyed rows，产生一键失焦。这两条为代码确定诊断。
- 未验证：指定基线日志只显示 ROW / COLUMN grow 警告，它既不是代码根因证明，也不能证明本版行为；ROW / COLUMN grow 警告未改布局，等待修复后实机确认是否能定位到固定兄弟缺 preferred 尺寸。
- 未验证：真机（中文 IME 全链路）未记录。
