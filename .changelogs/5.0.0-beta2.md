# Qz-UILib Minecraft 5.0.0-beta2

本版使用同版本 Core / Platform，将许可整改随安装包交付，覆盖 Minecraft 1.7.10、Forge 1.12.2、Forge 1.16.5 与 NeoForge 26.3。

## 修复

- 安装组合内的 Core 与字体适配包含修复后的字体、SnakeYAML、LWJGL、FreeType 和 HarfBuzz 许可及来源说明。
- 人工测试附件合并 gallery 与 core-verification 时，分别在 META-INF/licenses/core-gallery/LICENSE 与 core-verification/LICENSE 保留项目 MIT，并保留 Unicode、KaTeX 全文和关联通知；NeoForge 的嵌套 JAR 保留各自通知。
- Forge 1.12 的 Prism 缓存构建入口补齐与标准入口一致的版本常量生成和 mcmod.info 展开。

## 安装

按目标宿主下载本版安装 ZIP，整组替换旧版本。manual 与媒体 JAR 为可选附件，选择同一版本；正式包不含人工测试入口。原 beta1 的许可补充包及更正说明仍在原 Release。

## 验证范围

四宿主通过各自完整 build 和安装资产装配，检查实际许可随附与依赖隔离；游戏运行态需在目标实例验证。实际提交、发布运行和资产见下方构建证据。
