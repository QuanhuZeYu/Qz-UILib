# Qz-UILib 4.2.0

**本版要点**

- 新增远程 UI 会话运行时：内部改为 session / surface / content revision 绑定，远程页面与 HUD 的 stream、submit、close、expired 均携带并校验 `sessionId + surfaceId + contentRevision`，对外 facade 保持不变。
- 新增服务端权威远程配置页（`ConfigSyncTarget` / `RemoteConfigDocumentPages` / 服务端配置会话管理），支持 Forge 配置模板通过远程页面同步和提交。
- 新增网络实时子层 `NetService.realtime(...)` / `NetRealtimeChannel` 与传输层实时帧，为高频小二进制帧提供实验性通道。
- HTML-like 能力扩展：`DocumentNode.textContent` 读写、`input type=password/number`、textarea 软换行两级行模型与远程 CSS `background-image: url(...)` 单图解析。
- 新增脏子树布局缓存（静态 block / flex / table / inline-block / display:none 子树复用），`/qzuilib test` 视觉优先矩阵重建核心视觉样例。

## 兼容性与升级动作

- 本版本保持 4.1.x 稳定 API 向后兼容，重点是能力扩展、内部会话语义收口和运行时修复。
- 开发依赖基线同步到 GTNH `2.9.0-beta-1`；发布渠道仍为 JitPack + GTNH Maven，源码版本号由 Git tag / GTNH Gradle 推导。
- `runClient21` 的 CodeChickenLib MCP mapping 目录已改为启动前自动写入运行目录配置；本地 GTNH 2.9 beta smoke 仍可能受第三方 mixin 冲突阻塞。
- 升级动作：无需手工动作。

- 长文本绘制裁剪新增 `DocumentTextPaintClipper`，减少被 overflow clip 裁掉的长单行文本提交量；字体运行时高频诊断日志默认受 `Config.fontRuntimeDebug` 控制。
- 修复（浏览器语义）：DOM 同父移动、`removeChild` 返回值、`querySelector*` 文档根排除、`focusout` 事件、hover / active 状态传播、wheel 事件默认滚动前分发、布尔 `disabled`、margin collapse、flex min-content、table auto 列宽、absolute auto margin、fixed clip chain。
- 修复（top-layer / HUD / select）：select 弹层 detach 生命周期、transform 后弹层锚点、HUD top-layer 后代预过滤、popup 关闭后 hover / cursor 刷新、运行态 transform 后滚轮和滚动条命中。
- 修复（动画与文本）：keyframe forwards fill 按 direction 与最终迭代奇偶写入终值，`display:none` 中断运行中 transition 时派发 `transitioncancel`；`textInput.preventDefault()` 阻止内置 input / textarea 改值，textarea stale visual line cache 越界保护，输入框 auto 高度和 caret / selection 绘制坐标修正。
- 修复（绘制与样式）：transform 栈内禁用延迟文本批处理，避免文本 batch 使用屏幕坐标绕过父矩阵；host image 缺失资源保留 UILib 底色，不泄漏 Minecraft 紫黑 missing texture；挂载后的 `UiStyleSheet` 变更触发缓存失效，`UiStyleDeclaration.copyFrom(...)` 对已挂载元素触发布局 / 绘制失效。
