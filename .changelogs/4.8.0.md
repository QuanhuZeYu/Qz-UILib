# Qz-UILib 4.8.0 版本说明

## 本次更新

- 增加宿主无关的 screen/overlay projection composition，同一业务 state 可投放多个 occurrence，各 occurrence 的 scene、focus、capture、hover、cursor 与 animation 独立。
- 增加 Config-scoped Material 主题、Setting Row 页面结构与基于 host frame timestamp 的 Motion；覆盖 Button/Toggle/Navigation/section，补齐共享 focus border/选中态、输入与选择控件 chrome、Slider/Scrollbar 反馈及字段 dirty/error 语义色。
- 图片 API 收敛为 snapshot-only `HostImageSource.itemIcon(ItemStack)`：source 创建时复制完整 ItemStack，渲染改为上层替换当帧直绘——纯 2D 图标由 Qz 等价自绘，3D block/多 pass 委托原版 `renderItemAndEffectIntoGUI`（含 Forge hook），不经过 FBO 栅格化、缓存或占位。
- 现代配置页在世界内使用覆盖完整 framebuffer 的 80% 不透明暗色遮罩；Tab 立即严格单 live 切换，标题/字段卡片级联进入；导航与滚动 Motion 增强（指示条伸缩、160ms ease-out 滚轮收敛、scrollbar thumb 同步）。
- 字体排序与 draggable SimpleList 改为主流中线插槽换位，同帧 MOVE→UP/CANCEL/SCROLL 不再丢失最终顺序。
- 搜索选择器全链路重做：居中 70% 卡片面板、多分类维度、无上限结果列表与可见滚动条、物品图标渲染分级回退、多列成员网格（已选择容器）、成员删除一步直达。
- 修复 TextInput hover→focus 背景反向变暗、字段卡片进入动画 clip 越界等 Motion 边界问题；配置 NUMBER 读取按 raw 类别保真（整数回 Long、浮点回 Double）。

## 兼容性说明

- 移除 beta 公共文案 API `SearchPickerPresentation.Builder.cancelRemove/confirmRemove` 与对应 getter（SearchPicker 成员删除改为一步直达；beta API 不属于 LTS 稳定承诺，唯一下游 Qz-Miner 已同步）。
- 移除 4.x LIVE/SNAPSHOT/Slot 图片双栈、inventory-slot renderer、GuiContainer mixin 与旧万能 item renderer 公共合同；移除物品图标栅格化/缓存路线组件（`HostImageRenderSession`、`HostImageGlStateGuard` 等）与对应测试。
- 行为变化：item icon 无缓存、无占位、无预算/cooldown、无帧中止；纯 2D 图标路径不再绘制附魔 glint（与原版 2D 分支一致）；3D block、多 pass item model 委托原版行为一致；overlay 保持 icon-only 合同不绘制。
- FML 远端版本范围固定为 `[4.8.0,4.9.0)`：已发布旧 `4.7.0` 携带 `[4.7.0,4.8.0)` 会拒绝正式 `4.8.0`，混合双端需要协调升级。
- 主 `NetEnvelope` v2 与 Realtime v1 不变，不提供运行时协议协商或降级路径。
- Qz-Miner 编译依赖经仓库 libs 内置 dev 制品解析，不依赖 JitPack。

## 验证边界

- 本机完整 build（编译、checkstyle、全量 JUnit、assemble）通过；发布资产 workflow 自身执行 test build 作为 CI 证据。
- 运行态（配置页新视觉、选择器面板、成员网格与一步删除等）以用户真机验证为准，发布前尚未完成全量运行态验收。
