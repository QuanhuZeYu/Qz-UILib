## 本次更新

4.2.2 是 4.2.1 之后的小版本更新，新增字符级字体覆盖规则，并补齐配置页字体名自动完成与远程配置同步校验能力。

### 新增

- 新增 `fontSystem.characterFontRules` 字符字体覆盖规则，支持 `字符或范围=字体名` 配置格式。
- 字符选择器支持单字符、`U+XXXX`、`U+XXXX-U+YYYY`、`A-Z` 范围，以及 `disabled:` 禁用前缀。
- `FontMatcher` 在全局字体排序自动匹配前优先尝试首个启用且命中的字符规则，目标字体不存在或不能显示字符时继续回退自动匹配。
- Qz UILib 配置页新增字符字体规则专用编辑器，支持新增、启用/禁用、上下移动、删除、预设、格式校验和重叠提示。
- 字符字体规则的字体名输入复用自动完成输入控件，候选来源为当前字体排序快照。
- 新增通用 `DocumentAutocompleteInputControl` 及候选 provider、输入变更事件和候选选择事件。

### 修改

- 远程配置同步为 `characterFontRules` 增加字段级校验，避免绕过本地专用编辑器提交无效规则。
- 通用列表草稿解析支持逗号、中文逗号、分号、中文分号和换行拆分，字符字体规则远程草稿沿用同一语义。
- 使用文档补充字符字体规则和自动完成输入相关说明，稳定 API 清单同步记录新增能力边界。

## 兼容性说明

- 本版本保持 4.2.1 公共 API 向后兼容。
- 字符字体规则只影响命中字符的字体选择；规则目标不可用时仍回退到既有字体自动匹配链路。
- 重叠规则保持合法，运行时按列表顺序优先使用靠前规则，配置页只提示不阻断保存。
- 当前发布渠道仍为 JitPack + GTNH Maven；源码版本号由 Git tag / GTNH Gradle 推导。
