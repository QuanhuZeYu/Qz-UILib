## 本次更新

**4.5.0** 是 4.2.x 之后的重要次版本，核心是 **scene 新栈全面落地**，并完成 HTML-like 旧栈移除与配置页现代化。UI 主路径从 document / CSS 语义栈，切换为按 `NORTH_STAR` 宪章设计的声明式 scene 栈（signal → 脏标 → layout → Display List → GL）。

> 本版本含**破坏性变更**：旧 HTML-like 业务 API、Forge 配置模板页、远程配置同步等已删除。请按下方「迁移指引」接入。

---

### 一、scene 新栈（核心重构）

#### 架构心智

- **UI = f(state)**：控件用纯静态工厂 + `SceneNode` 组合，无 Widget 继承树。
- **细粒度响应式**：挂载时建立 signal → 节点属性绑定；更新粒度到属性级，列表用 keyed diff（I5）。
- **单向半环**：`PlatformInput → InputRouter → Scheduler.flush → SceneNode 脏标 → Layout → PaintPlan → Replayer`。
- **数据层 / 渲染层分离**：Display List（`PaintCommand` / `PaintPlan`）是唯一契约；渲染层不认识 signal，数据层不认识 OpenGL（I6）。

#### 分层能力

| 层 | 包 / 入口 | 说明 |
|---|---|---|
| 节点与脏标 | `ui.scene.node` | `SceneNode`、四级失效（LAYOUT / PAINT / GEOMETRY / COMPOSITE） |
| 布局 | `ui.scene.layout` | 纯数学布局引擎；`WidthSizing.SHRINK`、flex grow、min/max clamp 等 |
| 绘制 | `ui.scene.paint` | Display List 构建与回放 |
| 运行时 | `ui.scene.runtime` | mount / bind / show / portal / forEach keyed |
| 输入 | `ui.scene.input` | 平台无关输入路由；宿主适配在 `host/lwjgl`（I10） |
| 浮层 | `ui.scene.overlay` | portal / 锚定 / dismiss；R13 浮层显隐独立 signal |
| 控件 | `ui.scene.control` | Button / Toggle / Checkbox / TextInput / Select / Slider / Tab / List / DataTable 等；Primitive + 样式壳 |
| 表单壳 | `ui.scene.form` | `FormPageShell` / `FormFieldShell` / `FormActionBar` / `FormTheme`（零业务依赖） |
| 宿主 | `ui.scene.host` | `AbstractSceneHostWidget` 串 layout → route → flush → paint |

#### 控件与契约

- 控件契约 **R1–R13**（见 `control/package-info`）：静态工厂、create 体一次、样式经 bind 派生、浮层 expanded 独立可写等。
- 宪章不变量 **I1–I12** 贯穿实现与门禁（`scripts/check-scene-boundaries.ps1`）。
- 样板收敛：`SceneControlChrome`、`SceneAutocomplete` 成品壳、`DraftListBridge`（配置列表字段）等。

#### 诊断入口

- `/qzuilib test`：scene 新栈 test hub（Controls / Layout / Form / Scroll / Table 等 demo）。
- 配置页命令：`/qzuilib modernconfig`（本 mod 接入样板）。

---

### 二、旧栈移除

- **整支移除** HTML-like document 栈业务路径（`ui.dom` / 旧 component / document 控件等大批源码与测试）。
- 旧 `ForgeConfigTemplateScreen` 及约 20+ 协作类删除。
- 远程配置同步整支移除（`ConfigTemplateSyncManager` / `RemoteConfigDocumentPages` 等）。
- 通用远程 HTML 门面（`RemoteDocumentPages` / `RemoteHudOverlays` / `ui.remote`）当前**不在源树**；若文档仍描述，以源码为准（见兼容性说明）。

---

### 三、配置页现代化

- 通用框架：`club.heiqi.config`（schema / runtime 三态 Authority·DraftBuffer·Persistence）+ `club.heiqi.config.ui`（`ConfigUI` / `ConfigScreen` / FieldRenderer）。
- 本 mod 接入：`uilib.config.modern`（`ModernConfigEntry` / YAML `config/qzuilib-modern.yaml` / Bridge 回灌静态字段）。
- Forge Mods 按钮：`ModGuiFactory` → `ModConfigGui` → `ModernConfigEntry.createScreen`。
- 默认字段类型：STRING / NUMBER / BOOLEAN / CHOICE / SIMPLE_LIST；path 覆盖可挂专用 renderer。
- 接入文档：`docs/使用文档/02-控件/配置页（ModernConfig）.md`。

---

### 四、其他重要改进（4.2.5 之后累积）

- **字体**：字符硬裁切 / mipmap 羽化约束、characterFontRules + autocomplete、fontSort 拖拽手感与恢复默认策略。
- **输入**：下拉点击 / CLICK LCA、R13 浮层契约、ReactiveScheduler flush 双通道等 scene 输入链修复。
- **工程**：超千行文件拆分、复用性收尾、场景边界与文档悬空引用门禁、agent 协作体系。

## 兼容性说明（请务必阅读）

### 破坏性变更

| 已移除 / 不可用 | 替代 |
|---|---|
| HTML-like `UiDocument` / `ElementNode` 业务建页主路径 | scene：`SceneRuntime` + `Scene*` 控件 + `AbstractSceneHostWidget` / `McScreenBridge` |
| `ForgeConfigTemplateScreen` 及 Spec / 网络同步 API | `ConfigUI.buildScreen` + 自写 GuiScreen 桥；本 mod 见 `ModernConfigEntry` |
| 远程配置同步 API | 能力移除；重建需新设计 |
| 旧 Forge `.cfg` 作为本 mod 配置权威源 | YAML schema 驱动（`qzuilib-modern.yaml`）；`.cfg` 废弃不互通 |

### 仍可用 / 注意

- **网络层** `NetService` 等普通业务网络 API 仍在（与已删远程 UI 门面无关）。
- **字体** `FontService` 等 API 仍在；配置写入路径已走 modern 回灌。
- **4.1 / 4.2 文档中的 LTS 清单** 仍含大量旧栈与远程 UI 条目，**不能**当作 4.5.0 的可用 API 清单；以源码与 `配置页（ModernConfig）.md` 为准。清理任务登记在项目交接。
- 发布渠道仍为 JitPack + GTNH Maven；版本号由 Git tag / GTNH Gradle 推导。

### 迁移指引（他 mod）

1. 声明 `ConfigSchema` → `ConfigManager.bootstrap(file, schema)`。
2. `ConfigUI.buildScreen(manager, input, registryCustomizer, restorePolicyCustomizer)`。
3. 用 `McScreenBridge`（或等价）把 `ConfigScreen` 包成 MC `GuiScreen`。
4. 业务 UI 页面：用 scene 控件与 `AbstractSceneHostWidget` 建屏，勿再依赖 document 栈。

完整对比：[`4.2.5...4.5.0`](https://github.com/QuanhuZeYu/Qz-UILib/compare/4.2.5...4.5.0)
