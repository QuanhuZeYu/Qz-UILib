# Qz-UILib 4.6.3

## 本次更新

- 字体共享准备不再覆盖调用方的 depth test、depth mask 与 depth func；世界文字继承调用阶段的深度状态，screen/HUD 仍由各自 UI host 显式建立二维绘制状态。
- 普通（非潜行）玩家名称与计分板标签在同一世界渲染 pass 内延后到 TileEntity 之后，以 pass-scoped FIFO 回放；每项恢复原调用点亮度坐标，批次以 `finally` 恢复 post-host 坐标并关闭 lightmap。
- scene runtime 关闭时对已绑定 backend 强制应用 `DEFAULT` 系统光标，避免 pointer、text、none 等样式泄漏到后续界面；不改写 `cursorSignal`。
- FML 远端版本范围固定为 `[4.6.2,4.7.0)`，为双方都携带该合同的同 minor 端点提供握手准入。

## 兼容性说明

- 本版本不破坏公共 API；主 `NetEnvelope` 仍为 v2，Realtime `NetRealtimeFrame` 仍为 v1，不提供运行时协议协商、能力探测或降级路径。
- 无 Angelica 时允许标签延后；存在 Angelica 时仅精确版本 `2.1.50` 且兼容 guard 安装完成才启用。未知版本、探针失败或 guard 未安装时降级为原调用点即时绘制。
- FML 范围按 Maven 版本排序解释：会接受排序低于正式版的 `4.7.0-alpha`、`4.7.0-beta`、`4.7.0-rc1` 与 `4.7.0-SNAPSHOT`，拒绝正式 `4.7.0`。
- FML 会双向执行本端 checker。已发布旧 `4.6.2` 未携带该范围，仍按精确版本拒绝正式 `4.6.3`；新端点不能单方面绕过，混合双端需要协调升级。
- 远端缺少 `qz_uilib` 的方向性不变：客户端有而服务端缺少时接受，服务端有而客户端缺少时拒绝。
