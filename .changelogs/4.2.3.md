## 本次更新

4.2.3 是 4.2.2 之后的小版本更新，重点优化下拉选择控件在超长选项列表下的交互性能。

### 优化

- `DocumentSelectControl` 的候选面板改为可视窗口虚拟化渲染，完整选项数据仍保留在控件内部，但 popup DOM 只保留少量可复用 `option` 节点。
- 超长选项列表通过上下 spacer 模拟完整滚动高度，避免一万条候选项一次性创建、布局、绘制和命中测试全部 DOM 节点。
- 鼠标滚动、滚动条拖拽、键盘 Home / End / Up / Down 和程序化选择仍按真实选项索引工作。
- 默认滚轮滚动和滚动条拖拽发生偏移变化后会分发元素 `scroll` 事件，便于内置虚拟窗口和后续自定义滚动内容同步状态。

### 文档与测试

- 使用文档补充 `DocumentSelectControl` 的大列表虚拟化能力边界。
- 新增 select 一万条选项、远端窗口选择、键盘跳转和默认滚动事件分发回归测试。
- 新增 select 大列表虚拟化决策记录，说明该优化保留完整数据语义但只渲染可视窗口 DOM。

## 兼容性说明

- 本版本保持 4.2.2 公共 API 向后兼容。
- `DocumentSelectControl` 的 popup 内部 DOM 不再等同于完整选项列表；业务逻辑应继续依赖控件 API 和 change event 中的真实索引与文本。
- `DocumentSelectControl` 仍是传统单选下拉，不提供搜索、过滤、分组或可变高度选项；需要快速定位超长候选时仍建议使用 `DocumentAutocompleteInputControl`。
- 当前发布渠道仍为 JitPack + GTNH Maven；源码版本号由 Git tag / GTNH Gradle 推导。
