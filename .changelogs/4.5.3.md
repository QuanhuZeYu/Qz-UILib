## 本次更新

**4.5.3-beta-1** 是面向连续 beta 迭代的预发布修订，在 4.5.2 之上收紧配置草稿所有权、修 I3 展示初始化，并完善 stale/并发冲突易用性。

> **不是稳定 4.5.3**：本标签用于连续 beta 验证；稳定公共能力目标归入 **4.6.0**。正式 tag / GitHub Release 尚未执行。

### 新增

- `SaveOutcome.ConflictType`（含 `DRAFT_OWNER_MISMATCH`）+ `isConflict()` / `requiresReload()`
- `ConfigManager` 每实例不可伪造 owner token；`openDraft` 绑定 owner；`save` 在任何 base/validator/persistence 前拒绝 foreign/unbound draft
- `DraftBuffer.hasSameOwner`（不泄露 token 对象）
- `DraftSignalAdapter.replaceDraft`：要求同 owner + schema 路径/类型兼容；失败前完成校验且状态不变
- 独立事务 `baseValues`；ConfigScreen「丢弃编辑并重新加载」；中文冲突反馈

### 行为

- 未绑定 owner 的外部 Draft（如 `DraftBuffer.from(Authority)`）不得写任意 manager（`DRAFT_OWNER_MISMATCH`，`requiresReload=false`）
- **I3**：`SimpleListFieldRenderer` / `FontSortFieldRenderer` 的 render 构建期禁止 `Signal.set`、adapter seed、validation/feedback 清理；prefill 仅为局部只读初值；首次真实列表交互经 `onFieldEdit` 写入 draft
- `seedPresentation` 若保留：不得在 render 调用，且不再清 validation/feedback
- 冲突仍为 `Status.INVALID`；`requiresReload` 时不注入字段 error；不得自动 reload/merge/覆盖 Authority

### 兼容性说明

- 公共构造/工厂二进制与源码兼容；`setDraftAndCurrent` / `seedFieldBaseline` deprecated 仍可用
- 源码版本号仍由 Git tag / GTNH Gradle 推导
- 对比基线：4.5.2（beta 链，非正式 4.5.3 tag）
