# Qz-UILib 5.0.0 候选版本说明

## 本次更新

- 增加宿主无关的 screen/overlay projection composition，同一业务 state 可投放多个 occurrence，各 occurrence 的 scene、focus、capture、hover、cursor 与 animation 独立。
- 增加 Config-scoped Material 主题、Setting Row 页面结构与最小 Motion，首批配置页迁移到新的视觉与交互切片。
- 图片 API 收敛为 snapshot-only `HostImageSource.itemIcon(ItemStack)`；source 创建时复制完整 ItemStack，宿主按需栅格化和缓存静态 icon。
- 图片资源、FBO、动态纹理与运行时 adapter owner 增加失败隔离和可重试清理；item miss 与 cache hit 分别使用完整围栏和窄围栏。

## Breaking 说明

- 删除 4.x LIVE/SNAPSHOT/Slot 双栈、inventory-slot renderer、GuiContainer mixin 与旧万能 item renderer 公共合同。
- Qz-Miner 等消费者必须迁移到 `itemIcon(ItemStack)`；编译坐标目标为 `com.github.QuanhuZeYu:Qz-UILib:5.0.0:dev`。

## 兼容性边界

- 正式 tag 前必须将 FML 远端版本范围恢复为 `[5.0.0,5.1.0)`；正式 `5.0.0` 与后续 `5.0.x` 可在双方都携带该合同时互认，`4.x` 与正式 `5.1.0` 均拒绝。开发/beta 构建保持默认精确版本检查。
- 主 `NetEnvelope` v2 与 Realtime v1 不变，不提供跨 major fallback、运行时协议协商或 Java API 兼容承诺。
- 版本身份仍由不可移动 Git tag / GTNH Gradle 推导；本候选说明不代表 `5.0.0` tag、Release 或 JitPack 制品已经存在。
