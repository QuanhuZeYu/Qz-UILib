# Qz-UILib 4.9.0 版本说明

## 本次更新

- 控件字号全面动态化：任意控件用同一套入口调字号 —— 挂载式控件 `rt.mount(parent, Xxx.create(rt, props)).fontSize(int|signal)`、浮层各自入口（Dialog `ScenePortalHandle.fontSize` / 右键菜单 `SceneContextMenu.Handle.fontSize` / 通知 `SceneToast.defaultFontSize`）、页级 `rt.setDefaultFontSize`；控件内建文字自动跟随，字号成为布局与绘制的同源真值。
- 字号是可继承的声明：父节点声明一次、整棵子树生效，按父链就近竞争解析为四层真值（显式值 / 作用域 / 环境默认 / 回落）；`getFontSize()` 即生效值，`getExplicitFontSize()` 返回本节点自有显式声明（未声明时为空），沿父链解析出的声明值用 `declaredFontSize()`；需要隔离就在子节点重新声明一层。
- 用户字号倍率：`rt.setFontScale(100..200)` 统一放大界面文字，几何同步跟随 —— 段宽、行高、单元高等由字号派生，不再出现「字大了、框没大」（VirtualGrid 固定轨道 stride 为例外，已在实现中登记）。
- 受限槽位溢出策略：DataTable 表头与只读单元格、KeyValueMap 表头、ObjectField 标签槽改用省略号 + 单行约束，不再静默截断；自定义单元格渲染器可通过 `CellContext.contentWidth()` 读取可用宽。
- scene 文本输入底层能力补齐：框选（双击选词、三击选行、跨行拖选、Shift 扩展）、剪贴板（Ctrl+C/X/V 与平台降级链）、词跳转（Ctrl+左右 / Ctrl+Backspace/Delete）、caret 闪烁、水平滚动与 caret 跟随。
- TextArea 软换行：逻辑行按视口可用宽拆为视觉行，选区、上下移动、Home/End 与点击命中全部按视觉行语义。
- 文本控件 Undo/Redo：默认 100 条历史、连续输入 500ms 合并，Ctrl+Z / Ctrl+Y 或 Ctrl+Shift+Z。
- 三类浮层控件：`SceneContextMenu` 右键菜单（指针锚定 + 边缘翻转、键盘导航、输入框默认菜单含复制/剪切/粘贴/全选/撤销/重做）、`SceneDialog` 模态对话框（Tab 环限定在对话框内、ESC/按钮关闭、命令式 alert/confirm）、`SceneToast` 非模态通知（堆叠队列、按内容宽度收缩居中、到期淡出）。
- 现代富文本标签语法：`<color=#RRGGBB|命名色>` / `<b><i><u><s>` / `<size=N>` / `<br>`，任意嵌套、宽容解析（未知标签字面保留），测量 / 裁剪 / 换行 / 绘制全链路贯通；新增 `SceneLabel` 通用文本组件。
- 字体管线优化：世界加载上传泵（进入世界第一帧文字纹理解就绪）、字符页批上传与失败整页隔离、reload 惰性重置（内存约 123MiB -> 29MiB）、STB skyline 紧密装箱、渲染热路径逐 glyph 调用消除；atlas 参数化（`glyphInkPadding` / `atlasTextureScale` 可配），`FontRuntimeStats.slotsPerPage` 口径改为各页最大已分配槽位数。
- 帧时序改进：锚点不可见 overlay 的 dismiss 同帧生效（不再滞后一帧）；motion completion flush 合并进 SETTLE 首轮。
- 新增启动侧唯一权威判据 `LaunchSide`（客户端 / 专用服务端 / 未知），字体渲染门禁与网络主线程门禁共用。
- 清理：移除 scene 演示测试台与 `/qzuilib test`、`/qzuilib scene_test` 子命令（保留 `/qzuilib modernconfig` 配置页入口与网络自检三件套）。
- 兼容性修复：富文本显式大字不再侵入相邻行（行高按行内最大显式字号、逐行累计）、span 字号双重放大修复；专用服务端不再为一句恒 false 的判断常驻约 150MiB 字形表。
- 开发基线适配 GTNH 2.9.0-beta-3，并让玩家标签延后路径同时兼容两档基线：beta-2（Angelica 2.1.50）与 beta-3（2.2.10）下用同一份 jar 都能启用该特性（此前只在 beta-2 生效，在 beta-3 会因版本门失配而降级为即时绘制）。

## 兼容性说明

- 字号语义变化（相对 4.8.0）：`SceneNode.getFontSize()` 由「本节点字段原值」改为「生效值」（含父链继承与用户倍率）；需要本节点自有显式声明用 `getExplicitFontSize()`（可空），沿父链解析出的声明值用 `declaredFontSize()`。`setFontSize` 增加范围校验（越界抛 `IllegalArgumentException`）。
- 字号继承语义扩展：声明会被整棵子树继承（旧口径「不做子树继承」作废）；没有「取消继承」原语，隔离靠子节点重新声明一层。
- search 4 个 public 字号常量值未变（12），但语义由「显式字号」降级为「层 4 回落值」（`setFontSize` -> `setFallbackFontSize`），属行为变化。
- 专用服务端启动修复（issue #71）：无系统字体的精简镜像此前在预初始化阶段崩启动，现渲染骨架只在客户端引导；同族审计另修复越界配置值崩启动、未知 `netTransport` 值崩启动、CLIENT 侧主线程任务「承诺执行但永不执行」等问题。
- FML 远端版本范围固定为 `[4.9.0,4.10.0)`：已发布旧 4.8.0 携带 `[4.8.0,4.9.0)` 会拒绝正式 4.9.0，混合双端需要协调升级。
- 主 `NetEnvelope` v2 与 Realtime v1 保持不变，不提供运行时协议协商或降级路径。
- 内部收口（对下游可见度低但会改变行为推导）：删除旧字号通道 `SceneControlTypography` 与 42 处手工接线，字号读取收敛为单点；`RichTextTagParser.MIN/MAX_FONT_SIZE_PX` 迁至 `FontSizeLimits`（按 4.0 分支快照编译的下游需同步引用）。
