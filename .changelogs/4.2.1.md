## 本次更新

4.2.1 是 4.2.0 的热修版本，修复 Java 21 环境下 HUD 输入链路在多人游戏菜单页触发原生文本框反射深扫并崩溃的问题。

### 修复

- 修复 Qz-Team 等宿主注册 HUD 后，点击多人游戏进入 `GuiMultiplayer` 时，Qz-UILib 仍在菜单页创建 HUD 输入上下文并调用 `UiNativeTextInputInspector.hasFocusedTextInput(...)` 的问题。
- `UiHudDocumentHost.createInputContext(...)` 现在只会在 HUD 交互输入真实启用时探测宿主原生文本框焦点，`MENU` 与 `INGAME` 场景不再触发原生输入反射扫描。
- 补充 HUD 输入上下文回归测试，覆盖 `MENU` / `INGAME` 即使误传交互启用也不会进入原生文本框焦点探测。

## 兼容性说明

- 本版本保持 4.2.0 公共 API 向后兼容，仅收窄 HUD 内部输入探测时机。
- 多人游戏、主菜单、选图页、Forge 配置页等菜单类屏幕仍保持 HUD 隐藏与输入不接通语义。
- 当前发布渠道仍为 JitPack + GTNH Maven；源码版本号由 Git tag / GTNH Gradle 推导。
