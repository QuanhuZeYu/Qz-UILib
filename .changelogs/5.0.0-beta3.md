# Qz-UILib Minecraft 5.0.0-beta3

基于 `5.0.0-beta2` 的预发布更新，继续覆盖 Minecraft 1.7.10、Forge 1.12.2、Forge 1.16.5 与 NeoForge 26.3 宿主。本次更新引入原版文本不可变码点映射支持，修复 SDL 输入来源清理与下划线/删除线偏移，并将 Forge 1.7.10 的可选第三方 Mod 接入拆分至独立的 `Qz-UILib-Compat`。

## 主要更新

### 文本渲染与输入改进

- **不可变码点映射**：原版文本入口支持不可变码点映射，文本测量、单字符宽度计算、裁剪、换行与绘制共用同一套映射规则，完整保留业务原文与来源范围，并在资源重载时正确更新缓存代际（#53）。
- **装饰线基线修正**：修正原版字体下划线与删除线的基线偏移问题。
- **SDL 输入源隔离**：SDL 组字与采集来源绑定，停止与恢复时沿原生队列结束旧来源，避免迟到文本误入新焦点目标。

### 资源同步与宿主架构调整

- **后台资源准备与镜像**：字体与 Unicode 准备过程捕获所属资源代并在后台执行，经所属 owner 发布，关闭时自动结算既有队列。各宿主外层资源包从正式 Core 产物同步镜像字体、Unicode 与许可证文件，Core 类保持独立。
- **可选 Mod 接入拆分**：将可选第三方 Mod 接入从主宿主迁出。主宿主仅保留中性的 `MinecraftHostExtension` SPI；Angelica/Iris、lwjgl3ify/RFB 与 AE2 的接入移交至独立组件 `Qz-UILib-Compat` 提供（#69）。未安装相关 Mod 时沿原版路径运行。
- **安装身份校验**：安装清单精确记录实际安装 JAR、Maven 依赖身份与 SHA256 摘要，避免仅凭文件名猜测组件配套关系。

## 升级或安装说明

- **整套匹配安装**：请按目标 Minecraft 宿主安装整套匹配的 `5.0.0-beta3` 产物（Core、Platform、Minecraft 需统一为 `5.0.0-beta3`，避免混用旧版本）；`manual` 人工测试包和媒体包仍作为独立可选附件提供。
- **Forge 1.7.10 / GTNH 兼容组件安装**：在 Forge 1.7.10 / GTNH 环境中使用 Angelica、lwjgl3ify/RFB、AE2 或 GTNH 私用字符映射的用户，需另外安装配套的 `Qz-UILib-Compat 1.0.0-beta1`。
- **存量字体配置提示**：已保存完整 `font.candidates` 列表的用户不会自动获得新增默认候选字体。如需显示炼金符号等字符，请在字体设置中手动将 `builtin:noto-symbols` 添加至列表末尾（保留已有排序）。
- **开源许可**：项目自有代码继续采用 MIT 许可证；随包分发的 `Noto Sans Symbols` 遵循 SIL OFL 1.1 许可证，其余第三方组件保留各自原有许可。
