# Qz-UILib 4.11.0

**本版要点**

- **GTNH 兼容面扩张**：**2.8.0 / 2.8.4** 正式纳入支持面（Angelica `1.0.0-beta57` / `1.0.0-beta66b`、lwjgl3ify `2.1.15` / `2.1.16`、Hodgepodge `2.6.108` / `2.6.112`），并修掉两处**只有该世代才暴露**的缺陷：lwjgl3ify 文本接管按宿主世代分派（2.x 世代保留 MC `keyTyped` char 合成，不再被误判为「已接管」）、HUD 液态玻璃黑底（Angelica HUD 缓存把 HUD 渲染进独立 framebuffer，背景滤镜在其中采样不到世界画面）。
- **headless 出图与验收设施**（devtools，**不随发布 jar**）：GL 离屏出图 + 分辨率 / 页面 / 外观 / 环境四条矩阵轴 + 纯代码输入设备与输入脚本 + 目标寻址（节点地址、场景树投影、按文本查找）+ 失败语义与退出码分流 + 命令面 × 像素面交叉验证。
- **环境端口 `ui.env`**：宿主环境事实从进程级静态读取改为**注入式端口**（`UiEnvironment` + 缺席实现 + 生产适配器 `ProcessUiEnvironment`），代际读取点全部改走端口。
- **字号域收口**：`gameCharSize` / `glyphGenerationSize` 语义精确化（含配置键改名与兼容迁移）、字号域下界放开到 0（倍率 0..200）、「声明字号 → 生效字号」解析式收敛到唯一出口。
- **配置面**：schema 新增 INTEGER 字段类型（整数落盘形态 + 旧浮点值兼容读回），配置页装配与 MC 宿主拆类（`IntegerFieldRenderer` / `ModernConfigAssembly`）。

## 兼容性与升级动作

- **兼容边界：本版含公共面删除与签名变更**（minor 级，维持 4.9.0 / 4.10.0 的既有做法——含公共面删除的批次仍走 minor，major 只留给不兼容重构）：
  - `club.heiqi.uilib.font.FontRuntimeSettings`：`getCharSize()` → `getGameCharSize()`、`getAwtCharSize()` → `getGlyphGenerationSize()`；构造器前两个 `double` 形参随之改名（`charSize` / `awtCharSize` → `gameCharSize` / `glyphGenerationSize`）；
  - `club.heiqi.uilib.ui.scene.control.search.PickerMetrics`：`fontSizeFor(int, int)`、`clampPanelDeclaredFontPx(int)` 删除（字号解析收敛到字号域唯一出口）；
  - `club.heiqi.config.ui.field.PickerIconResolver.of(ValueEditorProvider)`、`club.heiqi.config.ui.field.PickerRevisionBridge.forSource(PickerCandidateSource)`：改为接收环境端口的重载（`of(ValueEditorProvider, ResourceEnvironment)` / `forSource(PickerCandidateSource, UiEnvironment)`）；
  - `club.heiqi.uilib.ui.diagnostic.UiPerformanceMonitor.beginFrame(...)` / `beginInputRouting(...)`：签名变更（诊断开关单源收敛）；
  - `club.heiqi.uilib.ui.scene.host.SceneHostAssembly.assemble(...)`、`club.heiqi.uilib.ui.scene.runtime.SceneRuntime` 构造器：签名变更（环境端口注入）。
  - 新增面见下方「本次更新」；公共面增删的逐条登记以 `docs/使用文档/公共API稳定清单.md` 为准。
- **FML 远端范围**：`MyMod.acceptableRemoteVersions` 由 `[4.9.0,4.11.0)` 收紧并抬界为 `[4.11.0,4.12.0)`——本版含公共面删除，按《发布流程》§1/§2 不沿用「区间不动」的默认；**4.11.0 与 4.10.x 及更早版本不承诺混用，客户端与服务端需成对升级**（同版本之间、以及 4.11.x 内部相互接受）。
- **配置持久数据**：字号域配置键随语义精确化改名，旧键按兼容迁移读回、回写新键；新增 INTEGER 字段类型只影响新声明，既有 yaml 的键、类型与写入格式不变；`general.chatFrame` 等既有键语义不变。
- **网络协议**：本批无协议相关改动，协议与通道注册表形态不变。
- **升级动作**：只需把客户端与服务端**同时**升到 4.11.x；无需手工改配置或迁移数据。若使用自定义字体配置，字号域旧键会在首次加载时被迁移（原值保留）。
