# 文档导航

本目录按四条路线组织项目文档，面向不同读者和用途。

## 文档路线

| 路线 | 目录 | 面向 | 说明 |
|------|------|------|------|
| 用户 README | [../README.md](../README.md) | 所有人 | 项目简介、快速开始、环境要求 |
| 外部开发者使用文档 | [使用文档/](使用文档/README.md) | 接入方 Mod 开发者 | 入门、控件、宿主集成、诊断入口 |
| 内部开发者文档 | [开发者文档/](开发者文档/README.md) | 框架维护者 | 架构方向、审查报告、错误记录、规格 |
| AI Agent 记忆区 | [AI记忆文档.md](AI记忆文档.md) | AI 协作 Agent | 长期稳定边界、导航规则、验证前提 |

## 各路线职责边界

- **用户 README**：项目第一印象，只放最核心的信息，不堆细节。
- **使用文档**：对外公开的接入手册，内容必须与实现一致，不能比实现更乐观。
- **开发者文档**：内部协作用，包含技术方向、审查结论、错误教训、规格定稿等。
- **AI 记忆文档**：只保留跨任务长期稳定的导航和边界信息，不承担流水账。

## 写入原则

- 新增对外能力 → 同步更新 `使用文档/`
- 新增审查结论 → 写入 `开发者文档/reviews/`
- 发现可复现错误 → 写入 `开发者文档/errors/`
- 长期稳定边界变化 → 更新 `AI记忆文档.md`
- 临时调试记录 → 不沉淀到文档
