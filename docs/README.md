# 文档导航（控制论闭环组织）

本目录只持久化五类文档：设定值、控制律、传感、反馈、诊断。纠偏是检测到误差后的动作机制，规则集中在 `AGENTS.md`，不单设目录。按"需要什么"对号入座，不要把本文件当知识仓库。

> **最高准绳**：根目录 [NORTH_STAR.md](../NORTH_STAR.md) 是 UI 系统中心思想宪章（设定值层锚），凌驾于以下所有文档。任何架构决策、性能优化、API 取舍都须先与它对照；冲突时按其《修订纪律》登记偏离。

## 读取顺序（控制论）

1. **定目标** → 设定值层对照信条与不变量 I1-I13
2. **查执行规范** → 控制律层（Git/命名/构建/编排）
3. **验证产出** → 传感层（跑门禁 + 测试体系）
4. **有误差** → 反馈层（交接看未收敛项 / 错误预防查通则）
5. **查系统健康** → 诊断层（技术债 / 项目结构）

## 写回纪律

权威源为 [AGENTS.md](../AGENTS.md) 反馈层·文档协作，本文件不重复。要点：

- 业务状态/阻断项/待决策事项 → `反馈层/交接.md`；实时 Git 分支/HEAD/工作区 → `git branch --show-current` / `git rev-parse HEAD` / `git status`
- 宪章指针/硬约束/边界现状 → `设定值层/`
- 执行规范（编排/命令/约定/发布）→ `控制律层/`
- 测试体系/门禁脚本 → `传感层/`
- 错误预防通则/决策回写 → `反馈层/`
- 技术债/项目结构/Config 模块 → `诊断层/`
- 对外能力变化 → `使用文档/`
- 临时调试、一次性试验结论不沉淀
