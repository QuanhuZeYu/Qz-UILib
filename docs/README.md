# 文档导航

本目录按四条路线组织项目文档，面向不同读者和用途。

> **最高准绳**：根目录 [NORTH_STAR.md](../NORTH_STAR.md) 是本项目 UI 系统的中心思想宪章，凌驾于以下所有文档之上。任何架构决策、性能优化、API 取舍都必须先与它对照；文档/代码与宪章冲突时，先改对照宪章，再按其《修订纪律》登记偏离。

## 文档路线

| 路线 | 目录 | 面向 | 说明 |
|------|------|------|------|
| 架构宪章（最高准绳） | [../NORTH_STAR.md](../NORTH_STAR.md) | 所有架构参与者 | UI 系统中心思想、核心信条、关键不变量、决策检查清单 |
| 用户 README | [../README.md](../README.md) | 所有人 | 项目简介、快速开始、环境要求 |
| 外部开发者使用文档 | [使用文档/](使用文档/README.md) | 接入方 Mod 开发者 | 入门、控件、宿主集成、诊断入口 |
| 内部开发者文档 | [开发者文档/](开发者文档/README.md) | 框架维护者 | 架构方向、错误预防通则、规格 |
| AI Agent 记忆区 | [AI记忆文档.md](AI记忆文档.md)、[记忆/](记忆/README.md) | AI 协作 Agent | 总导航、当前态、长期事实、决策记录 |

## 各路线职责边界

- **架构宪章**：UI 系统的中心思想与硬约束，凌驾于其它所有文档之上；只承载信条、不变量和取舍原则，不记录阶段流水或实现细节。其修订成本被有意抬高，信条与不变量的改动属重大架构变更。
- **用户 README**：项目第一印象，只放最核心的信息，不堆细节。
- **使用文档**：对外公开的接入手册，内容必须与实现一致，不能比实现更乐观。
- **开发者文档**：内部协作用，包含技术方向、审查结论、错误教训、规格定稿等。
- **AI 记忆区**：`AI记忆文档.md` 只保留总导航，`记忆/` 分层承载当前态、长期事实和关键决策。

## 写入原则

- 新增对外能力 → 同步更新 `使用文档/`
- 新增错误预防通则 → 写入 `开发者文档/errors/README.md` 对应类别
- 阶段目标、阻塞、下一步变化 → 更新 `记忆/当前态/`
- 长期稳定边界、目录结构、命令变化 → 更新 `记忆/长期事实/`
- 关键方案取舍 → 写入 `记忆/决策/`
- 临时调试记录 → 不沉淀到文档
> 完整写回纪律（含写回时机与自检）见 AGENTS.md 第 4 节
