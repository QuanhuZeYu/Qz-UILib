# 全库默认液态玻璃样式实施规划

> 状态：规划已落盘，实施未开始。本文和配套任务单不代表功能已交付。
> 调研基线：Qz-UILib 分支 `4.0`，提交 `8963f48a`。执行前必须读取实时 Git 与源码；不得重置到本基线。
> 用户目标：UILib 自带页面、通用控件和模板配件默认采用 iOS 液态玻璃风格。
> 本次授权范围是编写实施规划；后续由用户指定实施启动。本文不改写仓库 AGENTS.md 的公共 API、架构与发布边界。

配套文件：[小模型任务单](任务单-全库默认液态玻璃样式.md)。主代理负责契约、共享文件、集成与验收；小模型一次只领取其中一个任务实例。

## 1. 最终目标与完成定义

完成后，调用方使用现有普通控件工厂和默认页面模板，无需逐节点添加 backdrop，就得到统一的液态玻璃外观。模板内部生成的按钮、输入框、选择项、弹层、错误提示同样消费主题。

必须同时满足：

- 无显式主题时使用默认液态玻璃；默认采用深色配方起步，保留浅色配方能力，避免同时开展自动背景感知算法。
- 显式指定的控件配方、页面主题、聊天玻璃设置继续生效；关闭滤镜具有可读的替代底色。
- 换肤不丢失文本、选区、光标、滚动位置、选中值、焦点或 HUD 缩放状态。
- 同一内容多次投放时，节点、交互、动画和生命周期互相隔离。
- 代码与构建验收、实际 GPU 像素验收、游戏宿主视觉验收分别记录；缺一项不能声称全目标完成。

默认风格覆盖控件和语义表面。正文、图片、图表、富文本颜色与普通布局节点仍表达内容；不要求每个节点各自模糊背景。

### 3.1 既往缺陷必须保住

- 未提供初值的 Computed 在首次 flush 前可能为 null。不能在构造绑定器时直接解引用；通过 effect 应用初值，并加入首次挂载验证。
- 玻璃大面板边缘吸收已改为基础材质吸收率的相对增量。不得恢复独立深色 alpha，也不得用全局提亮掩盖暗边。
- blur=0 的液态玻璃仍可有折射和材质；必须按 UiBackdrop 现行 isActive 语义验证，不能假设所有配方在 blur=0 都发命令。
- borderWidth=0／透明边色与关闭 backdrop 是不同操作；前者不代表关闭全部材质高光。
- HUD 公共按钮的 scaleControls 默认开，倍率状态归 HUD 注册；主题不改变 opt-out、倍率或布局预算。
- 回调里卸载控件是合法场景；保留事件派发快照与键盘 pressed 清理逻辑。
- 位图图标不受 textColor 染色。优先使用既有图标资源或明确的文本前景绑定，不临时添加图片染色协议。

## 4. 主代理先定案的主题契约

本节是实现必须满足的语义；Java 类名、签名及存储接缝由任务 G00 在阅读实时源码后冻结。不得把下列概念名当作已经存在的 API。

### 4.1 来源优先级

`显式控件配方 > 显式局部/页面主题 > runtime 默认主题 > UILib 默认液态玻璃主题`。

- “没有配方”与“明确关闭滤镜”必须能够区分；不能用同一个 null 同时表达两者。
- 现有 SceneGlassButtonStyle.backdrop=null 继续表示关闭滤镜，不悄悄解释为继承。
- 旧 Props 构造、工厂重载和显式 FormTheme 调用继续可编译；不得随意增加 record 分量或改变旧方法含义。
- 普通 Label 的默认前景与显式 color 必须可区分；显式传入与旧默认相同的色值也必须保留。不得通过 color==TEXT_PRIMARY 猜测调用意图，此兼容接缝由 G00 冻结。
- 保留显式实色外观的选择；默认视觉改变属于本目标，旧显式配方不被默认主题覆盖。
- 不建立一份独立于主题的“聊天全局配置副本”。聊天配置只在聊天适配层转为局部主题覆盖。

### 4.2 数据和绑定

- 主题／配方用不可变值对象及值相等；主题通过 ReadableSignal 消费，更新只驱动受影响的外观。
- 主题消费方属于 control/form 或专门外观组合层。paint 保持自包含命令及纯值计算，不能订阅信号。
- 颜色、模糊、折射、边框等变化不得无故触发布局；明确的字体与尺寸变更才允许 layout 失效。
- 绑定器安装一次。替换主题时重算配方，不重新调用控件工厂，不累计动画轨道。
- 全局默认不持有某个页面的节点、Owner、runtime；独立 runtime 与局部覆盖不得串色。

### 4.3 延迟构建与弹层

主题作用域必须覆盖 mount、show、forEach 后续插入、portal 打开/重开。只在同步 builder 外套 ThreadLocal、退出后丢失主题的方案不合格。

portal 捕获来源主题信号而不是当时的颜色快照；打开后仍响应来源主题更新。Toast 若由 runtime 服务延后构建，也要明确每条消息的主题来源。页面关闭后不得残留监听。

G00 应优先比较显式传递主题与最小 runtime 接缝，选择能覆盖上述场景的最小实现；不可先建一个通用 CSS 级联引擎。涉及 Owner/runtime 等共享文件的修改只由基础任务负责人执行。

### 4.4 材质角色

| 角色 | 默认职责 | 层级规则 |
| --- | --- | --- |
| 页面主面板 | 温和折射、受控染色、稳定文字对比 | 页面背景／遮罩先协调，不能在玻璃前先画满不透明根背景 |
| 工具栏／导航底座 | 薄玻璃、清晰轮廓 | 与内容区分开；小按钮复用已有倒角能力 |
| 输入表面 | 弱光学效果、明确焦点、清晰文字与选区 | 文本不模糊，输入区无需套按钮按压动效 |
| 列表／表单分组 | 低干扰内容底座 | 优先一组共享表面，行使用轻量状态覆盖；虚拟化继续生效 |
| 菜单／对话框／提示 | 独立浮层与稳定可读性 | 遮罩和玻璃只各负责一次，不额外重复采样整页 |
| 滑块／开关／选中指示 | 小尺度高光与强调色 | 进度和选择状态不能只靠透明度区分 |
| 无滤镜替代 | 同一套圆角、前景、状态色 | 不支持 shader 时也可阅读和操作；不等同完整液态光学 |

初始参数从既有 DARK_THIN 和已通过验证的按钮配方起步；在大面板、小控件和嵌套场景验收后集中调整。叶子任务不各自调 shader 或复制魔数。

| 表单模板 | FormPageShell、FormFieldShell、FormLabeledControl、FormActionBar | 标题、字段、辅助文字、dirty/error、操作区统一 |
| 配置页 | config/ui/ConfigScreen、ConfigTheme 及所有当前注册 FieldRenderer | 真实默认配置页与编辑弹层使用新主题 |
| Playground | 当前 PlaygroundPageRegistry 所有页面及公共导航外壳 | 外壳默认玻璃，内容测试样本保留语义 |
| GlassLab | 页面外壳 | 实验样本继续保留显式材质，不能把 classic/关闭滤镜对照统一成液态 |
| 聊天与 HUD | 聊天面板、气泡、输入框、动作与公共工具 | 既有设置、倍率、关闭滤镜和自定义按钮配方继续有效 |

Label、富文本、分隔线、状态徽标和滚动容器按用途消费前景／表面角色，不机械追加玻璃。字体图集、内容图片、markdown/LaTeX 样本和 primitive 裸行为不是换肤对象。

页面清单必须沿真实注册与装配调用核对；仅搜索类名包含 Page/Screen 不能证明覆盖完整。ModernConfigScreen 目前是宿主桥，优先迁移其实际消费的 ConfigScreen，避免无必要地改宿主。

### 6.2 串行与并行

- 默认串行交付。共享同一工作树时，最多允许一个写代码的执行者；其他代理可只读审查。
- 需要并行时，主代理提供独立工作树/检出目录，确认完整包含依赖提交，分配无重叠文件。不得让并行任务共用 Gradle build 输出目录。
- 每个实例交付后主代理检查 diff、行为测试与复用情况。发现复制原版 GUI 或绕过 primitive，直接要求在原任务范围内重构。
- 接口未冻结时，不得让叶子任务猜方法名或建立占位 API；执行者报告具体缺口，主代理修复基础后继续派发。
- 集成提交改变了测试所覆盖的源码后必须重新验证。分支各自成功不能替代集成 build。
- 代码验收通过即可解锁后续依赖实例；GPU/宿主证据可在同类表面或整页集成阶段集中补齐。不得要求用户逐控件进游戏确认；总目标的最终完成仍以 G19 验收为准。

## 7. 验证与验收

### 7.1 每个实例的最低证据

- 至少覆盖默认工厂路径和显式覆盖路径，而不只验证新建样式类的 getter。
- 验证该控件相关的输入行为、状态反馈、主题更新和卸载清理。优先扩展既有行为测试，避免镜像实现的测试。
- 观察实际 PaintPlan/replay：预期采样的语义表面确有 BACKDROP，且没有紧随其后的不透明底盖；轻量行不要求独立 BACKDROP。
- 纯换肤不更换根节点或丢失现有编辑/滚动状态；变化只造成合理失效。
- 完整 `gradlew.bat build` 成功，之后才创建本地提交；检查 diff --check。失败须定位修复，不能删除旧断言。

### 7.2 跨组件场景

| 场景 | 必须观察 |
| --- | --- |
| 深色、浅色、纹理复杂的背景 | 正文/占位/禁用/错误可读；不整圈染黑或发白 |
| 大面板、小按钮与窄输入框 | 玻璃强度与尺寸协调，保留圆角抗锯齿 |
| 主题切换 | 原节点、文本、选区、焦点、滚动与选中值保留 |
| 隐藏后显示、列表后插入、菜单后打开 | 新节点使用来源主题最新值 |
| 两个 runtime 与同内容多次投放 | 覆盖互不串扰，分别卸载不影响对方 |
| 键盘与指针 | Tab、Enter/Space、方向键、拖动、失焦、禁用、取消与旧行为一致 |
| 关闭滤镜／关闭动效 | 不丢失文本或反馈；动效关闭立即到目标态 |
| 玻璃面板内打开下拉或对话框 | 主题不丢失、层级可读、无黑底采样、无异常重复模糊 |
