# 历史报告

本目录存放**已交付、已否决或已收口的历史材料与专项记录**：规划、任务单、契约、台账、审计包、验收、审查与任务笔记。
这里的材料只证明当时做过什么、验证到什么程度，**不构成现行要求**；现行规范见 [规格文档/](../开发者文档/规格文档/README.md)，
工程边界见 [AGENTS.md](../../AGENTS.md)，分区与文档职责分工见 [docs/README.md](../README.md)。

## 分区

| 子目录 | 内容 |
|--------|------|
| [专项施工/](专项施工/) | 专项施工包：规划、任务单、冻结契约、逐实例台账、审计包、验收记录与施工手册（液态玻璃专项、scene 文本输入能力补齐、投放职责聚合方案历史主体） |
| [审查/](审查/) | 架构、模块与设计审查报告（原 `开发者文档/架构审查/` 整体移入；含配置页设计复审） |
| [规划与设计/](规划与设计/) | 已交付或已收口的规划与设计材料（Markdown 渲染器与表格、LaTeX 排版能力建设、聊天工具栏与 HUD 布局编辑、HUD 虚拟窗口、现代配置实现蓝图、物品渲染上层替换大纲、网络自检规格母本） |
| [任务笔记/](任务笔记/) | 跨轮恢复用的专项任务笔记（并发计时类测试专项） |

## 使用约定

- 子目录按材料类别划分，不按时间；新归档材料进对应类别，不新开逐文件索引。
- 归档不改写原文：各文件头部状态行即其收口状态，未开工批次与未执行的真机/GPU 验收项如实留在原处。
- **归档件不构成现行施工依据**：需要引用时直接引其真实路径，只作为「当时做过什么、验证到什么程度」的证据，不作为当前规范或施工口径。
- 原文自述「待裁定 / 未开工 / 待验」的批次不随归档关闭：后续要启动时**按该文件自述取用**，并重新确认现行口径；本目录不另行维护进度。
