# 2026-05-09 HTML-like 滚动后 hover 状态未同步

## 错误现象

- 鼠标悬停在元素上后使用滚轮滚动，旧元素仍保持 hover 高亮或 tooltip。
- 鼠标已经进入新元素区域，但 hover 没有重新触发。

## 触发场景

- `HtmlLikeDocumentWidget` 发生滚轮滚动，内容相对鼠标位置变化。
- 滚动条拖拽改变内容位置时也会出现同类问题。

## 根本原因

- hover 命中只在鼠标移动时更新。
- 滚轮滚动和滚动条拖拽改变了布局偏移，但没有在偏移生效后重新做 hover 命中。

## 修复方案

- 滚轮消费后按当前鼠标位置重新命中 hover。
- 鼠标拖拽滚动条时先更新滚动状态，再重新命中 hover。
- 增加回归测试覆盖滚动后 hover 切换。

## 预防措施

- 任何会改变内容相对鼠标位置的输入分支，都必须在位移生效后刷新 hover。
- 新增滚动交互时同步补“旧目标退出 hover”和“新目标进入 hover”两类测试。
