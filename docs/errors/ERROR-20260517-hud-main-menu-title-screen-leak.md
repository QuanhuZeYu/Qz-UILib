# HUD 在新版主页 TitleScreen 上误显

## 错误现象

- HUD 浮窗在游戏主页上意外显示，用户在主菜单也能看到原本只应出现在游戏内的 HUD 内容。

## 触发场景

- 当前宿主界面是新版 Minecraft 游戏主页，类名可能为 `net.minecraft.client.gui.screens.TitleScreen`。
- HUD 可见性判断仍只识别旧版 `GuiMainMenu`，没有覆盖新版主页类名。

## 根本原因

- HUD 屏幕分类逻辑按类名白名单识别菜单页，但遗漏了新版主页 `TitleScreen`。
- 可见性门槛依赖分类结果，菜单页没有被正确归入 `MENU` 时，HUD 就会继续参与绘制。

## 修复方案

- 将 `TitleScreen` 相关类名纳入菜单分类。
- 增加可见性回归测试，确认 HUD 在主菜单类屏幕上不再显示。

## 预防措施

- 后续处理屏幕分类时，优先按“旧版类名 + 新版类名 + 测试用类名”三层覆盖。
- 对任何依赖屏幕分类的 HUD/输入门槛，都补一条主菜单回归测试，避免版本切换时再次漏判。
