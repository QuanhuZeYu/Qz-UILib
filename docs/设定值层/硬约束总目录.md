## 3. 布局跨类同步契约

> 权威源：源码类头 Javadoc，改布局引擎必读

- **ConstraintResolver ↔ SizingCalculator ↔ FlexLayouter 三处同步**：computeWidth 优先级链/三向锚定，改一处必须同步另两处，漏改即布局求解错乱 → `ConstraintResolver.java` / `FlexLayouter.java` 类头跨类契约段
- **I7 重算收敛铁律**：增量失效重算集合守恒，FlexLayouter 耦合不变式（斩断自反馈类型约束） → `FlexLayouter.java` 类头斩断自反馈类型约束段

## 4. paint/node 铁律

- **I6 PaintCommand 红线**：paint 命令对象禁止持有 SceneNode / 节点引用，构建期固化、回放期零节点反查 → `PaintCommand.java` 类头核心红线段
- **SceneNode 禁重写 equals/hashCode**：identity 语义锚定 measuredTextNodes 正确性，任何子类亦不得重写 → `SceneNode.java` 类头禁止重写 equals/hashCode 段
- **滚动仅标 GEOMETRY**：滚动绝不标 LAYOUT/PAINT，I7/I8 性能根基 → `SceneNode.java` 的 `scrollOffsetY` 字段 Javadoc 与 `setScrollOffsetY` 方法

## 5. scene 状态化禁区

> 权威源：决策文档

- **拖拽状态 signal 化边界**：拖拽**业务真值**（落点 index 等）仍当场按事件坐标算，不做 signal 化读路径；拖拽**视觉预览态**（浮起偏移）允许受控 signal 化，须满足：① owner-scoped 单一 signal（随组件卸载退订）；② 只驱动 COMPOSITE 级 transform（不触 layout/paint，守信条五）；③ 拖拽结束（UP/CANCEL）必 reset 归零 → `docs/反馈层/决策/fontsort-drag-signal-2026-07.md`
- **滚动/focus 不 signal 化**：滚动态、focus 态不做 signal 化（旧决策已删除，事实仍成立）
