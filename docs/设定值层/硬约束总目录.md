## 2. 控件契约红线 R1-R13

> 权威源：`src/main/java/club/heiqi/uilib/ui/scene/control/package-info.java`

- **R1-R12**：控件装配 12 条红线（纯静态工厂/零内部状态/handler 只写 signal/装饰节点 hitTestable(false)/受控控件零缓存/条件渲染走 show 禁命令式挂卸/浮层走 portal 等），违反即阻断合并 → `control/package-info.java:1-148`
- **R13 浮层显隐状态独立可写，禁派生自瞬态交互态**：expanded/open/visible 必须是独立可写 Signal，禁 Computed(focused/...)，否则 DOWN 隐式失焦跨帧掐断致 CLICK 不合成（真因 D1） → `control/package-info.java` R13 段
- **R11 镜像**：overlay 包有 R11 的同步声明（浮层显隐必须经 signal→portal 派生，禁止命令式挂卸） → `overlay/package-info.java:8`
- **R13 镜像**：overlay 包同步声明 R13（浮层显隐 signal 独立可写，禁派生自 focused 等路由瞬态态） → `overlay/package-info.java` R13 镜像段

## 3. 布局跨类同步契约

> 权威源：源码类头 Javadoc，改布局引擎必读

- **ConstraintResolver ↔ SizingCalculator ↔ FlexLayouter 三处同步**：computeWidth 优先级链/三向锚定，改一处必须同步另两处，漏改即布局求解错乱 → `ConstraintResolver.java:37-43` + `FlexLayouter.java:27-35`
- **I7 重算收敛铁律**：增量失效重算集合守恒，FlexLayouter 耦合不变式（斩断自反馈类型约束） → `FlexLayouter.java:37-46`

## 4. paint/node 铁律

- **I6 PaintCommand 红线**：paint 命令对象禁止持有 SceneNode / 节点引用，构建期固化、回放期零节点反查 → `PaintCommand.java:14-16`
- **SceneNode 禁重写 equals/hashCode**：identity 语义锚定 measuredTextNodes 正确性，任何子类亦不得重写 → `SceneNode.java:45-50`
