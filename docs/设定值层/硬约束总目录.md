# 高风险边界导航

本文件只帮助按改动主题定位风险，不是每次 scene 修改都必须逐条执行的检查表。总方向见根目录 `NORTH_STAR.md`，具体事实以相关源码、包级 Javadoc、测试、错误记录和决策为准。

| 主题 | 必须守住的结果 | 主要入口 |
|---|---|---|
| 平台隔离 | scene core 不依赖 LWJGL/Minecraft/Forge；数据/paint 层不调用 GL | `ui.scene.input`、paint/replay 边界 |
| 坐标 | layout、paint、replay、scissor 与 input 共享 logical px；host 只做边界换算 | host、`SceneEventContext`、backend |
| 状态与输入 | UI 由 state/signal 驱动；handler 不直接改节点或树 | reactive、`SceneInputRouter`、control 包 Javadoc |
| 绘制契约 | paint plan 自包含且不可变；replay 不反查可变节点 | `PaintCommand`、`ScenePaintReplayer` |
| 宿主渲染 | backend 恢复所有触碰的 GL 状态，异常和 capability 降级不泄漏状态 | 各 backend、GL 错误记录 |
| 配置数据 | 保存冲突不静默覆盖 Authority，失败不提交半成品 | Config 模块文档与测试 |

控件装配、布局求解、性能和测试细节留在对应源码与测试文档。只有改到相关主题时才继续阅读；改变公共 API、持久数据、兼容承诺或上述高风险边界前先取得用户确认。
