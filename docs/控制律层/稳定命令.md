# 稳定命令

本文件记录项目可长期复用的构建、检查、测试和运行命令。

## 环境前提

- Windows 环境，PowerShell
- `GRADLE_USER_HOME` 必须指向纯 ASCII 路径（由用户在 shell 环境中自行设置，例如 `[用户自定]/gradle-home`），避免中文、空格或特殊字符路径触发 Java 8 Gradle Worker 问题
- 不要并行执行多个 Gradle 构建命令，尤其不要同时运行 `compileJava`、`test`、`build`

## 常用命令

> 以下命令假定 `GRADLE_USER_HOME` 已在当前 shell 中正确设置。

- 编译：`./gradlew.bat --no-configuration-cache compileJava`
- 测试：`./gradlew.bat --no-configuration-cache test`
- 离线测试（依赖已缓存、GitHub manifest 不可达时回退）：`./gradlew.bat --offline --no-configuration-cache "-Pgtnh.settings.blowdryerTag=" test --tests "<类名>"`
- 离线编译（GitHub manifest 不可达时回退）：`./gradlew.bat --offline --no-configuration-cache "-Pgtnh.settings.blowdryerTag=" compileJava`
- 客户端：`./gradlew.bat --no-configuration-cache runClient21`，启动前会自动写入 `run/client/config/CodeChickenLib.cfg` 的 `mappingDir`
- Git 空白检查：`git diff --check`
- scene 边界门禁：`pwsh scripts/check-scene-boundaries.ps1`（评审 scene 改动前必跑，断言清单见 `docs/传感层/门禁脚本说明.md`）

## 运行目录与日志

- `runClient21` 的根运行目录：`D:\CodeSpace\MC\Qz-UILib\run`
- 客户端运行目录：`D:\CodeSpace\MC\Qz-UILib\run\client`
- 客户端常规日志：`D:\CodeSpace\MC\Qz-UILib\run\client\logs\latest.log`
- 客户端 Forge 日志：`D:\CodeSpace\MC\Qz-UILib\run\client\logs\fml-client-latest.log`
- JVM native 崩溃日志：`D:\CodeSpace\MC\Qz-UILib\run\client\hs_err_pid*.log`，按修改时间选最新文件

## 验证边界

- 纯 JVM 测试不要直接实例化继承 `GuiScreen` / `BaseScreen` 的页面类
- 每批开发应至少保持 `git diff --check`、相关测试、`compileJava` 可通过
- `runClient21` 若弹出 MCP 映射目录选择窗口，优先确认 `GRADLE_USER_HOME` 是否已指向纯 ASCII 路径，以及 `configureCodeChickenMappings` 是否已生成 `run/client/config/CodeChickenLib.cfg`
- 涉及游戏内 UI、HUD、输入、命令入口、远程页面或网络 smoke 的能力，需要使用 `runClient21` 进入游戏内验证
- `/qzuilib test` 当前打开 scene 新栈 test hub；`/qzuilib scene_test` 是同一入口的过渡别名
- 网络、远程页面、远程 HUD 与配置同步自检是后续 test 页面重建目标；恢复后仍需要提交按钮完成表单回传验证
- 默认 `runServer` 目前会被 LWJGL3ify relauncher 中止；dedicated server 完整 smoke 需换用不带该 relauncher 的服务端配置（预防通则见 `docs/反馈层/错误预防.md` Gradle/构建环境类）
- Forge 网络回退仍需单独切换 `netTransport=forge` 或 `-Dqzuilib.net.transport=forge` 验证
- `gtnhconvention` manifest 不可达时，单独 `--offline` 仍可能在 Blowdryer 配置阶段失败；需要同时传入 `"-Pgtnh.settings.blowdryerTag="` 临时禁用远端设置 tag 拉取。

## 维护规则

- 只有实际可执行、可复用的命令才能写入
- 命令或环境前提变化后及时更新本文件
