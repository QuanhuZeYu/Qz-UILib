# 稳定命令

本文件只记录用户与 CI 的长期入口。agent 不在本机执行 Gradle、编译、构建、测试、运行态或 verify；任务要求这些实证但尚无 CI/用户结果时返回 `INCOMPLETE`。

## 用户入口

以下命令由用户在 agent 外部配置好 `GRADLE_USER_HOME` 后执行，不授权 agent 调用：

- 编译：`./gradlew.bat --no-configuration-cache compileJava`
- 测试：`./gradlew.bat --no-configuration-cache test`
- 完整构建：`./gradlew.bat --no-configuration-cache build`
- 客户端：`./gradlew.bat --no-configuration-cache runClient21`
- Git 空白检查：`git diff --check`

不要并行执行多个 Gradle 构建。环境异常由用户处理；agent 禁止赋值、持久修复或用 Gradle/JDK home 参数绕过。

## Agent 终端入口

- agent 只通过 `python scripts/run-agent-command.py -- <executable> <args...>` 执行 Git 等获准外部命令，不直接使用 PowerShell/CMD/Bash。
- runner 使用参数列表、固定仓库 cwd、`shell=False`、300 秒超时与退出码传播；它不是 Gradle、编译、测试、构建、运行态或 verify 的授权入口。
- 复杂逻辑写成可审计 Python 文件，禁止复杂 `python -c`、命令字符串拼接、管道、重定向与 shell 插值。
- OpenCode 内置默认 `build` 也受以上边界约束；agent 名称不构成执行本机 build/test/verify 的授权。

## CI 入口

- `.github/workflows/build-and-test.yml` 调用固定 SHA 的 GTNH reusable workflow，并并行检查仓库零 PowerShell 约束。
- `.github/workflows/recover-4.6.2-release.yml` 仅用于固定 `4.6.2` draft 的只读验证或正式化；其 runner 使用 Java 25 执行 `./gradlew --no-configuration-cache --no-daemon test build`。
- workflow dispatch、push、tag 与 Release 写入均须另有用户授权；CI runner 的环境和权限不构成本地 agent 授权。

## 验证边界

- 纯 JVM 测试不要直接实例化继承 `GuiScreen` / `BaseScreen` 的页面类。
- 游戏内 UI、HUD、输入、网络与渲染 smoke 由用户运行 `runClient21` 验证。
- `/qzuilib test` 打开 scene test hub；`/qzuilib scene_test` 是过渡别名。
- 每批改动至少保持 `git diff --check`，并明确记录 CI/用户是否已提供相关测试与构建结果。
- agent 核对空白错误时使用 `python scripts/run-agent-command.py -- git diff --check`。
