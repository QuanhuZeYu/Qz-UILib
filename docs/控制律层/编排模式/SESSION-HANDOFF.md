# 跨会话交接模式

## 状态边界

| 层次 | 载体 | 内容 |
|---|---|---|
| 项目状态 | `docs/反馈层/交接.md` | 跨任务状态、阻断项、待决定事项 |
| 活动任务 | `.opencode/task.md` | 当前目标、写集、动作、验收、验证、结果 |
| 会话记忆 | `.opencode/session-handoff.md` | 单任务已验证事实、剩余动作与未决决定 |

## 写入与接续

- 用户要求暂停/新会话，或上下文较大时，覆盖式维护 handoff；只写任务单路径、已验证事实、完成项、剩余动作、待验证与未决用户决定。
- 不记录工具原始输出、大块文件、固定尝试计数或旧 `task_id`。
- 新会话先读取三层状态与本目录编排规则，再核对分支、HEAD、工作区及关键事实；有漂移先更新任务单。
- 任何 Task 返回后旧 `task_id` 不复用；后继任务均创建全新 task。

## 完成清理

- 清理无持续价值的 handoff 内容。
- 仅把会指导未来决策的事实回流到对应权威文档。
- 将跨任务未收敛状态写入 `docs/反馈层/交接.md`。
- 按 `docs/README.md` 人工核对链接、时态、状态与写回归属，并交独立 reviewer 复审。
