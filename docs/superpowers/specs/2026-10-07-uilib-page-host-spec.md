# UILib 页面接入与宿主生命周期规格

状态：已确认模块规格；与核心规格共同构成项目规格体系，仅定义本模块职责。

共同状态、布局、生命周期、输入与平台边界遵循[核心职责规格](<2026-10-07-uilib-core-contract-design.md>)；按职责选择规格见[规格入口](<../../开发者文档/规格文档/README.md>)。

## 1. 声明式页面接入与运行生命周期

页面作者通过正式入口提供内容树、状态绑定和业务策略；框架装配运行环境，统一协调输入、呈现与释放。普通页面无需自行创建 SceneRuntime、SceneFramePipeline、原生输入适配器或渲染资源，也无需手写逐帧驱动、失焦恢复和清理顺序。入口属于正式发行能力，不依赖 internal/devtools 或人工验收包。

初始树组合、响应式绑定及事件意图均是声明式表达。普通状态变化沿[核心规格第 3 节](<2026-10-07-uilib-core-contract-design.md>)更新，不重建运行环境；handler 的写入边界和受控交互命令沿[核心规格第 2 节](<2026-10-07-uilib-core-contract-design.md>)。公共签名、继承或组合方式留给设计，复用现有声明树。标准控件随组件建设完善，不作为正式接入的前置条件。

| 主体 | 职责 |
| --- | --- |
| 页面作者 | 内容、布局、业务状态与绑定、事件意图、初始/恢复焦点、模态显隐与关闭策略；游戏是否暂停等应用选择 |
| 页面运行环境 | 提供合法构造与事件上下文，组织挂载，协调既有布局/绘制/输入，管理本次接入的订阅与资源 |
| 平台宿主适配 | 窗口/framebuffer、资源和原生输入事实，坐标/事件转换、GPU 提交及可用性观察 |
| 自动化测试宿主 | 提供软件或真实GPU环境、窗口/资源事实及注入输入；复用同一正式运行环境，不自行装配第二套页面管线 |
| Minecraft 接入 | 对接 GuiScreen 打开、输入、绘制、重初始化和关闭，驱动运行环境并执行合法宿主 fallback |

自动化测试机与游戏宿主共用正式页面定义和运行环境，装配、挂载、更新、事件结算与结束走同一生产能力。测试应用层只负责场景、环境供给、输入注入、断言与结果报告；页面运行环境仍是生产发行能力，不依赖测试基类。纯逻辑、软件、GPU与MC证据分别归各自宿主，注入输入不冒称原生设备输入验证。

页面创建的派生、Effect 和资源可归属页面作用域，由框架释放；页面可声明自身释放动作。外部业务状态、编辑状态、任务和共享服务保持独立归属，关闭不隐含提交、清除草稿或取消任务，也不终止其他页面使用的共享资源。状态域、只读/写入及线程边界沿现有合同。

打开时，接入在合法上下文构造并挂载内容，建立环境与输入联系；状态、窗口和资源变化按依赖更新呈现，页面不调用 flush/layout/paint/replay。同一打开页面的 initGui 等尺寸重初始化不重复创建绑定或运行环境，不重置合法焦点、滚动或独立编辑状态。

原生输入由唯一消费者递交同一核心事件序列，复用范围、焦点、挂载身份和手势 owner。失焦取消、历史耗尽与物理释放确认由宿主统一协调；页面不另行轮询或凭物理快照提前放行。ESC 按[核心规格第 6.1 节](<2026-10-07-uilib-core-contract-design.md>)处理，未消费结果在对应状态与 Effect 成功结算后才执行 fallback，保持后续输入顺序。实际处理返回未消费后，不再检查页面或会话身份；接受处理中发生页面切换后，默认关闭仍执行并可能作用于后来页面的行为。

结束时停止本次业务输入，丢弃待处理业务意图并取消手势，解除挂载联系，按依赖顺序释放所属资源；不补跑帧或回放输入。再打开建立新的宿主输入联系，独立业务状态能否复用由调用方决定，节点身份与重挂载沿[核心规格第 5 节](<2026-10-07-uilib-core-contract-design.md>)。

构造、挂载或宿主资源创建失败时清理已取得的本次所属资源，不留下可交互的半初始化页面。结束或清理中一项释放失败仍尝试其余释放，保留原始失败及附加清理错误；重复结束不重复释放。handler、Effect、布局与 replay 失败沿既有通道暴露，不吞异常或当作未消费 ESC 执行 fallback；保留既有手势取消/物理尾部语义。迟到输入与呈现不得访问已释放接入；已处理的未消费 ESC 默认关闭沿上述取舍执行。

| 验收场景 | 可观察结果 |
| --- | --- |
| 通过正式入口打开声明的列表、按钮与嵌套模态 | 页面无管线装配、原生输入和清理接线，列表/字号/焦点/ESC 正常工作 |
| 窗口变化与同页重初始化 | 自动重排，无重复订阅/事件，状态及合法交互连续 |
| 开屏持键、失焦恢复、重复 ESC、跨帧输入 | 无尾部误触或重复按压级联关闭，事件与 fallback 顺序正确 |
| ESC 处理期间切换或结束页面并返回未消费 | 成功结算后仍执行默认关闭，不因页面或会话改变撤销 |
| 关闭后修改外部状态并再次打开 | 旧 UI 不接受更新/输入，外部状态有效，新接入使用当前值，无旧回调叠加 |
| 初始化或清理失败、重复结束 | 原始错误可定位，所属资源完成清理尝试，外部资源不被释放，无残留输入联系 |
| handler/Effect 失败 | 既有错误和手势尾部处理成立，不误执行关闭 fallback |
| 同一内容声明接入无平台验收及 LWJGL2/LWJGL3、MC 宿主 | 内容不依赖平台类型，适配差异不改变布局与输入权威 |

接入实现完成后，CoreLoopScreen 迁移到正式入口，保留具体能力验收操作并展示声明式使用；底层反例复用自动化入口。焦点调试操作不决定标准控件默认策略。本节不新增按钮默认聚焦、主题、导航显露或编辑/IME 接口。
