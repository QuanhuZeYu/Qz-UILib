# UILib 无平台配置规格

状态：用户已授权独立核心、核心配置及 MC 接入方向；本模块定义此次实现范围与验收，具体接口由实现承担。共同状态、生命周期与平台边界遵循[核心规格](<2026-10-07-uilib-core-contract-design.md>)。

## 1. 配置声明与权威值

配置声明是类型化键、编解码、默认值和明确校验。模块声明自己的选项，通用配置核心不认识 MC、字体或页面含义。配置实例由应用持有，不要求 UI 挂载或宿主类型；业务可直接读取当前值，也可通过既有响应式能力订阅变化。键身份唯一，重复或相互占用存储命名空间的声明须定位报错。

默认值属于声明；缺少键使用默认值，显式空字符串/空列表不等同于缺少键。列表值及向外发布的复合值保持不可变，外部修改不能绕过通知。初期支持 boolean、string 与 string list，模块可声明自己的编解码与校验，不预建配置编辑器、层级覆盖或通用事务框架。

一次加载先读取、解析和校验全部声明值，再在同一状态操作中发布；通知观察者获得同一批次的新值，读后即得到当前值。非法值定位配置键并报错，不部分发布，不默默改回默认值。解析失败前尚未发布属于本次操作未完成，不引入额外重试、回滚、旧结果恢复或降级策略。普通 set 同样校验、发布变化；相同值不重复通知。

## 2. 存储与环境边界

核心提供基于 Java 标准文件/字符 API 的 UTF-8 Properties 存取，调用方也可提供 Reader/Writer。宿主选择文件路径、调用时机和资源归属。初期列表用声明键下的 count 与索引项保存，区分空列表并保持顺序；文件中的未知键或非法列表结构明确报错。读写错误沿调用通道报告，不吞错、不增加自动监视或恢复策略。持久化显式调用，不将每次内存修改隐含解释为磁盘保存。

配置观察复用现有 ReactiveDomain/Signal/Owner；订阅的释放归订阅持有者。核心不安装宿主事件监听器，不创建后台线程，不每帧读取文件。文件不存在时，首次初始化由调用方明确使用默认值并创建文件，不与加载失败混同。

## 3. 字体首个接入

字体模块声明完整有序候选列表，遵循[字体规格第 2.4 节](<2026-10-07-uilib-font-renderer-spec.md>)。候选通过内置来源标识或系统文件路径明确表达；它们在同一列表中排序，不自动追加未声明来源。未配置采用模块默认列表，显式空列表保持空。解析到实际 face、字族及样式仍复用字体来源与适配，不建立第二套字体引擎。

MC 宿主调用核心配置实例。通用字体候选归字体模块；replaceVanillaFont 等 MC 专有选项归 MC 模块。配置变更和资源重载沿既有资源换代更新，页面不需要关闭重开。

旧 Forge systemFontFiles 只作为一次迁移输入：旧前缀转换为显式 file 候选，再接入当次实际默认内置顺序，得到等效完整列表；旧 replaceVanillaFont 同时迁移。新配置文件存在后以新文件为权威，不持续读取或合并旧值。旧文件不删除；非法旧配置迁移明确失败，不默默跳过。此迁移不把原前缀字段改成完整列表，也不建立长期双写兼容层。

## 4. 产物与验收

配置类归独立核心产物，产物加载及配置读写不要求 MC/Forge/LWJGL/native 存在。宿主通过核心产物调用配置，平台来源解析和事件监听留在宿主。

验收沿真实生产路径覆盖：默认与显式空值区分、列表顺序与文件往返、加载前全量校验及批次通知、错误键定位、订阅释放、完整候选排序/排除、迁移后的有效顺序，以及现有字体换代。用真实产物独立运行核心状态/配置流程；MC 宿主效果由实际发行组合验收，不以核心测试冒称游戏通过。
