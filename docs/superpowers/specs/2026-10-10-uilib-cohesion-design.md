# UILib 内聚优化设计

状态：根据用户“开始内聚优化”实施授权，由当前整体审查的具体职责缺口收敛设计；基础行为仍以核心与对应模块规格为权威，本稿定义本轮跨模块接口协作，不增加第二套合同。

## 目标与范围

保留自有状态、场景、布局、唯一输入路由、字体及绘制管线，使资源收尾、编辑文字语义、宿主格式转换及图像外观各有明确归属。依据 bc26c02c 整体源码审查，修正已经定位的具体分岔；样式双表达、同批布局共享和稳定语法派生沿现有接缝收口，不按类长度拆服务。不扩大 Markdown/数学功能，不将尚无运行反证的 Effect 时序变化混入。

## 生命周期

Runtime 是挂载资源关闭的完整责任边界。pointer/focus 关闭中的扩展回调错误与 root detach、Owner.dispose 的错误统一合并，不能阻断其余释放；结束时所属挂载资格和订阅全部失效，保留首个原始错误及后续 suppressed。PageSession 仍释放它自己的 pipeline/runtime/page scope，业务独立状态继续可用。复用既有 Owner 协议，不新增重试、恢复或回滚。

## 编辑文字与样式

纯 Unicode 字素规则、版本数据及逻辑来源属于中性文本能力，编辑状态不依赖字体 face、HB glyph cluster、宿主或 GPU。默认编辑与排版使用同一 ICU 与 Emoji 补充规则；自定义规则/重载保留显式稳定快照和失效归属，调用方协调替换并显式通知字体及编辑状态刷新，不以全局可变单例修改所有页面。编辑写操作与历史恢复以当前同一快照校正位置，规则变化不改写草稿或清历史。布局允许比字素更大的字形簇。

最终布局保留生产 Bidi 的方向/逻辑视觉边缘事实，复制、平移、重采样不得丢失；Field/Area 消费共同事实，不重新用原始文本和默认方向分析。单行限制换行并将保留的硬分隔符投影为可见标记，测量、最终排版与定位采用同一节点策略的方向、行高和显示投影；业务原文及来源坐标不变，普通不软换行文本仍保留硬段落。FontStyle 是字重字姿的规范权威；宿主旧布尔值在转换边界消化，装饰与实际光栅状态仍各有职责。

TextContent 提供中性稳定样式声明入口，内容由 TextInput、覆盖意图及诊断构成；样式意图不包含 MC code/palette、固定基础字体或字号。RGB 覆盖保留当前基础透明度，字重字姿使用 FontStyle，装饰以当前样式单位派生。resolve(currentBase) 输出既有 AttributedText。Typed 内容不受 DSL 子集能力限制，其 serializeRichTags 明确报告不支持，不以丢弃扩展属性冒充完整往返。DSL 的源结构、声明身份和来源处理一次，主题/字号变化仅派生属性视图。普通文本的 § 始终字面，不新增 Minecraft 内容模式。未支持效果使用既有能力诊断，不默丢也不让核心绘制入口崩溃。

测量和最终布局在同一个 scene 呈现批次按节点/约束共享已得到的布局事实；字体及内容代际变化沿现有呈现失效处理，不在每个控件增加独立跨帧字体缓存。

## 物品提示的宿主转换

Minecraft 格式解释实现归宿主并复用唯一 parser，原版字体替换仍通过宿主适配。MinecraftImageLoader 准备物品事实时一次将 raw tooltip 和 palette 转为中性内容。ItemImageFacts 不保存调色板、不解释 §，SceneImage 按当前主题/字号/字体/窗口派生提示布局，稳定内容和稳定样式复用当前结果。不能把长期 AttributedText 快照冻结基础字体，也不能通过删提示功能消除职责问题。

## 图像占位与同代绘制

加载、失败、自定义占位及数量/耐久成功覆盖层归 SceneImage 定义。IMAGE 命令携带不可变 pending/failed 备用 PaintPlan 与 readyOverlay；没有 live node、回调、signal 或 GPU ID。GL 资源层报告 ready/pending/failure，回放只选择上层表达；宿主 item render 一次失败后回放失败分支，不重新准备或执行原图像。

自定义占位仍是同一逻辑子树，保留 UUID、Mount/Owner 与绑定。现有管线在 dirty 呈现中捕获同代子片段：可见时使用主 Geometry；因 READY 被控件隐藏时，以已分配 image box/clip 使用同一 LayoutEngine 测量排列路径局部只读捕获，仅忽略框架隐藏的占位根，后代 visible/clip/padding/scroll 继续遵守。捕获不写 live visible、不发布第二输入 Geometry、不挂第二 Runtime。主绘制遍历排除已捕获子树，防止占位两次绘制。输入仍由当前 scene 资源事实与主 Geometry 决定。

prepare 收集主命令及可能选择的分支需求，一次固定 Frame，按既有 GlyphKey/content.identity 复用并保留预算与顺序。备用需求准备不等于绘制；所有主命令及成功覆盖层的资源先于备用层纳入并固定，纹理和字形消费同一资源优先层。备用浮层仍在全页内容之后按本次实际图像分支投影，不插入局部内容位置，也不重新执行原图像。上传/物品回放结果仍按既有 identity/request 回投下次呈现。当帧只能选择本帧已封闭片段，不拼接下代主题或几何；旧计划保有它的不可变内容引用。

## 验收

- 失焦回调抛错的真实 PageSession 关闭路径仍释放每项挂载资源，后续业务更新不通知旧节点。
- LF+独立组合标记、emoji/ZWJ/旗帜等编辑操作遵守共同字符边界；真实字体 RTL/控制显示标记/显式行高的光标与布局一致。
- 同一提示内容换主题、字号、候选及窗口后动态更新，来源诊断保留，核心不调用 MC parser。
- 自定义半透明/局部占位、上传排队/失败和 item render 抛错通过既有生产 PaintPlan/GPU 路径，仅绘声明的备用外观；成功覆盖层仅成功分支可见，后续绘制与 clip/order 保持。
- 必要短场景通过后完整 build，独立审查实际文件版本，本地精确提交后干净重建正式/人工附加包，按既有授权备份部署两测试实例并提供实机步骤。游戏不自动启动，实际用户反馈待验；自动化、GPU 独立场景与游戏验收不相互冒称。
