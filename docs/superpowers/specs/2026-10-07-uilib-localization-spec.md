# UILib 语言事实与翻译文案规格

状态：已确认模块规格。与[核心职责规格](<2026-10-07-uilib-core-contract-design.md>)共同定义行为权威；实现与验证结果另行取证。

## 1. 目标与职责

页面作者声明翻译键和参数，UILib 根据宿主当前语言与翻译资料派生文案。语言或翻译资源变化后，同一挂载页面的标准标签、按钮及自然布局自动更新，无需业务监听平台事件、重开页面或手动执行布局。字面字符串继续保持字面内容，不自动猜测它是翻译键。

无平台核心持有可追踪的语言与翻译资料事实、纯文案派生和作用域绑定；宿主提供已加载的语言资料与变化通知。Minecraft 适配复用原版加载、资源包覆盖和 Forge 合并后的翻译表，不建立第二套 .lang 解析、资源优先级或语言回退机制。排序和搜索可读取语言事实建立自己的纯派生，具体业务算法仍归调用方。

## 2. 文案表达与读取

翻译键是非空字符串。正式文案入口支持固定键、响应式键与响应式参数；来源状态变化使文案失效。参数按声明顺序交给格式化能力，不以共享可变数组保存旧参数。参数中的字面文本不会再次作为翻译键或富文本解析；需要嵌套译文时由调用方显式组合纯派生。

文案是普通可读信号，创建后首次读取即有基于当前资料的有效结果，键或参数写入后直接读取得到当前结果，不要求挂载、UI 帧或 flush，也不执行业务 Effect。标签、按钮及自定义控件消费同一文案入口，继续使用现有 NodeBinding、测量布局、文本排版与 PaintCommand。

当前语言标识及翻译资料变化分别可观察；同一语言的资料重新加载仍使依赖文案失效。宿主语言码可保持宿主约定，不要求业务从字符串比较猜测资料是否变化。

## 3. 格式与可见失败结果

本阶段复用 Java8 Formatter 的位置参数、字符串及百分号格式语义。Minecraft 适配沿用已加载翻译表的格式约定，包括原版加载阶段的数值占位归一；格式化 locale 使用该适配捕获的 Java 格式 locale，不能在同一资料事实求值过程中读入另一套变化中的格式环境。

缺失键显示键名本身，不隐式增加 UILib 语言回退、重试或保留旧译文。非法格式或参数不匹配显示 Format error: 加当前模板，使错误保持可见；这属于本模块明确结果，不吞掉其他运行异常。空键、null 键及非法来源声明是调用错误，及时报错。业务选择替代文案时自行声明，框架不推断业务策略。

## 4. 变化传播与生命周期

宿主在翻译加载、Forge 合并及原版翻译同步正常完成后发布新的资料事实；捕获实际用于该次加载的语言码，不以尚未就绪的语言元数据目录推断启动期语言。语言切换必须使用对应语言已加载资料，不发布新语言标识搭配旧翻译表。资料内容使用不可变视图或快照，派生读取不修改宿主、业务或节点。

MC 加载完成接缝只捕获资料事实，响应式消费者在原版资源包恢复异常范围之外递交；页面派生或 Effect 异常不得被误判为资源包损坏、移除资源包或保存替代配置。宿主正常更新入口递交待生效事实，不依赖页面绘制帧；资料最终状态可合并。一次资料通知完成各独立订阅的递交，单个订阅失败不使其余绑定永久保留旧资料。如果通知期间又生效较新资料，尚未递交的旧事实可被新事实取代；各订阅不能先收到新事实再倒退收到旧事实，重入发布后读取仍看到当前事实。通知后原样暴露首个错误，其余错误作为 suppressed 保留，不增加吞错、重试或恢复。

宿主通知按受控入口递交状态域，随后读取看到当前已生效资料；最终画面允许按现有呈现批次合并。资源重载不以语言码相同而被忽略，不逐节点或逐文案每帧轮询翻译表。文案改变沿实际依赖自动重测，绘制、裁剪、滚动范围和命中仍来自同代布局。

页面作用域拥有其语言订阅和文案派生，关闭释放这些关系；控件卸载释放呈现绑定，重挂载读取当前文案。独立业务作用域可自行持有语言绑定，不因控件关闭被销毁。释放后迟到通知不访问节点或恢复关闭页面；页面不关闭宿主共享资料源。语言或资源变化不改编辑草稿、光标、选区或业务权威值。

## 5. 本阶段交付与验收

本阶段交付正式无平台来源/绑定/文案入口、MC 语言资料完成事件适配、页面上下文接入和短小人工验收页。不扩展 Markdown、自动机器翻译、搜索算法或独立配置核心。

| 场景 | 可观察结果 | 验证通道 |
| --- | --- | --- |
| 首次及键/参数写后读取 | 获得当前译文，无挂载/帧推进或外部副作用 | 无平台真实响应式与文案入口 |
| 语言资料切换 | 已有标签/按钮更新，同一挂载身份保留，自然固定区与正文视口重测 | 正式页面与帧管线 |
| 同语言资料重载 | 文案及其几何更新，不因语言码未变继续缓存旧译文 | 正式来源通知及页面 |
| 缺键、格式错误、位置参数和百分号 | 按第3节产生可见结果，不增加恢复策略 | 正式格式化路径 |
| 参数与主题/窗口变更 | 当前文案重排，绘制与命中共享结果 | 正式布局、绘制计划和输入 |
| 卸载/重挂载、关闭、迟到通知 | 不叠加订阅、不访问关闭页面，独立状态与宿主资料源仍有效 | 生产生命周期与资源观测 |
| 翻译加载完成 | 捕获原版资源包和 Forge 合并后的当前语言资料 | MC适配自动场景与实际发行包 |
| 普通与增强宿主 | 两实例复用同一核心合同，语言与资源操作可见且布局协调 | 用户真机验收 |

重要合同与真实反例通过[统一测试应用](<2026-10-07-uilib-testing-spec.md>)补自动化测试机场景并实际执行；不写镜像实现、源码字面快照或为测试新增生产分支。自动化完成后记录覆盖范围，双实例的真实游戏表现由用户验收，不将独立运行结果外推为游戏通过。
