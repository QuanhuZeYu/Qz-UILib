# 原版字体接管短验收

使用固定 Prism 的 UILib 测试实例手动启动。新包默认接管标准 FontRenderer；首次 FML 启动字尚不接管。旧 UILib 与人工附加包会保存在实例外层的 uilib-backups 中。

1. 看主菜单、聊天输入、物品 tooltip：常用中文/Latin、颜色、粗斜体、阴影和换行应清楚；改变 GUI scale 后再次检查。新字形允许初次异步准备，已有热文字不应持续闪烁或缺字。
2. 在聊天输入框粘贴 `中文 ABC مرحبا क्षि ภาษาไทย 👩‍💻 🇨🇳`，暂不发送；用光标、删除和缩窄窗口检查完整簇与行尾。换成阿拉伯语界面再检查混合方向。
3. 在已有测试世界看告示牌、实体名字与浮动 tooltip：转相机、近距离穿过文字平面、退远及透过方块看遮挡，检查 world 变换、可见范围、清晰度和深度。开启已有可用 shaderpack 后重复；本次实例尚未发现已安装 shaderpack，不自动下载或启用。
4. 若世界允许命令，用 `/tellraw @p {"text":"ABCD","obfuscated":true}` 检查混淆文字；正文与阴影在同一时刻应同形。原有 `/qzcore` 人工面板仍可检查自有 scene 和滚动。
5. 退出客户端，在生成的 `config/qz_uilib.cfg` 把 `font` 类别的 `B:replaceVanillaFont` 改为 `false`，重启检查标准文字回到原路径，自有 scene 仍正常；再恢复 `true`。不通过运行异常暗中切回旧引擎。

反馈最小信息：开启/关闭接管、GUI scale、场景、语言或 shaderpack 名称、可复现操作，以及对应客户端 latest.log。性能门槛需真实 MC 记录：热文字 CPU/GPU p95 不超过原版 1.25 倍；原版低于 0.20 ms 时允许增量不超过 0.05 ms；整帧 p95/p99 增量不超过 1 ms。独立 CPU/GL 或合成 shader 数据不作为该性能结论。

这是本轮原版接管切片的人工验收，不是全库完成或正式发布。
