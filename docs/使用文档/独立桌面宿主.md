# 独立桌面宿主

桌面宿主通过 GLFW/LWJGL3 接入 UILib 的核心页面、输入及字体能力，不需要 Minecraft、Forge 或 lwjgl3ify。职责及验收见[桌面规格](<../superpowers/specs/2026-10-11-uilib-desktop-spec.md>)。

## 构建与启动

在仓库根目录执行 `gradlew.bat --no-configuration-cache desktopRun` 打开窗口。Unix 使用 `./gradlew`。`desktopVerify` 在真实窗口与 GL 上运行有限自动验收，使用独立测试入口和正式产物；自动注入事件不等同人工输入或操作系统 IME 验证。

`desktopDist` 生成当前构建平台的压缩分发，`installDesktop` 安装至 `build/install/desktop`。目录中 `lib` 包含桌面、核心和字体适配三个正式 jar，`bin` 包含 `qz-desktop.bat` 与 `qz-desktop.sh`。使用系统 Java 8 或设置 `JAVA_HOME`，启动脚本定位自身的 `lib` 目录；不需要 MC 安装目录。平台 native 按构建机选择，不能将本机分发直接当作其他操作系统或架构的包。

## 业务页面接入

`DesktopWindow.open(Path, ScenePage)` 接受已有声明式业务页面；不传页面的 `open(Path)` 显示默认示例。业务 `ScenePage` 只通过既有 `ScenePageContext` 声明、绑定并挂载内容，不负责 GLFW、字体创建或 GL 回放。应用入口持有 `DesktopWindow`，驱动 `frame()` 至 `shouldClose()`，最后关闭窗口；窗口自身负责页面会话及宿主资源释放。实现入口见 [DesktopWindow](<../../src/desktop/java/club/heiqi/uilib/host/desktop/DesktopWindow.java>) 与 [DesktopApplication](<../../src/desktop/java/club/heiqi/uilib/host/desktop/DesktopApplication.java>)。

## 配置与页面操作

默认读取或首次创建启动工作目录中的 `config/desktop.yaml`，启动时可传 `--config <path>` 明确路径。页面包括标题、计数按钮、YAML 重载按钮、标准文本框及可滚动列表。修改 YAML 后点击重载或按 Ctrl+R，窗口标题、页面文字、主题、字号及字体候选沿状态和资源换代更新，不需要重开页面。

```yaml
windowProfile:
  title: UILib Desktop
  text: UILib desktop — live signals
  dark: true
  fontSize: 22
font:
  candidates:
    - builtin:unifont
```

该例只声明一个字体候选；首次生成文件包含实际默认来源，可按需保留完整列表及其顺序。字体仍使用 `builtin:<id>`、`file:<path>` 的既有完整候选语义，空序列保持空；对象绑定、注释及错误规则见[配置规格](<../superpowers/specs/2026-10-11-uilib-config-spec.md>)。配置加载与资源错误沿调用通道报告，不自动切回默认或旧来源。

窗口和 framebuffer 的比例转换留在桌面适配中，尺寸变化继续驱动现有布局。鼠标、滚轮、键盘编辑、导航、剪贴板与 Unicode 文本提交接入正式页面输入。GLFW 字符回调提供提交字符，本版本不提供原生组合文本预编辑显示，不将它视为完整 SDL IME 接入。关闭窗口会结束页面、释放订阅和字体及 GL 资源，再销毁原生窗口。
