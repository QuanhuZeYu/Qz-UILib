# v4.x LTS 稳定 API 清单

本文定义 Qz UILib `4.1.0-LTS` 起（含 `4.2.0`）的公共 API 边界，明确哪些类型与方法属于稳定契约、
哪些虽对外可见但不承诺稳定、哪些已 deprecated 即将移除、哪些是内部类型不应直接使用。

> 4.1.x 系列在 LTS 期间不会破坏稳定 API；4.2.0 及之后可能扩展能力但保持向后兼容；
> 5.x 才允许破坏性调整。

## 阅读约定

| 标记 | 含义 |
|------|------|
| ✅ 稳定 | 业务代码可放心依赖；4.1.x 期间不会变更签名或语义 |
| ⚠️ 不稳定但暴露 | 对外可见但不承诺稳定；4.x 期间可能调整 |
| 🚫 已 Deprecated | 仍可用但已标注移除计划；建议尽早迁移 |
| 🔒 内部 (Internal) | LTS 不承诺稳定；包名带 `internal` 或 `__` 双下划线方法 |

| 类型 / 方法 | 说明 |

仍归属 `NetService` 网络入口。

## 已 Deprecated（🚫）

当前版本无 deprecated 但保留的公共 API。`DocumentLinkActivationEvent.markHandled()`
/ `isHandled()` 已在本版本删除，业务代码请改用 `preventDefault()` /
`isDefaultPrevented()`。

## 内部类型（🔒，业务代码不应使用）

下列类型属于框架内部协作 / 诊断 / 反射跳板，LTS 不承诺稳定：

`__` 双下划线方法目前保留为 public 是内部协作的君子协定：它们被公开出来是为了少数特殊宿主、
兼容层或诊断路径能接入当前运行时，但不属于稳定 API。业务代码可以看见这些方法，不代表可以获得
未来兼容承诺；后续版本可能改为 internal accessor、package-private bridge 或 deprecated facade。

- `club.heiqi.uilib.ui.screen.internal` 包下所有类型，包括：
  - `InternalScreenIdentity` / `PageDescriptor` / `DescriptorOwner`
  - `InternalHostedScreenFactory` 全部嵌套类型
- `club.heiqi.uilib.internal.devtools.*`
- 任何 `__` 双下划线开头的方法：
  - `UiDocument.__showTopLayerElement` / `__hideTopLayerElement` /
    `__getTopLayerElements` / `__isTopLayerElement`
  - `UiDocument.__createPseudoElementRuntime` / `__setInteractionRuntime` /
    `__dispatchLinkActivation`
  - `ElementNode.__getElementUid`
  - `DocumentNode.__appendGeneratedChild`
- `club.heiqi.uilib.font.FontReloadDebouncer`（package-private）
- `club.heiqi.uilib.ClientProxy` / `CommonProxy` / `MyMod`（mod 入口，由 Forge
  自动加载，业务代码不应直接构造）

历史 `UiHudDocumentHost` 及其输入、渲染钩子均已退出现行稳定 API；当前 HUD 入口为
`ClientHudService`，内部宿主不向业务暴露。
