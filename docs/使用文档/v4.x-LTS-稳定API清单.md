# v4.x LTS 稳定 API 清单

本文定义 Qz UILib `4.1.0-LTS` 起的公共 API 边界，明确哪些类型与方法属于稳定契约、
哪些虽对外可见但不承诺稳定、哪些已 deprecated 即将移除、哪些是内部类型不应直接使用。

> 4.1.x 系列在 LTS 期间不会破坏稳定 API；4.2.0 及之后可能扩展能力但保持向后兼容；
> 5.x 才允许破坏性调整。

## 阅读约定

| 标记 | 含义 |
|------|------|
| ✅ 稳定 | 业务代码可放心依赖；4.1.x 期间不会变更签名或语义 |
| ⚠️ 不稳定但暴露 | 对外可见但不承诺稳定；4.x 期间可能调整 |
| 🚫 已 Deprecated | 仍可用但已标注移除计划；建议尽早迁移 |
| 🔒 内部 (Internal) | LTS 不承诺稳定；包名带 `internal` 或 `__` 双下划线方法 |

### 远程页面

| 类型 / 方法 | 说明 |
|------|------|
| ✅ `club.heiqi.uilib.ui.remote.RemoteDocumentPages.open(player, page)` | 服务端向玩家打开远程页面 |
| ✅ `RemoteDocumentPages.open(player, page, handler)` | 服务端打开带表单提交回调的远程页面 |
| ✅ `RemoteDocumentPage` / `RemoteDocumentPage.builder(...)` | 远程页面模型，包含 `pageId`、`title`、安全子集 HTML、资源策略和元数据 |
| ✅ `RemoteDocumentSubmitHandler` | 服务端表单提交回调 |
| ✅ `RemoteDocumentSubmitEvent` | 表单提交事件，包含 `player`、`sessionId`、`pageId`、`action`、`formId` 与 `Map<String, List<String>> values` |
| ✅ `RemoteDocumentSubmitEvent.reply(...)` | 使用同玩家会话回复并打开新远程页面 |
| ✅ `RemoteDocumentResourcePolicy` | 远程图片与外部链接策略 |

远程 HTML 是 Qz UILib 安全子集：不执行 JavaScript，不嵌入真实浏览器；HTML/CSS 会被解析为
`UiDocument`、样式表和 `Document*Control` 控件。远程页面网络端点由库在 `preInit` 注册，
仍归属 `NetService` 网络入口。

## 已 Deprecated（🚫）

当前版本无 deprecated 但保留的公共 API。`DocumentLinkActivationEvent.markHandled()`
/ `isHandled()` 已在本版本删除，业务代码请改用 `preventDefault()` /
`isDefaultPrevented()`。

## 内部类型（🔒，业务代码不应使用）

下列类型属于框架内部协作 / 诊断 / 反射跳板，LTS 不承诺稳定：

- `club.heiqi.uilib.ui.screen.internal` 包下所有类型，包括：
  - `InternalScreenIdentity` / `PageDescriptor` / `DescriptorOwner`
  - `InternalDiagnosticScreenRegistry` 全部 page 描述符与 definition 引用
  - `InternalHostedScreenFactory` 全部嵌套类型
  - `UiDiagnosticsScreens` 全部 `createXxx` 工厂方法（package-private，仅供
    `/qzuilib test` 命令路径调起）
- `club.heiqi.uilib.internal.devtools.*`
- 任何 `__` 双下划线开头的方法：
  - `UiDocument.__createPseudoElementRuntime` / `__setInteractionRuntime` /
    `__dispatchLinkActivation`
  - `ElementNode.__getElementUid`
  - `DocumentNode.__appendGeneratedChild`
- `club.heiqi.uilib.font.FontReloadDebouncer`（package-private）
- `club.heiqi.uilib.ClientProxy` / `CommonProxy` / `MyMod`（mod 入口，由 Forge
  自动加载，业务代码不应直接构造）

`UiHudDocumentHost` 类本身是稳定 API，但下列方法属于框架内部 forge 事件钩子，
LTS 不承诺签名稳定：

- `handleInputFrame`
- `handleImmediateKeyboardInput` / `handleImmediateMouseInput`
- `renderHud` / `renderOnScreen`

## 反馈通道

- 行为偏离稳定 API 契约：在 GitHub Issue 中标注 `lts-regression`。
