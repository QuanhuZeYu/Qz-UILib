# 基础控件

> 本文件中的 `Document*` 示例属于已移除的旧 HTML-like 栈，仅作历史记录，不能作为当前功能分支的接入合同。
> 当前业务页面应使用 `ui.scene` / `SceneRuntime` / `ConfigUI`；ItemStack 图标只使用下方的 snapshot-only seam。

## 当前 Item icon

普通页面只展示物品图标时使用 `HostImageSource.itemIcon(ItemStack)`，不要构造 Slot/inventory 控件或传入 LIVE stack renderer：

```java
SceneImageSource icon = HostImageSource.itemIcon(stack);
```

- 创建 source 时复制完整 `ItemStack`，包括 metadata/NBT。
- source 后续不读取调用方 mutable stack。
- 只绘制 item/effect icon，不绘制数量、耐久、tooltip 或 carried overlay。
- 目标矩形会居中裁成 square；完全位于 clip 外时不排队。
- 预算、FBO 状态恢复、resource reload 和 placeholder 由 host coordinator 管理。
- 需要槽位点击、库存同步或 tooltip 时由业务 Mod 自己建模，不依赖 UILib 已删除的 Slot API。

以下旧章节不代表当前 public API；迁移时以 `docs/开发者文档/规格文档/物品视觉渲染接缝.md` 为准。

## 心智模型约定

- 结构节点优先直接使用 `UiDocument` 的 DOM-like API，例如 `document.div()`、`document.span()`、`document.table()`。
- 交互控件优先使用 `Document*Control`，不要在业务代码里自己判断某个标签是否足够“像 HTML”。
- 控件内部会选择合适的元素语义和事件绑定方式；业务作者只关心控件暴露的样式、状态和 handler。

## 按钮

`DocumentButtonControl` 使用真实 `button type="button"` 元素表达按钮。

```java
DocumentButtonControl button = new DocumentButtonControl(document, "确认");
button.setActionHandler(new DocumentButtonActionHandler() {
    @Override
    public void onAction(DocumentButtonActionEvent event) {
        // 在这里执行按钮动作。
    }
});
root.append(button.getElement());
```

能力边界：

- 支持鼠标 click。
- 支持 Enter 和 Space 键盘激活；Space 按下只进入 active 态，松开时触发动作。
- 支持 enabled/disabled。
- 支持 active 与 focus-visible 基础视觉状态。

## 单行文本输入

`DocumentTextInputControl` 用于单行文本输入，根元素使用真实 `input type="text"` 语义。

能力边界：

- 支持 placeholder。
- 支持 maxLength。
- 支持 Backspace 删除。
- 支持控制字符过滤。
- 支持 change handler。
- 支持 enabled/disabled 与 focus 边框；禁用会丢失交互焦点，重新启用后不会自动恢复输入态。
- 支持 `setType(DocumentInputType)` 切换 `TEXT` / `PASSWORD` / `NUMBER`：
  - `PASSWORD` 显示掩码字符（默认 `•`，可用 `setPasswordMaskCharacter(char)` 自定义），`getText()` 仍返回真实值，`value` 属性不暴露明文。
  - `NUMBER` 仅接受数字与数值语法字符（`0-9`、`. - + e E`）。
  - 切换类型会按新类型规则重新过滤已有内容。

## 自动完成输入

`DocumentAutocompleteInputControl` 用于“单行输入框 + 弹出下拉候选”的自动完成体验，主体复用真实
`input type="text"` 语义，候选面板使用 `listbox` / `option` 语义并按 top-layer 弹出，避免被普通父容器
`overflow` 裁剪。

```java
DocumentAutocompleteInputControl fontInput = new DocumentAutocompleteInputControl(document,
        "Minecraft", "Noto Sans CJK", "Source Han Sans")
        .setPlaceholder("输入字体名")
        .setSelectionHandler(new DocumentAutocompleteSelectionHandler() {
            @Override
            public void onSuggestionSelected(DocumentAutocompleteSelectionEvent event) {
                applyFontName(event.getSelectedSuggestion());
            }
        });
fontInput.getElement().style().setWidth(UiStyleLength.px(220));
root.append(fontInput.getElement());
```

自定义候选来源：

```java
fontInput.setSuggestionProvider(new DocumentAutocompleteSuggestionProvider() {
    @Override
    public List<String> getSuggestions(String query) {
        return searchFontNames(query);
    }
});
```

能力边界：

- 支持固定 options 列表，默认按大小写不敏感包含关系过滤。
- 支持 `DocumentAutocompleteSuggestionProvider` 按当前 query 返回候选，用于业务自定义过滤策略。
- 空 query 默认展示全部候选；可通过 `setShowAllWhenQueryEmpty(false)` 关闭。
- 候选提供器应按相关度返回结果；控件默认最多保留前 128 项，可通过 `setMaxSuggestionCount(...)` 调整上限。
- 候选面板内部按固定行高可视窗口虚拟化渲染；大量结果仍保留完整候选数据，但不会一次性创建全部 `option` DOM 节点。
- 大量结果通过 `setMaxVisibleOptions(...)` 控制可见行数并在面板内滚动，键盘高亮会自动滚入可视区域。
- 支持鼠标点击候选回填完整文本，并触发 `DocumentAutocompleteSelectionHandler`。
- 支持 Up / Down 移动高亮、Enter 选择、Escape 关闭候选面板且不改写文本。
- 支持 placeholder、maxLength、enabled/disabled、change handler 和扩展 key handler。
- 程序化 `setText(...)` 不触发 change/selection 事件。

## 多行文本输入

`DocumentTextAreaControl` 用于最小可用的多行文本输入，根元素使用真实 `textarea` 语义。

```java
DocumentTextAreaControl notes = new DocumentTextAreaControl(document)
        .setPlaceholder("请输入说明")
        .setMaxLength(400)
        .setChangeHandler(new DocumentTextAreaChangeHandler() {
            @Override
            public void onTextChanged(DocumentTextAreaChangeEvent event) {
                saveDraft(event.getText());
            }
        });
notes.getElement().style()
        .setWidth(UiStyleLength.px(240))
        .setHeight(UiStyleLength.px(96));
root.append(notes.getElement());
```

能力边界：

- 支持 placeholder。
- 支持多行输入、Enter 换行、Backspace/Delete 删除。
- 支持 Left/Right/Home/End/Up/Down 基础光标移动。
- 支持 `Ctrl+A` 全选与 `Shift + 方向键` 的最小选择编辑语义。
- 支持元素自身纵向与横向滚动；长内容会在聚焦与编辑时尽量让当前光标进入可视区域，鼠标点击行内位置会按 X 坐标定位光标。
- 当前按“每个 `\n` 形成一条逻辑行”的最小模型实现，不额外补浏览器 `pre-wrap` 软换行；超长单行主要依赖横向滚动而不是自动折行。

## SearchPicker 列表成员展示

`SearchPickerSpec.BindingMode.LIST_MEMBERS` 的管理浮层把已选成员显示为双行：第一行是领域主名称与固定操作列，第二行是 registry/canonical 补充信息与可选问题 badge。长文本保留完整值，只在各自布局盒内显式裁剪；结构容器不响应点击，仅编辑、移除按钮可命中。

Provider 可通过 `SearchPickerPresentation.Builder.currentMemberPrimaryFormatter(...)` 与
`currentMemberSecondaryFormatter(...)` 分别提供两行文案。旧
`currentMemberFormatter(...)` 继续映射第一行，未设置第二行时默认为空，现有 Provider 无需迁移。

当前成员区最多显示 6 个 42 logical px 双行成员，超过后在分区内滚动；搜索候选仍最多显示 12 个 34 logical px 单行结果。操作按钮列固定为 54 + 2 + 118 logical px，中英文及删除确认态不会改变按钮布局盒。

## 下拉选择

`DocumentSelectControl` 用于最小可用的标准下拉选择体验，根元素使用真实 `select` 语义，候选面板由内部 DOM 子树承载，展开时按 top-layer 弹出。

```java
DocumentSelectControl raritySelect = new DocumentSelectControl(document, "普通", "稀有", "史诗")
        .setChangeHandler(new DocumentSelectChangeHandler() {
            @Override
            public void onSelectionChanged(DocumentSelectChangeEvent event) {
                applyRarity(event.getSelectedOption());
            }
        });
raritySelect.getElement().style().setWidth(UiStyleLength.px(180));
root.append(raritySelect.getElement());
```

能力边界：

- 支持鼠标展开/收起与点击选择候选项。
- 支持 Enter / Space 展开或收起。
- 支持 Up / Down / Home / End 基础键盘导航，并同步当前值；长列表打开时会尽量把当前项滚入候选面板可视区域。
- 候选面板内部按可视窗口虚拟化渲染，超长选项列表不会一次性创建全部 `option` DOM 节点。
- 支持 enabled/disabled。
- 当前是最小可用单选下拉，不支持多选、可输入过滤、分组或搜索；需要可输入过滤时使用 `DocumentAutocompleteInputControl`。

## 开关

`DocumentToggleSwitchControl` 用 flex row 和 `justifyContent` 表达开关结构，并同步 `role="switch"`、`tabindex="0"`、`aria-checked` 与 `aria-disabled`。

能力边界：

- 支持鼠标点击切换。
- 支持 Enter 和 Space 键盘切换。
- 支持 enabled/disabled。
- 支持 focus-visible 和 toggle change handler。

## 复选框

`DocumentCheckboxControl` 用方框 + 标签文本表达表单语义的选中/未选中状态，并同步 `role="checkbox"`、`tabindex="0"`、`aria-checked` 与 `aria-disabled`。

```java
DocumentCheckboxControl checkbox = new DocumentCheckboxControl(document, "启用高级提示")
        .setChecked(true)
        .setChangeHandler(new DocumentCheckboxChangeHandler() {
            @Override
            public void onCheckboxChanged(DocumentCheckboxChangeEvent event) {
                applyAdvancedTips(event.isChecked());
            }
        });
root.append(checkbox.getElement());
```

能力边界：

- 支持鼠标点击切换。
- 支持 Enter 和 Space 键盘切换；Space 按下只记录状态，松开时切换。
- 支持 `indeterminate` 半选状态；用户切换会清除半选。
- 支持 enabled/disabled、focus-visible、悬停色和 change handler。
- 程序化 `setChecked(boolean)` 默认不触发事件，只有 `setChecked(value, true)` 会显式通知。

## 单选组

`DocumentRadioGroupControl` 用 `radiogroup` + 多个 `radio` 子项表达传统表单单选项，适合选项需要独立标签说明的设置页。

```java
DocumentRadioGroupControl quality = new DocumentRadioGroupControl(document, "低", "中", "高")
        .setOrientation(UiRadioOrientation.HORIZONTAL)
        .setSelectedIndex(1)
        .setChangeHandler(new DocumentRadioChangeHandler() {
            @Override
            public void onRadioChanged(DocumentRadioChangeEvent event) {
                applyQuality(event.getSelectedOption());
            }
        });
root.append(quality.getElement());
```

能力边界：

- 支持鼠标选择。
- 支持垂直方向 Up/Down、水平方向 Left/Right 切换。
- 支持 Space/Enter 选中当前聚焦项。
- 支持 enabled/disabled、选中态、悬停态、focus-visible 和 change handler。
- 程序化 `setSelectedIndex(int)` 默认不触发事件，只有 `setSelectedIndex(index, true)` 会显式通知。

## 滑块

`DocumentSliderControl` 用 `role="slider"` 的水平轨道、填充段和滑块按钮表达数值范围设置。

```java
DocumentSliderControl volume = new DocumentSliderControl(document)
        .setRange(0.0D, 100.0D)
        .setStep(5.0D)
        .setValue(50.0D)
        .setChangeHandler(new DocumentSliderChangeHandler() {
            @Override
            public void onSliderChanged(DocumentSliderChangeEvent event) {
                setVolume(event.getValue(), event.isCommitting());
            }
        });
root.append(volume.getElement());
```

能力边界：

- 首版支持水平滑块。
- 支持点击轨道跳转、拖动滑块连续更新。
- 拖动中事件 `isCommitting=false`，释放鼠标和键盘修改为 `isCommitting=true`。
- 支持 Left/Down、Right/Up、Home、End、PageUp、PageDown 键盘操作。
- 支持 enabled/disabled、focus-visible、悬停态、拖动态和 change handler。
- 程序化 `setValue(double)` 默认不触发事件，只有 `setValue(value, true)` 会显式通知。

## 分段选择器

`DocumentSegmentedSelectorControl` 用 radiogroup + radio 风格的 button 组表达多个互斥选项。

能力边界：

- 支持鼠标选择。
- 支持键盘选择和左右方向键切换。
- 支持 enabled/disabled。
- 支持选中态视觉和 selection handler。

## 标签页

`DocumentTabControl` 用 `tablist`、`tab` 与 `tabpanel` 表达设置页分类和属性面板分组。内容通过 `DocumentTabContentBuilder` 懒加载构建，切换后缓存复用。

```java
DocumentTabControl tabs = new DocumentTabControl(document)
        .addTab("图形", new DocumentTabContentBuilder() {
            @Override
            public void build(ElementNode panel, UiDocument document) {
                panel.appendText("图形设置内容");
            }
        })
        .addTab("音频", new DocumentTabContentBuilder() {
            @Override
            public void build(ElementNode panel, UiDocument document) {
                panel.appendText("音频设置内容");
            }
        })
        .setActiveIndex(0)
        .setChangeHandler(new DocumentTabChangeHandler() {
            @Override
            public void onTabChanged(DocumentTabChangeEvent event) {
                rememberTab(event.getActiveIndex());
            }
        });
root.append(tabs.getElement());
```

能力边界：

- 支持鼠标点击切换标签。
- 支持 Left/Right、Home、End、Space、Enter 键盘切换。
- `addTab` 只登记标签与 builder；首次 `setActiveIndex` 或用户切换到对应标签时才构建内容。
- 切走后会保留内容缓存；`rebuildTab(index)` 可清除并重建指定标签内容。
- 支持 enabled/disabled、活动态、悬停态、focus-visible 和 change handler。

## 通用拖拽

如果作者需要做可移动浮窗、拖拽面板或可重新摆放的小挂件，优先使用 HTML-like 元素级拖拽能力，而不是做 HUD 或某个页面专属的拖动逻辑。

- `draggable="true"`：让普通 `ElementNode` 进入浏览器式拖拽链路。
- `ElementNode.setDragStartHandler(...)` / `setDragOverHandler(...)` / `setDragEndHandler(...)`：分别处理 `dragstart`、`dragover`、`dragend` 心智下的拖拽生命周期。
- `ElementNode.setDragHandler(...)`：给任意元素挂接拖拽处理器。
- `DocumentElementDragEvent`：提供拖拽起点、当前指针位置、相对上次事件位移和拖拽阶段。
- `DocumentDraggableSupport`：把常见“拖住把手后更新 absolute/fixed 元素 left/top”逻辑收敛成可复用辅助器。

浏览器式列表重排可以把列表项声明为 `draggable="true"`，由列表容器在 `dragover` 中根据当前指针位置调整自身数据顺序，再重建对应 DOM 子树：

```java
ElementNode list = document.element("ul");
ElementNode item = document.element("li");
item.setAttribute("draggable", "true");
item.appendText("产品设计");
item.setDragStartHandler(event -> {
    draggingItem = "产品设计";
    return true;
});
item.setDragEndHandler(event -> {
    draggingItem = null;
    return true;
});
list.setDragOverHandler(event -> {
    reorderByPointerY(event.getDocumentY());
    return true;
});
list.append(item);
```

```java
ElementNode panel = document.div();
panel.style()
        .setPosition(UiPosition.FIXED)
        .setLeft(UiStyleLength.px(320))
        .setTop(UiStyleLength.px(40));

ElementNode handle = document.div();
handle.appendText("拖住这里移动");
panel.append(handle);

DocumentDraggableSupport.attach(panel, handle, DocumentDraggableSupport.DragAxis.BOTH);
```

能力边界：

- 当前优先支持鼠标左键拖拽。
- 拖拽采用位移阈值激活；按下到抬起未超过阈值时，仍保留原元素 click 语义。
- 拖拽事件坐标沿用 UILib 原生像素坐标体系；`DocumentElementDragEvent#getDocumentX()` / `getDocumentY()` 是 HTML-like 文档局部坐标，不是 Minecraft GUI 缩放坐标。
- 当前浏览器式链路已覆盖 `draggable="true"`、`dragstart`、`dragover`、`dragend`；`drop`、`dragenter`、`dragleave`、`DataTransfer` 与 `preventDefault()` 仍待后续补齐。
- 当前更适合 `position:absolute` 或 `position:fixed` 元素。
- 当前只负责 HTML-like 元素自身的位置更新，不自动处理底层宿主点击穿透仲裁。
- HUD 浮窗、页面内浮层、业务工具面板都应优先复用这层能力。

## 通用槽位

当前 Breaking major 已删除通用 Slot/inventory public seam。需要机器槽、配方槽、饰品槽或幽灵槽时，
由业务 Mod 用普通 scene node、input handler 和业务状态自行组合；不要恢复旧 `Document*Slot*` 或 inventory adapter。
只展示 ItemStack 时使用本文件开头的 `HostImageSource.itemIcon`。

## 页面级 Tooltip

如果 tooltip 需要覆盖在页面内容之上、跟随鼠标并规避局部裁剪，优先使用页面级 tooltip overlay，而不是把 tooltip DOM 塞进单个控件内部。

- `DocumentOverlayHostControl`：页面级 overlay 子树宿主，本身保持零尺寸，只负责统一承载浮层子树。
- `DocumentOverlayLayerControl`：通用 fixed overlay 层，负责层级、命中隐藏、离屏隐藏和位置/尺寸控制。
- `DocumentCursorOverlayControl`：页面级鼠标跟随图片浮层，适合鼠标携带物品、拖拽预览、跟随光标的宿主图片提示。
- `DocumentTooltipOverlayControl`：负责 tooltip 浮层 DOM、文本装配、离屏隐藏、指针跟随和页面级抑制。
- `DocumentTooltipLayoutResolver`：负责 tooltip 的指针避让定位与边缘收窄策略。

能力边界：

- overlay 基础设施优先保留 DOM 子树心智：页面先挂一个 overlay host，再把 tooltip、cursor、popover 等具体浮层作为子层挂进去。
- `DocumentOverlayLayerControl` 只负责 fixed 浮层公共结构，不直接绑定 tooltip、cursor、dialog 的具体语义。
- `DocumentCursorOverlayControl` 负责宿主图片源、指针偏移和显示/隐藏，不再要求页面控制器自己维护图片层 `left/top/display` 细节。
- 控件负责声明 tooltip 意图与内容；真正的 tooltip 浮层由页面级 overlay 承载。
- 当前 tooltip overlay 适合鼠标跟随型提示，不等同于锚定某个元素矩形的弹出层系统。
- 拖拽、鼠标携带物品、全局 hover 抑制等策略应由页面层决定，再通过 overlay 的 `suppressed` 状态统一生效。

## 浏览器式 img 位图

普通 `img` 元素已经支持通过 `src` 属性声明位图资源，适合页面图标、装饰图和提示图。本地资源路径使用 Minecraft `ResourceLocation` 风格：

```java
ElementNode icon = document.img();
icon.setAttribute("src", "qz_uilib:textures/ui/drag-handle.png")
        .setAttribute("alt", "拖拽");
icon.style()
        .setWidth(UiStyleLength.px(16))
        .setHeight(UiStyleLength.px(16));
root.append(icon);
```

也可以直接使用远程 HTTP/HTTPS 位图 URL：

```java
ElementNode avatar = document.img();
avatar.setAttribute("src", "https://example.com/avatar.jpg")
        .setAttribute("alt", "玩家头像");
avatar.style().setWidth(UiStyleLength.px(48));
root.append(avatar);
```

能力边界：

- 当前面向宿主可加载的位图资源，例如 PNG、JPG 等；不支持 `data:` URI 或 SVG。
- 本地 `src` 会解析为 `ResourceLocation`，可写 `namespace:path/to/image.png`，也可沿用 Minecraft 默认命名空间路径。
- 远程 `src` 支持 `http://` 与 `https://`，会在后台线程下载并缓存；加载完成后自动触发布局/绘制刷新。
- 远程图片加载完成后使用真实位图尺寸参与 auto 布局；加载完成前使用 HTML `width` / `height` 属性或默认 `16x16` 占位。
- `width` / `height` HTML 属性可作为未声明 CSS 尺寸时的固有尺寸；CSS `width` / `height` 仍优先于 HTML 属性。
- 只声明 CSS 宽或高时，会按图片固有比例推导另一边。
- `object-fit` 已在普通 `img` 绘制阶段支持 `fill`、`contain`、`cover`、`none`、`scale-down`；除 `fill` 外会按图片固有尺寸在内容区内居中，超出部分由内容区裁剪。
- `alt` 会作为图片元素的可访问名称；`aria-label` 优先级更高，`aria-hidden="true"` 会让元素从当前最小语义链路隐藏。
- 当图片资源解析失败且声明了 `alt` 时，当前会在图片内容区内绘制最小文本回退，不再静默空白。
- 当前尚未提供显式 `load` / `error` 事件、公开 `naturalWidth` / `naturalHeight` 属性或完整 inline replaced element 行为。

## 链接与列表语义节点

如果场景需要表达“正文中的链接”或“有结构的条目列表”，优先直接使用 `UiDocument` 的语义节点，而不是自己手写蓝色文本或缩进模板。

```java
document.setLinkActivationHandler(new DocumentLinkActivationHandler() {
    @Override
    public void onLinkActivated(DocumentLinkActivationEvent event) {
        openExternalPage(event.getHref());
        event.preventDefault();
    }
});

ElementNode helpLink = document.a();
helpLink.setAttribute("href", "https://example.com/help");
helpLink.appendText("查看帮助文档");

ElementNode todoList = document.ul();
todoList.append(document.li().appendText("准备素材"));
todoList.append(document.li().appendText("校对文案"));

ElementNode steps = document.ol();
steps.append(document.li().appendText("打开页面"));
steps.append(document.li().appendText("填写参数"));
steps.append(document.li().appendText("提交保存"));
```

能力边界：

- `a[href]` 默认可点击、可聚焦、带下划线和 `cursor:pointer`，不是单纯的“蓝色文本约定”；`a` 只是链接元素工厂，默认链接语义只在存在非空 `href` 时生效。
- `href="#target"` 会滚动目标元素进入可视区域。
- 外部链接、埋点或自定义跳转由 `UiDocument.setLinkActivationHandler(...)` 承接。
- `ul/ol/li` 会绘制真实项目符号或序号标记；页面作者不需要再手工拼 `- ` 或 `1. ` 前缀。
- 当前支持 `list-style-type`：`NONE`（隐藏标记）、`DISC`（实心圆，ul 默认）、`CIRCLE`（空心圆）、`SQUARE`（实心方块）、`DECIMAL`（数字序号，ol 默认）；可在 `ul`/`ol`/`li` 上声明并继承。
- 不支持 `list-style-position`、`list-style-image`、多级编号格式或自定义 marker 内容。

## 宿主图片控件

当前 scene 图片统一通过 `SceneImageSource` 表达；Minecraft ItemStack icon 使用 snapshot-only host source：

```java
SceneImageSource icon = HostImageSource.itemIcon(new ItemStack(Items.diamond_sword));
```

能力边界：

- source 只描述图片，不自动参与命中、焦点、键盘或 tooltip。
- Item icon 进入独立小 FBO，并在完整事务恢复验证后才发布到 host-owned cache。
- 当前内建 host source 支持静态 ItemStack icon、`ResourceLocation` 纹理区域和运行时 `BufferedImage`。
- 点击、拖拽或悬停由承载图片的 scene node 与 input handler 负责。

## 宿主背景贴图

如果更接近“组件背景图”的心智，可以使用 `DocumentHostImageDecorations.attachBackground(...)`：

```java
ElementNode card = document.div();
card.style()
        .setWidth(UiStyleLength.px(160))
        .setHeight(UiStyleLength.px(90))
        .setPadding(UiStyleLength.px(12));
DocumentHostImageDecorations.attachBackground(card,
        HostImageSource.texture(new ResourceLocation("minecraft", "textures/gui/options_background.png"), 32, 32));
```

能力边界：

- 背景贴图会作为目标元素的绝对定位装饰子层挂载。
- 默认命中隐藏，不会抢占目标元素本身的点击或 hover。
- 当前更适合静态背景或装饰贴图；如果需要拖拽移动，建议单独使用外层绝对定位元素配合现有事件系统实现。

## 使用建议

- 优先把控件作为 DOM 子树挂载，而不是用 custom renderer 手绘普通 UI。
- 控件视觉应通过标准样式表达；宿主图片、物品图标这类能力优先复用 `DocumentHostImageControl` / 背景贴图辅助，而不是在业务代码里直接写底层 custom renderer。
- 页面级交互应使用事件 handler，不要直接访问布局盒或 paint command。
- 如果只是做标题、段落、容器、行列结构，继续直接写 DOM-like 元素；如果需要可聚焦、可输入、可点击的标准交互，再切到 `Document*Control`。
