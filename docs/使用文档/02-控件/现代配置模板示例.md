# 现代配置模板示例配置

本文件给出 `ModernConfigTemplateScreen` 全部 12 个模板入口的完整 JSON/YAML 示例配置与对应 `FieldSpec` 声明，供接入方快速对照配置值、字段规格与最终 UI 表现。

> 模板选择规则、可选依赖回退边界见 [现代配置模板](./现代配置模板.md)。

## 前置约定

- 配置由 `club.heiqi.config` 模块加载，根节点必须是 MAP。
- `FieldSpec` 仅补充 UI 语义（label、范围、离散值、模板 hint 等），不改变配置存储结构。
- 模板类型枚举共 12 个用户入口（`STRING/NUMBER/BOOLEAN/CHOICE/LONG_TEXT/SIMPLE_LIST/TABLE/OBJECT/KEY_VALUE_MAP/PRESET_SELECTOR/RAW_EDITOR/ENHANCED_PICKER`）+ 2 个系统 fallback（`NULL/READ_ONLY`）。
- 下文每个入口给出：配置值（JSON + YAML）→ `FieldSpec` 声明 → 推断结果 → UI 表现。

## 1. STRING（文本）

**配置值**

```json
{
  "player": { "name": "Steve" }
}
```

```yaml
player:
  name: Steve
```

**FieldSpec 声明**

```java
spec.addField(new ModernConfigTemplateScreen.FieldSpec("player.name")
        .setLabel("玩家名称")
        .setDescription("显示在 HUD 上的玩家名。")
        .setPlaceholder("输入名称")
        .setMaxLength(32));
```

**推断结果**：节点为 STRING → `TemplateType.STRING`。

**UI 表现**：`DocumentTextInputControl` 单行文本输入。

## 2. NUMBER（数值）

**配置值**

```json
{
  "server": { "maxPlayers": 20 }
}
```

```yaml
server:
  maxPlayers: 20
```

**FieldSpec 声明（带范围，走 slider）**

```java
spec.addField(new ModernConfigTemplateScreen.FieldSpec("server.maxPlayers")
        .setLabel("最大玩家数")
        .setRange(1, 100)
        .setStep(1)
        .setDefaultValue(20));
```

**推断结果**：节点为 NUMBER、无小数点 → `TemplateType.NUMBER` + `integerNumber=true`。

**UI 表现**：声明了有限范围时用 `DocumentSliderControl` + 内联数值输入；未声明范围时退回 `DocumentTextInputControl`（NUMBER 类型）。

## 3. BOOLEAN（开关）

**配置值**

```json
{
  "feature": { "enableHud": true }
}
```

```yaml
feature:
  enableHud: true
```

**FieldSpec 声明**

```java
spec.addField(new ModernConfigTemplateScreen.FieldSpec("feature.enableHud")
        .setLabel("启用 HUD")
        .setDefaultValue(Boolean.TRUE));
```

**推断结果**：节点为 BOOLEAN → `TemplateType.BOOLEAN`。

**UI 表现**：`DocumentToggleSwitchControl` 开关。

## 4. CHOICE（离散选项）

**配置值**

```json
{
  "render": { "mode": "fast" }
}
```

```yaml
render:
  mode: fast
```

**FieldSpec 声明**

```java
spec.addField(new ModernConfigTemplateScreen.FieldSpec("render.mode")
        .setLabel("渲染模式")
        .setValidValues("fast", "balanced", "safe")
        .setDefaultValue("balanced"));
```

**推断结果**：`validValues` 非空 → `TemplateType.CHOICE`。选项 ≤4 走分段选择。

**UI 表现**：≤4 选项用 `DocumentSegmentedSelectorControl`；>4 选项用 `DocumentSelectControl`。

## 5. LONG_TEXT（长文本）

**配置值（含换行）**

```json
{
  "motd": "欢迎来到服务器\n第二条说明"
}
```

```yaml
motd: "欢迎来到服务器\n第二条说明"
```

**FieldSpec 声明（hint 强制长文本）**

```java
spec.addField(new ModernConfigTemplateScreen.FieldSpec("motd")
        .setLabel("服务器公告")
        .setTemplateHint("textarea")
        .setMaxLength(4096));
```

**推断结果**：含换行 或 `longtext/long-text/multiline/textarea/text-area` hint 或 ≥160 字符 → `TemplateType.LONG_TEXT`。

**UI 表现**：`DocumentTextAreaControl` 多行文本输入。

## 6. SIMPLE_LIST（primitive 列表）

**配置值**

```json
{
  "ports": [25565, 25566, 25567]
}
```

```yaml
ports:
  - 25565
  - 25566
  - 25567
```

**FieldSpec 声明**

```java
spec.addField(new ModernConfigTemplateScreen.FieldSpec("ports")
        .setLabel("监听端口列表")
        .setDefaultValue(Arrays.asList(25565)));
```

**推断结果**：LIST 且元素为 primitive → `TemplateType.SIMPLE_LIST`。

**UI 表现**：支持添加/删除/上移/下移/批量导入的 primitive list 编辑器。

## 7. TABLE（同构对象列表）

**配置值**

```json
{
  "servers": [
    { "host": "a.local", "port": 25565 },
    { "host": "b.local", "port": 25566 }
  ]
}
```

```yaml
servers:
  - host: a.local
    port: 25565
  - host: b.local
    port: 25566
```

**FieldSpec 声明**

```java
spec.addField(new ModernConfigTemplateScreen.FieldSpec("servers")
        .setLabel("服务器列表")
        .setDefaultValue(Arrays.asList(
                makeRow("host", "c.local", "port", 25567))));
```

**推断结果**：LIST 且元素主要为同构 MAP → `TemplateType.TABLE`，列集合稳定为 `[host, port]`。

**UI 表现**：`DocumentDataTableControl` 固定列、行内编辑、添加/删除行、按列排序。

## 8. OBJECT（普通 map 内联编辑）

**配置值**

```json
{
  "database": {
    "credentials": { "username": "admin", "password": "secret" }
  }
}
```

```yaml
database:
  credentials:
    username: admin
    password: secret
```

**FieldSpec 声明**：可不声明，按节点类型自动推断为 OBJECT。

```java
spec.addField(new ModernConfigTemplateScreen.FieldSpec("database.credentials")
        .setLabel("数据库凭证"));
```

**推断结果**：MAP 且无 `_presets`/`presets` → `TemplateType.OBJECT`。

**UI 表现**：卡片内联编辑，递归深度默认 5 层；超深层级通过「展开编辑」跳转树形导航。

## 9. KEY_VALUE_MAP（动态 map）

**配置值**

```json
{
  "labels": { "alpha": "A", "beta": "B" }
}
```

```yaml
labels:
  alpha: A
  beta: B
```

**FieldSpec 声明（hint 指定动态 map）**

```java
spec.addField(new ModernConfigTemplateScreen.FieldSpec("labels")
        .setLabel("自定义标签")
        .setTemplateHint("dynamic-map"));
```

**推断结果**：`dynamic-map/dynamic_map/map-dynamic/key-value/key_value/keyvalue/key-value-map/key_value_map/kv-map` hint → `TemplateType.KEY_VALUE_MAP`。

**UI 表现**：`DocumentKeyValueEditorControl` 三列编辑（key/value/type），支持 STRING/NUMBER/BOOLEAN/NULL 类型切换；重复 key 报错。

## 10. PRESET_SELECTOR（预设批量应用）

**配置值**

```json
{
  "profile": {
    "mode": "fast",
    "threads": 4,
    "_presets": {
      "fast": { "mode": "fast", "threads": 4 },
      "safe": { "mode": "safe", "threads": 1 }
    }
  }
}
```

```yaml
profile:
  mode: fast
  threads: 4
  _presets:
    fast:
      mode: fast
      threads: 4
    safe:
      mode: safe
      threads: 1
```

**FieldSpec 声明**：无需 hint，按 `_presets`/`presets` 子键存在性自动识别。

```java
spec.addField(new ModernConfigTemplateScreen.FieldSpec("profile")
        .setLabel("运行档位"));
```

**推断结果**：MAP 且含 `_presets`/`presets`（非空 MAP 或 LIST）→ `TemplateType.PRESET_SELECTOR`。

**UI 表现**：选择预设批量写入目标字段；偏离预设显示已修改标记；预设存储键 `_presets`/`presets` 在 applyDraft 时保留。

## 11. RAW_EDITOR（源码编辑器）

**配置值（JSON 子树，存为字符串）**

```json
{
  "payload": "{\"host\":\"localhost\",\"port\":8080}"
}
```

```yaml
payload: '{"host":"localhost","port":8080}'
```

**FieldSpec 声明**

```java
// 指定 JSON 格式
spec.addField(new ModernConfigTemplateScreen.FieldSpec("payload")
        .setLabel("JSON 负载")
        .setTemplateHint("json"));

// 或指定 YAML 格式
spec.addField(new ModernConfigTemplateScreen.FieldSpec("payload")
        .setLabel("YAML 负载")
        .setTemplateHint("yaml"));
```

**推断结果**：`json/json-editor/yaml/yaml-editor` hint → `TemplateType.RAW_EDITOR`，rawFormat 按 hint；`raw/raw-editor/code/source` hint → `RAW_EDITOR`，rawFormat 取 `fallbackFormat`（默认 JSON）。

**UI 表现**：`DocumentCodeEditorControl` 行号、基础高亮、Tab 插入、错误行提示；语法错误不污染当前草稿，applyDraft 写最后一次合法解析值。

## 12. ENHANCED_PICKER（增强选择器）

**配置值**

```json
{
  "theme": { "primary": "#FF8800" },
  "texture": { "block": "minecraft:block/stone" },
  "audio": { "click": "minecraft:block.stone.click" }
}
```

```yaml
theme:
  primary: "#FF8800"
texture:
  block: minecraft:block/stone
audio:
  click: minecraft:block.stone.click
```

**FieldSpec 声明**

```java
// 颜色选择器
spec.addField(new ModernConfigTemplateScreen.FieldSpec("theme.primary")
        .setLabel("主题色")
        .setTemplateHint("color"));

// 资源（退回文本输入）
spec.addField(new ModernConfigTemplateScreen.FieldSpec("texture.block")
        .setLabel("方块纹理")
        .setTemplateHint("resource"));

// 声音（退回文本输入）
spec.addField(new ModernConfigTemplateScreen.FieldSpec("audio.click")
        .setLabel("点击音效")
        .setTemplateHint("sound"));
```

**推断结果**：`color/colour/hex` hint → `ENHANCED_PICKER` + `PickerKind.COLOR`；`resource/asset` → `RESOURCE`；`sound/audio` → `SOUND`。

**UI 表现**：COLOR 用 `DocumentColorPickerControl`（色块 + HEX/RGB 输入 + 预览，支持 ARGB）；RESOURCE/SOUND 当前退回 `DocumentTextInputControl`（占位文案体现 hint）。

## 完整 Spec 组装示例

```java
ModernConfigTemplateScreen.Spec spec = new ModernConfigTemplateScreen.Spec(
        "mymod", "我的模组配置", mutableConfig)
        .setSubtitle("通过现代配置页编辑")
        .setDescription("覆盖 12 个模板入口的完整示例")
        .setConfigPath("config/mymod.json")
        .addField(new ModernConfigTemplateScreen.FieldSpec("player.name")
                .setLabel("玩家名称").setMaxLength(32))
        .addField(new ModernConfigTemplateScreen.FieldSpec("server.maxPlayers")
                .setLabel("最大玩家数").setRange(1, 100).setStep(1).setDefaultValue(20))
        .addField(new ModernConfigTemplateScreen.FieldSpec("render.mode")
                .setLabel("渲染模式").setValidValues("fast", "balanced", "safe"))
        .addField(new ModernConfigTemplateScreen.FieldSpec("theme.primary")
                .setLabel("主题色").setTemplateHint("color"));
```

> 入口检测与回退逻辑由 `ModConfigGui` 负责，接入方只需组装 `Spec` 并调用 `ModConfigGui` 提供的入口方法，无需直接 `new ModernConfigTemplateScreen`。
