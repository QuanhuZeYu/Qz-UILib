# 场景文本输入与浮层组件

> 适用范围：scene 新栈（club.heiqi.uilib.ui.scene）。文本控件遵循受控契约：文本真值由外部
> `value` 信号唯一持有，所有编辑经 `onChange.accept(next)` 上抛，控件自身绝不回写。

## SceneTextInput / SceneTextArea

### 受控契约

```java
Signal<String> value = Signal.create("");
SceneTextInput.Props props = SceneTextInput.Props.builder(value)
        .placeholder("输入…")
        .maxLength(32)
        .onChange(next -> value.set(next))   // 受控回路：回写 value
        .build();
Supplier<SceneNode> input = SceneTextInput.create(runtime, props);
runtime.mount(parent, input);
```

TextArea 同构，额外提供 `viewportHeight(int)`；`onChange` 中收到的文本可含 `\n` 换行符。

### 能力一览（P0/P1/P2 全部落地）

| 能力 | 快捷键/手势 | TextInput | TextArea |
|---|---|---|---|
| 框选 | 拖选 / Shift+方向键 / Shift+点击 | ✅ | ✅ 跨视觉行 |
| 词/行选择 | 双击选词、三击选行（TextArea=逻辑行） | ✅ | ✅ |
| 剪贴板 | Ctrl+C（无选区复制全文）/X/V、Ctrl+A | ✅ | ✅ |
| 词跳转 | Ctrl+←/→、Ctrl+Backspace/Delete | ✅ | ✅ |
| 文首尾 | Ctrl+Home/End | ✅ | ✅ |
| caret 闪烁 | 聚焦 530ms 亮/430ms 暗，交互重置 | ✅ | ✅ |
| 横向滚动 | caret 越界最小滚动（scrollableX） | ✅ | —（TextArea 由换行消除） |
| 纵向跟随 | caret 行超出视口滚动 | — | ✅ |
| soft wrap | 按视口可用宽软换行，↑/↓ 列保持、Home/End 视觉行级 | — | ✅ |
| Undo/Redo | Ctrl+Z / Ctrl+Y 或 Ctrl+Shift+Z（连续输入 500ms 合并） | ✅ | ✅ |
| 右键菜单 | 复制/剪切/粘贴/全选/撤销/重做（按 readOnly/选区启停） | ✅ | ✅ |
| IME | 组合态仅最终文本（lwjgl3ify 无 preedit 回调，已核实降级） | ✅ | ✅ |

只读态（`readOnly=true`）：可选中/移动/复制，禁止编辑与撤销；剪贴板仅 Ctrl+C。

## SceneContextMenu —— 右键上下文菜单

命令式打开：锚点取指针 host 局部坐标（事件上下文 `rawPointer - treeRootAbs`）。
自动向下/向上展开与横向收拢（`SceneAnchorResolver.resolveAuto`），ESC/外部点击/选择关闭，
↑/↓ 循环高亮、Enter 激活。

```java
rt.on(inputRoot, SceneEventType.POINTER_DOWN, (ev, ctx) -> {
    if (ev.getButton() != SceneMouseButton.RIGHT) {
        return;
    }
    SceneContextMenu.open(runtime,
            ctx.getRawPointerX() - ctx.getTreeRootAbsX(),
            ctx.getRawPointerY() - ctx.getTreeRootAbsY(),
            List.of(
                    SceneContextMenu.MenuItem.of("复制", () -> { /* ... */ }),
                    SceneContextMenu.MenuItem.of("删除", false, null),  // disabled
                    SceneContextMenu.MenuItem.divider(),
                    SceneContextMenu.MenuItem.of("关闭", () -> { /* ... */ })));
});
```

文本控件已内置默认右键菜单（复制/剪切/粘贴/全选/撤销/重做），无需自行注册。

## SceneDialog —— 模态对话框

`visible` 信号驱动；遮罩拦截指针（模态）、Tab 环自动限定对话框内、ESC 关闭。
`onDismiss` 实现必须把 `visible` 置 false。

```java
Signal<Boolean> dialogVisible = Signal.create(Boolean.FALSE);
SceneDialog.Props props = new SceneDialog.Props(
        dialogVisible,
        "删除确认",
        "此操作不可撤销，确定继续？",
        List.of(
                SceneDialog.Button.of("取消", () -> { }),
                new SceneDialog.Button("删除", SceneDialog.ButtonKind.DANGER, true,
                        () -> repository.delete())),
        () -> dialogVisible.set(Boolean.FALSE));
ScenePortalHandle handle = SceneDialog.create(runtime, props);
```

按钮 `ButtonKind`：`PRIMARY`（主操作）/ `NORMAL` / `DANGER`；
`closesDialog=false` 的按钮只执行回调不关闭；焦点态按钮 Enter/Space 激活。

## SceneToast —— 非模态通知

命令式投递，按 runtime 自动单例 host，底部堆叠，帧时间驱动自动消失（默认 3s），
整树不拦截指针（非模态）。

```java
SceneToast.show(runtime, "配置已保存");
SceneToast.show(runtime, "网络连接失败", 5_000_000_000L); // 5s
```

## 备注

- 真机帧管线（SceneFramePipeline）负责 overlay 锚定布局与 settle；单测环境下需手动布局 overlay 根。
- 剪贴板需宿主注入（`SceneRuntime.bindClipboard` + `ClipboardBackend`），未注入时 Ctrl+C/X/V 静默降级。
