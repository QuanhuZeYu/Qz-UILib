# 表格与背包槽位

表格和背包槽位是首版开放化中最容易被混用的两类能力，需要明确普通 UI 与 Minecraft 宿主能力的边界。

## 普通表格

`DocumentTableControl` 使用真实 `table/tbody/tr/td` 与按需 `thead/tr/th` 元素表达表格。

能力边界：

- 支持表头和表体。
- 支持列宽、自动列、行列 gap。
- 支持单元格 padding、border、background 和 text。
- 无表头时不保留空 `thead`。
- 绘制走标准 background、border 和 text paint command。

当前不覆盖：

- `colspan`。
- `rowspan`。
- `border-collapse`。
- `caption`。
- 完整 CSS table 算法。

## 背包槽位网格

当前槽位能力分三层：

- `SlotContentSnapshot`：槽位内容协议，负责描述占用态、内容类型、视觉内容源、显示名、数量和 tooltip。
- `DocumentSlotControl`：单个槽位控件，负责单格交互语义、样式状态和图片子节点装配。
- `DocumentSlotGridControl`：通用槽位网格，负责把多个槽位排成 `table/tbody/tr/td`。

`DocumentInventorySlotGridControl` 继续作为背包专用适配层存在，对外仍暴露 `InventorySlotSnapshot` 与背包点击/tooltip 语义，但内部已委托给通用槽位三层实现。

背包页 tooltip 的专项视觉与交互需求见 `docs/specs/inventory-overview-tooltip.md`。

能力边界：

- slot 背景和边框走标准 DOM 绘制。
- slot `td` 保留表格单元格语义。
- slot 同时带 `role="button"`、`tabindex="0"`、`data-slot-*` 和 `aria-label`。
- 支持鼠标 click、Enter/Space 左键激活、hover/active/selected 高亮；Space 按下只进入 active 态，松开时执行左键激活。
- 支持 tooltip hover 状态通知。
- Minecraft 物品图标通过每个槽位内部的 `DocumentHostImageControl` 子元素表达，不再由网格根元素批量回放绘制。
- `DocumentInventorySlotGridControl` 只负责把背包专用 `InventorySlotSnapshot` 转接到通用 `SlotContentSnapshot`，不再承载单槽位实现细节。

## 边界约定

- 普通表格不应依赖背包 slot 专用逻辑。
- 通用槽位能力优先扩展在 `SlotContentSnapshot`、`DocumentSlotControl`、`DocumentSlotGridControl` 上；不要把新能力继续直接堆进背包专用适配层。
- table 布局层不得加入 slot 专用分支。
- slot 半透明底板应叠在 UI 底图上，不应改成不透明来掩盖穿透问题。
- Minecraft 物品图标在作者侧心智上应被视为普通 DOM 图片子节点；底层宿主绘制细节由 `DocumentHostImageControl` 封装。
- 鼠标携带物品 overlay 应由页面级单一 DOM 图片层承载，不应回退到空元素 + custom renderer 的 retained 式叠层实现。
