# 完整业务页面示例

本文给出一个更接近真实接入的业务页面示例，串联页面打开、结构节点、文本输入、按钮和事件处理。

## 示例场景

- 页面标题和说明文字使用普通 DOM-like 结构节点。
- 角色名输入使用 `DocumentTextInputControl`。
- 提交按钮使用 `DocumentButtonControl`。
- 按钮动作会读取当前输入并更新页面内状态文案。

## 示例代码

```java
UiScreenManager.getInstance().enqueue(new Runnable() {
    @Override
    public void run() {
        Minecraft.getMinecraft().displayGuiScreen(UiDocumentScreens.createDocumentScreen(document -> {
            ElementNode root = document.getRootElement();
            root.style()
                    .setPadding(UiStyleLength.px(20))
                    .setBackgroundColor(0xE0101420)
                    .setTextColor(0xFFE5E7EB);

            ElementNode card = document.div();
            card.style()
                    .setWidth(UiStyleLength.px(420))
                    .setPadding(UiStyleLength.px(16))
                    .setBackgroundColor(0xCC111827)
                    .setBorderColor(0xFF334155)
                    .setBorderWidth(UiStyleLength.px(1));
            root.append(card);

            ElementNode title = document.element("h1");
            title.appendText("角色查询");
            card.append(title);

            ElementNode description = document.div();
            description.style()
                    .setMargin(UiStyleInsets.of(UiStyleLength.px(8), UiStyleLength.px(0),
                            UiStyleLength.px(0), UiStyleLength.px(0)))
                    .setTextColor(0xFFCBD5E1);
            description.appendText("输入角色名后点击按钮，这里只演示页面结构与事件流。");
            card.append(description);

            final String[] currentName = new String[] { "" };
            ElementNode status = document.div();
            status.style()
                    .setMargin(UiStyleInsets.of(UiStyleLength.px(12), UiStyleLength.px(0),
                            UiStyleLength.px(0), UiStyleLength.px(0)))
                    .setTextColor(0xFF93C5FD);
            final TextNode statusText = status.appendText("等待输入角色名。");

            DocumentTextInputControl nameInput = new DocumentTextInputControl(document)
                    .setPlaceholder("输入角色名")
                    .setChangeHandler(new DocumentTextInputChangeHandler() {
                        @Override
                        public void onTextChanged(DocumentTextInputChangeEvent event) {
                            currentName[0] = event.getText();
                            statusText.setText(event.getText().isEmpty()
                                    ? "等待输入角色名。"
                                    : "当前输入：" + event.getText());
                        }
                    });
            nameInput.getElement().style()
                    .setMargin(UiStyleInsets.of(UiStyleLength.px(12), UiStyleLength.px(0),
                            UiStyleLength.px(0), UiStyleLength.px(0)))
                    .setWidth(UiStyleLength.percent(1.0F));
            card.append(nameInput.getElement());

            DocumentButtonControl submitButton = new DocumentButtonControl(document, "打开角色页");
            submitButton.getElement().style()
                    .setMargin(UiStyleInsets.of(UiStyleLength.px(12), UiStyleLength.px(0),
                            UiStyleLength.px(0), UiStyleLength.px(0)));
            submitButton.setActionHandler(new DocumentButtonActionHandler() {
                @Override
                public void onAction(DocumentButtonActionEvent event) {
                    statusText.setText(currentName[0].isEmpty()
                            ? "请先输入角色名。"
                            : "准备打开角色页：" + currentName[0]);
                }
            });
            card.append(submitButton.getElement());
            card.append(status);
        }));
    }
});
```

## 这个示例想说明什么

- 打开页面时，优先调用 `UiDocumentScreens.createDocumentScreen(...)`，而不是自己拼 `HtmlLikeDocumentWidget`。
- 标题、说明、卡片容器这类纯结构节点，继续直接写 `document.element(...)`、`document.div()`。
- 输入框、按钮这类交互节点，优先使用 `Document*Control`，不要自己重复绑定 focus、text input 或 click 逻辑。
- `createDocumentScreen(...)` 已默认补齐根元素的全视口宽高和根滚动；示例里只关心页面视觉样式。
- 如果当前入口会在回调结束后关闭现有界面，例如聊天命令，就先通过 `UiScreenManager.enqueue(...)` 延后开屏。
