# 最小文档页面

本文给出首版开发者文档中的最小 HTML-like 页面结构。示例用于说明接入思路，具体公开 API 门面后续可在代码层进一步收口。

## 基本流程

1. 创建 `UiDocument`。
2. 获取根元素并设置布局样式。
3. 创建元素、文本和控件。
4. 创建 `HtmlLikeDocumentWidget`。
5. 将 widget 挂载到宿主 screen 的根视口。

## 示例代码

```java
UiDocument document = UiDocument.create();
ElementNode root = document.getRootElement();
root.style()
        .setWidth(UiStyleLength.percent(100))
        .setHeight(UiStyleLength.percent(100))
        .setPadding(UiStyleLength.px(16))
        .setBackgroundColor(0xE0101420)
        .setTextColor(0xFFE5E7EB);

ElementNode title = document.element("h1");
title.appendText("Qz UILib 页面");
root.append(title);

ElementNode content = document.div();
content.style()
        .setMarginTop(UiStyleLength.px(12))
        .setPadding(UiStyleLength.px(12))
        .setBackgroundColor(0xCC1F2937)
        .setBorderColor(0xFF60A5FA)
        .setBorderWidth(UiStyleLength.px(1));
content.appendText("这是一个通过 Java API 构建的 HTML-like 页面。");
root.append(content);

HtmlLikeDocumentWidget widget = new HtmlLikeDocumentWidget(document, 320, 180);
```

## 宿主挂载

当前内部页面使用 `BaseScreen` 和根 `Widget` 挂载 `HtmlLikeDocumentWidget`。面向外部开发者时，建议后续提供更薄的 screen 工厂，避免业务方直接复制内部诊断 screen 结构。

## 注意事项

- 根元素需要明确宽高或启用视口根滚动模式，否则布局结果可能不符合预期。
- 文本测量默认使用 Minecraft 字体运行时；纯 JVM 测试应注入确定性 `TextMeasureService`。
- `ElementNode.__getElementUid()` 是内部身份，不应作为业务 DOM id 使用。
- `data-hit-test-hidden="true"` 是内部 overlay 命中穿透约定，不是公开 CSS 能力。
