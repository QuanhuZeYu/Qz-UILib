# 最小文档页面

本文给出首版开发者文档中的最小 HTML-like 页面结构。宿主层已提供 `UiDocumentScreens.createDocumentScreen(...)`，用于从 Minecraft 入口直接创建业务 UI。

## 基本流程

1. 调用 `UiDocumentScreens.createDocumentScreen(...)`。
2. 在回调中获取根元素并设置页面样式。
3. 创建元素、文本和控件。
4. 使用 `Minecraft.displayGuiScreen(...)` 打开返回的 `GuiScreen`。

## 示例代码

```java
GuiScreen screen = UiDocumentScreens.createDocumentScreen(document -> {
    ElementNode root = document.getRootElement();
    root.style()
            .setPadding(UiStyleLength.px(16))
            .setBackgroundColor(0xE0101420)
            .setTextColor(0xFFE5E7EB);

    ElementNode title = document.element("h1");
    title.appendText("Qz UILib 页面");
    root.append(title);

    ElementNode content = document.div();
    content.style()
            .setMarginTop(UiStyleLength.px(12))
            .setPadding(UiStyleLength.px(12))
            .setBackgroundColor(0xCC1F2937)
            .setBorderColor(0xFF60A5FA)
            .setBorderWidth(UiStyleLength.px(1));
    content.appendText("这是一个通过 Java API 构建的 HTML-like 页面。");
    root.append(content);
});

Minecraft.getMinecraft().displayGuiScreen(screen);
```

## 宿主挂载

`UiDocumentScreens.createDocumentScreen(...)` 会负责：

- 创建 `UiDocument`。
- 创建并挂载 `HtmlLikeDocumentWidget`。
- 启用根元素视口滚动模式。
- 为根元素默认补齐 `width:100%`、`height:100%` 与 `overflow-y:auto`。
- 创建可直接传给 `displayGuiScreen(...)` 的 `GuiScreen`。

默认业务文档 screen 使用全视口挂载；页面留白、背景和滚动应由根元素样式表达。

## 注意事项

- 默认根元素已经是全视口并开启根滚动；只有需要覆盖默认行为时才显式设置宽高或 `overflow-y`。
- 业务 HTML-like 页面默认按原始文本处理，`§a`、`§k` 等内容会原样显示；如需显式解析 Minecraft 文本格式，可优先使用 `appendMinecraftText(...)` / `minecraftText(...)` 这类作者入口。
- 文本测量默认仍复用字体运行时；纯 JVM 测试应注入确定性 `TextMeasureService`。
- `ElementNode.__getElementUid()` 是内部身份，不应作为业务 DOM id 使用。
- `data-hit-test-hidden="true"` 是内部 overlay 命中穿透约定，不是公开 CSS 能力。
