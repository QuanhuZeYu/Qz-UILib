# 项目定位与能力边界

Qz UILib 首版面向 Minecraft 1.7.10 / GTNH / LWJGL3ify 环境提供 HTML-like UI 框架能力。

## 项目定位

- Qz UILib 是 Java UI 框架，不是浏览器内核。
- UI 作者通过 Java API 创建文档树、声明样式、注册事件和组装控件。
- 运行时负责把文档树转换为布局盒、paint command 和 `UiRenderContext` 绘制调用。
- Minecraft 宿主集成保留在外层，页面作者不应直接处理 OpenGL/FBO/shader/stencil 细节。
- HTML-like 文本默认是原始文本语义，不把 Minecraft `§` 格式码当作页面作者层的隐式样式系统。

## 当前可用能力

- DOM-like 文档树：`UiDocument`、`ElementNode`、`TextNode`。
- 宿主业务入口：`UiDocumentScreens.createDocumentScreen(...)`。
- 内建诊断/示例入口：仅保留内部开发工具命令入口，不构成对外页面 API。
- 常用样式：块布局、flex、table、px/%/auto 长度、margin、padding、border、分边 border-width / border-color、分角圆角、`box-sizing`、颜色、文本色、`font-weight`、`font-style`、overflow、absolute/fixed 定位、`box-shadow`、`outline`、`border-style`。
- 样式表规则：支持 tag/class/id/通配符/复合选择器、后代选择器 `A B`、子代选择器 `A > B`、交互伪类 `:hover` / `:focus` / `:focus-visible` / `:active` / `:disabled`、结构伪类 `:first-child` / `:last-child` / `:nth-child(...)`、按属性 `!important`、以及 `inherit` / `initial` / `unset` 级联关键字。
- 文本换行：`white-space:normal/nowrap`、`text-overflow:clip/ellipsis`、`word-break:normal/break-all/keep-all`、`overflow-wrap:normal/break-word/anywhere` 已在布局阶段生效。`nowrap` 优先禁止换行；ellipsis 仅在 `nowrap` 且宽度受限时生效；`anywhere` 与 `break-all` 会影响 auto 宽固有尺寸，`break-word` 只在受限宽度溢出时断长 token。
- flex 布局约束保持 HTML-like 直觉：`flex-direction:column` 下非 `stretch` 子项的 `width:auto` 会按内容收缩，而不是自动占满整行；auto 高文本块会按真实换行高度参与纵向排布，需要整行宽度时请显式设置 `width:100%`。
- 默认盒模型接近浏览器 `content-box`：`width:100%` 只约束内容宽，自身 padding/border 会叠加并可能溢出父内容盒；需要把 padding/border 收进指定宽度时显式使用 `box-sizing:border-box`。
- `position:absolute` 相对最近 positioned ancestor 的 padding box 定位；`position:relative` 的 `top/bottom:%` 按 containing block 高度解析。
- 输入事件：hover、active、click、dblclick、contextmenu、focus、key、text input、transitionend、animationend。
- 控件：按钮、单行文本输入、多行文本输入、下拉选择、开关、分段选择器、表格、背包槽位网格。
- 绘制：背景、边框、虚线/点线/双线边框、box-shadow、outline、文本、clip、scrollbar、custom renderer、group opacity、backdrop filter。
- 动画：颜色、透明度、圆角、backdrop blur，以及受控 layout 属性的 transition/keyframe。
- DOM 结构遍历：`getPreviousSibling()` / `getNextSibling()` 可按当前树结构直接读取相邻兄弟节点。
- 程序化交互：已公开 `ElementNode.focus()`、`blur()`、`scrollTo(scrollLeft, scrollTop)`、`scrollIntoView()`。

## 程序化焦点与滚动

- `focus()` 只对已挂载到当前文档、可聚焦、未 disabled 且处于可见布局中的元素生效；成功后会接入现有焦点链路，并在需要时自动滚入可视区域。
- `blur()` 只会清除当前已经获得文档焦点的同一元素；如果元素当前没有焦点，返回 `false`。
- `scrollTo(scrollLeft, scrollTop)` 只对当前文档中存在滚动范围的元素生效，偏移会按当前最大滚动范围夹取。
- `scrollIntoView()` 会滚动最近的可滚祖先，使目标元素尽量进入可视区域；目标已可见时通常不改变滚动值，但仍视为成功调用。
- `getScrollLeft()` / `getScrollTop()` / `getMaxScrollLeft()` / `getMaxScrollTop()` 可读取当前运行态滚动位置与可滚范围；元素未挂载或无滚动运行态时返回 `0`。
- 以上调用在元素未挂载、元素隐藏、不可聚焦或不具备滚动范围时保持无副作用并返回 `false`。

## 样式属性的已知边界

以下属性在底层或局部链路中已有基础，但页面作者层尚未完整接通，不应视为"已完整工作"：

- **`font-family`**：当前仍未向作者层开放为 CSS-like 样式属性；本次只补齐了 `font-weight` / `font-style`，没有扩到字体族声明、fallback 列表或声明式字体资源。
- **`white-space:pre/pre-wrap/pre-line`**：当前 `white-space` 仍仅支持 NORMAL / NOWRAP；本项目尚未提供保留空白符或保留换行的完整 CSS 模式。
- **`textarea` 软换行**：`DocumentTextAreaControl` 当前按“每个 `\n` 形成一条逻辑行”的最小模型实现，已支持多行输入、键盘光标移动、选区编辑和元素滚动，但还没有补浏览器 `pre-wrap` 式软换行；超长单行主要依赖横向滚动。
- **样式表规则边界**：当前 Java API 样式表不解析 CSS 文件，也不支持逗号分组、兄弟组合器、属性选择器、伪元素或 `@media`。`@media` 未纳入本轮，是因为当前样式表没有媒体环境宿主模型（视口尺寸、输入类型、宿主状态等）和重算触发契约；建议后续单独切分为“文档媒体环境对象 + media rule 容器 + 视口变化重算”的小专题。
- **状态伪类组合器边界**：`:hover` / `:focus` / `:active` 等交互伪类只基于当前计算目标传入的 `activeStates`。`.parent:hover .child` 这类依赖祖先运行时状态的选择器还没有完整状态传播模型，不应视为已支持。

## 事件与字体样式边界

- `dblclick` 是独立 DOM 事件，会在主按钮两次近距离、短时间内的连续命中 click 之后额外派发；单击事件不会因此被取消。
- `contextmenu` 作为独立右键菜单事件暴露，右键不会先派发普通 click；当前只负责事件语义与冒泡，不提供浏览器原生菜单系统、菜单项模型或宿主默认菜单接管。
- `transitionend` 按单个动画属性派发；`animationend` 按单个声明式 animation 名称派发；二者当前均为最小可用实现，只提供 target+bubble，不提供 capture 专用注册入口。
- `font-weight` 当前支持 `NORMAL` / `BOLD`；粗体会进入文本测量与换行计算。
- `font-style` 当前支持 `NORMAL` / `ITALIC`；斜体已进入文本绘制，但当前主要体现为渲染差异，不额外扩大 auto 宽测量。
- `font-weight` / `font-style` 的默认 `NORMAL` 样式与显式样式走同一最终文本绘制入口；文档层可把它们视为已接通属性，不需要为普通文本避开这两个声明。

## `cursor` 当前范围

- 运行时已把常用 `cursor` 值映射到 Minecraft 1.7.10 / LWJGL3ify / SDL 的真实系统光标：`default`、`pointer`、`text`、`move`、`not-allowed`、`wait`、`crosshair`、`ew-resize`、`ns-resize`、`none`。
- `grab` 与 `grabbing` 当前降级为 `move`，因为宿主标准系统光标集中没有独立的抓取手形。
- `help` 当前降级为 `default`，因为宿主标准系统光标集中没有独立的帮助问号光标。
- 鼠标离开命中元素、没有命中任何元素，或命中链（命中元素及其祖先）都未声明 `cursor` 时，会恢复默认箭头光标。
- 当前只支持宿主标准系统光标，不支持 CSS 自定义图片光标；`DocumentCursorOverlayControl` 仍然只是页面级图片覆层，不等同于系统光标。

详细差距分析见 [`docs/reviews/REVIEW-20260518-browser-capability-gap-audit.md`](../../reviews/REVIEW-20260518-browser-capability-gap-audit.md)。

## 当前非目标

- 不提供 HTML 文件解析。
- 不提供 CSS 文件解析（`@import`、`@media` 媒体查询）；Java API 已支持 CSS-like 选择器匹配（tag/class/id/复合/后代/子代/常用伪类）与样式表级联。
- 不提供 JavaScript DOM API。
- 不承诺 HTML5 全量语义。
- 不把 Minecraft GUI 生命周期或渲染底层暴露为页面作者 API。

## 开放化边界

- 首版文档应优先引导开发者使用 `createDocumentScreen(...)` 和 HTML-like 文档入口。
- 诊断页、Smoke 页和 Glass Lab 是开发工具，不是业务 UI 模板。
- 旧 retained `Widget` 树仍是后端基础，但不建议作为新业务页面的作者入口。
- 外部开发者需要的正式 API 门面后续可单独建立，不应直接把内部控制器作为稳定 API。
