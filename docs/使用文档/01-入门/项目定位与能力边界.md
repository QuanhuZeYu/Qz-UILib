# 项目定位与能力边界

Qz UILib 面向 Minecraft 1.7.10 / GTNH 环境提供 scene 树 + 细粒度响应式的 UI 框架；存在 LWJGL3ify 时会接入其增强输入能力，但发布产物不强制把它声明为下游硬依赖。

> 历史：本文件曾描述 HTML-like document 栈（`UiDocument / ElementNode / CSS-like 样式表`），该栈已随
> breaking major 整体删除；以下按 4.8.0 scene 栈现状重写。

## 项目定位

- Qz UILib 是 Java UI 框架，不是浏览器内核：不解析 HTML、不解析 CSS、不提供 JavaScript。
- UI 作者用 Java API 组装 `SceneNode` 树、声明 `Signal` 状态、经 `SceneRuntime` 挂载与绑定。
- 运行时把树转换为布局盒（flex）、`PaintPlan`（自包含不可变绘制计划）与 `UiRenderBackend` 调用。
- Minecraft 宿主集成保留在外层（`McScreenBridge` / `AbstractSceneHostWidget`），页面作者不直接处理 OpenGL/FBO/shader/stencil 细节。
- scene core 平台无关：编译期零 LWJGL/MC 依赖；平台适配只在 host 边界（`ui.scene.host.lwjgl` 反射探测）。

## 当前可用能力

- **响应式**：`Signal / Computed / Effect / Owner` 细粒度订阅，帧末 `flush` 批量落地，`SceneRuntime.mount / bind / bindComputed / forEach（keyed 列表）/ show（条件渲染）/ portal（浮层）`。
- **布局**：flex（column/row、gap/padding、grow/shrink、对齐）、约束解析、滚动容器、虚拟网格（`SceneVirtualGrid`）、anchor 定位浮层；脏标记向上冒泡 + 布局/绘制/合成三阶段剪枝。（曾有的独立 grid 布局门面 `GridLayouts/GridSpec` 因零生产消费者已退役，网格需求走虚拟网格/flex 行容器。）
- **控件**：按钮、单/多行文本输入、自动完成、下拉选择（单选/多选）、滑块、开关、复选框、单选组、分段选择器、标签页、数据表（可编辑单元格）、键值映射、对象字段、方块选择器面板（`ScenePickerPanel`，多列成员网格）、拖拽排序、面包屑、tooltip、列表与导航列表。
- **文本**：测量服务、自动换行、ellipsis 截断、字体服务（reload 生命周期）、glyph atlas 与批渲染。
- **绘制**：背景/边框/圆角/文本/图片、item icon（完整原版委托 + `RenderSemantics` + `ItemRenderTierRegistry` 分级）、backdrop blur、opacity、transform、clip。
- **输入**：键盘/指针/滚轮事件、焦点管理与 Tab 环、hover/active 状态、系统光标投影。
- **浮层**：portal / 锚定浮层（`portalAnchored` + `AnchorProvider`）、dismiss 策略、锚点不可见自动关闭。
- **动画**：Motion 逐帧插值（颜色/浮点）、staggered reveal 级联揭示。
- **配置**：`ConfigSchema` 声明 → `ConfigManager` 权威运行时（乐观保存、校验 reload）→ `ConfigUI.buildScreen` 配置页；SearchPicker 编辑器为 beta。
- **网络**：`NetService` Channel / Fetch / Stream / Store 双端通信。
- **HUD**：`ClientHudService` 被动展示（`TextHud` / `CompactHud`），不接收输入。

## 当前非目标

- 不提供 HTML 文件解析、CSS 文件解析、JavaScript DOM API，不承诺浏览器语义。
- 不提供背包槽位网格或通用 slot 容器（breaking major 已移除 `ui.slot / ui.inventory`）。
- 不把 Minecraft GUI 生命周期、GL 调用或渲染底层暴露为页面作者 API。
- 不向原版背包注入按钮，不占用全局热键；诊断页/示例页只作开发期工具，不构成对外稳定 API。
- scene 引擎内部（layout/paint 引擎、输入路由器、mixin、net 传输细节）与 `internal` 包不构成稳定承诺。
