# 接入指南

先核对[核心及模块规格](<../开发者文档/规格文档/README.md>)。规格定义目标与验收，下面的指南说明当前生产入口。

- [声明式页面接入](<../开发者文档/声明式页面接入.md>)：ScenePage、页面作用域和MinecraftSceneScreen。
- [标准控件与动态主题](<../开发者文档/标准控件与动态主题.md>)：正式按钮、标签、浅深主题和文案策略。
- [双实例验证清单](<../开发者文档/标准控件双实例验证清单.md>)：人工验收操作与反馈方式。

目前页面、标准按钮与标签、主题、焦点导航和滚动显露已接入。编辑/IME、其它控件及配置、网络、HUD等专题须按规格与当前源码核对，不能从旧版本教程推断为可用。
