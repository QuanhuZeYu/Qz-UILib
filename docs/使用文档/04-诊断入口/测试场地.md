# 测试场地（Test Playground）

> 适用范围：Qz UILib 内部调试设施（`internal.devtools.playground`），**不构成对外公共 API 承诺**。

测试场地是游戏内的 scene 新栈能力演示与验收入口，用于在真实 Minecraft 渲染与输入链路下验证
文本输入、浮层与响应式底层能力是否按预期工作。

## 打开方式

在游戏内聊天框输入：

```text
/qzuilib test
```

打开后进入 **总览（Home）页**：列出全部演示页与文本能力快捷键速查。顶部分段导航切换页面，
ESC 关闭测试场地返回原界面。

> 聊天命令执行结束后聊天界面仍会关闭当前 GuiScreen，故开屏操作延后到当前帧分发完成后执行
> （`TestPlaygroundEntry.open()` 内部经 `UiScreenManager.enqueue` 入队），不要在
> `processCommand` 中直接 `displayGuiScreen`。

## 演示页

| 页面 | 覆盖能力 |
|---|---|
| 总览（Home） | 页面清单（自动跟随注册表）、快捷键速查 |
| 单行文本 | SceneTextInput 受控契约、placeholder、maxLength 限长、只读态、密码/数字输入类型、输入实时回读与码点统计 |
| 多行文本 | SceneTextArea soft wrap 视觉行、跨行选区/双击选词/三击选行、剪贴板、Undo/Redo（Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z）、纵向跟随滚动 |
| 浮层 | SceneDialog 多按钮（NORMAL/PRIMARY/DANGER、closesDialog 语义、ESC 关闭、模态遮罩）、SceneToast 命令式投递与不同时长堆叠、SceneContextMenu 右键命令式打开与菜单项启停/分隔线 |
| 响应式 | Signal 受控源、Computed 记忆化派生、rt.show 条件渲染、rt.forEach keyed 列表增删协调 |

文本输入框内置默认右键菜单（复制/剪切/粘贴/全选/撤销/重做，按 readOnly/选区/历史自动启停），
无需额外配置。

## 快捷操作速查

| 快捷键 | 能力 |
|---|---|
| Ctrl+C / Ctrl+X / Ctrl+V | 复制 / 剪切 / 粘贴（无选区时 Ctrl+C 复制全文） |
| Ctrl+A | 全选 |
| Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y | 撤销 / 重做（连续输入 500ms 内合并为一条历史，上限 100 条） |
| Shift+方向键 | 扩展选区 |
| 双击 / 三击 | 选词 / 选行（TextArea 为逻辑行） |
| Ctrl+左 / Ctrl+右 | 词跳转 |
| Ctrl+Home / Ctrl+End | 文首 / 文尾 |
| Ctrl+Backspace / Ctrl+Delete | 删词 |
| 右键文本输入框 | 内置上下文菜单 |

剪贴板需宿主在 runtime 注入 `ClipboardBackend`（本场地由 LWJGL 桥接注入；未注入环境静默降级）。

## 扩展演示页

新增演示页的低成本路径（注册表是唯一扩展点）：

1. 实现 `club.heiqi.uilib.internal.devtools.playground.PlaygroundPage`：
   - `id()` 唯一小写 id、`title()` 导航标题、`description()` 总览说明；
   - `build(SceneRuntime rt)` 返回组件函数（在 mount Owner 作用域内执行一次，页面实例可持有
     自己的 `Signal` 状态，切走再切回状态保留）。
2. 把页面类放入 `internal.devtools.playground.pages` 子包。
3. 在 `PlaygroundPageRegistry.createDefaultPages()` 列表追加一条（顺序即导航顺序，首项为默认页）。

宿主导航（SceneSegmented）、Home 总览清单与单槽切换状态机自动生效，无需改动其它代码。

## 给演示页开发者的布局约束速查

- 按钮用 `PlaygroundKit.button/primaryButton`（内部已挂载并按内容宽 SHRINK 排布），
  **不要**再对返回值 `appendChild`，也不要自行 new 裸 ROW 放 FILL 按钮——那样按钮会拉满整行、
  后续按钮被挤出容器右缘（历史踩坑：ERROR-20260818-playground-row-button-fill-and-dual-mount）。
- 要「按钮靠右」用 `setMainAxisAlign(MainAxisAlign.END)`，要「两端撑开」用 `PlaygroundKit.spacer()`。
- 完整布局约束见 [开发者文档：布局约束与踩坑](../../开发者文档/布局约束与踩坑.md)。
