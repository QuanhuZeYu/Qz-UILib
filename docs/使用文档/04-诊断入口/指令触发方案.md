# 指令入口

Qz UILib 的调试入口只保留一个显式客户端指令：`/qzuilib modernconfig`（新架构配置页调试入口）。
scene 演示测试台（原 `/qzuilib test` 与 `/qzuilib scene_test` 及其 `internal/devtools/pages` 包）已移除。

本文只描述诊断入口约束；业务 UI 打开方式以 `03-宿主集成/Minecraft界面入口.md` 为准。

## 不会注入的默认入口

为避免与宿主自有界面冲突，本库不会向原版界面或全局热键注入入口：

- 不在原版背包页插入 `背包UI` 按钮。
- 不绑定全局热键打开或关闭诊断菜单。

## 指令入口

```text
/qzuilib modernconfig
```

命令语义：

- `/qzuilib modernconfig` 打开新架构配置页（`ModernConfigEntry.open()`）——uilib 作为新架构配置页
  首个真实使用方的调试入口。
- scene 演示测试台（test hub 与各 Scene demo 页）已移除，不再提供运行时演示页。

## 时序约束

- 聊天命令执行结束后，聊天界面仍会继续关闭当前 `GuiScreen`。
- 因此客户端命令不能在 `processCommand(...)` 中直接 `displayGuiScreen(...)`；
  开屏逻辑委托 `ModernConfigEntry.open()`（内部走延后开屏路径）。

## 验收

- 普通打开原版背包时不出现 `背包UI` 测试按钮。
- 按右 Shift 不打开诊断菜单。
- `/qzuilib modernconfig` 能打开新架构配置页，字段编辑与保存反馈正常。
