# 指令触发方案

首版面向其他开发者时，测试期入口应从默认 UI 注入和全局热键迁移到显式客户端指令。

## 要移除的默认入口

- 原版背包页注入 `背包UI` 按钮。
- 右 Shift 全局打开或关闭诊断菜单。

## 建议保留的诊断能力

- 诊断菜单。
- 布局诊断页。
- HTML-like Smoke 页。
- Glass Lab 页。
- 背包概览示例页。

## 指令入口

```text
/qzuilib test
```

命令语义：

- `/qzuilib test` 打开诊断跳转菜单。
- 诊断跳转菜单内提供布局诊断页、HTML-like Smoke 页、Glass Lab 页和背包概览示例页入口。

## 代码调整点

- 在客户端侧注册 `QzUiLibClientCommand`。
- 在 `ClientProxy` 中注册客户端命令。
- `ClientProxy` 不再默认注册 `InventoryScreenEntryListener`。
- `UiScreenManager` 删除或禁用 `Keyboard.KEY_RSHIFT` 打开诊断菜单逻辑。
- `UiInputTickListener` 保留，只负责输入 tick 和 UI screen manager tick。

## 验收

- 普通打开原版背包时不出现 `背包UI` 测试按钮。
- 按右 Shift 不打开诊断菜单。
- `/qzuilib test` 能打开诊断跳转菜单。
- 诊断跳转菜单能跳转到布局诊断页、HTML-like Smoke 页、Glass Lab 页和背包概览示例页。
- 诊断页中的输入、hover、click、scroll 和键盘焦点仍正常。
