# 指令入口

Qz UILib 的调试入口是显式客户端指令 `/qzuilib`，含两个子命令：

- `/qzuilib test` —— 打开 scene 测试场地（`internal.devtools.playground`），在游戏内验证
  文本输入/浮层/响应式能力（详见 [测试场地.md](测试场地.md)）；
- `/qzuilib modernconfig` —— 打开新架构配置页调试入口。

两个入口都是 internal 调试设施，不构成对外公共 API 承诺；本文只描述诊断入口约束，
业务 UI 打开方式以 `03-宿主集成/Minecraft界面入口.md` 为准。

## 不会注入的默认入口

为避免与宿主自有界面冲突，本库不会向原版界面或全局热键注入入口：

- 不在原版背包页插入 `背包UI` 按钮。
- 不绑定全局热键打开或关闭诊断菜单。

## 指令入口

```text
/qzuilib <test|modernconfig>
```

命令语义：

- `/qzuilib test` 打开 scene 测试场地（`TestPlaygroundEntry.open()`）——游戏内演示/验收
  文本输入、浮层与响应式能力的调试入口。
- `/qzuilib modernconfig` 打开新架构配置页（`ModernConfigEntry.open()`）——uilib 作为新架构配置页
  首个真实使用方的调试入口。

## 时序约束

- 聊天命令执行结束后，聊天界面仍会继续关闭当前 `GuiScreen`。
- 因此客户端命令不能在 `processCommand(...)` 中直接 `displayGuiScreen(...)`；
  开屏逻辑委托 `ModernConfigEntry.open()`（内部走延后开屏路径）。

## 验收

- 普通打开原版背包时不出现 `背包UI` 测试按钮。
- 按右 Shift 不打开诊断菜单。
- `/qzuilib test` 能打开测试场地，分段导航切换页面正常，文本输入框可聚焦编辑、右键菜单/对话框/Toast 可用。
- `/qzuilib modernconfig` 能打开新架构配置页，字段编辑与保存反馈正常。
