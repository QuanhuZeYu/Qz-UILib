## 2026-05-18-browser-capability-gap-audit
- 类型：浏览器常用能力差距审查
- 详情文档：[`docs/reviews/REVIEW-20260518-browser-capability-gap-audit.md`](reviews/REVIEW-20260518-browser-capability-gap-audit.md)
- 结论摘要：共核查 65 项浏览器常用能力（CSS 布局/样式/选择器、事件、DOM、表单），其中 27 项完整实现、8 项部分实现（声明与实现不一致）、30 项完全没有实现。发现 `cursor` 属性声明链路完整但系统光标从未映射、`overflow-wrap`/`word-break` 样式已声明但布局引擎未消费、`font-weight`/`font-style` 底层有能力但 CSS 属性层未暴露，三处属”文档比实现更乐观”。优先补齐建议：接通 cursor 系统光标、overflow-wrap 布局消费、focus()/blur() 公开 API、scrollIntoView 公开 API、textarea 多行文本。
