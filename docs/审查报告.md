## 2026-05-18-browser-capability-gap-audit
- 类型：浏览器常用能力差距审查
- 详情文档：[`docs/reviews/REVIEW-20260518-browser-capability-gap-audit.md`](reviews/REVIEW-20260518-browser-capability-gap-audit.md)
- 结论摘要：共核查 65 项浏览器常用能力（CSS 布局/样式/选择器、事件、DOM、表单），其中 27 项完整实现、8 项部分实现（声明与实现不一致）、30 项完全没有实现。发现 `cursor` 属性声明链路完整但系统光标从未映射、`overflow-wrap`/`word-break` 样式已声明但布局引擎未消费、`font-weight`/`font-style` 底层有能力但 CSS 属性层未暴露，三处属”文档比实现更乐观“。后续补齐状态：`cursor`、`overflow-wrap` / `word-break`、`focus()` / `blur()` / `scrollTo()` / `scrollIntoView()`、兄弟节点遍历、`font-weight` / `font-style`、`dblclick` / `contextmenu` / `transitionend` / `animationend`、`textarea`、最小 `select`、flex `order`、`calc()` 最小混合长度、`position:sticky` 首阶段闭环、`text-shadow`、`text-transform`、`text-indent`、`white-space:pre/pre-wrap/pre-line` 和单图 `background-image` 已落地；`font-family`、`display:grid`、`transform`、gradient、多背景、多重阴影、`float`、完整 `textarea` 软换行和完整浏览器原生下拉能力仍按详情文档边界处理。

## 2026-05-20-ui-framework-structure-audit
- 类型：UI 部分代码框架结构审查（明确排除字体服务）
- 详情文档：[`docs/reviews/REVIEW-20260520-ui-framework-structure-audit.md`](reviews/REVIEW-20260520-ui-framework-structure-audit.md)
- 结论摘要：UI 部分整体分层方向合理，单向依赖（dom + style → layout → paint command → renderer → render）、命令-回放分离、`DocumentEffectChain` 共享效果链、注入式时钟与运行时适配器、对外门面（`UiDocumentScreens` + `Internal*` 隔离诊断/示例）等都是优良设计。但存在以下结构性技术债：1) 5 个超千行的 god class（`DocumentLayoutEngine` 2964、`HtmlLikeDocumentWidget` 2107、`UiMainLayerSnapshotService` 1418、`DocumentAnimationTimeline` 1380、`UiRenderContext` 1376、`ElementNode` 1155，合计 ≈ 1.4 万行）；2) 8 个示例 controller 共约 250 KB / 5900 行 package-private 演示代码混入 `src/main` 主产物；3) `screen` 包 29 文件混 6 类抽象层级、`style` 包 51 文件铺一层；4) `dom/control` 实质是应用级控件却归属于 dom 包；5) `layout/UiAlignSelf` 死代码全项目零引用；6) 30+ 个 `DocumentElement*Event` 模板代码重复约 7×N 行；7) input 包反向依赖 `ui.hud` 与 `ui.screen` 破坏方向约束；8) 命名前缀 `Document*` / `Ui*` / `Internal*` / 无前缀 四套并存且无书面规范。已按 P0~P3 排序给出优先级与改动范围、风险评估，待用户决定是否启动具体重构任务。
