- 本文件是唯一权威状态源，状态变化直接覆盖，不堆历史交接。
- 只保留：当前状态 + 未收敛项 + 待拍板 + 最近完成简表 + 长期指针。
- 瞬时状态（分支/HEAD/工作区/测试/阻塞/待办）写本文件；
  控制律（完成标准/约束/审核纪律/fixer 串行规则）归 `AGENTS.md` 与
  `SUBAGENT-ORCHESTRATION.md`，不入本文件（避控制律误并入状态）。
- 长期事实按控制分层归位（设定值/控制律/传感/诊断层），关键取舍归 `docs/反馈层/决策/`，错误预防通则归
  `docs/反馈层/错误预防.md`，本文件只留指针。
- 未收敛项收敛后即从 §2 移除，不保留历史。

## 状态层次边界（防混淆）

本文件是**项目级**状态源（跨多任务、长期）。**会话级**工作记忆（单任务内、易失）不进本文件，归
`docs/控制律层/编排模式/SESSION-HANDOFF.md` 模式下的 `.opencode/session-handoff.md`。
会话 handoff 中"有持续价值的事实"任务完成后才回流到本文件或决策/错误预防，其余丢弃。
