## 当前状态

- 当前开发分支：`fix/browser-semantics-phase2`
- 首批 P0/P1 修复已落地：
  - `DocumentNode.insertBefore`/`replaceChild` 同父移动时先移除再重算参考索引，并补齐 `appendChild`/`insertBefore` 返回插入节点语义
  - `DocumentLayoutEngine` 按 max 再 min 应用尺寸约束，确保 `min-width/min-height > max-*` 时 min 胜出，并修正正负/全负相邻 margin collapse

  - `FlexLayoutHelper` 支持 row flex item 默认 `min-width:auto` 与 `flex-basis` 的 border-box 换算
- 已通过 `compileJava`、`git diff --check`、相关 DOM / layout / flex / effect / hit-test / paint / visual traversal 测试集
- 完整 `./gradlew.bat --no-configuration-cache test` 当前仍可能在配置阶段失败：`gtnhconvention` 加载 GitHub manifest 波动，属于既有外部阻塞记录
