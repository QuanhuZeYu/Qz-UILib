## 当前状态

- 当前主分支：`4.0`，已包含 phase1 全部提交，工作区干净，与 `origin/4.0` 一致
- phase1 已落地的浏览器语义结论（按子系统归并，细节以源码为准）：
  - 事件：`pointer-events` 默认继承；`click` 按 down/up 最近公共祖先解析 target，`mouseup` 按释放位置命中；raw button 键盘激活走完整 click 分发链；`AT_TARGET` 在 capture 后仍执行 target handler（除非 `stopImmediatePropagation()`）；事件返回值与默认行为解耦，`return true` 只停传播，默认行为仅受 `preventDefault()` 控制；`dblclick` / `contextmenu` 补齐 capture → target → bubble 三阶段
  - 样式与命中：`visibility:hidden` 隐藏自身但允许 `visibility:visible` 后代恢复绘制与命中
  - 布局：block 布局补齐 BFC margin collapse 阻断、普通父子顶部 margin collapse、overflow 阻断父子 collapse
  - 共享视觉层：新增 `DocumentVisualTraversal` 统一 `fixed/sticky` 偏移、scroll offset、overflow clip 链与 stacking phase；`DocumentPaintEngine`、`DocumentHitTestEngine`、`DocumentScrollState`、`HtmlLikeDocumentWidget` 改为复用同一套根级顺序与定位查询，不再各自维护遍历逻辑（含普通树 + `top-layer` 根盒统一 `VisualScene`）
  - `top-layer` 运行态：HUD 共享文档适配 `pointer-events` 继承，交互 mount root 显式恢复 `auto` 且宿主忽略 mount root 自身空白；动画时间线与 `requestAnimation(...)` 覆盖普通树 + `top-layer` 根盒
- 已补回归测试（按子系统）：`UiStyleResolverTest`、`DocumentHitTestEngineTest`、`DocumentPaintEngineTest`、`DocumentLayoutEngineTest`、`DocumentEventPropagationTest`、`HtmlLikeDocumentWidgetTest`、`DocumentVisualTraversalTest`、`DocumentScrollStateTest`、`UiHudDocumentHostTest`、`UiRuntimeSelfTestDocumentPageControllerTest` 及相关控件测试
- 已知有意能力边界（非待修复项，文档已声明）：keyframe per-stop timing 与完整 Web Animations API 不承诺；CSS `var(...)` 声明级自动解析未实现；`align-items:baseline` 首版等价 START
