## 当前状态

- 当前主分支：`4.0`
- 首批 P0/P1 修复已落地：
  - `DocumentNode.insertBefore`/`replaceChild` 同父移动时先移除再重算参考索引，并补齐 `appendChild`/`insertBefore` 返回插入节点语义
  - `DocumentLayoutEngine` 按 max 再 min 应用尺寸约束，确保 `min-width/min-height > max-*` 时 min 胜出，并修正正负/全负相邻 margin collapse
  - `DocumentEffectChain` 将 `position:fixed` 视为 CSS-like stacking context，并让 overflow 子内容 clip 可达性按 padding box 圆角判断
  - `ElementSemantics` 将 `disabled` 作为 HTML 布尔属性处理，`disabled="false"` 仍禁用
  - `FlexLayoutHelper` 支持 row flex item 默认 `min-width:auto` 与 `flex-basis` 的 border-box 换算
- 第二批浏览器语义修复已在当前工作分支落地：
  - `DocumentNode.removeChild` 改为返回被移除节点，非直接子节点报错；`DocumentQuerySupport.querySelector*` 不再把内部根节点作为 document 查询结果
  - `DocumentFocusManager` 将 `focusin` 限定为获得焦点，并新增独立 `focusout` 冒泡事件；焦点切换按 `focusout` → `focusin` → `blur` → `focus` 分发
  - `DocumentMouseEventDispatcher` 将 hover/active 作为状态通知，不再被目标 handler 返回值截断祖先通知
  - `UiStyleProperty` 修正 `border-collapse` 继承与 `font-style` 布局失效；复核确认 `text-shadow` 按 CSS 标准应保持继承
  - `DocumentPaintEngine` 将 inset box-shadow 绘制在背景之上、边框之下
- 第三批浏览器语义修复已合并回 `4.0`：
  - 新增 `DocumentElementWheelEvent` / `DocumentElementWheelHandler` 与 `setWheelHandler` / `setCaptureWheelHandler`
  - `HtmlLikeDocumentWidget.onMouseScroll` 先分发 wheel DOM-like 事件，再执行默认滚动；`preventDefault()` 阻止默认滚动，handler 返回 `true` 仅停止传播
- 第四批浏览器语义修复已合并回 `4.0`：
  - `transform` 祖先会建立 fixed containing block，fixed 后代改为相对该祖先 padding box 定位
  - `DocumentVisualTraversal` 在 fixed 后代位于 transform containing block 内时保留祖先 scroll/clip 传播，不再无条件清空 clip chain
- 已通过 `compileJava`、`git diff --check`、相关 DOM / layout / flex / effect / hit-test / paint / visual traversal 测试集；第四批已通过在线 `DocumentLayoutEngineTest` / `DocumentVisualTraversalTest` / `DocumentHitTestEngineTest` / `DocumentPaintEngineTest` 与在线 `compileJava`
- 曾通过完整 `./gradlew.bat --no-configuration-cache test`；第三、四批尚未重跑完整 test
- 已知有意能力边界（非待修复项）：keyframe per-stop timing、完整 Web Animations API、CSS `var(...)` 声明级解析、`align-items:baseline` 等价 START、CSS Grid、transform 矩阵堆栈、gradient、float
- B 类缺口当前进度：input type（password/number）已完成；font-family 因底层无字体族维度跳过并记录决策；textContent 已完成；textarea 软换行因需行模型重构跳过并记录决策；background-image 的 CSS `url(...)` 解析已完成，远程 CSS 支持 `ResourceLocation` 单图 URL 与 `none`，仍不扩展 HTTP 背景图、渐变、多背景或 repeat/position/size
