## SceneTable 进入页 POINTER 残留最终修复（已完成并真机验收）

- **真机现象**：用户反馈从上一个页面的手型按钮进入 `SceneTable` 独立页后，鼠标仍保持 `POINTER`，未恢复默认箭头。
- **最终根因**：旧 HTML-like 按钮页把共享宿主真实光标设为 `POINTER`，关闭时没有复位；新 `SceneTable` 页 `cursorSignal` 初值/期望值均为 `DEFAULT`，页面无非默认 cursor 节点，`cursorSignal.set(DEFAULT)` 被 `ReactiveScheduler` 同值去重吸收，cursor effect 不重跑，宿主真实状态无法恢复。
- **修复策略**：不把旧页残留 `POINTER` 初始化进新页 signal；改为宿主边界强制同步当前 UI 期望光标。`UiCursorHost.forceApplyCursor(...)` / `SystemUiCursorHost.forceApplyCursor(...)` 用于绕过宿主同值短路，处理宿主原生状态与响应式/宿主缓存漂移。
- **落地修复**：`HtmlLikeDocumentWidget.close()` 释放旧栈 document runtime 后强制 `forceApplyCursor(UiCursor.DEFAULT)`；补齐 `ForgeConfigTemplateScreen.onGuiClosed()` 与 `UiTestDocumentPageController.onDocumentClosed()` 的 `documentWidget.close()` 漏接。已否决 `SceneRuntime.flush()` 每帧 `forceApply`，避免把 SDL 同步放入 scene 热路径。
- **命名清理**：新增中性 `UiCursorHost` / `SystemUiCursorHost`；旧 `DocumentCursorHost` / `SystemDocumentCursorHost` 仅作为旧栈兼容入口，默认单例委托同一个 `SystemUiCursorHost`。`LwjglCursorBackend` 改走 `UiCursorHost.system()`，新栈与该适配层已无旧栈 `Document...` 光标命名。
- **测试**：`HtmlLikeDocumentWidgetCursorTest` 覆盖 DEFAULT 系统光标路径、`forceApplyCursor(DEFAULT)` 绕过同值短路、widget close 强制复位；`SceneRouterCursorTest` 验证 scene cursor signal 行为未破坏。定向测试结果以最近交接记录为准。
- **真机验收**：用户已确认进入 `SceneTable` 页后手型残留问题不再出现。

## 滚动后 hit/绘制不跟随修复（已完成，待真机复验）

- **根因（explorer 侦察验证）**：`scrollOffsetY` 是 paint-only 偏移。`SceneNode.setScrollOffsetY` 只 `markGeometryDirty` 不 `markSelfLayout`（守 I7，layout 刻意不把 offset 烤进 LayoutBox.y）；`ScenePaintEngine:174` 唯一注入 `-scrollOffsetY`；但 `SceneHitTester:67-68` 与 `SceneGeometry.absoluteBox:39-40` 只读 LayoutBox 累加绝对坐标、对滚动零感知。导致：①主树 trigger/卡片 hit 不跟随 ②trigger 的 absoluteBox 停在旧位 → overlay anchorY 错 → listbox 绘制和命中全错（比①多错绘制）。anchor 是每帧重解析（非快照），根因在解析源不读滚动。
- **修复（3 实现 commit + 1 登记commit）**：
  - `a62da1d6` 对齐滚动偏移几何探针：抽 `SceneGeometry.childYBase(parent, parentAbsY)` 单层注入原子（判 `parent.isScrollable()` 而非 self——scrollable 节点自己不被自己 offset 位移），`ScenePaintEngine`/`SceneHitTester`/`SceneGeometry.absoluteBox`（回溯式沿 parent 链注入）三方共用同一原子定义，消除「三处独立累加」温床；paint 改用原子纯重构零行为变化；hit-test 递归注入偏移。
  - `7c814926` 裁剪滚动视口命中区域：`SceneHitTester.hitTestRecursive` 新增 clip bounds 递归参数（null=无裁剪），进入 scrollable 子树用其 LayoutBox 绝对盒作 clip，嵌套取交集，子节点注入滚动后 absBox 与 clip 零交集跳过；类保持无状态（参数传递不用成员栈）；与 paint CLIP 对称（滚出视口不可点）。
  - `18143ecf` 关闭不可见锚点浮层：`AbstractSceneHostWidget.dismissOverlaysWithInvisibleAnchor` 独立步骤（render 中 layoutOverlays 后单独调用，不混进纯布局的 layoutOverlays）；对每个有 anchorProvider 的 overlay entry，沿 trigger parent 链收集所有 isScrollable 祖先视口框求交，零交集 → `entry.requestDismiss()` 走 signal 回调 `expanded.set(false)`（守 I11 逃生舱②）；有交集即保持防半遮闪关；单帧绘制延迟可接受不特判。`AnchorProvider` 最小扩展 `getNode()/forNode()` 支持可见性判断（原只暴露矩形）。复用 `SceneGeometry.intersect` 求交原子。
  - `d0e3445b` 登记与规范：NORTH_STAR《偏离登记》`:247` scrollable 条目补完几何探针对齐；AGENTS.md 第 7 节新增中断恢复纪律。
- **裁决与审核**：oracle 裁决方案正确，三关键修正——①工具判 parent.isScrollable 而非 self ②paint 共用单层注入原子但不共用 absoluteBox（下沉 O(N) vs 回溯 O(N²)，强行共用会变 O(N²)）③absoluteBox 保持纯几何不加 clip/可见性，可见性独立成 host 步骤；clip 用递归参数传递保 SceneHitTester 无状态。不破 I7/I11/I6/I10，不需新增偏离登记（属 `:247` scrollable 项实现补完）。reviewer 审核三 commit 通过无阻断，oracle 8 修正点全 ✓，9 项指定测试（A2 判 parent 专杀 / B5 嵌套回溯 / B6 paint=absoluteBox / E 组 dismiss 三态 / 偏移对齐 hit+anchor / clip 滚出+部分+嵌套）全补齐通过。建议改进非阻断：AnchorRect 包归属（核心层依赖 overlay 层，既有问题本次加剧，可后续下沉）、hitTest 递归内 AnchorRect 分配（非热路径可接受）。
