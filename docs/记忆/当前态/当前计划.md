# 当前计划

本文件记录“接下来做什么”，只保留短期内真正会执行的步骤。

## 当前计划

1. 暂停推进新功能、新样例和 B 类缺口填补，当前以查找 bug、代码审查和优化建议复核为主
2. 每次审查前先明确范围，例如目录、模块、用例或历史 review；涉及具体类、调用链、依赖图或影响面时，按 `docs/记忆/长期事实/CodeGraph协作.md` 先用 `codegraph` MCP 缩小范围，再读源码确认
3. 审查输出优先按严重度列出 findings，并包含文件/行号、问题现象、影响范围、复现或验证方式；未发现问题时也要明确说明残余风险和测试缺口
4. 发现可复现错误或重要教训时写入 `docs/开发者文档/errors/`；形成系统性审查结论时写入 `docs/开发者文档/reviews/`
5. 只有用户明确要求修复时，再按独立分支、最小回归测试、最小实现修改和定向验证推进

## 每步完成标准

- 总导航保持精简，不重新堆积长期事实和进度流水账
- 长期事实只记录中长期仍有效的目录、边界、命令和项目约定
- 当前态可频繁覆盖，但必须服务下一位接手者快速恢复现场
- 决策记录写清背景、候选方案、最终选择、影响范围和后续注意事项
- 验证命令和运行前提以 `docs/记忆/长期事实/稳定命令.md` 为准

## 更新规则

- 只保留 3 到 7 个短期有效步骤
- 计划变化时直接改写，不保留历史版本
