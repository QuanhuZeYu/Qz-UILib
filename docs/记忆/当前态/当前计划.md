# 当前计划

本文件记录“接下来做什么”，只保留短期内真正会执行的步骤。

## 当前计划

1. 当前批次已新增 `UiKeyCodes`，控件、文档、remote、config、devtools 与测试侧已从 `Keyboard.KEY_*` 迁移到该常量层；已通过 `git diff --check`、定向测试和 `compileJava`，本次提交后收口。
2. 暂不拆 `LwjglxPollingInputBackend` 与 `UiHostInputCoordinator` 的真实 `Keyboard/Mouse` 调用；这些属于客户端宿主输入事件源边界，可继续直接接触 `org.lwjglx.input.*`。
3. 渲染业务未发现直接使用 `org.lwjglx`；渲染链主要依赖 `org.lwjgl.opengl.*` / `org.lwjgl.BufferUtils`，不要与本轮 `lwjglx` 键码常量拆解混做。
4. 后续验证目标仍保持：每批运行 `git diff --check`、相关定向测试和 `compileJava`；纯 JVM 测试不要新增 legacy LWJGL 运行依赖。
5. 后续如继续源码层解耦，优先单独评估 `SystemDocumentCursorHost` 的 `Display` 静态 import 与反射 `Mouse/Cursor`，不要与 OpenGL/字体 atlas 混做。
