# 当前计划

本文件记录“接下来做什么”，只保留短期内真正会执行的步骤。

## 当前计划

1. 新任务开始时先读 `docs/AI记忆文档.md` 与 `docs/记忆/README.md`
2. 按任务类型读取 `当前态/`、`长期事实/`、`决策/` 和对应专题文档
3. 代码或文档改动完成后，检查是否需要更新当前态、长期事实、决策、错误记录或审查记录
4. 涉及 Java 源码或运行链路改动时，至少执行对应 Gradle 编译或测试命令
5. 涉及游戏内 UI、HUD、输入、远程页面或网络 smoke 时，使用 `runClient21` 与 `/qzuilib test` 做实际验证

## 每步完成标准

- 总导航保持精简，不重新堆积长期事实和进度流水账
- 长期事实只记录中长期仍有效的目录、边界、命令和项目约定
- 当前态可频繁覆盖，但必须服务下一位接手者快速恢复现场
- 决策记录写清背景、候选方案、最终选择、影响范围和后续注意事项
- 验证命令和运行前提以 `docs/记忆/长期事实/稳定命令.md` 为准

## 更新规则

- 只保留 3 到 7 个短期有效步骤
- 计划变化时直接改写，不保留历史版本
