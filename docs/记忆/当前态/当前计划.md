## 当前计划（无样式 primitive 插队重构，2026-06-24）

> SceneDataTable 行内编辑 + demo 页 + 行高对齐 + 斑马纹收口已通过真机验证。
> 真机反馈：可编辑视觉效果偏弱，玩家可能误判为只读组件。
> 用户确认：作为 UI 库，**无样式基础组件 primitive 是必须能力**。
> 下个会话优先从该插队重构开始。

1. **启动 TextInput primitive**：抽 `SceneTextInputPrimitive`（或等价无样式行为核心），
   保留 `SceneTextInput` 作为默认 chrome wrapper，现有 API 兼容。
2. **启动 Select primitive**：抽 `SceneSelectPrimitive`，保留 overlay/anchor/键盘/滚动行为，
   `SceneSelect` 作为默认 chrome wrapper。
3. **迁移 DataTable 使用 primitive**：DataTable 不再依赖 `flat` 战术变体，
   改用无样式 primitive + cell 自身样式。
4. **回收 flat 战术债**：primitive 消费方稳定后，评估 `flat` 字段是否保留兼容、
   标记过渡，或收口为 wrapper 预设。
5. **后续恢复主线**：嵌套分类树导航 / 字段引擎最小切片；深水区继续暂缓。

## 每步完成标准

- 涉及生产 Java 代码改动时至少通过 `compileJava`（优先 `jetbrainsBuildProject`）
  并补相关测试；提交前过 `git diff --check`。
- scene 新栈改动须对照 NORTH_STAR 不变量（尤其 I1/I4/I6/I7/I10/I11）自检，
  偏离按《修订纪律》登记。
- 实现完成后必须经一次独立子代理审核；代码实现审核默认使用 @reviewer，
  Oracle 仅用于架构方案裁决/复杂边界复核且默认新开 session。
- 帧率/真机实测交用户跑，本地验证结果只记录在交接、提交说明或开发者文档中，
  不写入远端 Release 正文。
- 完成独立任务后，检查是否需要更新 `当前态/`、`长期事实/`、`决策/`、`errors/`、`reviews/`。
- 控件完成后必须建 demo 页接入 hub，否则用户无法真机验证。
