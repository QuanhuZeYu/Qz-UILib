## 每步完成标准

- 涉及生产 Java 代码改动时至少通过 `compileJava`（优先 `jetbrainsBuildProject`）
  并补相关测试；提交前过 `git diff --check`。
- scene 新栈改动须对照 NORTH_STAR 不变量（尤其 I1/I4/I6/I7/I10/I11）自检，
  偏离按《修订纪律》登记。
- 实现完成后必须经一次独立子代理审核；代码实现审核默认使用 @reviewer，
  Oracle 仅用于架构方案裁决/复杂边界复核且默认新开 session。
- 帧率/真机实测交用户跑，本地验证结果只记录在交接、提交说明或开发者文档中，
  不写入远端 Release 正文。
- 完成独立任务后，检查是否需要更新 `当前态/`、`长期事实/`、`决策/`、`errors/`、`reviews/`。
- 控件完成后必须建 demo 页接入 hub，否则用户无法真机验证。
- **并行 fixer 只写代码不跑 build**，编译/测试统一由主 Agent 串行单次跑，
  避免并行 Gradle 竞争 build/ 目录误报（ERROR-20260624 已立项）。
- **token 实际值以 SceneChromeTokens.java 源码为准**，不依赖过期文档清单。
- **oracle 裁决架构方案后**，如方案涉及长期可引用的设计决策，
  建议补写 `docs/记忆/决策/` 文档沉淀。
- **I11 逃生舱②扩张纪律**：扩之前证明它确实是一类新的权威交互真值，
  而非可以用现有机制表达的东西。
