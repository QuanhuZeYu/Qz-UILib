# 当前计划

本文件记录“接下来做什么”，只保留短期内真正会执行的步骤。

## 当前计划

1. 基于已落地的 P0 registry / builder / checker / state，优先接入 CSS / Layout / Paint 的首批真实视觉样例，每批 8 到 12 张
2. 新样例写入 `UiTestMatrixRegistry`，由 `UiTestGroupVisualBuilder` 渲染，语义断言边界通过 `UiTestSemanticChecker` 和 `UiTestMatrixState` 回写，不在 `UiTestDocumentPageController` 堆叠卡片逻辑
3. 样例编号使用 `VIS-*` / `SEM-*` 新前缀，观察要点必须以 `预期结果：` 开头，并保持视觉状态与语义状态分离
4. 保持 DOM / CSS / Layout / Paint / Input / Controls / TextFont / Animation / RuntimeHost / RemoteNet 十组导航，不恢复旧页面名结构
5. 每批保持 `git diff --check`、目标 `UiTestDocumentPageControllerTest` 和 `compileJava` 通过；涉及游戏内 UI、HUD、输入、命令入口、远程页面或网络 smoke 时再用 `runClient21` 验证
