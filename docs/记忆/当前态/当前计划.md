# 当前计划

本文件记录“接下来做什么”，只保留短期内真正会执行的步骤。

## 当前计划

1. 当前批次已新增 `LwjglInputRuntime`，输入轮询后端和宿主输入协调器不再静态 import `org.lwjglx.input.*`，运行时优先反射 `org.lwjglx`，缺失时降级反射 legacy `org.lwjgl`。
2. `Lwjgl3ifyInputBackend` 已移除 `org.lwjglx.Sys` 时间戳依赖，统一使用 JDK 单调纳秒时钟，不改变 `UiKeyEvent.keyCode` 语义。
3. `UiHudDocumentHost` 不再直接读取 `Mouse.isGrabbed()`，改走 `UiHostInputCoordinator.isNativeMouseGrabbed()`；`SystemDocumentCursorHost` 已移除 `Display` 静态 import，系统光标仍仅在 SDL / LWJGLX 光标桥可用时启用，否则 no-op。
4. 渲染链仍主要依赖 `org.lwjgl.opengl.*` / `org.lwjgl.BufferUtils`，不要与本轮 `lwjglx` / `lwjgl3ify` 可选化混做。
5. 后续验证目标仍保持：每批运行 `git diff --check`、相关定向测试和 `compileJava`；纯 JVM 测试不要新增 legacy LWJGL 运行依赖。

## 每步完成标准

- 总导航保持精简，不重新堆积长期事实和进度流水账
- 长期事实只记录中长期仍有效的目录、边界、命令和项目约定
- 当前态可频繁覆盖，但必须服务下一位接手者快速恢复现场
- 决策记录写清背景、候选方案、最终选择、影响范围和后续注意事项
- 验证命令和运行前提以 `docs/记忆/长期事实/稳定命令.md` 为准
- `lwjglx` / legacy LWJGL 输入运行时解耦至少通过 `git diff --check`、相关输入/光标/HUD 定向测试和 `compileJava`
- 发布依赖降级后如涉及发布验收，需验证 `publishToMavenLocal` 产物元数据中不再强制声明 `lwjgl3ify`
