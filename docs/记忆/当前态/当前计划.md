# 当前计划

本文件记录“接下来做什么”，只保留短期内真正会执行的步骤。

## 当前计划

1. AWT baseline + actual pixel bounds + 可变 slot 的字体 atlas 契约已引入；决策见 `docs/记忆/决策/DECISION-20260611-awt-ink-bounds-atlas.md`
2. 后续路线继续扩展字体引擎的字号能力，再实现数学公式渲染和排版能力；决策见 `docs/记忆/决策/DECISION-20260611-font-size-before-latex-math.md`
3. 字体引擎字号阶段优先让字号进入文本测量、布局、裁剪、绘制与 glyph 缓存口径；对外按 UI 像素 `font-size` 表达，内部按目标像素尺寸提交 glyph quad
4. 数学公式阶段在字号能力稳定后推进，以 LaTeX 风格数学子集为输入，采用自研公式 AST + box layout，复用字体系统渲染普通符号、希腊字母、上下标和公式规则线
5. 首批公式能力不追求完整 TeX 宏系统，先覆盖 `^`、`_`、`\frac`、`\sqrt`、常见希腊字母、基础大运算符和 inline/block 公式
6. 实现前继续以源码和稳定命令确认影响面；每批落地至少通过 `git diff --check`、相关定向测试和 `compileJava`
