## 每步完成标准

- 涉及生产 Java 代码改动时至少通过 `compileJava`（优先 `jetbrainsBuildProject`）并补相关测试；提交前过 `git diff --check`。
- scene 新栈改动须对照 NORTH_STAR 不变量（尤其 I4/I6/I7/I10/I11）自检，偏离按《修订纪律》登记。
- 实现完成后必须经一次独立子代理审核；代码实现审核默认使用 @reviewer，Oracle 仅用于架构方案裁决/复杂边界复核且默认新开 session。
- 帧率/真机实测交用户跑，本地验证结果只记录在交接、提交说明或开发者文档中，不写入远端 Release 正文。
- 完成独立任务后，检查是否需要更新 `当前态/`、`长期事实/`、`决策/`、`errors/`、`reviews/`。
