# 当前计划

本文件记录“接下来做什么”，只保留短期内真正会执行的步骤。

## 当前计划

1. 继续研究 `lwjglx` 源码层解耦，优先处理控件、文档、remote、config、devtools 中只为 `Keyboard.KEY_*` 常量引入 `org.lwjglx.input.Keyboard` 的场景。
2. 设计内部 `UiKeyCodes` 或等价键码常量层，保持 `UiKeyEvent.keyCode` 仍使用当前 LWJGL2/MC 键码数值，不改变对外事件语义。
3. 暂不拆 `LwjglxPollingInputBackend` 与 `UiHostInputCoordinator` 的真实 `Keyboard/Mouse` 轮询调用；这些属于客户端宿主输入事件源边界，需单独方案。
4. 渲染业务未发现直接使用 `org.lwjglx`；渲染链主要依赖 `org.lwjgl.opengl.*` / `org.lwjgl.BufferUtils`，不要与本轮 `lwjglx` 键码常量拆解混做。
5. 每批替换后跑 `git diff --check`、输入/控件/HUD 定向测试和 `compileJava`，纯 JVM 测试不要新增 legacy LWJGL 运行依赖。
