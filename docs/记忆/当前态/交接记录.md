### 滚动 API 封装决策
oracle 评估 3 候选：A 独立工具类 / B 声明式 setAutoScroll / C runtime 方法。
用户拍板候选 A。否决 B（伪声明式，纯数据节点藏隐式状态，踩 §7 反模式）。
`SceneScrolls.attach` 返回 `Signal<Integer>` 供调用方观察位置 / 编程式滚动。
stopPropagation 策略固定为「内层到边界才放行冒泡」标准浏览器行为，不开放配置。
