### 关键裁决（5 项 + 持久化格式）
1. current/draft 真相归属 → 方案A：核心层 DraftBuffer 持真相，signal 是镜像
2. Authority KV 存储 → 直接持 Map，不复用 DefaultMutableConfig
3. EventBus → 复用现有 ConfigChangeEvent/ConfigChangeListener
4. 事件类型 → 新增 ChangeType.BATCH_SAVE
5. 软依赖打包 → P0/P1 同 jar + 运行时检测，独立发布留 P2
6. 持久化格式 → 新旧配置统一 YAML + SnakeYAML 2.2 shadow 打包
7. ConfigManager.flushRaw() → 确认为有意设计（供 LegacyAdapter.setRawJson 后显式持久化），已补登记施工图
