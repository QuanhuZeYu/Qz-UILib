### 根因与最终方案

- **根因**：ink 子区 UV 精确贴字符 + shader `fontF.frag:51-54,23-25` uvBounds 硬墙把 ink 子区外采样判 0
  + padding 区纯透明无过渡带，mipmap 高 mip 级 texel 跨 slot 混合，边缘 AA 被 smoothstep 阈值化放大成硬边
- **最终方案**：`INK_PADDING` 6→8 + `INK_BLEED=1.0F`，`resolveGlyphQuadMetrics` UV/几何协同外扩 1 像素，
  uvBounds 自动跟随（`GlyphRenderBatch.addQuad` 用同一组 UV）
- **原理**：不烘焙时 padding 纯透明，mipmap 降采样时 ink 边缘 AA 像素自然渗透到 padding 生成半透明 texel，
  UV 外扩 + uvBounds 放宽让 shader 采到这些渗透 texel，边缘过渡自然且无白边
- **回退原因**：方案②烘焙白色羽化导致所有字符（含单色字形）出现白边——单色字形走 shader 单色路径
  虽用 Color.rgb 替换纹理 RGB，但烘焙的半透明 alpha 参与 smoothstep 阈值化形成浅色描边
