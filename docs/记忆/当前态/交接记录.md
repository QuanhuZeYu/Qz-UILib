## 最近一次交接

- 当前分支：`refactor/decouple-lwjgl3ify`；第一阶段已完成输入后端加固，`UiInputService` 对外 facade 和调用点保持不变。
- 已完成源码方向：新增内部 `UiInputBackend`，`Lwjgl3ifyInputBackend` 通过反射订阅 `InputEvents`，`LwjglxPollingInputBackend` 作为无 `InputEvents` fallback；若 `InputEvents` 存在但监听注册失败，会启用键盘轮询兜底；主源码不再静态 import `me.eigenraven.lwjgl3ify.api.InputEvents`。
