### primitive 插队重构决策
- 用户确认：作为 UI 库，无样式基础组件库是必须能力。
- `flat` 是战术过渡，不应长期演化成一堆 variant。
- 目标分层：unstyled primitive（行为、输入、overlay、anchor、状态）+
  styled wrapper（默认背景、边框、圆角、padding、hover/open chrome）。
- 下个会话优先从 TextInput/Select primitive 开始，保留现有 public API 兼容。
