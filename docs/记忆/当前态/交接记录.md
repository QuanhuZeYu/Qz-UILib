### 重要约束（保留前轮 + 本轮补充）

- 入口检测的是 `club.heiqi.config` 模块能力是否存在，不是检测配置文件是否存在。

- Forge 回退不需要理解复杂 config 模型；接入方自己决定复杂结构如何在 Forge cfg 下兼容，推荐 JSON 字符串属性。
- UI 风格沿用当前 Forge 配置模板页，不另起视觉体系。
- `MutableConfig` 裸值本身不包含 schema；choice、默认值、数值范围等 UI 语义依赖 `ModernConfigTemplateScreen.FieldSpec`。
- Batch 5 拆 4 个接力阶段（详见 `docs/记忆/当前态/Batch5接力计划.md`），每阶段独立提交、独立交接，**不要跨阶段做**。

- `ModernConfigSearchIndex` 不参与 draft/dirty；只读 rootSnapshot + 通过 binding.isDirty() 查询脏标记。
