### 重构要点

- **half-leading 模型**：calculateTextTop 输出从 lineBoxTop 改为 lineBoxTop + halfLeading
  - halfLeading = (lineHeight - (ascent + descent)) / 2
  - TOP/CENTER/BOTTOM 三分支均补 halfLeading，halfLeading 可为负（CSS 合法）
- **lineHeight 字体驱动**：从 ceil(charSize*(1+lineSpacing)) 改为 A+D+lineGap
  - 兜底：A+D+lineGap==0 返回 fontSizePx
- **lineGap 暴露链**：GlyphGenerator 取 LineMetrics.getLeading → GlyphInfo →
  GlyphRuntimeTables leadingNormal/Bold → TextLayoutService.getLineGap → SceneTextMeasurer default
- **删除 lineSpacing**：FontConfig 字段+load+affectsFontRuntime+onConfigReload 全清
- **旧栈测试适配**：9 个失败测试修复（QzUiLibClientCommand + DocumentPaintRendererTest）

### 行业标准依据

- CSS2.1 §10.8.1 half-leading 模型
- CSS line-height: normal = A+D+lineGap
- AWT LineMetrics 经 OpenType hhea/sTypo 取值
- 决策文档：`docs/记忆/决策/DECISION-20260625-text-vertical-alignment-refactor.md`
