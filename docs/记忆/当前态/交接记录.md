### 方案要点

- **渲染约束**：scene 渲染层 `drawBaselineAlignedString` 不按 `\n` 自动分行
  （`TextLayoutService.parseSegments:92-132` 只处理 § 格式码），故 TextArea 必须按行拆成
  独立文本节点，不能用单文本节点传含 `\n` 整段。
- **结构**：root(COLUMN) → viewport(scrollable+preferredHeight) → content(COLUMN) →
  forEach 行（key=行号，rowIdx → ROW{prefix, caret, suffix}）+ show placeholder。
- **caret 模型**：全局码点索引 `Signal<Integer>`，跨行用 `lineStartIndex`/`lineEndIndex`/
  `caretRow`/`moveCaretVertical` 派生行号/列。每行 caret 节点常驻，宽度 0/1 切换 +
  `caretColor` signal 注入协调每行颜色。
- **行内文本更新**：itemComponent 每 key 只调一次，行内 prefix/suffix 用 Computed 监听
  value + caretIndex 响应式更新 setText。
- **滚动**：复用 `SceneScrolls.attach(viewport)`。
- **chrome**：wrapper 复用 SceneChromeTokens/SceneStateColors；文本色未由 wrapper 控制
  （行节点分散在 primitive 内，基础版限制）。
