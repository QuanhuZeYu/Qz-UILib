### 一句话现状
SceneSelect 真机滚动暴露的「外层 viewport 滚动后主树 hit 与 overlay listbox 绘制/命中都停在旧坐标」缺陷已修复（同一根因：scrollOffsetY 是 paint-only 偏移，hit-test/absoluteBox 零感知）；经 explorer 侦察 → oracle 裁决 → fixer 三 commit 实现 → reviewer 审核通过；待真机复验后进入字段引擎最小切片。

### 本次结论（按提交时序）
- **根因（explorer 侦察验证）**：`scrollOffsetY` 是 paint-only 偏移。`SceneNode.setScrollOffsetY` 只 `markGeometryDirty` 不 `markSelfLayout`（守 I7，layout 刻意不把 offset 烤进 LayoutBox.y）；`ScenePaintEngine:174` 唯一注入 `-scrollOffsetY`；但 `SceneHitTester:67-68` 与 `SceneGeometry.absoluteBox:39-40` 只读 LayoutBox 累加绝对坐标、对滚动零感知。导致：①主树 trigger/卡片 hit 不跟随（缺陷1）②trigger 的 absoluteBox 停在旧位 → overlay anchorY 错 → listbox 绘制和命中全错（缺陷2，比缺陷1多错绘制）。anchor 是每帧重解析（非快照），根因在解析源不读滚动。
- **oracle 裁决**：方案正确，三个关键修正——①工具判 `parent.isScrollable()` 而非 self（scrollable 节点自己不被自己 offset 位移）②paint 共用单层注入原子但不共用 absoluteBox（下沉 O(N) vs 回溯 O(N²)，强行共用会变 O(N²)）③absoluteBox 保持纯几何不加 clip/可见性，可见性独立成 host 步骤。clip 用递归参数传递保 SceneHitTester 无状态。不破 I7/I11/I6/I10，不需新增偏离登记（属 :247 scrollable 项实现补完）。
- **commit 1 `a62da1d6` 对齐滚动偏移几何探针**：抽 `SceneGeometry.childYBase(parent, parentAbsY)` 单层注入原子（判 parent 不判 self），`ScenePaintEngine`/`SceneHitTester`/`SceneGeometry.absoluteBox` 三方共用同一原子定义；paint 改用原子（纯重构零行为变化）；hit-test 递归注入偏移；absoluteBox 回溯式沿 parent 链注入。解决真机 P0 bug。
- **commit 2 `7c814926` 裁剪滚动视口命中区域**：`SceneHitTester.hitTestRecursive` 新增 clip bounds 递归参数（null=无裁剪），进入 scrollable 子树用其 LayoutBox 绝对盒作 clip，嵌套取交集，子节点注入滚动后 absBox 与 clip 零交集跳过。类保持无状态。与 paint CLIP 对称（滚出视口不可点）。
- **commit 3 `18143ecf` 关闭不可见锚点浮层**：`AbstractSceneHostWidget.dismissOverlaysWithInvisibleAnchor` 独立步骤（render 中 layoutOverlays 后单独调用，不混进纯布局的 layoutOverlays）；对每个有 anchorProvider 的 overlay entry，沿 trigger parent 链收集所有 isScrollable 祖先视口框求交，零交集 → `entry.requestDismiss()` 走 signal 回调 `expanded.set(false)`（守 I11 逃生舱②）；有交集即保持防半遮闪关；单帧绘制延迟可接受不特判。`AnchorProvider` 最小扩展 `getNode()/forNode()` 支持可见性判断（原只暴露矩形）。复用 `SceneGeometry.intersect` 求交原子。
- **commit 4 `d0e3445b` 登记与规范**：NORTH_STAR《偏离登记》`:247` scrollable 条目补完几何探针对齐（影响范围列补 childYBase 原子/hit-test clip/dismiss 步骤说明，回归锚点补 4 测试类，日期列追加「几何探针对齐补完 2026-06-23」）；AGENTS.md 第 7 节新增中断恢复纪律（子代理中断必须用原 task_id 恢复 session 保留进度，不得新开 session 空跑重做）。
