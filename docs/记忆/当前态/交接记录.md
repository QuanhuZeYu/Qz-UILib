2. **SceneScrolls.attach 防呆**：null 检查 + isScrollable 检查，非 scrollable viewport 抛 IllegalArgumentException
3. **SceneSegmented 内置默认高**：create 内对 root 设 `preferredHeight = lineHeight(16) + 2*PAD_LG`；删 ConfigScreen 手动设高
4. **SceneScrollContainer 高阶工厂（新文件）**：封装 5 步样板（container/viewport/content/attach/可选 scrollbar），Javadoc 显式写明 viewport 高度仍需调用方在布局链保证

测试：ConstraintResolverWarnTest（3 项）/ SceneScrollsTest（+4 项 attach 防呆）/ SceneSegmentedTest（+1 项内置高断言）
