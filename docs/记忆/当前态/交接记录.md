### Bug 1 真机诊断结论

- **现象**：配置页内容不跟随滚轮滚动
- **根因**：`SceneScrolls.attach` 中 `maxScroll = SceneGeometry.maxScrollY(viewport)` 真机实测为 0。这是几何正确行为——配置页内容高度小于视口高度（content < viewport），内容不溢出，`maxScrollY = max(0, contentHeight - viewportHeight) = 0`。`clamped = Math.max(0, Math.min(0, next)) = 0` 恒为 0，`clamped != current` 永不成立，`scrollSignal` 不更新，滚动不工作属预期
- **裁决**：用户拍板"接受现状不修"——内容不溢出时无滚动需求，几何上本就不该可滚
- **不是 bug 的部分**：滚轮事件链路本身工作正常（`[scroll-diag]` / `[scroll-route]` / `[scroll-handler]` 日志确证事件从 LWJGL → InputSource → Router → SceneScrolls handler 全链路到达，wheelDelta 非零）
