## 历史交接（2026-06-15 第 5 次）

- **当前分支**：`4.0`。任务：ModernConfig 配置页仍卡顿（第 4 次文本测量重构后用户复测仍 ~3FPS），探针定位真实根因并修复。
- **根因（已坐实，堆栈 100% 一致）**：`FlexLayoutHelper.flushAnonymousTextItem` 在布局过程中为 flex 容器内裸文本创建临时匿名元素 `qz-anonymous-flex-item` 并 `setAttribute("data-hit-test-hidden")`，而 `ElementNode.setAttribute` 值变化时 `markSubtreeMutated → recordLayoutMutation → layoutVersion++`。该匿名元素从不挂入文档树，其 bump 是错误副作用，形成「布局→bump layoutVersion→下帧布局缓存失效→重排」死循环。配置页 ~20 个含裸文本 flex 容器 → 单帧 `layoutVersion` 被 bump 20 次。属布局引擎通用缺陷，非 ModernConfig 独有。
- **修复（已合入工作区，未提交）**：`ElementNode` 新增框架内部静默写属性入口 `__putGeneratedAttribute(name,value)`（不触发失效，与 `__appendGeneratedChild`/`__copyFromSilently` 同约定）；`FlexLayoutHelper.flushAnonymousTextItem` 改用它。diff 仅 2 文件（`ElementNode.java` +15、`FlexLayoutHelper.java` 改 1 行）。
- **实测收益**：稳态帧时间 340ms → 18~30ms，FPS 2.7 → 34~46（约 12 倍）；布局 `relayout x20` 消除，稳态 `resolve(cached)` 命中。
- **验证**：`compileJava` 通过；回归 `FlexLayoutHelperBoundaryTest`、`DocumentLayoutEngineTest`、`HtmlLikeDocumentWidgetLayoutCacheTest`、`HtmlLikeDocumentWidgetInlineLayoutCacheTest`、`HtmlLikeDocumentWidgetHitTest` 全过。临时诊断探针（drawSelf 分段 recordPhase、resolveLayoutBox 失效原因、DocumentNode.markMutated 堆栈采样）**已全部回退**，工作区只剩真实修复。
- **错误与诊断路线文档**：`docs/开发者文档/errors/ERROR-20260615-flex-anonymous-item-layout-self-pollution.md`，内含「UI 卡顿诊断可复用路线」（探针四步法：拿读数→recordPhase 区分重建/回放→定位失效缓存键→markMutated 堆栈采样）。
- **剩余第二层瓶颈（未处理，下一任务）**：稳态仍有 `replay(cmd~724) 约 17~27ms`，724 条 paint 命令回放本身偏慢。嫌疑：`DocumentPaintRenderer.render` 每帧 `new IdentityHashMap` 重建 styleMemo + 每个非文本命令 `UiStyleResolver.computeWithParentStyle` 全量重算 computed style；另有偶发 `resolve(rebuildCmd)`（命令数 720↔737 抖动，疑似 caret blink/hover 改 paintVersion）。详见下方"给下一个 agent 的提示词"。
- **待办**：本次修复尚未提交，需用户确认后提交到 `4.0`（或新分支）。
