## 最近一次交接

- 当前分支：`refactor/font-size-px-rendering`；目标是在不按字号 AWT 烘焙 atlas 的前提下，把 UI 语义化 `font-size: px` 接入测量、布局、裁剪和绘制。
- 已新增 `TextMeasureStyle`，默认 `DEFAULT_FONT_SIZE_PX = 18`，用于保持现有 `FontConfig.charSize=9` 与 UI 固定 2 倍缩放的默认视觉等价；`TextMeasureService` / `DefaultTextMeasureService` 已加入语义化测量、行高和裁剪 overload。
- `TextLayoutService` 已新增 `getStringWidth(String, TextMeasureStyle)`、`trimStringToWidth(String, int, TextMeasureStyle)`、`getSegmentWidth(..., fontSizePx)`、`getCodepointWidth(..., fontSizePx)`、`getLineHeight(TextMeasureStyle)`；字号宽度换算以 `FontConfig.charSize` 为基准，不新增多字号 AWT atlas 烘焙。
- `font-size` 已接入 `UiStyleProperty` / `UiStyleDeclaration` / `ComputedStyle` / `UiStyleResolver` / `RemoteCssParser`；`TextLayoutHelper` 与 `InlineLayoutHelper` 的文档文本路径已改为直接按 `TextMeasureStyle` 测量 UI px，`DocumentLayoutTextRun` 会保存布局期文本样式快照。
- 绘制路径已接入字号快照：`DocumentPaintCommand` 携带 `TextMeasureStyle`，`DocumentPaintRenderer` / `DocumentTextPaintClipper` 使用 run 快照，`UiRenderContext` 增加 `drawText(..., TextMeasureStyle)` 和语义化测量，`DefaultFontRendererAdapter` 增加 `drawBaselineAlignedStringPx(...)`。
- 已新增 `HtmlLikeDocumentWidgetRenderingTest.shouldRenderTextWithFontSizeSnapshot` 覆盖 `font-size:12px` 对布局宽高和绘制快照的影响；当前 `git diff --check`、`./gradlew.bat --no-configuration-cache compileJava`、`./gradlew.bat --no-configuration-cache --rerun-tasks compileJava` 已通过。
