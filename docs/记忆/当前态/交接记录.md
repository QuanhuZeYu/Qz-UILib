### 主线：BUG1 第二次回归——坐标系 rootAbsY 错位修复

**错误现象**：`c62ae524` 修复 hit-test transform 错位后单测全绿（rootAbs=0,0），但真机仍拖不动。thumb 滚动到非顶部后点击 thumb 视觉位置，column DOWN handler 走 page 分支而非拖动分支，scroll 跳跃一页。

**根本原因**：column DOWN handler 判定「点击是否落在 thumb 视觉区」时坐标系错位——`ev.getPointerY()` 是画布逻辑坐标（含 rootAbsY），`SceneGeometry.absoluteBox` 是 host 局部坐标（不含 rootAbsY），两者比对差一个 `rootAbsY`。真机 GUI 居中 margin≠0 时错位暴露；单测 rootAbs=0,0 画布逻辑==host 局部，错位不暴露（假绿）。

**修复方案**（commit `a7959d41`）：
- SceneEvent 新增 `hostPointerY` 字段（= `pointerY - rootAbsY`，host 局部），与 `absoluteBox` 同系
- delta 范式：拖动闭包用 `ev.getHostPointerY()` 记 `dragStart[1]`，MOVE 时 `pointerDelta = hostPointerY - dragStart[1]`，全链路 host 局部系，rootAbsY 自然消去
- column DOWN handler 改用 `ev.getHostPointerY()` 判定 thumb 视觉区，与 `absoluteBox` 同系
- 删除原视觉中心校准逻辑，改为 delta 范式（dragStart[1]=点击点 host 局部 Y），首帧 MOVE delta=0 不跳跃
- 单测补 rootAbsY≠0 路径，显式传非零 rootAbsX/Y

详细错误分析见 `docs/开发者文档/errors/ERROR-20260630-scrollbar-drag-hit-test-transform.md`（已补充第二次根因章节）。
