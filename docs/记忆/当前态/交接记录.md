### 主线：BUG1 拖拽失效修复

**错误现象**：滚动条无法拖拽。

**根本原因**：thumb 用 COMPOSITE 级 `Transform.translate` 平移（守信条五零重排），但 `SceneHitTester` 只读 `LayoutBox` 不叠加 transform（`SceneHitTester.java:77-78`）。thumb 布局位置永远在 column 顶部 Y=0，视觉位置在 translateY；用户点击视觉位置命中 column 而非 thumb → thumb 的 DOWN handler 永不触发。

**修复方案**：
- column 的 DOWN handler 检测 `clickY` 落在 thumb 视觉区内时，手动启动拖动
- 复用 thumb 的 `dragStart` / `dragging` 闭包，并在 `dragStart` 内校准视觉中心（用当前 translateY 作为拖动起点，而非布局位置 Y=0）
- `ctx.requestPointerCapture()` 捕获指针
- column 注册 MOVE / UP / CANCEL，转发给拖动闭包，确保拖动结束状态正确清除

详细错误分析见 `docs/开发者文档/errors/ERROR-20260630-scrollbar-drag-hit-test-transform.md`。

### 主线：BUG2 section 切换内容消失修复

**错误现象**：切换 section 后内容消失 / 滚动位置错乱。

**修复方案**：
- per-section scroll state：每个 section 独立维护滚动偏移，切换时保存/恢复
- Props 拆 read/write：滚动偏移的读路径与写路径分离，避免同帧读写互相覆盖
- `activeScroll` 用 Computed 包裹 clamp，确保恢复值始终在 `[0, maxScroll]` 区间内
- 订阅 `layoutDoneSignal`：section 切换后内容几何变化通过 epoch 桥接同帧刷新，消除滞后一帧
