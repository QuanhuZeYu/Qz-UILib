### Bug 1 真根因（确证版，覆盖此前"接受现状不修"结论）

- **现象**：配置页内容不跟随滚轮滚动
- **真根因**：`navRoot` 作为容器型固定子未设 `preferredHeight` → grow 求解器在布局求解时早退 → viewport 拿不到固定高度 → viewport 被 content 反向撑大 → `contentHeight - viewportHeight ≤ 0` → `maxScroll = max(0, contentHeight - viewportHeight) = 0` → `clamped` 恒为 0 → `scrollSignal` 不更新
- **关键链条**：根因不在滚轮事件链路（事件链路全程正常），而在布局求解阶段 viewport 高度未固定
- **修法**：`navRoot` + `saveFeedbackBar` 显式设 `preferredHeight`，让 grow 求解器能正常求解，viewport 拿到固定高，content 溢出时 `maxScroll > 0` 成立
- **落地 commit**：`f3a01cd6`
- **此前"接受现状不修"结论作废**：那是基于"maxScroll=0 是几何正确行为"的误判，Oracle C 复审确证真根因后已推翻
