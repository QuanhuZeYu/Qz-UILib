# 项目约定

本文件记录项目级、长期有效、且不适合直接塞进 `AGENTS.md` 的具体约定。

## 文档约定

- `docs/AI记忆文档.md` 只作为总导航，不承载阶段流水账、类清单、修复日志或大段项目事实
- `docs/记忆/当前态/` 记录当前阶段、状态、计划和交接，可频繁覆盖
- `docs/记忆/长期事实/` 记录目录结构、架构边界、稳定命令和长期约定
- `docs/记忆/决策/` 记录关键技术取舍和重要边界决定
- `docs/使用文档/` 记录对外接入方式，内容必须与实现一致，不能比实现更乐观
- `docs/开发者文档/errors/` 记录可复现错误和教训，`docs/开发者文档/reviews/` 记录审查结论

## 协作约定

- 本次迁移只借鉴 Harmes-Rust 的仓库内分层记忆框架，不迁移其 Rust / egui 桌面 Agent 产品架构
- 需要具体类、入口和目录位置时，用 Glob/Grep/Read 现查，不在记忆文档维护易过期清单
- 已接入 CodeGraph MCP 后，具体类、方法、调用链、依赖图和影响面优先用 `codegraph` 查询缩小范围，再用源码读取和测试确认；详细约定见 `docs/记忆/长期事实/CodeGraph协作.md`
- 临时调试记录和一次性试验结论不沉淀到长期记忆
- 发现长期事实已经能稳定归属到使用文档、开发者文档、错误记录或审查记录时，应写回原文档，不复制到总导航

## 适合写入本文件的内容

- 项目特有的模块拆分约定
- 特定错误处理口径
- 配置文件组织方式
- 测试目录和命名口径
- 文档命名和示例维护约定

## 不适合写入的内容

- 通用 Git 规范、提交规范、Java 通用规范
- 当前任务状态或阶段计划
- 一次性试验结论
