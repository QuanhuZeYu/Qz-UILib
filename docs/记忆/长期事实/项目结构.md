# 项目结构

本文件记录项目目录结构、主入口和模块职责等中长期稳定信息。

## 当前状态

- 当前仓库是 Minecraft 1.7.10 / GTNH / LWJGL3ify 环境下的 Java Mod 工程
- 根目录使用 GTNH Gradle Kotlin DSL 配置：`settings.gradle.kts`、`build.gradle.kts`、`gradle.properties`
- 根包：`club.heiqi.uilib`
- Mod ID：`qz_uilib`
- Forge Mod 入口：`src/main/java/club/heiqi/uilib/MyMod.java`
- 公共初始化代理：`CommonProxy`
- 客户端初始化代理：`ClientProxy`

## 主要目录

- `src/main/java/club/heiqi/uilib/ui/`：HTML-like UI 框架主体，包含文档、DOM、样式、布局、绘制、渲染、控件、事件、输入、HUD、远程页面等模块
- `src/main/java/club/heiqi/uilib/net/`：双端网络层，包含 API、编解码、核心调度、Store、vanilla/Forge 传输适配
- `src/main/java/club/heiqi/uilib/config/`：Forge 配置页、配置模板、远程配置同步和配置控件绑定
- `src/main/java/club/heiqi/uilib/font/`：字体服务、字体排序和渲染相关能力
- `src/main/java/club/heiqi/uilib/client/`：客户端 Tick、HUD 渲染、输入桥接和 Minecraft 侧模型适配
- `src/main/java/club/heiqi/uilib/internal/devtools/`：内部诊断与 `/qzuilib test` 开发工具入口
- `src/test/java/club/heiqi/uilib/`：纯 JVM 单元测试与边界测试
- `docs/使用文档/`：对外接入文档
- `docs/开发者文档/`：内部架构、审查、错误和规格文档
- `docs/记忆/`：AI 协作记忆层

## 维护规则

- 只记录相对稳定的结构，不记录一次性试验目录
- 结构发生真实变化后再更新，不预写未来状态
- 需要具体类、方法或调用关系时，仍以 Glob/Grep/Read 和源码为准
