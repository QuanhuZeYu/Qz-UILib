# 项目结构

本文件记录项目目录结构、主入口和模块职责等中长期稳定信息。

## 当前状态

- 当前仓库是 Minecraft 1.7.10 / GTNH / LWJGL3ify 环境下的 Java Mod 工程
- 根目录使用 GTNH Gradle Kotlin DSL 配置：`settings.gradle.kts`、`build.gradle.kts`、`gradle.properties`
- 根包：`club.heiqi.uilib`
- Mod ID：`qz_uilib`
- Forge Mod 入口：`src/main/java/club/heiqi/uilib/MyMod.java`
- 公共初始化代理：`CommonProxy`
- 客户端初始化代理：`ClientProxy`

## 主要目录

- `src/main/java/club/heiqi/uilib/ui/`：UI 框架主体；**scene 新栈为当前主实现路径**
  - `ui/scene`（`node` / `layout` / `paint` / `control` / `input` / `form` / `overlay` / `host` / `runtime` / `text`）：按 `NORTH_STAR.md` 的声明式新栈，受宪章 I10/I11 直接约束；承载配置页与内部 devtools（`/qzuilib test`）
  - `ui/reactive`、`ui/render`、`ui/base`：信号/渲染/基础值与布局辅助
  - 其余支撑包：`ui/event`、`ui/text`、`ui/image`、`ui/inventory`、`ui/slot`、`ui/host`、`ui/screen`、`ui/runtime`、`ui/diagnostic`、`ui/widget`、`ui/input` 等
  - 旧 HTML-like document 业务包（`ui/dom`、`ui/layout`、`ui/paint`、`ui/component`、`ui/control`、`ui/document` 等）**源码已移除**，不再作为对外主路径
- `src/main/java/club/heiqi/uilib/net/`：双端网络层，包含 API、编解码、核心调度、Store、vanilla/Forge 传输适配
- `src/main/java/club/heiqi/uilib/config/`：本 mod 配置接入
  - `ModConfigGui` / `ModGuiFactory`：Forge guiFactory 反射中转
  - `modern/`：`ModernConfigEntry` / `ModernConfigScreen`（`McScreenBridge`）/ `ModernConfigBootstrap` / `ConfigValueBridge` / `ConfigSaveListener` / `QzUiLibModernSchema`
  - 旧 Forge 配置模板页与远程配置同步类已删除
- `src/main/java/club/heiqi/uilib/font/`：字体服务、字体排序和渲染相关能力
- `src/main/java/club/heiqi/uilib/gl/`：GL 相关底层能力
- `src/main/java/club/heiqi/uilib/mixin/`：mixin 包（`gradle.properties` 的 `mixinsPackage=mixin`、`coreModClass=mixin.early.EarlyMixins`）
- `src/main/java/club/heiqi/uilib/client/`：客户端 Tick、输入桥接和 Minecraft 侧适配
- `src/main/java/club/heiqi/uilib/internal/devtools/`：内部诊断与 `/qzuilib test` 开发工具入口
- `src/main/java/club/heiqi/uilib/Config.java`：uilib 包根下的运行时配置类（与独立模块 `club.heiqi.config.Config` 同名不同实体，注意区分）
- `src/main/java/club/heiqi/config/`：**独立配置模块**
  - `schema` / `runtime`：Schema DSL 与 Authority/Draft/Persistence
  - `ui`：配置页 `ConfigUI` / `ConfigScreen` / FieldRenderer
  - 根下 `Config` / `ConfigNode` 等：通用 JSON/YAML 节点读写（非配置页主路径）
- `src/test/java/club/heiqi/uilib/`：纯 JVM 单元测试与边界测试
- `src/test/java/club/heiqi/config/`：独立配置模块的单元测试
- `docs/使用文档/`：对外接入文档
- `docs/开发者文档/`：内部架构、审查、错误和规格文档

## 维护规则

- 只记录相对稳定的结构，不记录一次性试验目录
- 结构发生真实变化后再更新，不预写未来状态
