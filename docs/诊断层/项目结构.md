# 项目结构

本文件记录项目目录结构、主入口和模块职责等中长期稳定信息。

## 当前状态

- 当前仓库是 Minecraft 1.7.10 / GTNH / LWJGL3ify 环境下的 Java Mod 工程
- 根目录使用 GTNH Gradle Kotlin DSL 配置：`settings.gradle.kts`、`build.gradle.kts`、`gradle.properties`
- 根包：`club.heiqi.uilib`
- Mod ID：`qz_uilib`
- Forge Mod 入口：`src/main/java/club/heiqi/uilib/MyMod.java`
- 公共初始化代理：`CommonProxy`
- 客户端初始化代理：`ClientProxy`

## 主要目录

- `src/main/java/club/heiqi/uilib/ui/`：UI 框架主体，当前是 **dom 旧栈 + scene 新栈 strangler 共存**格局，子包以源码为准
  - `ui/dom`、`ui/layout`、`ui/paint`、`ui/component`、`ui/control`、`ui/document`（含 `HtmlLikeDocumentWidget`）：HTML-like 旧栈，当前仍是对外主路径，业务入口深度依赖；Phase 5 退役时间表待用户裁决，详见 `docs/诊断层/scene技术债.md` §四
  - `ui/scene`（`node`/`layout`/`paint`/`component`/`input`）：按 `NORTH_STAR.md` 模型重写的声明式新栈，受宪章 I10/I11 直接约束；当前承载内部 devtools 默认 test hub（`/qzuilib test`）
  - `ui/reactive`、`ui/render`：新旧两栈共用的支撑包（signal/effect/scheduler 与 UiRenderContext），保留不动
  - 其余支撑包：`ui/animation`、`ui/event`、`ui/style`、`ui/text`、`ui/image`、`ui/inventory`、`ui/slot`、`ui/host`、`ui/hud`、`ui/remote`、`ui/runtime`、`ui/diagnostic` 等
- `src/main/java/club/heiqi/uilib/net/`：双端网络层，包含 API、编解码、核心调度、Store、vanilla/Forge 传输适配
- `src/main/java/club/heiqi/uilib/config/`：Forge 配置页、配置模板、远程配置同步和配置控件绑定
- `src/main/java/club/heiqi/uilib/font/`：字体服务、字体排序和渲染相关能力
- `src/main/java/club/heiqi/uilib/gl/`：GL 相关底层能力
- `src/main/java/club/heiqi/uilib/mixin/`：mixin 包（`gradle.properties` 的 `mixinsPackage=mixin`、`coreModClass=mixin.early.EarlyMixins`）
- `src/main/java/club/heiqi/uilib/client/`：客户端 Tick、HUD 渲染、输入桥接和 Minecraft 侧模型适配
- `src/main/java/club/heiqi/uilib/internal/devtools/`：内部诊断与 `/qzuilib test` 开发工具入口
- `src/main/java/club/heiqi/uilib/Config.java`：uilib 包根下的运行时配置类（与独立模块 `club.heiqi.config.Config` 同名不同实体，注意区分）
- `src/main/java/club/heiqi/config/`：**独立配置模块**，支持 JSON/YAML 复杂配置，未来可拆分为独立模组
- `src/test/java/club/heiqi/uilib/`：纯 JVM 单元测试与边界测试
- `src/test/java/club/heiqi/config/`：独立配置模块的单元测试
- `docs/使用文档/`：对外接入文档
- `docs/开发者文档/`：内部架构、审查、错误和规格文档
- `docs/记忆/`：AI 协作记忆层

## 维护规则

- 只记录相对稳定的结构，不记录一次性试验目录
- 结构发生真实变化后再更新，不预写未来状态
- 需要具体类、方法或调用关系时，仍以 Glob/Grep/Read 和源码为准
