# 语言与翻译接入

行为合同见[语言与翻译规格](<../superpowers/specs/2026-10-07-uilib-localization-spec.md>)。本页说明正式文案入口的用法。

页面通过 `ScenePageContext.localization()` 取得页面所属语言绑定，生成普通可读文案信号，再交给标准控件。MC 页面自动使用宿主已完成加载的翻译资料；业务无需注册资源监听或手动重新测量。

```java
import club.heiqi.uilib.ui.reactive.Signal;
import club.heiqi.uilib.ui.scene.control.SceneLabel;
import club.heiqi.uilib.ui.scene.control.SceneButton;
import club.heiqi.uilib.ui.scene.control.SceneTheme;
import club.heiqi.uilib.ui.scene.localization.LocalizationBinding;

// ScenePage 构造回调内部。
LocalizationBinding language = page.localization();
Signal<Integer> count = page.domain().signal(1);
Signal<SceneTheme> theme = page.domain().signal(SceneTheme.dark());
SceneLabel.create(page, language.text(() -> "example.result.count", count), theme);
SceneButton.create(page, language.text("example.action.add"), theme,
    () -> count.set(count.get() + 1));
```

以上示例只展示文案声明；把返回节点加入页面布局并 mount 的方法见[页面接入](<声明式页面接入.md>)。固定键与固定参数使用 `text(String, Object...)`；响应键和响应参数使用 `text(ReadableSignal<String>, ReadableSignal<?>...)`。响应参数应传给后者，避免将 Signal 对象作为固定格式参数。两类入口均返回纯 `Computed<String>`，首次及来源写入后的读取不依赖呈现帧。

`language()` 提供当前语言标识，`snapshot()` 提供已生效资料。语言依赖的排序或搜索可读取它们构造纯派生；同语言重载时依赖 `snapshot()` 可观察资料变化。字面字符串仍按字面使用，翻译参数不会再次被解释成翻译键或富文本。

无平台宿主提供 `LocalizationSource`；`LocalizationSnapshot` 复制翻译表并固定格式 locale。`MutableLocalizationSource` 是可通知来源，宿主资料完成后发布新快照，不能把尚未完成加载的可变表交给页面。独立业务使用自己的 Owner 构造 `LocalizationBinding`，与页面生命周期分别归属。

人工验收入口是安装独立人工包后执行 `/qzcore lang`。先按“切换语言”观察同一页面的标题、按钮、正文译文；按“参数 +1”和“长短标题”观察文案及自然高度；最后按“重载资源”确认“已观察资料更新”变化、页面继续可操作。该计数来自真实资料信号而不是按钮点击次数。主题、字号和窗口可用于检查重排与正文滚动；关闭重开不应叠加更新订阅。语言切换会改变游戏当前语言，测试后可切回所需语言。

页面关闭自动释放其绑定和文案派生；控件卸载只释放呈现绑定。页面不关闭共享资料源，也不因语言改变覆盖编辑草稿。缺键显示键名，格式不匹配显示 `Format error: ` 和当前模板；格式语义使用 Java8 Formatter，MC 已加载表保留原版数值占位归一。
