# 独立语言资源与翻译接入

行为合同见[语言规格](<../superpowers/specs/2026-10-07-uilib-localization-spec.md>)。UILib 提供自己的语言资源流，不读取、合并或兼容 MC/Forge 翻译表。业务若要显示物品名称或其他宿主文案，自行处理并将结果作为普通文本/信号交给控件。

## 声明自己的资源流

语言文件使用 UTF-8 Java properties，可直接写中文；支持 Java properties 的注释、续行和反斜杠转义。示例资源位于自己的包内目录，而非 MC 的 assets/.../lang：

```text
uilib/localization/example/en_US.properties
uilib/localization/example/zh_CN.properties
```

```properties
example.result.count=共有 %1$d 个结果，完成度 %2$.1f%%
example.action.add=增加
```

```java
import java.util.Locale;
import club.heiqi.uilib.ui.scene.localization.LocalizationResource;
import club.heiqi.uilib.ui.scene.localization.LocalizationFlow;

LocalizationFlow language = new LocalizationFlow("zh_CN", Locale.ROOT,
    LocalizationResource.classpath(MyPage.class.getClassLoader(),
        "uilib/localization/example"));
```

构造、`select` 和 `reload` 声明 `IOException`，上面的资源创建示例位于允许传播该异常的应用初始化方法。按钮或页面构造回调不能声明受检异常时，业务可捕获后以 `UncheckedIOException` 携带原原因抛出，不静默忽略或自行恢复；也可在应用初始化完成后将共享流交给页面。

资源按显式声明顺序加载，后声明来源覆盖前者同名键。同一文件重复键后者覆盖。可使用 `LocalizationResource.directory(path)` 读取独立目录中的 `<language>.properties`，或以正式输入流合同提供业务来源；UILib 在加载后关闭每个输入流。语言标识必须是非空单一路径段，缺少声明资源或非法资源不能当作空表。

流不自动扫描模组、不补英文表、不监听游戏资源包。调用 `language.select("en_US")` 选择自身资源语言；修改独立资料后调用 `language.reload()` 重新加载当前语言，同语言也使依赖失效。所有资源读完后才生效，不发布半表或新语言码搭配旧译文；失败原原因可见，无隐式重试、替代语言或恢复操作。Java 格式 locale 显式固定，数值占位 `%d`/`%f` 保留原语义。

## 页面显式绑定

```java
import club.heiqi.uilib.ui.reactive.Signal;
import club.heiqi.uilib.ui.scene.control.SceneLabel;
import club.heiqi.uilib.ui.scene.control.SceneButton;
import club.heiqi.uilib.ui.scene.control.SceneTheme;
import club.heiqi.uilib.ui.scene.localization.LocalizationBinding;

// ScenePage 构造回调内部；language 是应用显式持有的独立流。
LocalizationBinding text = page.localization(language);
Signal<Integer> count = page.domain().signal(1);
Signal<Double> progress = page.domain().signal(0.0);
Signal<SceneTheme> theme = page.domain().signal(SceneTheme.dark());
SceneLabel.create(page,
    text.text(() -> "example.result.count", count, progress), theme);
SceneButton.create(page, text.text("example.action.add"), theme,
    () -> count.set(count.get() + 1));
```

将节点加入布局并 mount 的方法见[页面接入](<声明式页面接入.md>)。页面惰性建立唯一绑定；同一来源反复请求返回同一绑定，不能把已建立绑定换为另一来源。语言不是 `SceneHost` 的服务，没有语言文案的页面无需提供来源。

固定键和参数使用 `text(String, Object...)`；响应键和参数使用 `text(ReadableSignal<String>, ReadableSignal<?>...)`。固定键配响应参数写成 `() -> "key"`，避免把 Signal 误传为固定 Object 参数。两种入口均生成纯 Computed，首次及写后读不依赖页面帧/flush，不执行业务 Effect。

`language()` 观察当前语言码；`snapshot()` 观察整个当前资料，依赖后者才能感知同语言重载。缺键显示键名，非法格式显示 `Format error: ` 加模板，字面参数不再翻译。排序和搜索可自行读取这些事实构造纯派生。

## 语言偏好与生命周期

MC 应用可以读取 `Minecraft.getMinecraft().gameSettings.language` 作为初始选择输入，或在应用自己的偏好变化入口调用流的 `select`。这只是语言码偏好，译文仍来自 UILib 独立资源；框架不改 MC 设置，不导入 MC 语言表。只支持部分语言的业务显式决定映射到哪种自身语言，不能依靠框架猜测补缺。

应用持有并关闭共享流，页面关闭只释放绑定与派生。页面私有流可在页面回调创建并 `page.own(language)`，再建立绑定，使页面自动释放其所有权。独立业务用自己的 Owner 构造 LocalizationBinding；控件卸载只释放呈现关系，重挂载读取当前事实。

## 短小人工验收

安装独立人工包后执行 `/qzcore lang`。页面只有中文/英文，自身初始选择从 MC 偏好取得，`zh_CN` 使用中文，其余使用英文；这是该验收页的明确选择。

同页点击“切换语言”，观察标题、按钮和正文；点参数及长短标题观察自然布局；点“重载语言资料”观察真实快照更新计数，页面继续可操作。主题、字号、窗口及正文滚动用于核对同代几何。按钮只操作该页的 UILib 流，不切换/保存游戏语言，不触发 MC 资源包重载。

页内资源来自独立 classpath，重载验证重新读取与资料通知；真实目录修改后译文变化由独立资源自动场景验证。业务目录来源可以在修改完成后显式 reload，框架不自动监控文件。
