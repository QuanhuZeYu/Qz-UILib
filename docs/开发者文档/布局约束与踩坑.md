# 布局实现检查入口

布局要求只以 [核心及对应模块规格 第 4 节](<../superpowers/specs/2026-10-07-uilib-core-contract-design.md#4-布局与自定义控件>) 为准。业务声明尺寸意图和关系，框架维护实际布局；固定/自然/分配意图与 min/max 独立，空间不足按声明策略处理。

现有 preferredWidth、WidthSizing、grow 与 mount 等 API 是待对齐实现，不以旧优先级或“所有行内控件必须 SHRINK”等技巧定义新需求。遇到不符记录实现偏差，不把业务手算、内部节点补宽或固定兄弟先验作为规范。

检查生产布局及实际使用路径，确认声明、测量、绘制与命中是否一致；具体算法与接口按 spec 的设计缺口完成。
