# 单行编辑接入与双实例验证

行为权威为[编辑规格](../superpowers/specs/2026-10-07-uilib-editing-spec.md)、[核心规格](../superpowers/specs/2026-10-07-uilib-core-contract-design.md)和[页面宿主规格](../superpowers/specs/2026-10-07-uilib-page-host-spec.md)。本页是当前单行切片的接入示例与人工验证步骤，多行控件尚未接入。

## 接入

业务在所属 ReactiveDomain 内构造 SceneEditState(domain, "12")，页面使用 SceneTextField.create(ctx, state, theme, readOnly, onSubmit)。state 不归旧控件或页面 scope；关闭页面只解绑，同域重开可继续使用同一 state。MinecraftSceneScreen(domain, page) 可借用已有业务域。

onSubmit 收到 Submission，业务校验 request.text 后调用 state.accept(request, normalized) 或 state.reject(request, reason)。返回值表示结果是否仍对应当前请求与草稿；仅接受且返回 true 时，本例把规范化值写入独立业务值。异步完成通过 domain.execute 递交，旧请求结果仍记录在其 status()，不会改变后来草稿、光标、选区、会话或错误。

默认 CONFIRM 在 Enter 请求完成；INPUT 在实际文本变化后请求不结束会话；BLUR 在正常离开且有活跃会话时请求完成。业务决定接受或拒绝，普通禁用、模态覆盖、解绑与关闭不隐含提交。readOnly 仍允许选择、复制与 Tab 导航。

reset(value) 明确重建基线并清历史；cancel() 恢复基线结束会话；synchronizeExternal(value) 只在没有活跃会话时正常跟随。移动、选择与复制不开始会话。单行移除 CR/LF，未完成整数负号与空串可以保存在草稿。

## 宿主输入能力

普通 1.7.10 LWJGL2 使用既有 Keyboard 历史与剪贴板边界，接收 WindowsKeyboard 已确认的 WM_CHAR 中文文本、普通字符及完整 UTF-16 代理组合。正式页面自动借用原生重复事件设置并在关闭或初始化失败时恢复；编辑字符、空格、删除与方向键支持系统持键重复，按钮 Enter/空格与 ESC 仍由既有单次按压门处理。业务无需自行开启 repeat 或增加字符消费者。当前该宿主没有真实 preedit 接缝，已确认中文文本接受与输入法临时组字呈现、候选确认隔离是不同能力，后者尚不能据此验收。

GTNH 当前实装 lwjgl3ify 3.0.31 / SDL3 3.4.2。在原有 SDL 消费循环中只采集同序的按键、真实组字与完整文本提交，再由正式页面输入管线递交。旧 Keyboard 合成字符不再重复写入。适配是否实际注入、候选键与 commit 的真实时序，须在该实例验证；自动 GPU 场景只验证核心收到事实后的呈现与行为。

## 两实例人工步骤

分别启动普通 1.7.10 与 GT_New_Horizons_2.9.0-beta-3_uilib测试，进入世界执行 /qzcore。测试包需与生产包来自本轮同次部署。两个实例结果分别记录，不能将一次反馈外推为两个都通过。

1. 点击整数字段，Ctrl+A 输入 -，Enter：草稿保留 -，业务值不变，显示业务拒绝原因；输入 0012 确认，业务值规范化为 12。空串也应可编辑而后拒绝。
2. 输入 abc 连续文字，Ctrl+Z 撤回同一输入组；Ctrl+Y 重做。方向、Home/End、Shift 选择、鼠标 DOWN/MOVE/UP 拖选应定位完整字符；粘贴 fi中文😀é 后移动或删除不得拆代理/组合字符。粘贴单次撤销。
3. 普通空格和持续按空格只输入文本，Enter 请求确认，默认 Tab/Shift+Tab 离开字段不提交；原按钮 Enter/空格仍按首次按下激活一次。
4. 输入 123，点击暂存请求，再改成 456，点击完成旧请求：456 与当前光标选区保留，旧请求不能改写业务值。重置为12可以清历史；活跃草稿时外部值99改变业务值但不覆盖草稿。
5. 开启只读：选择、复制与 Tab 可用，键入/删除/剪切/粘贴/撤销/确认不修改或提交。禁用字段应取消交互。切换主题、字号、窗口后文字、选区与光标在同一真实裁剪区域；长单行光标横向显露。
6. 保留未提交草稿，ESC 关闭后 /qzcore 重开：同一独立状态仍保留草稿；普通 ESC 不默认取消草稿。切出窗口再回来，旧持键或旧鼠标尾部不得意外输入；开页前持 Ctrl 后新按 A/C/V 应可用。
7. GTNH 中文输入法：组字可见，候选方向/删除/空格/Tab 归输入法，不修改已确认草稿；候选 Enter 只确认组字，后续 Enter 才提交字段。整段中文提交可一步撤销，取消组字后普通英文继续输入可正常合组；组字中转只读不应锁住复制或 Tab。失焦、关闭、重开不重放旧组字。

普通实例也观察实际中文提交是否可输入并反馈，但缺少 preedit 的能力限制单列；中文粘贴通过不等于中文输入法组字通过。遇到失败请提供实例名、操作顺序、草稿/业务值实际结果，必要时截图与该实例日志。
