# 开发者文档

本目录面向框架维护者和 AI 协作 Agent，仅保留产品输出区剩余资料：规格定稿、原版输入链路分析、开放化方案。

> 本区为内部开发资料，不面向外部接入开发者。对外接入说明见 [使用文档](../使用文档/README.md)。
> 控制系统区（设定值/控制律/传感/反馈/诊断五层）已迁出本目录，统一入口见 [../README.md](../README.md)。

## 目录结构

| 文件/目录 | 说明 |
|-----------|------|
| [Minecraft原版输入链路.md](Minecraft原版输入链路.md) | 原版 GuiScreen/GuiContainer 键鼠分发内部架构分析 |
| [开放化调整.md](开放化调整.md) | 从内部验证转向开发者入口的开放化方案与边界 |
| [规格文档/](规格文档/README.md) | 示例页专属规格与专项方案定稿 |

## 与控制系统区的关系

- 宪章/硬约束/边界 → `../设定值层/`
- 编排/命令/约定/发布流程 → `../控制律层/`
- 测试体系/门禁 → `../传感层/`
- 错误预防/交接/决策 → `../反馈层/`
- 技术债/项目结构/Config 模块 → `../诊断层/`
- `../README.md` 是文档唯一总入口
