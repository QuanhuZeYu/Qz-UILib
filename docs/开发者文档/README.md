# 开发者文档

本目录面向框架维护者和 AI 协作 Agent，收录架构图、规格定稿与原版输入链路分析。

> 本区为内部开发资料，不面向外部接入开发者。对外接入说明见 [使用文档](../使用文档/README.md)。
> 文档分区与文档职责分工见 [docs/README.md](../README.md)。

## 已收口材料（不作为当前施工依据）

已交付、已否决或已收口的施工包、审查报告与规划材料不在本目录维护，统一归档在 [历史报告/](../历史报告/README.md)：[专项施工/](../历史报告/专项施工/)、[审查/](../历史报告/审查/)、[规划与设计/](../历史报告/规划与设计/)、[任务笔记/](../历史报告/任务笔记/)。

这些材料只证明当时做过什么、验证到什么程度，不构成当前施工依据——当前约束以源码注释与 [规格文档/](规格文档/README.md) 为准；持续有效的设计意图、契约边界与失败语义按 [AGENTS.md](../../AGENTS.md) 写在最近的代码注释处；结论跨模块、需读代码之外的上下文才看得懂时才落 [反馈层/errors/](../反馈层/errors/)。

> 旧「控制系统区」（设定值/控制律/传感/反馈/诊断层）与「开放化调整」方案文档已不在文档树内，需要时从 git 历史取。
