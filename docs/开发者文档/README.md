# 开发者文档

本目录面向框架维护者和 AI 协作 Agent，记录内部操作资料：错误预防、发布流程、规格定稿。

> 本区为内部开发资料，不面向外部接入开发者。对外接入说明见 [使用文档](../使用文档/README.md)。

## 目录结构

| 文件/目录 | 说明 |
|-----------|------|
| [错误预防.md](错误预防.md) | 按类别沉淀的错误预防通则（只留怎么正确处理，不堆个案） |
| [发布流程.md](发布流程.md) | tag 发布、release 覆盖文件与标准发布步骤 |
| [Minecraft原版输入链路.md](Minecraft原版输入链路.md) | 原版 GuiScreen/GuiContainer 键鼠分发内部架构分析 |
| [开放化调整.md](开放化调整.md) | 从内部验证转向开发者入口的开放化方案与边界 |
| [specs/](specs/README.md) | 示例页专属规格与专项方案定稿 |

## 与其他文档区的关系

- 项目设计真相（边界/约束/技术债/测试/结构）见 `../架构/`
- 关键取舍理由见 `../决策/`
- 当前工作现场见 `../进展/`
- `../README.md` 是文档唯一总入口
