# 液态玻璃按钮样式

`SceneLiquidGlassStyle` 位于 `ui.scene.control`，为已有按钮绑定统一的拟物玻璃外观。每颗按钮有独立的玻璃面、倒角反光、厚底和接触阴影；承载按钮的容器只负责排列，不画连片玻璃底座。它不依赖聊天、HUD、网络图标或 Minecraft，图标按钮和文字按钮均可复用。

```java
SceneButtonPrimitive.Result button = SceneButtonPrimitive.create(rt,
        new SceneButtonPrimitive.Props(label, enabled, onClick));
button.root().setPadding(6, 12, 6, 12);
SceneLiquidGlassStyle.bindButton(rt, button.root(), button.label(), enabled,
        SceneButtonVariant.STANDARD, backdrop);
return button.root();
```

在组件构建作用域内调用一次。行为、布局尺寸、内容颜色与 tooltip 由调用方装配；样式管理背景染色、倒角边缘、圆角、滤镜、实体高度、内容透明度与微移，以及光标。内容根的 transform 由样式管理，需要其他变换时使用额外内容子节点。不要在同一节点上叠加 `SceneButton` 的默认外观绑定，否则两套绑定会争用属性。

| 状态 | 外观 |
| --- | --- |
| 常态 | 独立凸起玻璃面；上缘高光、下缘厚度与接触阴影；默认就保留清晰透镜 |
| 悬停 | 玻璃面与内容抬起，倒角反光和透镜增强，阴影体现离地高度 |
| 按下 | 玻璃面与内容落下、阴影收紧、透镜减弱，圆角轮廓保持稳定 |
| 焦点 | 浅蓝倒角缘光，支持与悬停/按下同时表达 |
| 禁用 | 内容淡化、弱缘光，仍保留玻璃厚度和折射；优先于全部交互态 |

`STANDARD` 使用中性冷白，`PRIMARY` 使用浅蓝染色，`DANGER` 使用浅红染色。染色保持轻薄，体积感来自有方向的反光、厚底和投影。配色与状态配方集中在该类中，不散落到业务组件。

`backdrop` 从宿主传入，样式保留材质、模糊半径与饱和度；对液态配方只调整透镜强度。传入 `null` 时关闭滤镜，仍保留立体轮廓与交互反馈。聊天 HUD 对小按钮单独限制模糊半径，避免沿用大面板的强模糊后折射细节被抹平；每颗按钮各自采样游戏背景，按钮间保留透明间隙。

过渡复用 `SceneRuntime` 的颜色与浮点动画，启用 Motion 时持续 160ms，否则立即应用。实体高度、缘光与透镜只产生 paint 失效，内容微移与透明度只产生 composite 失效。圆角保持不变；交互根不移动、不缩放，投影和玻璃面均限制在原按钮盒内，布局与命中区域保持不变。绑定和动画随 Owner/runtime 卸载清理。

内部立体表面使用 scene 绘制属性，并通过既有 `PaintCommand` 输出背景、滤镜与倒角，不新增渲染后端或绕过 scene 的 GL 绘制。普通节点不启用该属性，保留原有绘制路径。
