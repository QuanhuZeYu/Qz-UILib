# 液态玻璃按钮样式

`SceneLiquidGlassStyle` 位于 `ui.scene.control`，为已有按钮绑定统一的玻璃外观。它不依赖聊天、HUD、网络图标或 Minecraft，图标按钮和文字按钮均可复用。聊天 HUD 工具栏是首个接入点。

```java
SceneButtonPrimitive.Result button = SceneButtonPrimitive.create(rt,
        new SceneButtonPrimitive.Props(label, enabled, onClick));
button.root().setPadding(6, 12, 6, 12);
SceneLiquidGlassStyle.bindButton(rt, button.root(), button.label(), enabled,
        SceneButtonVariant.STANDARD, backdrop);
return button.root();
```

在组件构建作用域内调用一次。行为、布局尺寸、内容颜色与 tooltip 由调用方装配；样式管理背景染色、边框、圆角、滤镜、内容透明度和光标。不要在同一节点上叠加 `SceneButton` 的默认外观绑定，否则两套绑定会争用属性。

| 状态 | 外观 |
| --- | --- |
| 常态 | 低透明度染色、细亮边、较弱透镜 |
| 悬停 | 更圆的轮廓、增强缘光、透镜恢复到宿主配方强度 |
| 按下 | 圆角收紧、透镜减弱、染色加深 |
| 焦点 | 独立的浅蓝亮边，支持与悬停/按下同时表达 |
| 禁用 | 内容淡化、弱边框、透镜归零；优先于全部交互态 |

`STANDARD` 使用中性冷白，`PRIMARY` 使用浅蓝染色，`DANGER` 使用浅红染色。配色与状态配方集中在该类中，不散落到业务组件。

`backdrop` 从宿主传入，保留材质、模糊半径与饱和度；对液态配方只调整透镜强度。传入 `null` 时关闭滤镜，仍保留轮廓与交互反馈，供玻璃设置关闭时使用。

过渡复用 `SceneRuntime` 的颜色与浮点动画，启用 Motion 时持续 160ms，否则立即应用。圆角、缘光与透镜只产生 paint 失效，内容透明度只产生 composite 失效；不缩放或移动节点，按钮布局与命中区域保持不变。绑定和动画随 Owner/runtime 卸载清理。
