# 液态玻璃按钮样式

`SceneLiquidGlassStyle` 位于 `ui.scene.control`，为 `SceneButtonPrimitive` 绑定拟物玻璃外观。每颗按钮有独立玻璃面、倒角反光、厚底和接触阴影；排列容器不需要连片玻璃底座。行为仍由 primitive 提供，外观只消费交互与配方信号，不依赖聊天、HUD、Minecraft 或图片来源。

## 响应式入口

```java
public static void bindButton(SceneRuntime rt, SceneNode button, SceneNode motionRoot,
        ReadableSignal<Boolean> enabled, ReadableSignal<SceneGlassButtonStyle> style);

public static void bindForeground(SceneRuntime rt, SceneNode textNode,
        ReadableSignal<SceneGlassButtonStyle> style, int fallbackColor);
```

在组件构建作用域内绑定一次，后续只更新 style 信号。材质、variant、过滤开关、状态配色及其他配方字段可在同一按钮上切换，不需要重建节点或重复调用绑定器。style 信号与发布值均不可为 null；配方的 backdrop 和 foreground 字段允许 null。

以下构建代码放在 `rt.mount(..., () -> { ... })` 内。新增 motionRoot 承载层让样式微移与业务内容自己的变换分别拥有属性槽：

```java
SceneButtonPrimitive.Result button = SceneButtonPrimitive.create(rt,
        new SceneButtonPrimitive.Props(label, enabled, onClick));
button.root().setPadding(6, 12, 6, 12);

SceneNode motionRoot = SceneNode.row();
motionRoot.setHitTestable(false).setWidthSizing(SceneNode.WidthSizing.SHRINK);
button.root().removeChild(button.label());
motionRoot.appendChild(button.label());
button.root().appendChild(motionRoot);

Signal<SceneGlassButtonStyle> style = Signal.create(SceneGlassButtonStyle.builder()
        .variant(SceneButtonVariant.PRIMARY)
        .backdrop(backdrop)
        .foreground(0xFFF4F8FF)
        .build());
SceneLiquidGlassStyle.bindButton(rt, button.root(), motionRoot, enabled, style);
SceneLiquidGlassStyle.bindForeground(rt, button.label(), style, 0xFFFFFFFF);
return button.root();
```

宿主配置已经是响应式信号时，可将 `Computed<SceneGlassButtonStyle>` 直接作为 style。业务事件只发布意图或更新信号，例如 `style.set(style.get().toBuilder().backdrop(null).build())` 关闭过滤；handler 不改节点属性或树结构。

## 属性归属

| 对象 | 样式管理的属性 | 调用方管理的属性 |
| --- | --- | --- |
| button 交互根 | backgroundColor、borderColor、borderWidth、统一 cornerRadius、surfaceElevation、backdrop、cursor | 行为、布局、padding、尺寸、tooltip；根 transform/opacity 可由宿主负责 |
| motionRoot 专用承载层 | transform、opacity，均为绝对值覆盖 | 构建时的布局与子节点装配 |
| motionRoot 后代的业务内容 | bindButton 不写任何属性；仅显式 bindForeground 的 textNode.textColor 归 helper 管理 | 内容、字号、图片、自身 transform/opacity，以及未绑定 helper 的颜色 |

motionRoot 应是 button 的后代且与 button 不同；业务内容继续挂在 motionRoot 下面。样式不创建或检查这棵结构，不遍历后代，不保存业务子节点列表。需要同时移动图标与文字时，把它们放在同一个 motionRoot；它们仍可拥有独立的变换、透明度和颜色。承载层及装饰内容按业务需要设置为不可命中，输入由 primitive 的根处理。

不要给同一属性建立第二套绑定，也不要在同一个 button 上叠加 `SceneButton` 默认外观。bindForeground 只处理一个指定文本节点：foreground 非 null 使用该 ARGB，null 恢复显式传入的 fallbackColor，恢复也遵循动画时长。它不改变图标位图颜色；位图不受 textColor 染色，这里没有新增图片染色协议。多段文字可分别调用 helper，或由业务建立自己的颜色派生绑定。

## 不可变配方

`SceneGlassButtonStyle.builder()` 的默认值匹配旧入口，`toBuilder()` 复制现有配方，修改 builder 不会改变已构建实例。相同字段具有值相等语义，可交给 Signal/Computed 去重。

| 字段 / builder 方法 | 默认值及语义 |
| --- | --- |
| variant | STANDARD；null 同 STANDARD。PRIMARY 浅蓝、DANGER 浅红，STANDARD 中性冷白 |
| backdrop | null，关闭过滤并保留轮廓和状态反馈；非 null 保留宿主材质、模糊与饱和度 |
| cornerRadius / borderWidth | 8 / 1 logical px，非负整数，变化只影响 paint；borderWidth 控制盒内倒角带宽，极大值保留非空内孔，0 关闭倒角及内缘阴影 |
| idle / hovered / pressed / disabled | 可选 `StateStyle` 覆盖；null 表示采用当前 variant 对应默认值 |
| focusEdge | `0xD0C7EEFF`，只覆盖非禁用态缘色 |
| contentLift | 2 logical px，有限非负数；motionRoot 的 Y 偏移 = `-contentLift * elevation`，不改变玻璃实体自身渲染升降幅度 |
| disabledOpacity | 0.35，有限的 [0,1]；非禁用态 motionRoot.opacity 为 1 |
| transitionMillis | 160，非负整数；0 立即应用，runtime 未启用 Motion 时也立即应用 |
| foreground | null，只有显式 bindForeground 消费；null 回退 helper 的 fallbackColor |

`new SceneGlassButtonStyle.StateStyle(int tint, int edge, float elevation, float lensFactor)` 将单态字段收在一个不可变值中：tint 和 edge 是完整 ARGB 定值，高度为 [0,1]，透镜系数有限且非负。最终透镜强度按 `UiBackdropEffect` 现有规则限制在 [0,1]。NaN、Infinity、负尺寸、负时长以及越界透明度/高度会被拒绝。

edge 的 alpha 为 0 时关闭倒角及内缘阴影，仍保留实体厚底、表面渐变和 backdrop 自身的光学缘光；非零 alpha 沿用原有拟物强度曲线。

显式 StateStyle 优先于 variant：例如覆盖 hovered 后切换 PRIMARY → DANGER，hovered 仍保持自定义 ARGB；未覆盖的其他态随 variant 更新。调用 `toBuilder().hovered(null)` 可恢复当前 variant 的默认悬停态。focusEdge 仍高于非禁用态自定义 edge。

| 状态 | 默认高度 | 默认透镜系数 | 默认外观 |
| --- | --- | --- | --- |
| idle | 0.5 | 0.85 | 玻璃面凸起、上缘高光、下缘厚度与接触阴影 |
| hovered | 1 | 1 | 玻璃面与内容抬起，缘光与透镜增强 |
| pressed | 0 | 0.60 | 玻璃面与内容落下，阴影收紧、透镜减弱 |
| disabled | 0.35 | 0.65 | 内容淡化、弱缘光，保留厚度与折射 |

状态优先级是 disabled > pressed > hovered > idle，focus 作为非禁用态缘色覆盖。没有 busy、selected 或下一阶段状态机制。

## 动画、材质和生命周期

颜色、实体高度、微移、透明度和液态透镜系数复用 SceneRuntime 的颜色/浮点动画轨道。时长与目标一起读取：改变配方后，新目标使用新时长；进行中的动画切换到 0 时立即完成。非零时长只改变后续重定向的时长，同目标进行中的轨道不因单独调整时长重新起计时。材质家族、模糊、饱和度和过滤开关立即更新；即使动画还在进行，后续透镜样本也只作用于最新材质，不恢复旧过滤配置。经典 backdrop 原样传递，不施加液态透镜。

button 的 paint 属性只触发 paint 失效，motionRoot 的变换和透明度只触发 composite 失效，不改变布局尺寸。样式不移动或缩放交互根，命中区域保持原布局盒。宿主额外设置根变换的行为仍由 scene 的既有变换与命中合同决定。

所有 Computed、绑定与动画轨道跟随当前 Owner；组件卸载时退订并取消动画。若绑定时没有当前 Owner，则归 runtime 根 Owner，由 runtime.dispose() 清理。清理后样式不会再写入节点；清理不回滚已经应用的属性。每个 occurrence 独立创建按钮与绑定，不跨投放共享节点。

内部立体表面通过现有 scene 绘制属性与 PaintCommand 输出背景、滤镜和倒角，不新建渲染后端，不绕过 scene，不使用原版 GUI 或 Tessellator。宿主仍负责提供合适的 backdrop 配方，例如为小按钮限制模糊半径，保留折射细节。

## HUD 公共工具与聊天接入

`HudToolbarSpec` 的 `publicButtonStyle(ReadableSignal<SceneGlassButtonStyle>)` 只配置外接层追加的公共按钮，不改写自定义工厂的节点或动作。默认保留 `DARK_THIN`、模糊半径 6、液态强度 1 的配方；自定义与公共按钮要共享主题时，由调用方显式传入同一信号。

```java
Signal<SceneGlassButtonStyle> tools = Signal.create(SceneGlassButtonStyle.builder()
        .backdrop(UiBackdrop.liquidGlass(UiGlassMaterial.THIN, 4, 0.8F))
        .foreground(0xFF182028)
        .build());
HudToolbarSpec spec = HudToolbarSpec.builder().publicButtonStyle(tools).build();
// 更新已有公共按钮，保留工具栏节点和 HUD 当前倍率。
tools.set(tools.get().toBuilder().backdrop(null).build());
```

聊天动作按钮和公共缩放按钮通过 `ChatToolbarAppearance` 显式共享既有聊天设置：活动 UI 帧采样玻璃开关、模糊与液态强度，按配方值去重后通知样式。聊天输入框直接使用 `SceneTextInputPrimitive`，由包内 `ChatInputChrome` 唯一管理背景和边框，保留输入、选区、双端 caret 与补全行为。

按钮的 Enter/Space 按压反馈由输入路由维护，并与指针按压合成；松键、失焦、禁用、卸载和取消会清理。LWJGL 宿主只为已经通过回调投递的激活键补充释放事件，不额外生成激活；外部文本模式下 Space 的 KEY 与 TEXT 各自承担按钮操作和文本输入。

## 渲染参数与验证边界

液态配方的零模糊半径只执行折射后的单点采样。覆盖率与折射法线采用同一圆角轮廓，支持直角和四角独立的圆角矩形；纹理采样显式处理屏幕 Y 轴与纹理 V 轴方向差异。所有门面重载统一穿透宿主缩放。

固定管线和纯色兜底仍不具备完整液态效果；多层透明容器及任意变换的背景采样语义保留现有边界，本次未重构合成层。GL-free 状态与几何测试不能替代宿主集成验收。隐藏 OpenGL 上下文中的 shader 编译与 FBO 像素测试可验证 shader 本身，但不能代表 Minecraft、Angelica、lwjgl3ify 或所有 GPU 的组合表现。

## 旧入口兼容

```java
SceneLiquidGlassStyle.bindButton(rt, button.root(), button.label(), enabled,
        SceneButtonVariant.STANDARD, backdrop);
```

原六参数签名完整保留，并委托默认配方；null variant 仍表示 STANDARD，null backdrop 仍关闭过滤。旧入口仍直接管理传入 content 的 transform/opacity，默认状态配色、圆角、厚度、透镜、160ms 过渡与 Owner 合同不变。旧调用方需要额外业务变换时可把业务内容放到 content 的后代；新代码建议显式命名 motionRoot 承载层。
