# HUD 在主页类屏幕上误显

## 错误现象

- HUD 浮窗在游戏主页上意外显示，用户在主菜单也能看到原本只应出现在游戏内的 HUD 内容。

## 触发场景

- 当前宿主界面是 Minecraft 游戏主页或第三方替换主页，类名可能为 `net.minecraft.client.gui.screens.TitleScreen`、`net.minecraft.client.gui.GuiMainMenu`，也可能是第三方自定义主页如 `galaxyspace.core.gui.GSGuiMainMenu`。
- HUD 可见性判断若只覆盖部分主页类名，就会让遗漏的主页继续被当作普通容器态页面处理。

## 根本原因

- HUD 屏幕分类逻辑按类名白名单识别菜单页，但主页识别名单不完整，容易遗漏新版主页或第三方自定义主页。
- 可见性门槛依赖分类结果，菜单页没有被正确归入 `MENU` 时，HUD 就会继续参与绘制。

## 修复方案

- 将原版旧主页、新版主页和已确认的第三方主页类名一并纳入菜单分类。
- 增加可见性回归测试，确认 HUD 在主菜单类屏幕上不再显示。

## 预防措施

- 后续处理屏幕分类时，优先按“原版旧类名 + 原版新类名 + 已确认第三方类名”三层覆盖。
- 对任何依赖屏幕分类的 HUD/输入门槛，都补一条主菜单回归测试，避免版本切换时再次漏判。
