# 2026-05-07 背包 tooltip 32px 半径口径偏差

## 错误现象
- 背包页 tooltip 定位测试在窄屏边缘场景下失败。

## 触发场景
- `InventoryTooltipLayoutResolver` 用对角分量近似 32px 鼠标清空带，但可用宽高裁剪口径与设计文档不一致。

## 根本原因
- 设计要求是 tooltip 与鼠标保持固定 `32px` 半径范围；实现却把可用宽高也按对角分量收缩，导致边缘收窄条件下宽度判断过紧。

## 修复方案
- 将可用宽高计算改为按 `32px` 清空带预留，同时继续保留对角落点锚定。

## 预防措施
- 页面级浮层定位的“锚点位移”和“可用空间预留”必须分别核对，不要混用同一个几何近似。
