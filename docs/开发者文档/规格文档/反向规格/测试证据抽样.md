## 数值 Oracle 的独立复核

本轮用代码计算样本：剩余视口宽 = 父宽 − 滚动条宽 − gap，视口与滚动条右边界合回父宽；权重比例总量与 max 撞顶再分配合回总预算。可复现输入与算法：


```python
def oracle():
    parent, bar, gap = 100, 8, 3
    viewport = parent - bar - gap
    assert viewport == 89 and viewport + gap + bar == parent
    total, weights = 100, [2, 3, 1]
    alloc = [total * w // sum(weights) for w in weights]
    alloc[-1] += total - sum(alloc)
    assert alloc == [33, 50, 17] and sum(alloc) == total
    total, frozen = 300, 50
    remaining = total - frozen
    alloc = [remaining // 2, frozen, remaining - remaining // 2]
    assert alloc == [125, 50, 125] and sum(alloc) == total
```

以上只校验例子的算术与总量，不证明取整政策已经获用户认可，也不复现生产引擎。此代码在文档校验阶段由 Node 等价执行验算。
