# 物品视觉渲染接缝规格

> 状态：**现行规范**（「产品合同」「几何」「执行」三节为本文件的现行内容；机制细节以 `ui.image.MinecraftItemIconRenderer`、`RenderSemantics`、`ItemRenderTierRegistry` 的类注释为准）。
> 物品渲染按上层替换路线落地为当帧直绘，原解耦路线（FBO 栅格化、会话缓存、三态结果、GL 围栏、占位、预算/cooldown、帧中止、epoch 清缓存）已整体删除。Breaking major 目标不变：用户已选择清理旧兼容面，不维持 4.x LIVE/SNAPSHOT/Slot 双栈。

## 产品合同

UILib 只提供普通 UI 使用的静态 ItemStack icon：

- factory 创建时复制完整 ItemStack snapshot，包括 metadata/NBT；
- source 创建后不再读取调用方 mutable stack，getter 亦返回防御拷贝；
- 只绘制 item/effect icon，不绘制 count/durability overlay；
- scene core 只认识 opaque `SceneImageSource`；
- 宿主物品渲染能力缺失（空适配器、无 Minecraft 上下文、宿主不具备委托条件）时跳过绘制：不崩溃、不画占位；
- host close/resource reload 清理普通 bitmap upload texture。

明确不包含 GuiContainer、Slot、inventory、carried、tooltip、input、worker/Future、全局资源图或跨 host GPU cache。

## 几何

- `destinationSide = min(targetWidth, targetHeight)`，square 在目标矩形中居中。
- `rasterSide = min(destinationSide, internalCap)` 仅保留为兼容数值，不再限制 backing raster：绘制按 destination square 直接执行。
- 完全位于有效 clip 外的请求跳过绘制。

## 执行

- 每次请求由 `ItemIconRenderer`（默认 `MinecraftItemIconRenderer`）当帧直绘到当前主层：无 FBO 栅格化、无缓存、不画占位图（UNRENDERABLE 分级项由宿主回退占位样式，见 `ItemRenderTierRegistry`）、无围栏、无帧中止、无 epoch 清缓存。
- 纯 2D 图标、3D block 与多 pass item model **一律完整委托**原版 `RenderItem.renderItemAndEffectIntoGUI`（含 Forge hook 与 GUI 标准光照成对开闭），没有分支判定、没有 2D 等价自绘；渲染语义按 `RenderSemantics`（默认 ISOLATED：`GlStateScope` 入口态快照 + finally 恢复；VANILLA：保留原版全部残留），渲染分级经 `ItemRenderTierRegistry` 三次追踪永久分级（RENDERABLE 快路径 / UNRENDERABLE 停止渲染宿主回退占位 / NEEDS_ISOLATION 每次隔离 + 排空）。
- 绘制全程在 `GUI_ITEM_Z_LEVEL = 100` 深度执行并无条件恢复调用前 zLevel；矩阵 push/pop 成对。
- 能力缺失一律安全跳过、不崩溃：空适配器（无 `ItemIconRenderer`）、`Minecraft` 上下文为空、宿主不具备委托条件（`fontRenderer` 或 `textureManager` 为空）时跳过绘制；missingno 与其余兜底沿用原版语义。
- 不用像素回读证明视觉 no-op；普通 texture/bitmap 使用独立轻路径，不经过 item icon 路径。

## Breaking 迁移

- 删除 LIVE alias、旧 snapshot overlay 语义和万能 `HostImageRenderer` public 合同。
- 普通 texture/bitmap 使用独立轻路径，不经过 item icon 直绘；自定义 plain renderer 是受信任窄委托，必须自行遵守 `HostImageRenderer` 的状态纪律。
- `UiRuntimeAdapters` 不再携带 inventory-slot renderer；`ui.inventory`、`ui.slot` 和 GuiContainer mixin 移出目标源码。
- Qz-Miner `BlockPickerVisualAdapter` 迁到新 icon factory（显式键工厂 `HostImageSource.itemIcon(ItemStack, String)`）；业务枚举、label、picker、codec 和 Config Draft 仍归 Miner。
- 本条接缝属 Breaking major，长期合同语义只有一句：旧 LIVE/SNAPSHOT/Slot 面不再恢复，下游按新 icon factory 迁移。**迁移期的版本号、编译坐标与依赖区间不在本文固化**——它们随发布批次变化，一律以实时真源为准：UILib 的 FML 远端范围见 `src/main/java/club/heiqi/uilib/MyMod.java` 的 `acceptableRemoteVersions`（区间口径与发布动作见 `docs/开发者文档/发布流程.md`）；下游 Qz-Miner 的编译坐标见其 `dependencies.gradle`，`required-after` 依赖声明见其 `MyMod` 的 `@Mod` 声明。
- 历史注记：本节曾把目标版本写死为 UILib `5.0.0`、Miner 编译坐标 `5.0.0:dev`、运行依赖 `[5.0.0,6.0.0)`、UILib 远端范围 `[5.0.0,5.1.0)`；那是当时的迁移预案，未按该形态落地，不得当作现状依据。
