# 物品视觉渲染接缝规格

> 状态：已实施（2026-08-13，提交 323d25da）。物品渲染按上层替换路线落地为当帧直绘，原解耦路线（FBO 栅格化、会话缓存、三态结果、GL 围栏、占位、预算/cooldown、帧中止、epoch 清缓存）已整体删除；本文同步内部机制现状，产品合同不变。Breaking major 目标不变：用户已选择清理旧兼容面，不维持 4.x LIVE/SNAPSHOT/Slot 双栈。

## 产品合同

UILib 只提供普通 UI 使用的静态 ItemStack icon：

- factory 创建时复制完整 ItemStack snapshot，包括 metadata/NBT；
- source 创建后不再读取调用方 mutable stack，getter 亦返回防御拷贝；
- 只绘制 item/effect icon，不绘制 count/durability overlay；
- scene core 只认识 opaque `SceneImageSource`；
- 宿主物品渲染能力缺失（空适配器、无 Minecraft 上下文、无 items atlas 能力）时跳过绘制：不崩溃、不画占位；
- host close/resource reload 清理普通 bitmap upload texture。

明确不包含 GuiContainer、Slot、inventory、carried、tooltip、input、worker/Future、全局资源图或跨 host GPU cache。

## 几何

- `destinationSide = min(targetWidth, targetHeight)`，square 在目标矩形中居中。
- `rasterSide = min(destinationSide, internalCap)` 仅保留为兼容数值，不再限制 backing raster：绘制按 destination square 直接执行。
- 完全位于有效 clip 外的请求跳过绘制。

## 执行

- 每次请求由 `ItemIconRenderer`（默认 `MinecraftItemIconRenderer`）当帧直绘到当前主层：无 FBO 栅格化、无缓存、无占位、无围栏、无帧中止、无 epoch 清缓存。
- 分支判定与原版 `RenderItem.renderItemIntoGUI` 一致：3D block（`RenderBlocks.renderItemIn3d`）或多 pass item model 委托持有的原版 `RenderItem.renderItemAndEffectIntoGUI`，保留全部原版行为与 Forge hook，GUI 标准光照成对开闭。
- 纯 2D 图标按原版 2D 分支等价自绘：disable lighting → enable blend → `glBlendFuncSeparate(770, 771, 1, 0)` → bind items atlas → 可选 tint color → enable alpha test → Tessellator quad → 收尾 enable lighting / disable alpha test / disable blend，结束状态与原版 2D 分支一致；附魔 glint 在 2D 路径不绘制（与原版 2D 分支一致）。
- 绘制全程在 `GUI_ITEM_Z_LEVEL = 100` 深度执行并无条件恢复调用前 zLevel；矩阵 push/pop 成对。
- 能力缺失一律安全跳过、不崩溃：适配器未注入 item icon renderer、`Minecraft` 上下文为空、items atlas 无法取得（texture manager 为空、atlas 非 `TextureMap` 且无图标）时跳过绘制；missingno 兜底沿用原版语义。
- 不用像素回读证明视觉 no-op；普通 texture/bitmap 使用独立轻路径，不经过 item icon 路径。

## Breaking 迁移

- 删除 LIVE alias、旧 snapshot overlay 语义和万能 `HostImageRenderer` public 合同。
- 普通 texture/bitmap 使用独立轻路径，不经过 item icon 直绘；自定义 plain renderer 是受信任窄委托，必须自行遵守 `HostImageRenderer` 的状态纪律。
- `UiRuntimeAdapters` 不再携带 inventory-slot renderer；`ui.inventory`、`ui.slot` 和 GuiContainer mixin 移出目标源码。
- Qz-Miner `BlockPickerVisualAdapter` 迁到新 icon factory；业务枚举、label、picker、codec 和 Config Draft 仍归 Miner。
- Breaking seam 的目标 UILib 版本为 `5.0.0`；Qz-Miner 编译坐标固定为 `5.0.0:dev`，运行依赖固定为 `[5.0.0,6.0.0)`。UILib FML 远端范围独立固定为 `[5.0.0,5.1.0)`，主信封 v2 与 Realtime v1 不变。

## 首片验收

- snapshot copy；icon-only；18x18、64x16、16x64、64x64、64x128 square fit。
- 纯 2D 等价自绘路径、3D block / 多 pass 委托路径、空适配器与无 atlas 能力跳过绘制（不崩溃、不画占位）。
- 普通 bitmap upload 在 host close 释放。
- 源码与测试不出现新的 GuiContainer、Slot、inventory 或 LIVE seam。
