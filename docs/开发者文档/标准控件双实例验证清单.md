# 标准控件双实例验证清单

目标是两个实例各验一次同一正式页面：Prism 的 `1.7.10` 与 `GT_New_Horizons_2.9.0-beta-3_uilib测试`。生产 UILib 与人工入口包配套部署；旧包保留在各实例 `qz-deployment-backups`。不要在同一 mods 下保留两份 UILib。

本轮代理完成自动核心/软件场景、真实 GL 字体与像素及 LWJGL2 场景，不启动游戏；以下设备与游戏生命周期由用户操作，反馈前不声称 MC 实机通过。入口使用[正式标准控件](<标准控件与动态主题.md>)。

先关闭两个实例已有游戏进程，再从 Prism 启动待验实例，进入任意世界并执行 `/qzcore`。不需要修改世界内容。页面应有“浅色/深色”“字号”“标题”“模态”、A/B 焦点操作、条目列表，以及底部限高长文案、单行省略和禁用按钮。

| 操作 | 观察结果 |
|---|---|
| 开页后看按钮、标签与列表 | 无首帧空主题、默认颜色与文字有效；按钮可以自然换行 |
| 滚列表到中部，点击“浅色”，再点击“深色”，反复切换 | 已有背景、正文、按钮、焦点边框随主题改变；操作计数与列表不重置，滚动不回顶部，页面保持打开 |
| 点“标题”“字号”切换文案和字号，再调整窗口大小 | 文字与按钮按实际空间自动重排，列表获得剩余空间；无需关页重开；焦点仍指向合法原目标 |
| 缩窄窗口看底部限高长文案，再悬停 | 正文只显示完整行及省略号，没有半截行；即时出现完整文案提示，按钮尺寸不变，提示不抢焦点 |
| 用 Tab/Shift+Tab 找到底部长按钮，移开鼠标 | 键盘聚焦也能显示全文提示；提示在窗口内，不新增导航项；极小窗口连一行也放不下时允许空正文但仍可看提示 |
| 观察单行策略按钮及禁用按钮 | 单行按钮不换行，放不下有省略；禁用有区分颜色，点击无业务动作，Tab跳过，Enter/空格不能激活它 |
| 选中“添加”按钮，按一次 Enter，再按一次空格；分别长按 | 每个新的按压段只添加一次，repeat不连发；Tab只移动焦点、不添加；点击也只执行一次 |
| 鼠标按住按钮后移出再释放；按住时切出窗口并释放再切回 | 不出现迟到点击；返回后不保留按下色，新点击正常；物理尾部不转交给新目标 |
| 聚焦一个按钮，按住Enter或空格切出窗口，再切回并释放 | 失焦及恢复旧按压段不触发；释放后新的按压可以触发 |
| 点“模态”→“内层模态”，再分别按ESC | 一次按压只关当前层，repeat不连关；焦点按既有范围策略返回；后台按钮不响应且不显示后台提示 |
| 按ESC关整页，再次 `/qzcore`；可开页时仍持有ESC | 关闭后不重放旧输入；再次开页正常，持键不立即关闭新页，释放后的新ESC才正常关闭 |

两个实例各跑一遍并分别记录“通过／异常”。异常反馈需要：实例名、操作顺序、预期与实际、截图；若崩溃或无法开页，附该实例 `logs/latest.log` 的相关堆栈。优先截图浅深主题各一张和长文案提示一张；正常时无需为所有步骤逐项截图。

若页面在很小窗口因固定验收控件总高度超出屏幕而部分内容不可见，先放大窗口完成清单；本轮不新增焦点自动显露能力。主题随重新打开回到页面声明的初始深色，运行时切换仍保持当次会话状态。
