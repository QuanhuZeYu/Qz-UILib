# 声明式页面接入

行为合同见[页面接入规格](<../superpowers/specs/2026-10-07-uilib-page-host-spec.md>)，本页说明正式生产 API 的用法。

页面定义是 `ScenePage` 构造回调。在合法域内声明状态、内容树、布局与业务策略，通过 `ScenePageContext.mount` 接入根节点。已有状态由调用方传入；本页订阅和资源通过 `scope()`、`own()` 明确归属。

`ScenePageSession` 组织 runtime、管线和作用域；普通内容不创建这些对象，也不手工 flush/layout/replay。MC 页面直接继承 `MinecraftSceneScreen`，宿主协调输入、绘制、尺寸重初始化和释放。

```java
import club.heiqi.uilib.ui.host.minecraft.MinecraftSceneScreen;
import club.heiqi.uilib.ui.reactive.Signal;
import club.heiqi.uilib.ui.scene.layout.Size;
import club.heiqi.uilib.ui.scene.node.SceneNode;
import club.heiqi.uilib.ui.scene.control.SceneButton;
import club.heiqi.uilib.ui.scene.control.SceneTheme;

public final class ExampleScreen extends MinecraftSceneScreen {
    public ExampleScreen() {
        super(page -> {
            Signal<String> caption = page.domain().signal("点击更新");
            Signal<SceneTheme> theme = page.domain().signal(SceneTheme.dark());
            SceneNode action = SceneButton.create(page, caption, theme,
                () -> caption.set("已更新"));
            page.mount(new SceneNode().size(Size.fill(1), Size.fill(1)).add(action));
        });
    }
    @Override public boolean doesGuiPauseGame() { return false; }
}
```

标准按钮与标签用法见[标准控件与动态主题](<标准控件与动态主题.md>)；编辑/IME 控件仍按所属模块建设。焦点、模态和 ESC 策略在声明树表达；业务回调只更新状态或发布意图。正式接入不决定业务是否保存、清空草稿或停止外部任务。

软件和 GPU 测试使用同一个页面定义：`ScenePageSession.open(domain, host, measurer, definition)`。宿主只供给窗口、度量和回放事实，通过 session 的 pointer/navigation/escape/frame 递交动作；场景在测试应用中断言实际状态、几何或像素，结束关闭 session。host/measurer 默认借用，页面专有资源在回调内 own；共享字体和宿主窗口仍归调用方。

外部 executor 的初始化按独立域操作递交，输入和帧可在 open 返回后递交，会排在构造之后。底层 runtime/pipeline 观察需在初始化已执行后使用。初始化及其首次 Effect 失败沿原 executor 错误通道报告并清理，不会回退为未消费 ESC。

同页 initGui 尺寸变化保留会话和绑定；frame 感知宿主尺寸自动重排。关闭立即停止本页输入和迟到结果，卸载及释放在当前最外层操作/Effect 结束后进行，失败时也完成清理尝试，不补帧或回放。handler/Effect 的原异常保持主异常，清理错误作为 suppressed；重复关闭安全。

无平台内容可独立复用；MC 接入把原生事件转换成同一生产事件序列，父 GuiScreen 仍是唯一原生队列消费者。软件/GPU 注入不能代表 MC 实际设备事件验收。
