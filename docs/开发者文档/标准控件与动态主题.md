# 标准控件与动态主题

行为依据[主题与控件文案规格](<../superpowers/specs/2026-10-07-uilib-theme-spec.md>)，页面运行环境用[正式声明式入口](<声明式页面接入.md>)。本页介绍 `ui.scene.control` 内 API。

`SceneTheme` 是不可变样式值，提供 `light()`、`dark()`，公开颜色、文字样式和间距；构造器允许自定义主题，`withTextStyle` 修改文字样式并保留其他主题值。控件接收 `ReadableSignal<SceneTheme>`，颜色、字号、padding 变化自动失效；业务用 signal.set 新值切换，不修改字段或主动刷新布局。

```java
Signal<SceneTheme> theme = page.domain().signal(SceneTheme.dark());
Signal<String> caption = page.domain().signal("操作");
SceneNode action = SceneButton.create(page, caption, theme, () -> caption.set("已操作"));
SceneNode switchTheme = SceneButton.create(page, () -> "浅色", theme,
    () -> theme.set(SceneTheme.light()));
SceneNode title = SceneLabel.create(page, () -> "标题", theme);
page.mount(new SceneNode().size(Size.fill(1), Size.fill(1))
    .add(title).add(action).add(switchTheme));
```

`SceneButton.create(page, text, theme, action)` 默认填充宽度、自然高度；`SceneLabel.create(page, text, theme)` 默认自然尺寸。返回现有 `SceneNode`，作者可声明 `.size(...)`、`.enabled(...)`、`.focusable(...)` 或响应绑定；无需接内部文字节点、补文字宽度或初始主题。固定文案可用 `() -> "文案"`；动态文案可给 Signal/Computed 或可追踪来源的读取函数。派生主题使用 `page.domain().computed(page.scope(), ...)`，不是业务先算一遍初值。

默认文案策略是 `SceneTextPolicy.WRAP`。create 重载的末参数可选 `ELLIPSIS_SINGLE_LINE` 或 `OVERFLOW`，同一文字区域参与测量与实际绘制；按钮限高用 `.size(Size.fill(1), Size.natural().bounds(0, 60))` 或固定高度。默认只画放得下的完整行，最后完整行添加真实字体省略号；空间不足一整行时正文可为空，源文案仍保留。

被省略的按钮悬停或聚焦时显示完整文案提示。提示在所有内容之后绘制、限制在当前 viewport，不占布局、不参与命中、不抢焦点，不改按钮尺寸或字体。超过整个 viewport 的超长文案保留完整排版，仅裁剪可见提示区。公开 `OVERFLOW` 保留不受正文内区限制的文字，仍服从祖先 clip，不显示默认省略提示。

按钮默认参与 Tab，点击取得焦点；Enter/空格沿同一业务 action 激活，宿主按压段门防 repeat。禁用按钮及不可用祖先不会激活或显示后台提示。标签默认不获取焦点。点击聚焦是 `SceneNode.clickFocus(true)` 的显式声明，普通节点默认策略未变化。业务回调继续只更新状态或发意图，持有的外部业务与编辑状态不因主题切换重建。

软件自动验收 `standardControlsScenario` 共用正式 Session，验证实际几何、计划、焦点和业务动作；真实 GPU 场景验证主题像素与真实字体省略。MC 桥仍需双实例原生设备验证，按[双实例验证清单](<标准控件双实例验证清单.md>)执行。
