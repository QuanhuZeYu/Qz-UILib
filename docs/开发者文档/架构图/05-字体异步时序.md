# 字体异步时序（L2）

L2 时序视图：一次 reload 从任意线程信号到 render tick 唯一 reconcile、再到 candidate 校验与不可逆 commit 的完整生命周期，以及 shutdown 后 reinitialize 的特殊收敛路径。

> 素材基线：源码实时状态（2026-08-13）

## reload reconcile 生命周期

```mermaid
sequenceDiagram
    participant ANY as 任意线程
    participant FS as FontService
    participant SIG as FontReloadSignal
    participant CW as "candidate worker AsyncFontGenerationCandidateScheduler"

    ANY->>FS: reload()
    FS->>SIG: 发布（quiet 150ms）
    Note over SIG: latest-wins，合并计数
    Note over FS: 仅 RenderTick.END 处理，Splash 活跃只延后不丢
    FS->>FS: tickMainThread（唯一 reconcile owner）
    Note over FS: single-flight ticket
    FS->>FS: capture FontGenerationBuildRequest
    Note over FS: 不执行目录 I/O
    FS->>CW: 提交（单 worker，单排队槽）
    Note over CW: 旧 signal 取消并丢弃旧 flight
    CW-->>FS: candidate 完成
    loop 每 render tick 轮询校验
        FS->>FS: desired sequence + active base version epoch + settings identity + fingerprint
    end
    alt settings 与指纹未变化
        FS->>FS: 只确认 ticket
        Note over FS: 不推进 generation epoch，不重建 worker atlas
    else 发生变化
        FS->>FS: commitReloadLocked
        Note over FS: pause + reset dispatcher
        Note over FS: admitCommit 线性化，在不可逆 publication 前
        FS->>FS: 发布新 ActiveFontGeneration
        FS->>FS: 旧代 retire
        FS->>FS: dispatcher 恢复
        FS->>FS: finishCommittedReload
        FS->>FS: 布局失效 best-effort
    end
    Note over FS: 失败 250ms 起 5s 封顶指数 backoff，不确认 ticket
```

## reinitialize 特殊路径

```mermaid
sequenceDiagram
    participant I as "initialize 调用线程"
    participant FS as FontService
    participant OE as "旧 candidate executor（shutdown 后未终止）"
    participant RT as render tick

    I->>FS: reinitialize()
    Note over I: 调用线程不做同步 prepare publish
    FS->>FS: 用旧 active 恢复服务
    FS->>FS: 发布 fresh 复核 signal
    Note over OE: 旧 executor 继续运转直至 quiescent
    RT->>FS: reconcile 收敛
```

## 图注

- 失败退避从 250ms 开始、5s 封顶的指数 backoff，且失败不确认 ticket，避免静默丢换代。
- 换代 defer 条件：frame lease 未归零、旧 batch 未 flush、retiring atlas page ownership 未释放。
- atlas ownership 硬上限为 active + retiring；retiring ownership 不阻塞 fingerprint no-op ticket 确认。
- commit 前的校验（desired sequence、active base version/epoch、settings identity、fingerprint）全部未变化时，只确认 ticket，不做任何 generation/epoch 推进，也不重建 worker 或 atlas。
