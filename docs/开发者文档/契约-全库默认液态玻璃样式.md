# 全库默认液态玻璃样式：G00 冻结契约与覆盖清单

> 状态：G00 定案已落盘，实施从 G01 开始。本文是配套[实施规划](规划-全库默认液态玻璃样式.md)与[任务单](任务单-全库默认液态玻璃样式.md)的**冻结接口文档**，叶子实例只消费本文签名，不得自行改名或新建占位 API。
> 定案基线：分支 `4.0`，提交 `4549c8dc`（规划文档提交）。执行前读实时 Git；不得重置到本基线。
> 本文只冻结契约与清单，不代表功能已交付；实现状态见任务单台账。

## 1. 实测接缝事实（定案的依据）

| 事实 | 证据 |
| --- | --- |
| `Owner` 只有 `current/createChild/createEffect/run/onCleanup/dispose/isDisposed`，无上下文槽、`parent` 无 getter | `ui/reactive/Owner.java:19-146` |
| `ReactiveContext` 是包内 final 类，仅两个 ThreadLocal（当前 Effect、当前 Owner） | `ui/reactive/ReactiveContext.java:10-30` |
| `Effect.run()` 只切换当前 Effect，不切换当前 Owner | `ui/reactive/Effect.java:71-81` |
| `mount` 同步在 `childOwner.run(...)` 内执行 builder | `runtime/SceneRuntime.java:161-190` |
| `show` 的内容 builder 在 `condOwner.createChild()` 的 `owner.run(...)` 内执行 | `runtime/SceneConditionalRenderer.java:120-136` |
| `forEach` 的项 builder 在 `listOwner.createChild()` 的 `itemOwner.run(...)` 内执行 | `runtime/SceneKeyedListReconciler.java:183-192` |
| `portal` 的内容 builder 在 `portalOwner.createChild()` 的 `owner.run(...)` 内执行 | `runtime/SceneRuntime.java:1076-1091` |
| 因此**四条延迟构建路径的 builder 执行期 `Owner.current()` 均非 null**，且各自挂到来源作用域的 child | 上述四处 `owner.run(...)` |
| `SceneLiquidGlassStyle.bindButton` 已是「无当前 Owner 时 `rt.__runRoot(...)` 重入」的既有先例 | `control/SceneLiquidGlassStyle.java:54-57` |
| 主题现状只有静态 token + 显式形参：无 ThemeContext、无继承、无局部覆盖 | `SceneChromeTokens`、`SceneStateColors`、`SceneGlassButtonStyle`、`FormTheme`、`ConfigTheme` |
| 浮层 root 不挂主树，节点祖先链在浮层处断开 | `overlay/SceneOverlayHost.java:101-105` |

**结论**：主题传播只需给 `Owner` 加一个可继承的上下文槽 + 沿父链解析；`mount/show/forEach/portal` **无需**改动构建点。不再需要 ThreadLocal 包装、不再需要 handle 携带主题字段、不再需要 CSS 级联引擎。

## 2. 冻结类型与签名

新包：`club.heiqi.uilib.ui.scene.theme`（下称 `theme` 包）。`theme` 包只依赖 `ui.reactive`、`ui.render`、`ui.scene.node`、`ui.scene.input`、`ui.scene.runtime`；**不得** import `ui.scene.control`、`ui.scene.form`、`internal.*`、`club.heiqi.config.*`、Minecraft/LWJGL。

### 2.1 `Owner` 作用域槽（G01 负责，reactive 层唯一改动）

```java
// club.heiqi.uilib.ui.reactive.Owner
/** 在本作用域写入上下文值（键为标记对象，建议用专用常量）；value 为 null 时移除该键。 */
public void setScope(Object key, Object value)

/** 沿本作用域到根向上查找首个非 null 值；本作用域已 dispose 或键不存在时返回 null。 */
public Object findScope(Object key)

/** findScope 的类型化便捷入口；值类型不匹配时返回 null。 */
public <T> T findScope(Object key, Class<T> type)
```

- 键相等按 `equals`；值不做拷贝。
- 子作用域继承 = 沿 `parent` 链查找，不需要显式拷贝。
- `dispose()` 后本作用域及其子树的值不可见（实现可在 dispose 时清表，或让 `findScope` 对 disposed 直接返回 null）。
- 不新增第三个 ThreadLocal，不暴露 `parent` getter，不改变既有 7 个方法的语义。

### 2.4 作用域解析（G01 定义）

```java
// club.heiqi.uilib.ui.scene.theme.SceneThemes
public static final SceneTheme DEFAULT = SceneTheme.liquidGlassDark();

/** 把主题安装为 runtime 级默认（写到 rootOwner 作用域）；同一 runtime 可重复安装，后者覆盖。 */
public static void install(SceneRuntime rt, ReadableSignal<SceneTheme> theme)

/** 解析当前外观来源：Owner 链局部主题 > runtime 默认 > 库默认。返回值恒非 null。 */
public static ReadableSignal<SceneTheme> resolve(SceneRuntime rt)

/** 在当前 Owner 下建子作用域并写入局部主题，body 内构建的控件继承它。 */
public static void withTheme(ReadableSignal<SceneTheme> theme, Runnable body)

/** 便捷派生：当前来源主题下的某角色配方信号。 */
public static ReadableSignal<SceneSurfaceStyle> surface(SceneRuntime rt, SceneTheme.Role role)
```

- `resolve` 的实现只读 `Owner.current().findScope(...)`，**不得**在构造期解引用未求值的 Computed。
- 局部作用域通过 `withTheme` 建立；`withTheme` 在 `Owner.current() == null` 时直接执行 body（退化为 runtime 默认），不抛异常。
- 库默认用只读常量信号（`get()` 恒返回 `DEFAULT`），**不得**返回可写 `Signal`，避免跨 runtime 串色。
- 不新增 `SceneRuntime` 字段：runtime 默认主题落在 `rootOwner` 的 scope 槽，独立 runtime 天然隔离。

### 2.9 选中配方接缝（G05 定案）

```java
// club.heiqi.uilib.ui.scene.theme.SceneThemes
/** 选中/未选中切换的角色配方：未选中用 role 配方，选中态用主题强调色替换 tint。 */
public static ReadableSignal<SceneSurfaceStyle> selectableSurface(
        SceneRuntime rt, SceneTheme.Role role, ReadableSignal<Boolean> selected)
```

- 选中态只替换 tint 的 RGB 通道（保留原 alpha），edge/elevation/lens/圆角保持 role 配方；disabled 仍走 role 的禁用档。
- Toggle 轨道、Checkbox 勾选框、Radio 指示、Segmented/Tab/NavList/VirtualGrid 选中项统一消费它；**选中不能只靠透明度区分**。
- thumb/勾选/单选标记的强调色取 `SceneThemes.accent(rt)`，文字取 `foreground(rt)`/`onAccentForeground(rt)`；不得新建色板。

## 3. 优先级与 null 语义（唯一权威）

```text
显式控件配方 > 显式局部/页面主题 > runtime 默认主题 > UILib 默认液态玻璃主题
```

| 表达式 | 含义 |
| --- | --- |
| 控件未传样式参数 | 跟随主题（`SceneThemes.surface(rt, role)`） |
| 控件传 `ReadableSignal<SceneSurfaceStyle>` | 显式配方，完全覆盖主题（含该信号为 null 值的分支由调用方保证非 null） |
| `SceneSurfaceStyle.backdrop == null` | 显式关闭滤镜，tint 必须可读 |
| `SceneTheme.withoutBackdrop()` | 全库无滤镜替代档 |
| `SceneThemes.withTheme(sig, body)` | body 内构建的控件把 sig 作为来源主题（可再嵌套覆盖） |
| `SceneThemes.install(rt, sig)` | runtime 默认主题 |

| FormPageShell | `PANEL`（root/viewport） | 主题语义色 | 标题/状态区协调 |
| FormFieldShell | `GROUP` | `foreground`/`errorText`/`dirtyColor` | 无边框模板保持无边框 |
| FormActionBar | `TOOLBAR` | `foreground` | 内部按钮走 Button 角色 |
| ConfigScreen / ConfigTheme | `PANEL`/`GROUP`/`TOOLBAR` | 主题语义色 | 配置包只消费，不反向成为主题中心 |
| Playground 外壳与页面 | `PANEL`/`TOOLBAR`/`GROUP` | 主题语义色 | 诊断样本保留显式材质 |
| GlassLab 外壳 | `PANEL`/`TOOLBAR` | 主题语义色 | 样本区保留 classic/liquid/关闭滤镜对照 |
| 聊天面板/气泡/输入 | 保持既有聊天玻璃设置（局部配方） | 既有设置 | 通用主题不 import chat3 |
| HUD 工具栏 | 保持 `HudToolbarSpec` 显式配方与缩放语义 | 既有 | 主题不改倍率/布局预算 |

**导航族选项的滤镜口径（G09 裁决）**：Segmented / Tab / NavList 的每个选项消费
`selectableSurface(INDICATOR, selected)`，**保留配方自带的轻滤镜**，与 G05 选中族（RadioGroup circle、
Checkbox box、Toggle track）一致。「不给每个子项重复安装滤镜」的语义是「不得在配方之外再叠第二层玻璃、
也不得让内容区各自采样背景」，不是「把选项配方的 backdrop 置空」。

**Breadcrumb 例外（G09 裁决）**：面包屑无选中态、是纯文字路径，**不装表面与滤镜**（段默认透明，
hover/pressed/focus 只取 INDICATOR 配方的 tint 档做极淡覆盖）；路径文字取 `foreground` 而非 `accent`
——accent 在深色宿主底上仅 1.54:1，正文色 11.12:1（WCAG 实算）。

## 10. 实现落地记录（G01–G03）

以下为本契约在实施中的具体落地形态，叶子任务按此消费；与本文前述条目的差异只在此处列举。

| 条目 | 落地形态 | 原因 |
| --- | --- | --- |
| runtime 默认主题 | `SceneThemes.install(rt, signal)` 写入 `rootOwner` 作用域槽，**SceneRuntime 零改动** | 与既有 `__runRoot` 语义一致；独立 runtime 天然隔离 |
| `resolve` 无 Owner 时 | 经 `rt.__runRoot(...)` 读该 runtime 根作用域，找不到才回落库默认 | 避免 effect 体内误取别的 runtime 默认值 |
| `surface(rt, role)` 初值 | 构造期捕获主题信号 + `Effect.untrack` 读初值，派生期只读该信号 | 守「构造期不读未求值 Computed」与「不污染外层 effect 依赖」 |
| 按钮前景 | `SceneTheme` 构造时给 BUTTON_* 角色填充默认前景（标准=正文色、强调/危险=强调底前景），配方显式值优先 | 让 `SceneButton` 只用一条 `bindForeground`，不必再持主题信号 |
| 禁用反馈 | 文字色不重染；禁用由 motionRoot 的 `disabledOpacity` 表达 | textColor 只有一个写入者（bindForeground） |
| 表面绑定 | `SceneSurfaceBinder` 为唯一通用实现；`SceneLiquidGlassStyle.bindButton/bindForeground` 适配 `SceneGlassButtonStyle` 后委托它 | 全库只有一套动画/滤镜轨道；按钮旧入口与语义不变 |
| 默认配方带实体高度 | 按钮/面板等角色 `idle.elevation=0.5`，走 `SceneSurfaceReliefPainter` 浮雕路径：**不再单独发 BORDER 命令**，边框由方向性 ROUNDED_BAND 表达，BACKGROUND 四角半径按厚度内缩 1px | 既有「实体厚度」绘制路径；测试需按浮雕语义断言 |
| `SceneButton.Props` | 新增第 5 分量 `ReadableSignal<SceneSurfaceStyle> surface`（null=跟随主题）；旧 3 参/4 参构造器保留 | 显式配方优先于主题，旧调用零改动 |
