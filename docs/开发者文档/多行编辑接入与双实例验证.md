# 多行编辑接入与双实例验证

行为以[编辑规格](../superpowers/specs/2026-10-07-uilib-editing-spec.md)、[核心规格](../superpowers/specs/2026-10-07-uilib-core-contract-design.md)和[页面宿主规格](../superpowers/specs/2026-10-07-uilib-page-host-spec.md)为准。本文说明正式多行切片的接入及本轮人工验收。已有单行接入见[单行指南](单行编辑接入与双实例验证.md)。

## 接入

在业务所属 ReactiveDomain 内构造 `new SceneEditState(domain, initial, SceneEditState.Mode.MULTI_LINE)`；页面用 `SceneTextArea.create(ctx, state, theme, readOnly, onSubmit)` 声明。明确文本区域的视口高度，例如 `.size(Size.fill(1), Size.fixed(160))`，外层继续按普通 scene 布局组合。单行字段与多行区域各接匹配模式；不在控件间临时改变同一状态的模式。

多行将 CRLF 和 CR 归一为 LF，保留末尾空行。软换行取决于实际宽度与生产字体排版，不写回草稿。独立状态持有文本、选区、草稿会话、历史与提交结果；页面关闭只释放呈现和输入绑定。业务仍通过 Submission 的 accept/reject 校验当前请求，不能将迟到结果覆盖新草稿。

Enter（包括小键盘 Enter）换行；Ctrl+Enter 请求完成提交。Home/End 到视觉行首尾，Ctrl+Home/End 到全文首尾；Shift 扩展选区，上下移动连续保留水平目标。默认 Tab/Shift+Tab 导航，不插入制表符。可编辑焦点由既有唯一 router 决定，原生输入与单行共用正式宿主。内部滚轮通过同一命中与裁剪机制改变正文视口；稳定帧不强行滚回光标。

普通 1.7.10 可接收已确认中文，当前没有真实 preedit 事实；GTNH 使用官方 SDL 观察桥。两者的输入法证据须分开记录，不能用粘贴通过代替真实中文输入。

## 双实例真机测试清单

分别启动普通 **1.7.10** 与 **GT_New_Horizons_2.9.0-beta-3_uilib测试**，进入世界执行 `/qzcore`，向下滚动到“多行正文”。使用本轮部署的生产包与人工测试包。结果按实例分别记录。

| 项目 | 操作 | 通过表现 |
| --- | --- | --- |
| 基础换行 | 点击正文，Ctrl+A，输入两行文字；分别按主 Enter 与小键盘 Enter | 插入换行，业务接受值不变；一次按压只产生一次换行 |
| 提交和拒绝 | Ctrl+Enter 或“提交正文”；再输入包含“拒绝”的正文并提交 | 正常接受整串正文；拒绝时保留草稿、选区并显示原因 |
| 换行粘贴 | 粘贴带 CRLF/CR 的多行文字，末尾保留一个空行；在末行键入 | 正确分行，末尾空行可定位及编辑；整次粘贴一步撤销 |
| 文字边界与历史 | 输入 `中文🙂 é`，跨行拖选、复制、剪切；Ctrl+Z/Ctrl+Y；持续按 Backspace | 不拆 Emoji 代理或组合字符；跨行选区与复制包括换行；历史恢复文本和选区 |
| 视觉行导航 | 缩窄窗口造成软换行；上下移动、Home/End、Shift 扩选，再 Ctrl+Home/End | 按实际视觉行定位，上下连续保持水平目标；全文命令到首尾；软换行不改变草稿 |
| 滚动与裁剪 | “恢复样例”，滚轮查看正文；停留几帧；点击已滚动文字再编辑 | 视口不在稳定帧跳回光标；命中与显示一致；编辑时显露当前位置；文字及选区不画出正文 |
| 动态重排 | 保留跨行选区，改变窗口、字号、主题 | 重排与光标、选区协调；草稿和逻辑选区保留；小窗口可通过外页滚动到控件 |
| 只读和禁用 | “正文只读”后选择、复制、滚动、Tab，再尝试编辑与提交；随后禁用 | 只读仍可查看选择复制，不能修改或提交；禁用取消交互；恢复后无旧输入重放 |
| 导航与页面生命周期 | Tab/Shift+Tab 离开，保留未提交草稿，ESC 关闭后重开；切出窗口再回来 | Tab 不插字符、不默认提交；重开保留业务持有草稿；旧持键和鼠标尾部不输入 |
| 迟到请求与外部值 | 暂存正文请求，继续编辑，再完成旧请求；活跃草稿时点击“外部正文” | 新草稿、光标和选区不被旧结果或外部值覆盖；空闲状态可正常跟随外部值 |
| 真实中文输入 | 用输入法输入中文；GTNH 观察拼音候选，候选 Enter 后再按 Enter，最后 Ctrl+Enter | 已确认中文可输入；GTNH 候选确认不同时换行或提交，下一次 Enter 才换行；整次候选提交可一步撤销 |
| 单行防回归 | 上方整数字段输入负号、中文、连续空格、重复删除；主/小键盘 Enter | 原单行确认、拒绝、持键和输入法行为保持 |
| 原版替代字体大小 | 查看聊天、菜单、按钮、物品说明等原版文字，切换 GUI Scale；比较中英文与格式颜色、阴影、换行 | 默认字体比前版略小；行距和基线协调，测宽与绘制一致，无切字、重叠或错位；UILib 明确字号不随之缩小 |
