# Minecraft 多版本宿主接入

状态：本次多实例安装与实机验收的已授权范围。

## 目标与运行组合

用户在 Prism Launcher 中打开实例后，能打开同一测试广场，运行邮箱、正式配置、拖放排序、滚动与媒体案例。测试内容继续由无平台核心及共享广场定义；Minecraft 只提供窗口、原生输入、资源和运行生命周期。

本次目标为现有实例：Forge 1.7.10 / 10.13.4.1614 / Java8 / LWJGL2；GTNH 2.9.0-beta-3 / 1.7.10 / LWJGL3ify 与 Angelica；Forge 1.12.2 / 14.23.5.2864 / Java8 / LWJGL2；Forge 1.16.5 / 36.2.42 / Java8 / LWJGL3；NeoForge 26.3 / 26.3.0.86 / Java25 / SDL。版本与加载器保留现状。既有原版字体替代能力的范围保持原合同；新接入以 UILib 页面为目标。

## 归属与主流程

核心继续只提供状态、场景、布局、输入路由与绘制计划。共享 GL、CPU 字体、图像、媒体以及配置合同沿现有能力使用；新增的嵌入式页面服务负责组合这些现有能力，不重新实现它们。

各版本宿主负责加载器入口、页面打开关闭、资源变更通知、framebuffer 尺寸与原生事件转换。绘制和命中统一使用 framebuffer 像素，Minecraft GUI Scale 不改变 UILib 字号与几何。唯一原生事件消费者按采集顺序递交正式 ScenePageSession；开屏持键、失焦、ESC、组字与释放沿[页面宿主规格](<2026-10-07-uilib-page-host-spec.md>)。不通过全局替换游戏输入回调接管其他页面。

新版提取式渲染宿主在真实 GPU 提交阶段消费不可变 PaintPlan，提取阶段不执行 GL。页面结束后不得回放旧页计划；资源结束遵循其所有权。宿主提交必须保持有效的目标 framebuffer 与宿主 GL 状态；宿主虚拟化状态仍从实际有效状态取得。

测试广场保留独立附加产物，版本宿主消费同一份共享声明及资源。人工附加包仅登记显式客户端命令 `/qzcore`，不向游戏主菜单注入测试入口或兼容其他模组的菜单实现。生产入口可打开任意 ScenePage；普通页面不手动装配帧管线。正式发布策略与坐标不在本次任务中调整。

## 装配与验收

旧版主构建保留现有工具链；其他加载器通过独立构建入口处理自己的映射与元数据，消费根项目输出。相同 Java 目标内复用同一核心、共享 GL 与字体输出，版本源码只含各自宿主职责。Java8 与 Java21+ 输出分别装配，不复制核心实现。

逐实例验证真实发行安装组合：启动成功、从正式入口打开广场目录、浏览案例、运行一次关键交互、调整窗口或缩放后画面与命中对齐、关闭并重开无旧输入或资源残留。媒体使用随附示例验证解码与可见播放。安装与运行记录绑定实际源码和产物版本；独立桌面或编译成功不替代游戏实机。

安装变更限于 UILib 和被实际兼容故障阻塞的调用方接入产物，各自原产物保存在实例备份目录。现有世界与业务用法沿用；必要调用方适配保留相同业务请求、字段含义和使用条件。兼容故障在所属接入边界定位，不能以删除既有功能或改变核心合同通过验收。
