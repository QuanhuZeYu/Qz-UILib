# Minecraft Scene HUD

本能力先接入 Forge 1.7.10；其他版本原有页面能力保持。业务提供 ScenePage、状态、显隐和位置；宿主在游戏 HUD 阶段使用同一 ScenePageSession、MinecraftSceneHost 与 PaintPlan，正常游戏中不读取或消费鼠标/键盘事件，不影响准星、快捷栏及其他 Mod。

HUD 内容按真实尺寸排版，锚点与逻辑偏移表达位置，GUI Scale、视口、字体和主题变化后更新并约束到可用空间。放置通过正式 SceneControl 排列和共同几何表达，不平移旧绘制计划或维护另一套命中。

显式编辑页复用 MinecraftSceneScreen 和正式 SceneDraggable，提供拖动、吸附、缩放及恢复默认；正常释放只更新业务草稿，ESC/失焦取消拖动不提交。业务决定保存，通用宿主不写业务配置。普通 HUD 无输入资格，编辑时只使用编辑页当前范围。

GPU 资源只在渲染主线程建立和释放；隐藏、菜单、F1 与无世界时停止呈现推进，世界替换和断线清理旧页面资源，重新进入可重建，不关闭共享字体/图像服务。关闭幂等，登记的外部监听对称解除。

无窗口场景验证正式会话、显示资格、位置约束、输入隔离和生命周期；真实 GL 状态、缩放与 Mod 共存保持实机未验证直到取得游戏证据。
