# MC 宿主渲染优化规格

共同合同见[核心规格](<../../../Qz-UILib-Core/specs/2026-10-07-uilib-core-contract-design.md>)与[字体规格](<../../../Qz-UILib-Core/specs/content/2026-10-07-uilib-font-renderer-spec.md>)；本规格只定义 MC 接入边界。

## 1. 目标与范围

scene 与原版 FontRenderer 替代入口复用不可变 PaintPlan、字体服务、资源和共享 backend；原版调用不创建 scene 节点或运行时。Core 持有中性载荷与合批逻辑，Platform 持有 GPU 呈现与绑定，Minecraft 只装配宿主范围和兼容事实，跨仓消费明确 Maven 产物。优化不扩展到任意世界、实体或第三方渲染器。

## 2. 合批合同

默认保序与显式 `render.aggressiveBatching` 统一遵循[字体规格 §5.2](<../../../Qz-UILib-Core/specs/content/2026-10-07-uilib-font-renderer-spec.md#52-按需增量与效率>)。配置沿共享设置页与宿主发布，不另建页面状态；颜色、位置和 UV 可由顶点承载，材质、资源、裁剪、混合/深度、目标及变换必须兼容。默认不能越过遮挡矩形或打散阴影、正文、装饰的实际次序。

## 3. 提交范围与宿主状态

一次 replay 是封闭范围：保存实际触碰的进入态，建立已知状态，结束或异常时恢复；外部委托前 flush，返回后重建状态。staging 与 GPU 缓冲有界复用，满容量分段；不逐图元查询并恢复全部 GL 状态。

普通 FontRenderer 调用在返回前提交已就绪文字。已知延期宿主按其正式屏障和 pass 回放，不能用 Java 调用顺序猜 GPU 顺序；跨调用合并仅限框架 replay 或明确接入的宿主范围，不为未知 Mod 建全帧缓冲。管线、pack、pass、frame 与资源租约变化必须结束前批，业务无需手动 flush。

scene 使用 framebuffer 像素；原版入口保留 caller 的 GUI/世界变换与 GUI Scale。字形未就绪保留定位并暂留空白，回放不重新排版或等待后台任务。已引用资源固定到回放结束，不能因淘汰、重排或换代使旧 UV 指向其他字形。资源完成沿 prepare 发布，GPU 创建和释放均在所属上下文线程。

## 4. 原版入口与宿主兼容

替代开关及标准度量/绘制语义沿字体规格第 4 节。关闭沿原入口；运行错误不触发隐式原版恢复，UILib 页面始终用自有引擎。共享 backend 恢复进入态，原版适配器另负责标准入口的 alpha-test、末字形颜色及必要纹理尾状态。

纯 Forge 1.7.10、Java8/LWJGL2 的默认接管须成立；不以补装 LWJGL3ify/Angelica、更换 Java 或删减文字能力完成验收。UniMixins 安装及实例操作按用户授权。可选 LWJGL3ify/Angelica 缺席时不影响原路径，存在时验证其实际提交顺序与状态合同。

## 5. 无平台验证

复用[统一测试应用](<../../../Qz-UILib-Core/specs/verification/2026-10-07-uilib-testing-spec.md>)、正式字体和生产 backend。软件参考核顺序与几何，真实 GL 核像素、透明、裁剪、状态恢复及资源换代；mock 不作为 GPU 证据。MC 另核标准接口返回、GUI Scale、GUI/HUD、告示牌、名签、混排委托及延期宿主，不外推独立环境结果。

## 6. 验收与性能证据

覆盖透明重叠、阴影、嵌套裁剪、宿主屏障、图集换页、容量、冷/热缓存、滚动、字体换代及替代开关。默认保序和显式激进模式分别使用符合其顺序的独立像素参考。

相同输入分别比较原版、自有逐图元与自有合批；后两者共用字体、几何和缓存，逐图元仅作基准。记录 CPU/GPU 耗时、整体慢帧、draw/状态切换、上传和内存，门槛沿字体规格 §2.7；不以 draw 减少推断更快。先做无平台验证，再按授权短测指定 MC 实例。

## 7. 资源与缓冲

普通二维图集按相邻状态合批；纹理数组在兼容页之间用 layer 保序。两者都分离单色与彩色格式，按实际 GL 能力和预算分配有界页组，不预分配最大容量；数组路线须与二维基线取得真实性能、像素和内存对照。

图元连续写入有界 staging，每段一次顶点上传；EBO 随容量建立并复用。页组、采样或状态变化才拆批，同数组换层无需拆批。驱动等待与顶点打包以实测判断；映射、环形缓冲、实例化等机制只在实际热点需要时另议。
