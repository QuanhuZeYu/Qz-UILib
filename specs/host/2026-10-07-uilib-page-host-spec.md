# UILib 页面接入与宿主生命周期规格

状态：已确认模块规格。

共同状态、布局、生命周期、输入与平台边界遵循[核心职责规格](<../2026-10-07-uilib-core-contract-design.md>)；按职责选择规格见[规格入口](<../README.md>)。

## 1. 声明式页面接入与运行生命周期

页面作者通过正式入口提供内容树、状态绑定和业务策略；框架装配运行环境，统一协调输入、呈现与释放。普通页面无需自行创建 SceneRuntime、SceneFramePipeline、原生输入适配器或渲染资源，也无需手写逐帧驱动、失焦恢复和清理顺序。入口属于正式发行能力，不依赖 internal/devtools 或人工验收包。

初始树组合、响应式绑定及事件意图均是声明式表达。普通状态变化沿[核心规格第 3 节](<../2026-10-07-uilib-core-contract-design.md>)更新，不重建运行环境；handler 的写入边界和受控交互命令沿[核心规格第 2 节](<../2026-10-07-uilib-core-contract-design.md>)。公共签名与继承/组合方式由设计选择，复用现有声明树；接入不依赖标准控件全部齐备。

| 主体 | 职责 |
| --- | --- |
| 页面作者 | 内容、布局、业务状态与绑定、事件意图、初始/恢复焦点、模态显隐与关闭策略；游戏是否暂停等应用选择 |
| 页面运行环境 | 提供合法构造与事件上下文，组织挂载，协调既有布局/绘制/输入，管理本次接入的订阅与资源 |
| 平台宿主适配 | 窗口/framebuffer、资源和原生输入事实，坐标/事件转换、GPU 提交及可用性观察 |
| 自动化测试宿主 | 提供软件或真实GPU环境、窗口/资源事实及注入输入；复用同一正式运行环境，不自行装配第二套页面管线 |
| Minecraft 接入 | 对接 GuiScreen 打开、输入、绘制、重初始化和关闭，驱动运行环境并执行合法宿主 fallback |

自动化与游戏共用正式页面定义及生产运行环境，装配、挂载、更新、事件结算与结束沿同一能力；生产运行环境不依赖测试基类。测试职责与各宿主证据边界见[测试应用规格](<../verification/2026-10-07-uilib-testing-spec.md>)。

页面创建的派生、Effect 和资源可归属页面作用域，由框架释放；页面可声明自身释放动作。外部业务状态、编辑状态、任务和共享服务保持独立归属，关闭不隐含提交、清除草稿或取消任务，也不终止其他页面使用的共享资源。状态域、只读/写入及线程边界沿现有合同。

打开时，接入在合法上下文构造并挂载内容，建立环境与输入联系；状态、窗口和资源变化按依赖更新呈现，页面不调用 flush/layout/paint/replay。同一打开页面的 initGui 等尺寸重初始化不重复创建绑定或运行环境，不重置合法焦点、滚动或独立编辑状态。

原生输入由唯一消费者递交同一核心事件序列，复用范围、焦点、挂载身份和手势 owner。窗口失焦也沿同一采集顺序取消手势并清理键盘焦点，不立即清焦点越过待结算输入；普通手势取消不因此隐含清理键盘焦点。失焦取消、历史耗尽与物理释放确认由宿主统一协调；页面不另行轮询或凭物理快照提前放行。ESC 按[核心规格第 6.1 节](<../2026-10-07-uilib-core-contract-design.md>)处理，未消费结果在对应状态与 Effect 成功结算后才执行 fallback，保持后续输入顺序，迟到结果不能影响另一页。

结束时停止本次业务输入，丢弃待处理业务意图并取消手势，解除挂载联系，按依赖顺序释放所属资源；不补跑帧或回放输入。再打开建立新的宿主输入联系，独立业务状态能否复用由调用方决定，节点身份与重挂载沿[核心规格第 5 节](<../2026-10-07-uilib-core-contract-design.md>)。

构造、挂载或宿主资源创建失败时清理已取得的本次所属资源，不留下可交互的半初始化页面。结束或清理中一项释放失败仍尝试其余释放，保留原始失败及附加清理错误；重复结束不重复释放。handler、Effect、布局与 replay 失败沿既有通道暴露，不吞异常或当作未消费 ESC 执行 fallback；保留既有手势取消/物理尾部语义。迟到输入、呈现与关闭结果不得访问已释放接入。

页面上下文提供可追踪的宿主根可用宽高，初次声明即可读取，后续窗口变化在处理输入和结算声明之前发布。它们是宿主环境事实，不是子控件的最终布局盒；业务可据此声明响应策略，不读回几何补偿普通排版。相同空间不重复发布变化，关闭后不再更新。

| 验收场景 | 可观察结果 |
| --- | --- |
| 通过正式入口打开声明的列表、按钮与嵌套模态 | 页面无管线装配、原生输入和清理接线，列表/字号/焦点/ESC 正常工作 |
| 窗口变化与同页重初始化 | 自动重排，无重复订阅/事件，状态及合法交互连续 |
| 开屏持键、失焦恢复、重复 ESC、跨帧输入及旧关闭结果 | 无尾部误触或连续关闭多层，事件与 fallback 顺序正确，不影响后来页面 |
| 关闭后修改外部状态并再次打开 | 旧 UI 不接受更新/输入，外部状态有效，新接入使用当前值，无旧回调叠加 |
| 初始化或清理失败、重复结束 | 原始错误可定位，所属资源完成清理尝试，外部资源不被释放，无残留输入联系 |
| handler/Effect 失败 | 既有错误和手势尾部处理成立，不误执行关闭 fallback |
| 同一内容声明接入无平台验收及 LWJGL2/LWJGL3、MC 宿主 | 内容不依赖平台类型，适配差异不改变布局与输入权威 |

人工验收入口使用正式页面能力，保留具体验收操作并展示声明式使用；底层反例复用自动化入口。焦点调试不决定标准控件策略，按钮、主题、导航与编辑/IME 合同由所属规格维护。
