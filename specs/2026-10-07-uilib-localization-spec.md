# UILib 独立语言资源与翻译文案规格

状态：已确认模块规格。共同状态、生命周期与平台边界遵循[核心规格](<2026-10-07-uilib-core-contract-design.md>)。

## 1. 目标与职责

页面作者声明翻译键和参数，UILib 从业务显式提供的独立语言资源流派生文案。语言选择或资料重载后，同一挂载页面的标准控件和自然布局自动更新，无需重开页面或手动布局。字面字符串保持字面内容。

UILib 拥有语言资源加载、显式语言选择、资料组合、不可变快照、变化通知与纯文案派生，不接入、合并、兼容或回退到 Minecraft/Forge 的语言表、资源包语言优先级及语言资料加载机制。应用接入层可读取 MC 的语言设置作为语言选择偏好，显式传给独立流，以统一使用体验；偏好输入不携带宿主译文，不把核心绑定到 MC，也不赋予 MC 资源加载语义。Item 等宿主内容若需要翻译，由业务自己处理并作为普通文案交给页面；UILib 不提供宿主翻译适配。

## 2. 独立资源流

业务显式声明资源集合、初始语言标识和 Java 格式 locale，资源流不扫描模组或全局路径，不自行读取宿主语言或系统默认语言。初始标识可由应用接入层从用户的宿主语言偏好取得；持续跟随时由应用显式把语言偏好变化递交 select，UILib 不因此接管宿主设置或宿主翻译。仅支持部分语言的应用显式决定偏好到自身语言集合的映射，框架不推断替代语言。流可以共享给多个业务域/页面，语言选择和重载是流自身的公开操作，直接调用后已生效资料可读，不依赖游戏 tick 或 UI 帧。

正式加载格式采用 UTF-8 Java properties（按 Reader 读取）：键值、注释、续行及反斜杠转义遵循 Java8 Properties 语义，不要求 Unicode 文案写成转义。同一文件重复键后者覆盖；显式资源集合按声明顺序加载，后声明资源覆盖前者同名键。仅加载指定语言，不隐式补其他语言。资源读取入口提供 classpath 指定根及独立文件目录，均按语言标识定位 .properties；语言标识是非空单一路径段，拒绝路径分隔符与 .、..。classpath 路径从 UILib/业务自己的包内资源读取，不调用 MC ResourceManager。业务可通过公开输入流合同提供其他独立来源，其协议归业务。

选择语言必须完整读完该语言的全部声明资源后，一次发布对应语言与翻译表。重载重新读取当前语言，即使语言标识不变也发布新资料。流不注册平台监听、不轮询文件或逐文案轮询；资料提供者修改完成后显式调用 reload。格式 locale 固定为业务声明的值，不在求值中读取全局变化中的 locale。

缺少声明资源、IO 失败和非法 properties 转义是调用失败，暴露定位信息和原始原因；不得把失败当缺键、发布半表、新语言码搭配旧表、隐式恢复/重试或选择替代语言。未完成的加载尚未生效，已生效快照不因此回滚或重新发布；这不构成失败后恢复策略。成功加载后消费者失败仍保留新事实，不回滚。输入流无论成功失败均关闭。流关闭释放订阅并拒绝后续读取/选择/重载/订阅，绑定持有的不可变快照不被销毁。

## 3. 文案表达与格式

正式入口支持固定键及参数、响应式键及参数；返回普通可读信号。首次和写后读取得到当前文案，无需挂载/帧/flush，不执行业务 Effect。参数数组独立保存，不重译参数中的字面文本；嵌套译文由业务显式组合纯派生。语言标识和资料分别可观察，同语言重载依赖资料事实失效。

格式遵循 Java8 Formatter 的位置参数、数值及百分号语义，原样保留资源中的 %d/%f，不执行 MC 数值占位归一。缺键显示键名；非法格式或参数不匹配显示 Format error: 加当前模板，其他异常原样暴露。空/null 键及非法来源是调用错误。

## 4. 传播与生命周期

独立来源发布不可变资料，绑定经既有 ReactiveDomain 将其递交各状态域，用 Signal/Computed/Owner，不引入平行状态系统。选择/重载返回后来源 current 已生效；异步域按自身执行入口推进绑定，同域状态写入后读取保持即时，不增加跨域等待屏障。已排队旧资料不能在较新资料生效后覆盖它；同步通知错误由来源聚合，异步执行错误继续沿原状态域/executor 通道暴露。一次资料通知完成各独立订阅的递交，单个失败不使其余绑定永久留旧；通知中较新事实可替代尚未递交旧事实，各订阅不能先新后旧，重入发布返回后读取最新。通知后原样暴露首错误，其余作为 suppressed；不吞错/重试/恢复。

页面显式选择自己的 LocalizationSource，惰性建立唯一语言绑定；语言不属于 SceneHost 的环境能力，不从 MC 页面入口自动注入全局语言源。无语言页面不需要虚假初值，同页不能把已建立绑定偷偷换成另一来源。页面 Owner 关闭其绑定和派生，不关闭外部共享流；页面显式 own 的私有流随页面释放。控件卸载仅释放呈现关系，重挂载读当前文案；独立业务使用自身 Owner。关闭后迟到通知不访问节点或复活页面。

文案沿既有 NodeBinding、标准控件、文本排版与 PaintCommand 更新，几何遵循核心第 3.4 节。语言选择或重载不改变草稿、光标、选区或业务值。

## 5. 公开能力与验收

正式能力包含独立资源读取、流、选择、重载、快照、绑定、页面显式接入、可运行语言验收场景与源码接入示例。MC 语言服务、LanguageManager/Locale mixin 与语言 tick/reload/shutdown 接线不属于正式入口，不保留兼容桥。不提供全局语言配置、自动扫描、文件监控、网络下载或机器翻译。

| 场景 | 可观察结果 | 验证通道 |
| --- | --- | --- |
| 真实 classpath/独立目录资源 | UTF-8、转义、数值模板及声明覆盖顺序正确 | 无平台正式读取与流 |
| 指定语言及同语言重载 | 仅当前语言资料，重载后现有文案与几何更新 | 正式流、业务域和页面 |
| 失败与流关闭 | 无半表/隐式回退/复活，原因可见、输入释放 | 真实文件/输入流与生产生命周期 |
| 首次、键/参数写后纯读及格式错误 | 当前结果，无 Effect/帧依赖，错误可见 | 既有核心场景 |
| 重入、独立域、卸载重挂载及迟到 | 事实不倒退，独立绑定更新，关闭不复活 | 真实 Signal/Owner/Effect |
| 主题、窗口、自然固定区和滚动 | 控件身份保持，绘制与命中一致 | 正式页面管线 |
| 普通和 GTNH 实例 | UILib 自己切语言/重载，游戏语言与配置不变 | 用户真机验收 |

验收复用[统一测试应用](<2026-10-07-uilib-testing-spec.md>)，验证与授权遵循核心第 9 节。
