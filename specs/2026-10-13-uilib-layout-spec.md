# UILib 常规布局规格

状态：已确认模块规格。

状态、尺寸、同树几何、生命周期、输入与平台边界遵循[核心职责规格](<2026-10-07-uilib-core-contract-design.md>)；按职责选择规格见[规格入口](<README.md>)。

## 1. 职责与范围

页面作者声明节点、顺序、尺寸意图、排列关系、显隐及滚动策略，框架完成测量、最终分配与共同几何。横排和纵排沿已有轴向、间距与带权填充规则；响应网格组合相同节点与真实内容。自定义容器通过正式子测量与最终排列能力接入同一管线，文字投影只表达内容，不承担普通容器的准备阶段。

测量使用正文约束，最终排列使用含 padding 的分配外盒与相对原点；内边距只计算一次。普通排列遵守子项的 fixed/min/max，文本与数学嵌入的内容盒合同仍归内容模块。页面不读回结果补偿普通布局，容器不修改最终几何或另接绘制、输入管线。

本模块包括普通响应网格及非文字容器的正式消费；所属层从普通流抽出的空间合同归[所属层与输入范围规格](<2026-10-13-uilib-layer-input-spec.md>)。跨行列、轨道语言、绝对定位、通用变换动画与虚拟化另行规划，不引入新的逻辑树或平台适配。

有限呈现值可通过正式绑定表达当前尺寸意图，或作为控件依赖参与正式排列；时间与挂载合同归[主题与控件规格](<2026-10-07-uilib-theme-spec.md>)。每批结果仍遵守硬尺寸边界，当前实际外盒、裁剪及子项位置同时用于画面和输入。仅绘制位移不能替代共同几何，普通页面不读回布局作逐帧补偿；本能力不承诺局部几何求解或免除必要重排。

## 2. 响应网格声明

策略包含正的最小列宽、非负列间距和行间距，单位为 logical px。策略来源可追踪且可动态替换，不绑定窗口或主题的构造期快照。网格默认填充宽度、自然高度，不默认裁剪或滚动；页面可组合已有合法尺寸、裁剪与滚动声明。

### 2.1 列槽、顺序与尺寸

- 当前可见子项按逻辑顺序逐行排列；隐藏项不参与排列，隐藏与删除的身份和资源语义遵循动态结构规格。
- 根据当次正文可用宽度与最小列宽选择可容纳的最多列数，不超过参与项数量。空间不足仍有一列并保留最小列宽；空集合无列槽、内容行或额外间距。
- NATURAL 网格的宽度为选定列槽的最小宽度加列间距，测量与排列均以该自然槽宽测子项。FIXED/FILL 按实际正文宽度分配列槽，多出的 logical px 按列顺序分配；空间不足不压小最小列宽，未满最后一行不重新伸展槽宽。
- 子项在当次列槽下测量，沿已有 FIXED、NATURAL、FILL 与 min/max 合同。FILL 宽度使用列槽并受自身边界约束；FIXED/NATURAL 保持尺寸，不被强行压到列槽。
- 硬子项超过列槽时允许溢出，不重新选择列数，不缩字号或隐藏内容，也不扩大自然网格的列槽宽度。裁剪、可见性和滚动由已有声明决定。

### 2.2 行高与内容

每行由该行真实度量及硬边界决定高度，子项顶部对齐。行高未确定时，高度 FILL 按自然内容及硬下界测量，不把父可用高度分给每个子项；确定行高后，FILL 使用该行高度并受自身边界限制。网格的固定或填充高度多出的空间不自动分摊到行。

自然高度按子项最终合法宽度测量，不能沿用父满宽或先前宽约束下的换行高度。文字、文档、图像与输入控件继续进入核心唯一几何、裁剪和命中，绘制只消费发布结果。

### 2.3 独立示例

最小列宽 180、列间距 12、参与项 5：

| 正文宽度 | 列数 | 填充列宽 | 自然列槽总宽 |
| --- | --- | --- | --- |
| 600 | 3 | 192、192、192 | 564 |
| 400 | 2 | 194、194 | 372 |
| 160 | 1 | 180，沿已有溢出策略处理 | 180 |
| 601 | 3 | 193、192、192 | 564 |

空集合没有内容行和间距，节点 padding 与自身 Size.min 仍由核心处理。

## 3. 动态性与拥有权

内容、字体、语言、主题、策略及可用空间变化沿实际依赖自动重排或重绘。网格不拥有外部策略信号；派生策略归声明者已有 Owner 或页面作用域。滚动重排可复用有效内容度量，布局结果不经业务状态回写。

网格不建立另一套条目身份；子项拥有、保留、稳定键与明确移动继续遵循[动态结构规格](<uilib-dynamic-structure-spec.md>)。普通重排保留有效 UUID、合法焦点及草稿，关闭和销毁沿既有作用域释放。

## 4. 有限验收

| 场景 | 可观察结果 |
| --- | --- |
| 外部非文字容器的测量宽度与最终分配不同 | 当次重新测量真实子项，边框与 padding 正确，绘制和输入共享几何，无文字准备旁路 |
| 真实卡片组合文字、文档、图像与输入，正文宽度变化 | 依独立示例换列，真实自然高度和可见命中同步更新，页面不提供排列回调 |
| 空集合、隐藏项及未满最后一行 | 无空白行间距，隐藏不占槽，最后一行使用同一列宽 |
| 硬宽度溢出、自然网格、行高未定的 FILL | 硬边界保持，自然槽宽测量正确，父高不灌入行，子项仍按唯一几何处理 |
| 字号、文案、主题派生策略和稳定键重排 | 当前内容自动更新，合法焦点、草稿和 UUID 连续 |
| 隔离正式 core 制品调用公开工厂、frame 与输入 | 无 gallery 或平台依赖，实际布局与业务输入可消费，不仅检查类存在 |

反馈复用正式页面、事件、真实字体及 PaintCommand；真实字体测量、注入输入、软件回放和原生设备各按实际证据区分，不外推未执行的宿主。
