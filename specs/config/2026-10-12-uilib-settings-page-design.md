# UILib 配置页面规格

状态：已确认模块规格。

本页依据用户提供的 Shadcn Admin 参考与重做反馈实施。本文维护共享页面的视觉与交互合同；配置存取、字体及宿主生命周期各归所属规格。

## 1. 目的与职责

让用户通过 UILib 自身配置页管理完整字体候选顺序及当前宿主选项，明确区分编辑草稿、当前生效值与已持久化值。配置类型、校验、YAML 注释及迁移继续由[无平台配置规格](<2026-10-11-uilib-config-spec.md>)维护；草稿、焦点和提交沿[编辑规格](<../scene/2026-10-07-uilib-editing-spec.md>)及[核心第 6 节](<../2026-10-07-uilib-core-contract-design.md#6-输入范围宿主与焦点>)。

| 职责 | 归属 |
| --- | --- |
| 页面、分类导航、表单草稿、状态文案、操作意图 | 共享 ScenePage 声明与既有信号、编辑状态 |
| 类型绑定、校验、配置值发布和 YAML 读写 | 正式配置核心；页面不解析 YAML 节点 |
| 有序来源、真实字体匹配、度量、整形、资源换代与文字绘制 | 现有字体服务与同一 PaintPlan |
| 文件路径、字体文件读取、MC 专有选项及资源更新接入 | 所属宿主；共享页面不依赖 MC/Forge 类型 |

工作区编辑完整有序的 font.candidates、共享主题 ui.theme 与 MC 宿主的 mc.replaceVanillaFont。主题选择属于应用全局配置，按[主题规格](<../content/2026-10-07-uilib-theme-spec.md>)发布与持久化；样本文字仍为页面查看状态，不产生配置变化。通用自动配置编辑器及任意字段推断不纳入本页。字体拖动排序复用正式 SceneSortableList，页面只声明来源身份与草稿移动意图。

## 2. 视觉方向与布局

参照 [Shadcn Admin 设置页](https://shadcn-admin.netlify.app/settings)：统一设置页头、分类导航与有宽度上限的正文表单，靠留白、字重与细分隔线组织字段，不将每个分组装进卡片。仅参考视觉与交互组织；正式页面沿 UILib scene、响应式绑定与标准控件组织。

默认进入统一“外观”表单，字体来源、主题和实际生效文字预览在同一正文中，不保留独立旧字体页面。宽窗口左侧为固定工作区分类导航及产品/宿主信息，右侧顶部是主题快捷切换与返回入口；统一“设置”标题说明工作区范围，分类正文以较小标题和说明开头。当前配置阶段在底部全局操作区显示。正文独立滚动且完整避让操作区，首屏不能由候选长表及逐行工具主导。进入 MC 页面时保留完整设置表面。

视觉以中性灰、细分隔线与小圆角为基础；主按钮为高对比实色，当前导航及键盘焦点用同一克制强调色。红色用于字段错误，成功色只用于真实完成反馈。阴影只用于弹层及轻微层次，不用于每个卡片。图标为辅助，所有操作保留可读文案或完整提示。

正文采用无衬线字体、左对齐标签、简短说明与一致间距；页标题高于卡片标题，卡片标题高于字段标签，路径用等宽文字。卡片内以行和分隔线组织，避免把每个字段再次放入独立卡片。数值与尺寸是主题设计参数，由实际字体、宿主空间及缩放驱动，不以布局后的读回补宽度。

宽窗口采用固定左侧分类、右侧表单；表单限制阅读宽度，以字体来源摘要与管理动作、主题选择、可编辑的当前生效文字样本组织字段。标准桌面首屏可直接操作这些字段，无需先滚过来源长表。空间不足时分类收束为顶部选择入口，沿正式所属层显示分类项，选择或关闭后返回原触发点。字体行在窄空间内将动作换到名称下方；长路径保持编辑和查看能力，说明自然换行。操作、错误和关闭入口仍可到达。页面作者声明具名区域、分类、内容、状态来源与动作，组件封装响应适配与装饰，不依赖子槽索引或编写最终坐标。

## 3. 页面信息架构

### 3.1 字体与排版

字体是“外观”表单中的字段。默认正文显示有序来源摘要和数量，以“管理字体来源”打开该字段编辑窗口；不再用独立分类或默认长表表示字体设置。底部共同状态显示“已保存 / 有待应用修改 / 已应用，未保存”。

“管理字体来源”窗口按实际顺序展示全部来源；每行包含序号、可读来源名称、内置/文件类型、来源标识或路径、上移/下移/移除动作。每行提供独立拖动把手，拖动时显示候选插入位置和来源预览；正常放下只一次改变草稿顺序，ESC 或失焦取消时保持原顺序。重复声明沿独立 Source.identity 保持行与焦点；列表边缘停留可自动滚动。键盘拾取、上下选择和确认使用通用排序控件；原上移/下移/移除仍可用。排序不隐含按语言重分组、不自动追加未声明来源，不隐式应用或保存。较长列表在边框容器内部滚动，当前行操作保持可达。

管理窗口中的“添加来源”进入该字段的来源编辑模态：选择内置来源或文件路径，内置选择由字体模块实际来源提供；文件路径由宿主解析，不假设存在原生文件选择器。提交后添加到末尾。非法标识和空路径错误显示在对应输入旁，草稿保留。来源添加成功、取消或 ESC 返回字体管理；完成管理后回到外观表单，来源变更仍只是草稿。“恢复默认”仅将模块默认完整列表写入页面草稿，不立即应用或保存。

空列表是合法且明确的声明：显示“未配置字体候选”及“不会自动补入默认字体”；仍可添加、应用和保存，不禁用合法空值。实际生效列表为空时，样本显示明确不可用说明，不挂载依赖 default 来源的样本控件；不借界面字体伪装实际样本。样本编辑状态保留，生效来源恢复后重新呈现。

“文字样本”直接使用当前生效字体呈现可编辑的中文与拉丁文字，可自由输入数字、符号及 emoji 并重置；说明明确“使用当前生效字体”，避免把未应用草稿显示为已生效。应用后沿同一资源换代更新样本，实际所用来源可在来源信息中观察。设置界面显式使用随包、附带原许可的无衬线 UI 字族；不改变或隐式追加 font.candidates。样本使用实际生效的候选列表，显式空值不被 UI 字体掩盖。浏览器参考文字不作为 UILib 字体覆盖或整形证据。

### 3.2 Minecraft 接入

MC 宿主显示“接管原版文字绘制”开关：左侧标签与说明、右侧开关。说明清楚区分原版文字适配与 UILib 自身页面绘制。切换只改变草稿，应用后由 MC 所属选项发布；不将开关挂入通用字体核心。

非 MC 宿主不提供可修改的 MC 开关。设计预览可以查看该页的 MC 场景样本；正式桌面页面不冒充可控制游戏。兼容问题说明归真实诊断，不通过推荐关闭其他 Mod 或修改全局配置代替正常接入。

### 3.3 配置文件

只读信息区展示宿主实际配置路径、YAML 格式和当前保存状态。提供“从文件重新加载”与“保存到文件”；不提供伪造的文件打开按钮或原生选择器。路径来源是宿主实际选择结果，不硬编码安装目录。

从文件重新加载是显式动作，按配置核心全量读取与校验；成功后更新生效值、保存基线及页面草稿，并通知宿主刷新资源。即使候选声明相同，显式加载仍更新资源，支持同路径字体文件内容更新。文件已加载而后续资源更新失败时保留已读取值与保存基线的事实，准确报告资源错误，不自动回滚。存在未应用草稿或已应用未保存值时，先确认将使用文件内容替换这些变化；错误留在文件字段组，不把失败写成“已重新加载”。没有自动磁盘轮询、后台监视、隐式重试或失败后恢复分支。

### 3.4 全局主题

“外观”分类提供浅色与深色预览选项，顶部保留主题快捷切换；两者修改同一工作区主题草稿，设置页立即按草稿预览；主题加入共同脏状态，并显示“应用后全局生效，保存后重启保留”。应用全部更改才发布应用级选择，保存到文件才持久化；不隐式写文件。放弃编辑恢复当前生效主题，关闭放弃未应用预览，已应用未保存主题继续生效；重新打开读取当前选择。其他页面使用已发布全局值，设置页预览不外泄。

## 4. 编辑、应用与保存

整个设置工作区共同持有一份草稿，分类切换不丢失本次未应用修改；应用和保存覆盖本页所属的全部实际选项，按钮文案明确“应用全部更改”。页面草稿、当前生效值与本页面最近成功读取/保存的文件值分别比较，不以时间戳或每次渲染递增的版本号制造冲突。

| 动作 | 行为与反馈 |
| --- | --- |
| 输入、开关、排序、移除 | 更新页面草稿；不自动应用或写文件 |
| 应用全部更改 | 将当前字段编辑结果纳入草稿并按声明校验全部所属值；通过后发布本次生效值，触发既有资源更新；不写文件 |
| 保存到文件 | 仅保存当前生效值；存在未应用草稿时禁用并说明“先应用更改”；成功后更新保存基线 |
| 放弃编辑 | 将草稿恢复到当前生效值；已经应用但未保存的变化仍然生效，不伪称已撤销 |
| 恢复默认 | 将对应模块默认值放入草稿，用户随后显式应用和保存 |
| 从文件重新加载 | 确认放弃未落盘变化后显式加载；成功才更新页面基线 |
| 返回或关闭 | 无变化时直接结束；存在草稿或已应用未保存变化时，显示继续编辑 / 不保存并离开的选择，并说明未应用草稿放弃、已应用值保留、关闭不会保存 |

没有变化时应用、保存与放弃编辑保持禁用；仅未保存时允许保存；有草稿时允许应用及放弃编辑。来源读取、值校验与持久化错误分别定位字段或文件，不用单一“失败”替代原因。应用遇到来源错误保留草稿；若配置值已发布而随后资源更新失败，准确显示当前已发布值与资源错误，不自动回滚。保存失败时生效值保持当前事实，状态仍为未保存，不自动重试。

字段使用表单应用策略，Tab 或背景正常失焦不自动保存。排序和移除等所属输入工具可按核心声明保留相关编辑焦点；删除真实目标后由动态结构资格释放处理。模态、Tab、ESC、背景失焦与被动提示不另建焦点权威。

运行配置由别处正式发布变化时：草稿未修改则随当前生效值同步；存在草稿则保留草稿，说明“当前生效配置已变化”，由用户选择放弃草稿同步，或明确再次应用本页更改。页面仍可编辑，不把变化永久转成只读。仅磁盘内容被外部修改时不冒称已探测；显式加载/保存按配置核心合同执行，本期不承诺文件级冲突检测。

## 5. 状态与可访问性

固定操作栏说明当前配置阶段与可用动作；错误在对应字段旁，成功反馈短暂显示且不抢焦点。保存失败不显示保存成功反馈；“已保存”状态按第 4 节最近成功读取或保存的文件基线比较。状态按配置语义比较，用户改后再改回基线应恢复无变化状态。

标签与字段关联；开关状态不只靠颜色；图标按钮可被键盘到达并有可读名称。Tab 按逻辑树顺序，说明文字不参与导航；当前分类有明确选中状态。添加来源与关闭确认使用正式模态，退出按核心范围恢复。样本编辑区与配置字段区分，样本修改不产生配置脏状态。

## 6. 设计及实现验收

正式交付为共享 ScenePage、独立桌面设置入口与 Forge 模组选项接入。浏览器原型仅保留视觉参照，正式配置输入、文件与资源结果必须经生产管线验收。

正式实现验收复用页面声明与正式输入：修改后导航切分类保持草稿；应用后生效且未写文件；保存后重新加载等效值及用户注释保留；无变化不通知；空候选仍为空；错误保留草稿及准确路径；排序保持条目身份；文件加载、外部正式发布、关闭和模态返回按上述阶段处理。桌面实机验证布局、主题、键盘及文字像素；MC 使用发行组合按会话授权单独验证，不外推桌面结果。
