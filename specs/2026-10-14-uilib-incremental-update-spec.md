# UILib 局部变化的增量更新规格

状态：本次任务目标与首期设计稿；总体推进方向已认可，尚未实施。

## 1. 目标与首期边界

局部内容变化携带节点来源进入运行时，框架只结束受影响内容的文字测量请求代际；未变节点在相同请求与资源条件下继续复用结果。页面与自定义控件仍通过现有声明、信号与依赖入口表达变化，不手动同步布局。

本期贯通失效来源、祖先依赖传播、节点文字请求复用与生命周期清理。测量、文字投影、最终排列和几何发布继续沿正式管线；正常更新仍允许遍历逻辑树及执行控件回调。本期不承诺任意控件尺寸结果、排列结果或整棵子树几何的跨批次复用。

状态、共同几何、业务权威与平台边界沿[核心规格](<2026-10-07-uilib-core-contract-design.md>)；布局与扩展沿[布局规格](<2026-10-13-uilib-layout-spec.md>)；身份与拥有权沿[动态结构规格](<uilib-dynamic-structure-spec.md>)；性能采样沿[性能压测规格](<2026-10-14-uilib-performance-testing-spec.md>)。本文只维护本次增量更新的职责与有限验收。

## 2. 当前事实与设计依据

规划基线为 refactor/uilib-core / e31d2f69。当前普通节点变化进入[无来源的测量失效](<../src/core/java/club/heiqi/uilib/ui/scene/node/SceneNode.java#L494>)，运行时推进全局测量代际；[布局引擎](<../src/core/java/club/heiqi/uilib/ui/scene/layout/SceneLayoutEngine.java#L76>)据此清空所有节点的文字请求缓存。具体耗时占比需在实施第一阶段取得当前版本数据。

[SceneControl](<../src/core/java/club/heiqi/uilib/ui/scene/control/SceneControl.java#L21>)已有测量、排列及绘制依赖声明；本次复用这些入口。文档行内内容在子测量后读取[数学基线事实](<../src/core/java/club/heiqi/uilib/ui/scene/control/SceneMath.java#L237>)，因此本期保留控件测量与呈现回调，避免仅缓存宽高却遗漏关联事实。旧版本性能数据只用于选题，不作为本期基线或收益证明。

## 3. 职责与协作

| 主体 | 决定与维护 | 提供的事实 |
| --- | --- | --- |
| 页面与控件作者 | 现有逻辑声明及可通知依赖 | 内容、结构及变化来源 |
| SceneNode | 声明属性变化的节点来源 | 哪个节点的测量输入改变 |
| SceneRuntime | 挂载期测量输入代际、祖先传播及交互资格重验 | 节点输入代际与确属全局的测量失效代际 |
| SceneFramePipeline | 声明收敛、宿主度量代际与一致几何生效 | 本批正式根集合、环境及资源事实 |
| SceneLayoutEngine | 同批测量/排列，文字请求缓存的选择与生命周期 | 正式几何；可复用且仍有效的请求入口 |
| BatchTextMeasurer | 同一节点有效代际内的精确文字请求复用 | 实际文字服务的布局结果 |
| 测试应用与宿主 | 正式负载、真实输入、采样及证据导出 | 当前版本的行为与同宿主性能反馈 |

测量来源变化先影响所属节点及依赖它的祖先，再由本批实际约束计算结果。首期使用逻辑祖先链作为安全传播范围，不凭固定尺寸提前截断传播；未变兄弟继续保留各自文字请求。结构移动同时影响旧父与新父的祖先链。

## 4. 变化与生效规则

| 触发 | 本期处理 | 可观察结果 |
| --- | --- | --- |
| 局部文案、样式、尺寸意图或控件测量依赖变化 | 更新来源及相关祖先的测量输入代际，正常重测/排列 | 新内容生效，未变兄弟的相同文字请求复用 |
| 仅绘制依赖变化 | 沿已有绘制失效更新 PaintPlan | 正文度量和共同几何保持有效 |
| 排列依赖或正式滚动变化 | 正常更新位置、裁剪及命中，复用仍有效的文字请求 | 所见位置与后续输入一致 |
| 增删、重排、折叠及同页移动 | 在所属集合、旧父/新父及其祖先传播；重验有效输入资格 | 内容范围和位置更新；身份与编辑状态按既有合同延续 |
| 字体/宿主度量资源换代 | 结束全部依赖该度量代际的文字请求 | 无旧字体结果残留，包括同语言资源重载 |
| 窗口或根约束变化 | 按当前空间重测/排列，沿既有视口失效处理 | 换行、硬尺寸、裁剪及滚动范围正确 |
| 既有无来源失效入口 | 保留全局测量失效含义 | 无法定位来源的既有调用继续正确更新 |

直接属性、正式控件依赖及文档/图像的内部通知均须接入来源传播。聚焦、手势释放、输入顺序与声明收敛保持既有职责；局部测量代际不成为第二套焦点或几何权威。

## 5. 缓存有效性与释放

文字请求结果须同时满足节点当前挂载/输入代际、度量资源代际及请求内容、样式、宽度、文字策略的匹配。属性文本继续按既有不可变身份处理，不推断等价。局部失效清理相关节点请求；全局度量失效仍清理对应全部请求。

缓存归所属帧管线与布局引擎管理。节点请求有明确容量上限，并清理本次已不需要的请求；卸载或销毁的节点不能由缓存继续持有，重新挂载不得误用旧挂载结果。关闭帧管线释放缓存。隐藏的正式备用捕获子树仍沿同一布局引擎取结果，主布局与备用捕获不相互清掉对方仍有效的请求。

同批子测量入口只在本批有效，不放入跨批次缓存。控件 measure/layoutText/presentText/arrange 继续建立本次完整内容事实，普通容器仍在最终 arrange 消费实际外盒。

## 6. 验收场景

| 场景 | 独立期望与反馈 |
| --- | --- |
| 页面稳定呈现 | 延续既有几何/计划复用；无节点或绑定重建 |
| 固定约束下只更新一行文案 | 新文字实际出现；正式测量仍可执行，未变行的相同请求不再进入真实文字服务 |
| 更新自然高度并影响父布局 | 必要父重排、兄弟位移、裁剪及滚动范围同步正确；尺寸变化不等于所有兄弟重新整形 |
| 外部自定义控件的测量/排列/绘制依赖分别变化 | 仅用既有 SceneControl 依赖入口；更新阶段正确，未变内容可复用 |
| 相同源码的新文档声明、内联图像状态及公式变化 | 内容身份、尺寸、基线、链接命中均为当前事实 |
| 增删、重排、折叠、同页跨父移动 | 旧父与新父都更新；合法焦点、草稿和 UUID 按既有合同连续，失效手势结束 |
| 字体资源换代、语言重载、字号和窗口变化 | 不复用旧代际/旧约束结果，无需重开页面 |
| 备用图像子树捕获、卸载/重挂、关闭 | 主绘制及备用分支正确，节点缓存不跨结束的挂载或页面残留 |
| 无来源的既有测量失效 | 真实文字服务重新处理相关请求，保留原行为 |

行为反馈复用正式 session、控件、真实字体及输入；场景级委托统计只观测真实调用，不增加公共测试计数器或替代生产算法。必要像素/命中回归沿现有软件回放或真实 Desktop 验证。

性能实施前保存当前版本原始基线，实施后用相同宿主、规模、内容和采样参数比较请求数、文字请求耗时、宿主帧耗时与分位数。请求次数不等同完整 native 整形。阶段探针注明嵌套边界，探针数据不与未插桩基线混比；分位数和比较由代码从原始样本计算。

本期完成须满足来源传播和有限行为验收、可证实的未变内容请求复用、缓存有界与释放、完整 build，以及同宿主性能复测。只有改善超出复测波动才声称帧耗时提升；若热点定位或复测反证预期，先重评本链路中的重复工作。本期不预设跨机器速度线或改善百分比。

## 7. 后续专题

本期反馈决定是否继续设计任意控件的完整测量结果复用、布局依赖图或子树几何复用。真实动态数据浏览功能随后检验扩展能力；虚拟列表与异步化按实际规模和热点另行规划，不并入本次交付。
