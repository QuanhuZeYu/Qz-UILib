# UILib 局部变化的增量更新规格

状态：规划稿；总体推进方向已认可，首期目标供实施使用，尚无运行结论。

## 1. 目标与范围

局部内容变化携带来源进入运行时，框架沿实际依赖更新测量与呈现结果；未变节点在相同文字请求、约束及资源条件下复用有效结果。页面和自定义控件继续通过已有声明、信号及正式依赖入口表达变化，不手动同步布局。

首期覆盖来源传播、局部文字请求复用及所属缓存生命周期。必要父布局与兄弟位置更新继续发生；本期允许正常遍历和控件回调，不承诺任意控件尺寸、排列结果或整棵子树几何的跨批次复用。复用必须保留本次内容的完整测量、基线、文字投影和最终排列事实。

状态、共同几何、业务权威与平台边界沿[核心规格](<2026-10-07-uilib-core-contract-design.md>)；布局与扩展沿[布局规格](<2026-10-13-uilib-layout-spec.md>)；节点连续性沿[动态结构规格](<uilib-dynamic-structure-spec.md>)；内部协作沿[职责规格](<2026-10-14-uilib-internal-responsibilities-spec.md>)。

## 2. 变化与生效

| 触发 | 必须成立的结果 |
| --- | --- |
| 局部文案、样式、尺寸意图或控件测量依赖变化 | 目标内容与相关布局自动更新；未变节点的相同有效文字请求可复用 |
| 仅绘制依赖变化 | 当前绘制表达更新，不使仍有效的正文度量或共同几何失效 |
| 排列依赖或滚动变化 | 位置、裁剪与命中同步更新，复用仍有效的文字请求 |
| 增删、重排、折叠及同页移动 | 所属集合及旧、新布局归属均正确更新；身份和编辑状态沿既有合同 |
| 字体或宿主度量资源换代 | 依赖旧度量的结果结束，不混用旧测量与新字形 |
| 语言资料重载、文案派生或主题变化 | 按实际变化更新相关内容，同语言标识不能阻止更新 |
| 窗口或根约束变化 | 按当前空间重测或重排，换行、硬边界与滚动范围正确 |
| 既有无来源测量失效 | 保留整体失效的原有含义，仍能正确更新 |

直接属性、正式控件依赖及文档/图像内部通知均进入来源传播。节点输入、祖先布局依赖、约束及资源事实共同决定复用有效性；具体代际字段和传播算法由实现选择。

## 3. 缓存与完整事实

缓存按实际节点及挂载生命周期、测量输入、文字请求、约束与度量资源失效，有明确容量边界和释放来源。卸载、销毁、重挂载或页面关闭不能误用已结束挂载的结果或让缓存持续持有已退出节点；清理不关闭业务共享状态及字体服务。

主布局和已声明备用捕获沿同一框架处理，不能互相清掉对方仍有效的事实。同批子测量能力仍只在本批有效；复用结果不保存该临时入口，也不省略控件内容需要的完整事实。普通容器最终排列继续消费当前实际外盒，绘制与输入共用正式几何。

## 4. 验收

| 场景 | 独立期望 |
| --- | --- |
| 无变化连续呈现 | 延续既有几何/计划复用，不重建节点或绑定 |
| 固定约束下仅更新一行 | 当前文字真实出现，未变行的相同请求不再重复进入实际文字服务 |
| 自然高度变化影响父布局 | 父重排、兄弟位移、裁剪及滚动范围正确；无关内容不因此重复请求相同文字 |
| 自定义控件分别改变测量、排列、绘制依赖 | 仅用正式入口，更新阶段和内容正确 |
| 同源码的新文档、内联图像及公式变化 | 内容身份、尺寸、基线和链接目标均为当前事实 |
| 增删、折叠、重排及跨父移动 | 双方布局正确，合法草稿和焦点按既有合同连续，失效手势结束 |
| 字体/语言资源、字号和窗口变化 | 无旧代际或旧约束残留，无需重开页面 |
| 备用捕获、卸载重挂及关闭 | 所属绘制正确，已结束挂载的缓存和通知不残留 |
| 调用既有无来源失效入口 | 原有整体更新能力保持 |

行为观测采用正式 session、控件、真实字体与输入，必要图像与命中沿软件回放或实际宿主核验。场景委托统计观测真实调用，不读取私有缓存推导期望或新增公共测试计数器。请求数不等同完整 native 整形次数，文字请求减少也不能代替几何正确性证据。

性能基线、原始样本、分位数、热点定位和同宿主前后复测统一遵循[性能压测规格](<2026-10-14-uilib-performance-testing-spec.md>)。请求复用与帧耗时改善分别报告，时间收益须超出复测波动；本期不新增跨机器性能线，也不改变字体模块已确认的原版对照门槛。

达到来源传播、有限行为、有效请求复用及缓存释放的验收，并完成同宿主复测后，本期目标完成。实际源码诊断、接口草案、任务步骤、运行证据和后续选题留在临时计划及记录，不作为长期合同。
