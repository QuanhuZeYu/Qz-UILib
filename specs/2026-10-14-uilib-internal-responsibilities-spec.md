# UILib 内部职责整理规格

## 1. 目标与边界

按现有[核心职责规格](<2026-10-07-uilib-core-contract-design.md>)整理内部协作，减少相同协议的多处实现和协调类中的局部算法。公开入口、业务状态权威、布局/输入合同与资源拥有规则沿所属模块规格；本规格不改变公共兼容、版本或发布策略。规模与分支计数只定位候选，整理以真实职责、状态归属及调用关系为依据。

## 2. 职责与协作

| 主体 | 决定与维护 | 提供给协作者的事实 |
| --- | --- | --- |
| SceneRuntime | 唯一挂载、绑定刷新、输入权威与失效代际；验证调用授权及迁移条件 | 正式节点归属、挂载身份与当前输入几何 |
| SceneFramePipeline | 输入顺序、声明/布局收敛与呈现代际 | 已准备的正式几何、当次字体/宿主度量代际 |
| 内部绘制收集器 | 按正式几何收集控件内容、后绘制与overlay；捕获备用子树 | 不可变PaintPlan；不调度输入、刷新声明或发布布局 |
| 编辑声明绑定 | 独立编辑状态、主题、只读来源接入节点声明 | 同一正式挂载绑定，生命周期由节点/页面承担 |
| 共同编辑命令 | 来源文本、组字优先、草稿命令与提交协调 | 已存在编辑状态的变更与消费结果 |
| 单行/多行控件 | 各自视口、视觉导航、选区绘制和模式命令 | 消费同一草稿与共同协议；不另建业务状态或输入所有者 |
| 文档代码视口、表格与单元格 | 普通容器自然测量与最终子排列、局部横向滚动 | 当批真实子测量和相对外盒ChildPlacements |
| 宿主适配 | 原生输入与资源事实、运行与结束入口 | typed输入和已有核心失焦事件；不复制焦点/组字协调 |

## 3. 不变量

- 迁移公共句柄与声明入口分别保留授权、诊断及mutation作用域，共用已有挂载迁移步骤；同页移动不重建挂载token/绑定，不混合逻辑拥有与激活Owner。
- 绘制提取继续消费同批正式几何和唯一布局引擎。控件内容、paintAfterChildren与全页overlay顺序不变；备用捕获仅改变绘制区域，不能建立另一套主输入geometry或hover裁决。
- 编辑提取采用包内组合，共同来源事件与命令复用现有SceneEditState。单行和多行各自的来源事件导航清理、Enter/Tab、二维视口行为保留，INPUT仅在实际草稿文字改变时提交。
- 普通非文字代码视口、表格与单元格在arrange根据最终外盒和同批子测量计算排列；文字投影不承担子布局准备，也不借临时prepared跨阶段传递普通排列。
- 宿主失焦沿正式有序focusLost入口释放指针/焦点与组字。字体资源关闭仍结束全部已拥有资源，保留首个异常及后续清理异常。

## 4. 验收

- 既有单多行编辑、IME、词编辑、动态结构、层输入、图像fallback/overlay与宿主场景验收通过；职责提取不新增测试专用生产接口。
- 代码视口回归直接以不同最终盒执行正式arrange，验证padding、超宽内容、动态限界与空内容；覆盖此前依赖presentText准备的阶段错误。
- 必要宿主责任偏差通过可替代实机的现有正式适配验收与完整编译保护；MC实机运行另按会话授权。
- 完整build与发行隔离通过后才能提交。保留可复算规模/精确重复候选和独立审查证据；不以文件变短、类数增加或词法分支减少单独宣称认知复杂度降低。
