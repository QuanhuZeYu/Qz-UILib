# UILib 内部协作职责规格

状态：已确认跨模块职责规格。

## 1. 范围与归属

本规格明确呈现运行时内部协作者的职责与交接，不固定类数量、包内组合方式、字段或方法签名。公开状态、布局、输入与生命周期合同归[核心规格](<../2026-10-07-uilib-core-contract-design.md>)及[规格入口](<../README.md>)列出的所属模块。

## 2. 职责与交接

| 主体 | 决定与维护 | 提供给协作者的事实 |
| --- | --- | --- |
| 挂载与绑定运行时 | 节点归属、挂载连续性、声明刷新与失效来源；协调唯一路由器 | 当前有效声明、挂载身份与交互资格 |
| 帧协调管线 | 输入顺序、声明与布局收敛、当批呈现准备 | 同批正式几何与当前宿主/字体度量事实 |
| 布局引擎 | 内容测量、最终外盒分配、相对排列、裁剪及滚动范围 | 绘制与输入共用的正式几何 |
| 绘制收集器 | 消费正式几何收集控件内容、后绘制与全页提示；捕获已声明的备用子树 | 不可变 PaintPlan；不刷新声明、发布布局或裁决输入 |
| 编辑声明绑定 | 接入独立编辑状态、主题与只读来源，管理所属呈现订阅 | 当前声明与有效编辑状态；不另建草稿 |
| 共同编辑协调 | 文本来源、组字优先、共同草稿命令与提交协调 | 已有编辑状态的变更及输入消费结果 |
| 单行/多行控件 | 各自视口、视觉导航、选区呈现及模式命令 | 消费共同编辑合同，不另建焦点或输入所有者 |
| 普通复合容器 | 自然测量、按最终外盒排列及所属局部滚动 | 同批直属子测量与相对子区域；不通过文字投影准备普通排列 |
| 宿主适配 | 原生输入、资源事实及宿主运行/结束入口 | 按序递交中性输入与生命周期事件，不复制核心焦点或组字协调 |

## 3. 协作边界与验收

- 逻辑拥有和挂载作用域分开；明确移动的授权、诊断及连续性沿[动态结构规格](<uilib-dynamic-structure-spec.md>)维护。
- 绘制收集保留控件内容、所属子内容、后绘制及全页提示的语义顺序；各呈现组末尾结束所属后绘制。所属层组序归[所属层规格](<2026-10-13-uilib-layer-input-spec.md>)，备用捕获只提供绘制表达，其原树身份与输入资格归[图像规格](<../content/2026-10-07-uilib-image-spec.md>)。
- 单行和多行的 Enter/Tab、视觉导航及视口差异归[编辑规格](<2026-10-07-uilib-editing-spec.md>)；共同命令不覆盖这些差异。
- 普通代码视口、表格和单元格在最终排列中消费实际外盒及同批子测量，沿[核心第 4.4 节](<../2026-10-07-uilib-core-contract-design.md#44-自定义控件的正式接入职责>)。真实文字/数学投影可消费内容子测量，不把普通排列结果跨阶段暂存。

验收从正式页面、真实输入和共同几何观察移动连续性、编辑行为、绘制顺序与容器最终排列；资源清理及宿主证据按所属模块核验。具体类拆分、任务步骤和运行记录留在实现及临时记录。
