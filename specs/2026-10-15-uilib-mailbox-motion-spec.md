# UILib 邮箱真实动效还原目标

状态：用户要求先完善邮箱，并明确以当前调试浏览器中的真实 Gmail 为参考；本稿据现场观测收敛实施范围。

## 1. 结果与范围

沿既有[邮箱还原目标](<2026-10-15-uilib-mailbox-fidelity-spec.md>)的业务、视觉与生命周期。本期还原实际观察到的状态过渡：导航内部形状、留白和文字即时显隐，搜索背景及主动作阴影，并核对分类、选择与行内动作的即时和渐变反馈。实际操作与当前数据立即生效，动效只协调呈现。

导航整体的展开/折叠占位与主工作区按目标状态切换，导航条目内部宽度和边距使用有限短过渡，图标中心保持稳定，文字按目标状态立即显隐；不能把整体工作区的平滑缩放当作真实参考。主动作只过渡最小宽度，文字立即显隐；展开后的自然内容可以立即撑开，收起后按剩余图标与变化的最小宽度求尺寸。字号、窗口和主题变化持续使用当前来源。导航选中表面右端保持圆角，左端从展开平边连续变为折叠圆角；标签和计数共用随当前内边距分配的裁剪区，不互相穿插。

折叠导航持续悬停后临时展开，覆盖工作区而不推动列表；离开结束临时展开并收回，固定展开状态独立于悬停。展开内容沿正式排列与命中，覆盖区域的动作不穿透到后台邮件行；主导航按钮、窗口变化、隐藏与卸载结束过时的等待。延迟由挂载期有限时间推进，无案例线程。

搜索聚焦与失焦的背景使用短 ease-in 过渡，阴影按实际焦点及时切换；主动作悬停阴影使用更短的 linear 过渡。导航内部沿 Material 标准曲线，快速反向从当前可见值续接，并按已走的曲线比例缩短返回时长，短途反向不拖满原始时长。具体时长与曲线在所属使用点按现场参照维护，真实中间帧校准。

分类选中指示、业务结果和批量动作集合按当前意图立即切换；既有行内次级动作渐显和键盘立即显现继续保持。没有观察依据的横滑指示、整页阅读换场、行逐项入场或星形旋转不列为本期目标。阅读、分类和批量流程仍参与业务回归。

## 2. 框架职责

控件决定呈现目标、默认节奏及如何映射为尺寸、内部排列和角色色；页面声明内容、来源与业务动作。框架在节点挂载生命周期内推进有限过渡，并通过既有绑定与控件依赖更新呈现；宿主提供正常帧，不由页面创建计时线程或每帧读取时间回写布局。

同一宿主帧及其输入批次使用同一份单调时间。推进发生在可写的呈现准备阶段，随后结算现有声明，唯一布局发布画面与输入共同使用的几何，再收集 PaintPlan。布局、绘制和纯派生继续只读；同批多次 prepare 不会重复推进。

只有活跃且仍挂载的有限过渡参与推进；完成精确落端点并结束调度，卸载/关闭释放所属推进和订阅，重挂直接消费当前目标。静止画面继续复用既有结果。普通排列仍保留合法 fixed/min/max 与当前尺寸约束，不另建几何、焦点或命中权威。

本期新增挂载期有限呈现值绑定，复用 Signal、NodeBinding、SceneControl 的测量/排列/绘制依赖、正式 ChildPlacements 和现有 PaintPlan。现有 nextPaintNanos 保持只重绘的含义，不引入通用仿射变换、组透明度、离屏合成或独立动画引擎。

## 3. 页面声明体验

页面作者声明业务模型、主题来源、导航项、搜索、列表和阅读内容及业务动作。默认过渡、悬停等待、文字与计数裁剪、覆盖排列、命中及卸载清理由控件和框架承接，页面不持有进度、计时、坐标补偿或手工失效逻辑。

导航项通过名称、图标、选中与计数来源、激活动作表达；增删一个普通项或修改文案、图标及动作不需要复制尺寸公式、绑定时间线或知道子槽顺序。页面布局按导航和工作区等角色组合，不依赖第三个孩子恰为留白之类的隐含约定。响应依赖由来源读取追踪，不用字符串拼接状态充当依赖键。

以正式邮箱声明和一项额外导航项的实际使用验证这些边界。简洁以页面作者需要理解和维护的事实判断，不以行数或另设私有包装掩盖未解决的职责问题。

## 4. 验收

通过同版本 Desktop 正式发行组合与共享邮箱保存真实 GPU 连续帧，包含导航内部展开/折叠与中途反向、搜索 focus/blur、主动作 hover/leave、行内按钮渐显及键盘立即显现。每个实际呈现帧采原生像素区域、同代共同几何、帧开始/呈现/读回时刻，采完后再编码；交换后读取FRONT，避免把旧BACK像素与当前几何配对。报告实际帧间隔和采样缺口，参考以每个rAF采样，不用稀疏固定时点或插值帧代替真实过程。

中途点击当前可见图标和主体时实际对象正确；分类、勾选、批量操作及阅读返回不延迟或重复业务动作。宽窄窗口、字号、主题及资源变化保持当前文字、几何、裁剪与滚动范围；不能只用终态截图证明动效。

过渡中切出、卸载、重挂和关闭无迟到更新。完成后连续静止帧恢复正式几何与 PaintPlan 复用。复用统一测试应用补充防住真实时间与生命周期回归的有限场景，完整 build 和独立审查通过后本地提交；MC 启动和部署按会话授权单独执行。
