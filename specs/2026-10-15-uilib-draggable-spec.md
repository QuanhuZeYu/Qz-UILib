# Draggable 拖拽规格

依据用户明确新增需求及[真实 dnd-kit React / Draggable 参考](https://main--5fc05e08a4a65d0021ae0bf2.chromatic.com/?path=/docs/react-draggable--docs)。该地址的 react-draggable 是示例名，实际文档为 @dnd-kit/react 的 useDraggable；本模块采用 UILib 自有声明与输入布局体系，不引入 Web 库。

## 目的与职责

将普通内容声明为可被指针拾取的元素，手势期间内容跟随指针，原排版槽和兄弟次序保持；正常释放或取消后回到原槽。多个元素拥有各自独立状态，活动手势仍由现有唯一指针路由器归属。拖中反馈作为只读状态供页面声明样式和文案。业务要保存位置或接收落点时须显式声明其业务行为，普通Draggable不推断这些含义。通用列表排序由下述 SceneSortableList 负责呈现与输入，权威条目顺序仍归调用者。

页面仅声明内容与拖动状态，标准组件处理测量、位移与交互。移动进入正式 SceneControl arrange 的子排列结果，由唯一 SceneGeometryView 同时服务绘制、裁剪、点击、悬停和滚动；不得仅移动 PaintPlan 或在业务中维护第二套坐标命中。原槽不保留可点的幽灵目标。

## 指针与生命周期

主键在当前可见内容范围按下开始，后续移动与释放始终沿同一个 MountHandle owner；指针离开原区域后仍继续手势，第二键不能抢占。目标随指针移动但内容的普通占位不随拖动扩展或挤压兄弟。祖先本来声明的裁剪与输入范围继续生效；示例底色不是拖拽边界。

内容中的普通交互子控件仍依既有命中次序拥有自己的点击或编辑行为，不因包装就被父拖拽劫持。取消、失焦、禁用、隐藏、卸载、范围切换、异常清理及关闭使临时拖动结束，迟到MOVE/UP不能复活旧手势或激活其他节点。显式ESC消费活动拖拽并回原位，不隐式触发页面返回。路由器在现有受控分发范围通知失去捕获，控件清理内部状态，不绕过handler边界。

拖中窗口和父布局/滚动变化继续以当前分配位置与共同几何协调，不把起拖时的布局快照当永久坐标权威。默认回位是正常拖动语义，不是失败回滚或另加恢复策略。

## 键盘

可拖内容可沿正式Tab导航到达，Space 或 Enter 开始键盘拖动，方向键移动，Space 或 Enter 结束并回位，ESC取消；焦点离开时结束临时键盘拖动。键盘和指针共用同一控件状态与正式排列，不订阅宿主原生键码、不劫持已有编辑子控件。

## 手柄、预览与位移约束

可声明单个或多个把手，只有当前有效把手区域可由指针起拖，正文和内部按钮/编辑器保持原交互。未声明把手时沿内容起拖。键盘使用同一正式焦点单元，不建立独立宿主监听。预览是组件拥有的独立纯视觉声明，原内容保持占位、身份和编辑状态；预览沿正式 PASSIVE 所属层位置端口发布一次几何，在当前 modal 所属范围内显示，不借图像或旧 PaintPlan 变换伪造。

支持横轴、纵轴、网格吸附、页面视口及父容器边界。顺序为轴约束、网格、边界限制；硬边界优先，边缘可停在非整网格位置。指针与键盘、拖中反馈和正常结束的最终位移使用同一解，不读回结果逐次补偿。窗口/父空间/策略变化沿正式依赖求当前结果。

指针激活可立即、距离、延迟及二者 OR。延迟分支仅在移动容差内有效，超出容差不复活该分支；距离分支仍可独立达成。未激活的释放不发布放下。时钟由正式输入帧推进，停止移动仍可到期，取消/失焦/失格终止等待。输入帧只登记当前有计划的已挂载交互，本批有效几何后推进一次；发生 handler 或 Effect 失败时，沿原失败边界取消唯一指针捕获，并通知本批实际参与且仍同挂载的输入帧控件结束临时交互，键盘无捕获时同样取消。通知与 captureLost 分离且状态清理幂等，保留原异常与清理异常，不全树重置、不取消后来新挂载。当前宿主只提供鼠标坐标与按钮，不声称实现触摸或独立 pointerType 默认策略。旧工厂保持即时拾取，参考案例显式展示距离和延迟。

正常放下可声明一次结束意图，取消、失格、等待中释放不调用结束动作。意图传当前受约束的最终位移，不以 active 下降猜测提交。

## 可排序列表与字体来源

SceneSortableList 以独立条目键和行声明组成列表。拖动把手或键盘拾取时保留原节点/挂载/焦点及条目数据，只显示纯视觉预览和候选插入标记；排序目标根据当批真实变高行几何判断，不能用固定行高或显示序号代替身份。键盘上下选择相邻插入位置，正常 Space/Enter 或指针释放时只发一次 Move(key,beforeKey) 意图，beforeKey 为空表示末尾；候选位置未改变时不发布 Move。ESC、失焦、移除活动条目、范围结束或失格只结束临时交互，不更改权威顺序。

排序过程中靠近最近声明滚动视口边缘，按时间在正式 ScrollPosition 内连续滚动；指针停边仍继续，到边界/离开/结束停止。滚动使原槽离开可见范围时，预览来源仍为持续有效的列表容器。容器或所属范围失活仍按既有来源合同结束。自动滚动不制造业务 wheel 回调、不滚穿 modal/所属层到后台。无活动手势时不启动输入帧扫描或重建列表。

字体列表按 Source.identity 保留重复来源的独立行，放下只一次更新 SettingsModel 草稿，不应用、不写盘；原上移/下移/移除和添加仍可用。应用、保存、放弃和重载继续沿配置事务，字体匹配优先级只随实际应用值改变。

## 验收

共享参考案例进入测试广场：单个与多个可拖元素，可见活动反馈、结束回槽，普通内容声明不需布局回调。实际输入验证移动量与同一几何一致、兄弟稳定、旧槽无目标、移出原槽释放、第二元素独立、普通子按钮优先、ESC/失焦/禁用/卸载取消及物理尾部不重启；缩放和重排按宿主现有坐标转换与唯一排列验证。真实桌面使用已安装回调和实际GPU画面，同时运行正式完整build。MC仅已有源集编译和成品门禁，不推定实机结果。
