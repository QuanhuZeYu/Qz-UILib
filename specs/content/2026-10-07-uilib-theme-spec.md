# UILib 主题与标准控件规格

状态：已确认模块规格；与核心规格共同构成项目规格体系，仅定义本模块职责。

共同状态、布局、生命周期、输入与平台边界遵循[核心职责规格](<../2026-10-07-uilib-core-contract-design.md>)；按职责选择规格见[规格入口](<../README.md>)。

语言事实、翻译键、参数、资源失效和翻译结果语义由[语言与翻译规格](<2026-10-07-uilib-localization-spec.md>)定义；本模块定义文案在控件中的布局和交互，不重复翻译合同。

## 1. 全局主题选择

UILib主题模块声明应用级 ui.theme，YAML取值为 light 或 dark，缺少字段默认 light；非法值沿配置核心完整校验报错，不半发布。MC与桌面分别由宿主唯一ConfigSession持有该值并使用其实际配置路径，不创建第二主题文件或跨应用全局单例。加载、应用和重新加载后，所有消费默认主题的页面随变化更新；保存成功后下次启动加载同一选择。

页面上下文提供所属状态域的主题选择和标准主题派生；独立页面域通过既有状态通知递交应用事实，不能直接跨域借用配置Signal。呈现订阅归页面，关闭页面只释放自己的绑定，不结束宿主持有的主题配置。页面和控件仍可显式派生局部样式或进行标明为预览的主题演示，默认选择来自全局配置，新的全局发布使普通主题演示恢复到该值；不把局部演示保存为全局设置。设置页的主题草稿、预览、应用与保存归[配置页面规格](<../config/2026-10-12-uilib-settings-page-design.md>)。

## 2. 主题与标准控件文案

正式主题派生入口保证有效初值，创建后即可挂载标准控件，后续来源变化继续更新；业务不补算初值或主动刷新。Computed 的首次、写后及派生链读取遵循[核心第 3.1 节](<../2026-10-07-uilib-core-contract-design.md#31-状态独立性与可见性>)；求值可惰性进行。主题入口不自动修复无效业务主题，初始化不能意外将派生内部依赖挂入外层重建 Effect。

标准控件公开换行、单行省略或允许溢出等文案策略，按实际可用文字空间测量、布局与绘制。语言、字体、主题及空间变化自动适配，业务无需访问内部子节点或布局后补宽度。

标准单行字段可声明响应式空态提示，提示仅在真实显示内容为空且没有组字时绘制，不参与草稿、提交、选择或复制，也不覆盖组字。字体、文案、空间及资源换代更新提示。字段可选择无边框呈现用于复合表面，真实caret、选择、编辑和输入语义仍相同；既有工厂默认保留边框。

逻辑焦点与显示焦点线索分开，保持唯一路由权威。标准按钮通过Tab导航或键盘激活时显示焦点框；主键点击仍取得逻辑焦点，普通按钮不显示键盘焦点框，移动指针本身不改变输入方式。文字输入控件无论点击或键盘聚焦都保持光标、选择及编辑线索。显式焦点请求和模态返回沿当前输入方式呈现，失活/卸载仍按现行规则释放焦点，不能保留第二份可输入目标。

标准按钮默认参与 Tab 导航，点击取得焦点；当前合法焦点按钮用 Enter 或空格激活，一段按压仅一次，repeat 不重复执行业务。禁用按钮不取得焦点或激活。此默认不改变普通声明节点；按钮作者可显式修改焦点资格，点击聚焦及明确保焦动作沿核心第 6.2 节执行。标签不参与焦点导航。

标准按钮默认换行，自然高度随内容增长；明确尺寸与最大高度仍受既定规则约束。高度受限且文字放不下时，默认仅显示完整行并标示省略，完整文本通过悬停或键盘聚焦后的被动提示查看。提示不改变按钮尺寸或焦点，不擅自增高或缩字号。作者可明确选择其他文案策略。

文字区域连完整行或省略标示都放不下时不绘制残行，仍保留完整文案。溢出按钮悬停或键盘焦点可见时即时显示被动完整文案提示，在当前 viewport 内放置；提示不参与输入、模态或布局，空间不足仅裁剪提示区域，不改变原按钮或字号。提示依据当前悬停或焦点可见状态显示；两者均离开来源按钮后提示消失，显式保焦动作按实际焦点判断。提示不额外维持来源按钮的焦点。此默认不推广到所有控件。

## 3. 复选框与图标动作

标准复选框声明 UNCHECKED、CHECKED、MIXED 三种显示状态，写入意图与来源状态分开。CHECKED 激活请求 false，UNCHECKED/MIXED 激活请求 true；控件不隐含全选范围或业务集合。禁用、点击聚焦、Tab 与 Enter/Space 激活沿标准按钮的共同输入合同，显示状态变化只改变绘制，不重新测量名称。

复选框可显示名称或仅显示标记；图标动作只显示明确的向量符号。两者都要求完整可读名称，仅标记/图标模式在当前悬停或键盘焦点时即时显示被动名称提示；提示不改变布局、输入和焦点。字号、主题、名称和宿主空间变化动态更新；命中区域包含正式 padding，不依赖缺字占位或固定字号。

图标动作的星标、归档、邮件、导航、搜索等符号是通用视觉内容，具体业务动作由调用方提供；次级图标与父级主体分别激活，不由控件推断冒泡或批量业务。标记可响应式变化（例如星标轮廓/填充），保留控件、焦点与命中身份，单纯标记变化只失效绘制。复合动作可消费同一图标的纯装饰节点，装饰不建立额外动作或焦点目标。有限标准图标与圆角通过实际像素 coverage 平滑边缘，载荷仍是正式不可变 PaintPlan；缓存只持有限形状/大小，不持节点或主题。

## 4. 有限过渡与被动悬停

控件可在正式绘制扩展声明有限过渡的下一次绘制时刻。宿主正常帧在到期时仅更新PaintPlan；过渡结束恢复静态计划复用，不启动逐控件线程或每帧全量状态轮询。卸载/关闭后不继续持有更新任务；该绘制期限不改变业务值、输入身份或独立布局事实。

呈现声明可绑定有限数值过渡：框架在同一宿主帧及其输入批次的单调时刻推进，随后结算声明，再准备共同几何与绘制；同批多次 prepare 不重复推进。初次/重新挂载直接消费当前目标，持续挂载的反向变化从当前值续接；返回当前段的反向起点时按已走曲线比例缩短有效时长，完成精确落端点并停止推进，卸载结束所属时间线。映射只表达呈现，不延迟业务状态或执行模型动作；布局、绘制和纯派生保持只读。仅活跃挂载参与推进，不建立永久tick或逐控件线程。几何映射沿布局规格的尺寸与共同排列，绘制期限仍只重绘。

被动悬停可作为挂载期呈现来源：唯一路由器按当前有效几何、裁剪及输入范围发布命中所属子树的进入/离开，订阅者可声明进入等待；离开和卸载立即结束等待与所属呈现。它不新增点击、捕获、焦点或第二命中区域；纯绘制仍只读，呈现映射在声明准备阶段执行。

## 5. 本地文件选择

文件选择器组合 UILib 正式场景、输入框、按钮、滚动区及模态范围，在所属页面窗口内呈现。目录访问使用 Java 标准文件 API；不委托 Swing、AWT、JavaFX、游戏控件或原生文件选择对话框。调用方提供初始目录并接收选中的文件或取消意图，业务决定后续用途。

选择器采用 shadcn 式中性色、轻边框和圆角表面，标题、说明、路径、目录内容及操作分区清晰。文件/目录以图标与名称区分，主确认与次级导航/取消有明确层级；默认界面文字使用随包无衬线字族及已有文字覆盖候选；这是局部 UI 字体声明，不修改或跟随应用默认候选配置，调用方显式字族/候选仍按其主题声明使用。浅深色、声明字号/字族和窗口变化沿正式测量与失效更新。

用户可从根目录或盘符、上一级及路径输入导航，浏览目录、选择并确认任意扩展名的普通文件。中文、空格和加号保留实际路径身份；确认时重新核验文件。空目录及不可访问或不存在的路径在选择器内反馈，保留继续导航与取消入口。取消按钮或 ESC 只结束选择器，不提交文件；调用方原有状态保持。模态期间后台不接受指针、键盘与文本输入，返回沿共同焦点范围合同处理。

目录读取不阻塞宿主输入与呈现；请求、结果和工作归当前选择器生命周期，导航、取消或卸载后迟到结果不覆盖当前目录或恢复已结束界面。工作队列、目录结果存储及挂载行有明确上限，大目录分批浏览。导航、重新打开及显式刷新重新读取文件事实，不依赖每帧重扫；主题、字体与窗口空间变化沿正式控件和布局更新。

验收使用实际目录和正式输入路径，覆盖目录与上级导航、分页、刷新、任意扩展名文件确认、路径错误、取消及 ESC、模态隔离、窗口变化与释放。平台专项运行结论仍按实际宿主分别记录。
