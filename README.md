# Qz-UILib

一个现代化的UI组件库，专为构建美观、响应式的用户界面而设计。采用扁平化设计语言，支持圆角、渐变等现代视觉效果。

## ✨ 核心特性

### 🎯 现代化设计
- **扁平化设计语言** - 符合当代UI设计趋势
- **丰富的视觉效果** - 支持圆角、渐变、阴影等
- **事件驱动架构** - 基于现代化的组件交互模式
- **层级管理系统** - 提供灵活的UI组件组织方式

### 🔄 重构进展
> 🚧 项目目前处于积极重构阶段
- 正在迁移至**事件驱动模式** + **层级模式**
- 旨在提供更现代化、易用的设计模式
- 提升组件的可维护性和扩展性

## 🖋️ 增强的字体系统

引入革命性的平滑字体渲染技术，提供卓越的文本显示体验：

| 特性 | 说明 |
|------|------|
| **高清平滑渲染** | 字体显示更加清晰锐利 |
| **全Unicode支持** | 完整支持多语言和特殊字符 |
| **优化可读性** | 专为现代高分辨率显示器优化 |

## 🏗️ 智能布局系统

借鉴QT设计理念，提供强大的自动布局能力：

### 布局器类型
- **居中布局器** - 智能中心对齐
- **垂直布局器** - 灵活的垂直排列
- **水平布局器** - 高效的水平排列

### 响应式优势
- 🔄 **自动适应** - 根据容器大小智能调整
- 📱 **多设备兼容** - 完美适配不同屏幕尺寸
- 🎨 **直观配置** - 简化的布局参数设置

## 📦 组件生态系统

### 基础组件库（当前版本）
- **标签 (Label)** - 文本显示组件
- **按钮 (Button)** - 交互式按钮
- **文本按钮 (TextButton)** - 简约风格按钮
- **列表 (List)** - 数据列表展示
- **滑动条 (Slider)** - 范围选择控件
- **输入框 (Input)** - 文本输入控件

### 组件特性
- 🎨 **高度可定制** - 丰富的样式配置选项
- ⚡ **性能优化** - 高效的渲染和事件处理
